O Obsidian utiliza ficheiros Markdown `.md` como formato principal para notas. Isto torna fácil importar ficheiros Markdown para o Obsidian. Muitas aplicações podem editar ficheiros Markdown ou exportar para este formato.

Existem várias formas de adicionar ficheiros Markdown ao seu cofre do Obsidian:

1. Arrastar e largar ficheiros ou pastas na janela do [[Explorador de ficheiros]]
2. Utilizar o explorador de ficheiros do sistema (por exemplo, o Explorador do Windows ou o Finder no macOS) e mover os ficheiros diretamente para a pasta do cofre do Obsidian.

## Importar ficheiros Markdown com o Importer

Utilize o [[Importador|plugin Importer]] oficial quando quiser selecionar pastas dentro de uma importação, importar um ficheiro `.zip`, padronizar a formatação, mover etiquetas em linha para [[Propriedades|propriedades]] ou aplicar um modelo.

1. Abra **[[Definições|Definições]] → Plugins da comunidade** e [instale o Importer](obsidian://show-plugin?id=obsidian-importer).
2. Ative o plugin Importer.
3. Abra o **Importer** utilizando a [[Paleta de comando|paleta de comandos]] ou o ícone na barra de ferramentas.
4. Em **File format**, selecione **Markdown (.md, .zip)**.
5. Escolha ficheiros Markdown individuais, pastas ou ficheiros zip.
6. Reveja as pastas detetadas, as opções de saída, o modelo gerado e os exemplos de pré-visualização.
7. Selecione **Import** e aguarde que a importação termine.

Consulte [[Modelos do Importador]] para personalizar o nome da nota importada, as propriedades e o conteúdo.
