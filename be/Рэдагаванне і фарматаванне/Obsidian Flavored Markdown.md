Obsidian імкнецца да максімальных магчымасцей, не парушаючы існуючыя фарматы. Таму мы выкарыстоўваем спалучэнне розных варыянтаў [[Асноўны сінтаксіс фарматавання|Markdown]].

Obsidian падтрымлівае [CommonMark](https://commonmark.org/), [GitHub Flavored Markdown](https://github.github.com/gfm/) і [LaTeX](https://www.latex-project.org/).

> [!tip]- Markdown унутры HTML
> Obsidian не апрацоўвае сінтаксіс Markdown унутры HTML-элементаў. Гэта свядомае рашэнне дзеля хуткасці і каб не ўскладняць парсер пры працы з вялікімі дакументамі.
>
> Напрыклад, фарматаванне Markdown накшталт `**тлусты**` або `` `код` `` не будзе апрацоўвацца ўнутры `<div>`, `<span>`, `<table>` або любых іншых HTML-тэгаў.
>
> ```md
> <div>
> Гэта **не будзе** тлустым.
> </div>
> ```

### Падтрымліваемыя пашырэнні Markdown

| Сінтаксіс       | Апісанне                                                              |
| --------------- | --------------------------------------------------------------------- |
| `[[Link]]`      | [[Унутраныя спасылкі\|Унутраныя спасылкі]]                                |
| `![[Link]]`     | [[Убудаванне файлаў\|Убудаванне файлаў]]                                    |
| `![[Link#^id]]` | [[Унутраныя спасылкі#Спасылка на блок у нататцы\|Спасылкі на блокі]]       |
| `^id`           | [[Унутраныя спасылкі#Спасылка на блок у нататцы\|Вызначэнне блока]]        |
| `[^id]`         | [[Асноўны сінтаксіс фарматавання#Зноскі\|Зноскі]]                         |
| `%%Text%%`      | [[Асноўны сінтаксіс фарматавання#Каментарыі\|Каментарыі]]                      |
| `~~Text~~`      | [[Асноўны сінтаксіс фарматавання#Тлусты, курсіў, вылучэнне\|Закрэсліванне]]  |
| `==Text==`      | [[Асноўны сінтаксіс фарматавання#Тлусты, курсіў, вылучэнне\|Вылучэнне]]      |
| `` ``` ``       | [[Асноўны сінтаксіс фарматавання#Блокі кода\|Блокі кода]]                   |
| `- [ ]`         | [[Асноўны сінтаксіс фарматавання#Спісы задач\|Незавершаная задача]]           |
| `- [x]`         | [[Асноўны сінтаксіс фарматавання#Спісы задач\|Выкананая задача]]              |
| `> [!note]`     | [[Вынаскі\|Вынаскі]]                                                 |
| (гл. спасылку)  | [[Пашыраны сінтаксіс фарматавання#Табліцы\|Табліцы]]                        |

Некаторыя з іх, напрыклад унутраныя спасылкі, каментарыі і вылучэнне, — асаблівасці Obsidian. Іншыя праграмы для Markdown могуць паказваць іх як звычайны тэкст.
