На гэтай старонцы пералічаны прадвызначаныя спалучэнні клавіш для навігацыі і рэдагавання тэксту ў Obsidian. Гэтыя спалучэнні забяспечвае аперацыйная сістэма або фрэймворк, на якім пабудаваны Obsidian, і змяніць іх у Obsidian нельга.

Пра спалучэнні клавіш для каманд Obsidian, якія можна наладзіць, глядзіце [[Гарачыя клавішы]].

## Спалучэнні клавіш для Windows і Linux

### Агульныя дзеянні

| Дзеянне | Спалучэнне |
|-|-|
| Скапіяваць | `Ctrl+C` |
| Выразаць | `Ctrl+X` |
| Уставіць | `Ctrl+V` |
| Уставіць без фарматавання | `Ctrl+Shift+V` |
| Адрабіць | `Ctrl+Z` |
| Паўтарыць | `Ctrl+Shift+Z` або `Ctrl+Y` |
| Скапіяваць абзац | `Ctrl+C` (без вылучанага тэксту) |
| Выразаць абзац | `Ctrl+X` (без вылучанага тэксту) |

### Рэдагаванне тэксту

| Дзеянне | Спалучэнне |
|-|-|
| Уставіць новы радок| `Enter` |
| Выдаліць папярэдні сімвал | `Backspace` |
| Выдаліць наступны сімвал | `Delete` |
| Выдаліць папярэдняе слова | `Ctrl+Backspace` |
| Выдаліць наступнае слова | `Ctrl+Delete` |
| Выдаліць бягучы радок | `Ctrl+Shift+K` (без вылучанага тэксту) |

### Навігацыя па тэксце

| Дзеянне | Спалучэнне |
|-|-|
| Перамясціць курсор на адзін сімвал | `Left/→` |
| Перамясціць курсор у пачатак папярэдняга слова | `Ctrl+←` |
| Перамясціць курсор у канец наступнага слова | `Ctrl+→` |
| Перамясціць курсор у пачатак бягучага радка | `Home` |
| Перамясціць курсор у канец бягучага радка | `End` |
| Перамясціць курсор на папярэдні радок | `↑` |
| Перамясціць курсор на наступны радок | `↓` |
| Перамясціць курсор у пачатак нататкі | `Ctrl+Home` |
| Перамясціць курсор у канец нататкі | `Ctrl+End` |
| Перамясціць курсор на старонку ўверх | `Page up` |
| Перамясціць курсор на старонку ўніз | `Page down` |

### Вылучэнне тэксту

| Дзеянне | Спалучэнне |
|-|-|
| Спрасціць вылучэнне | `Escape` |
| Вылучыць усё | `Ctrl+A` |
| Пашырыць вылучэнне на адзін сімвал | `Shift+Left/→` |
| Пашырыць вылучэнне да пачатку папярэдняга слова | `Ctrl+Shift+←` |
| Пашырыць вылучэнне да канца наступнага слова | `Ctrl+Shift+→` |
| Пашырыць вылучэнне да пачатку бягучага радка | `Shift+Home` |
| Пашырыць вылучэнне да канца бягучага радка | `Shift+End` |
| Пашырыць вылучэнне да пачатку нататкі | `Ctrl+Shift+Home` |
| Пашырыць вылучэнне да канца нататкі | `Ctrl+Shift+End` |
| Пашырыць вылучэнне на старонку ўверх | `Shift+Page up` |
| Пашырыць вылучэнне на старонку ўніз | `Shift+Page down` |

### Фарматаванне тэксту

| Дзеянне | Спалучэнне |
| ---- | ---- |
| Тлусты тэкст | `Cmd+B` |
