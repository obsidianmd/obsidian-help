Вынаскі дазваляюць дадаваць у нататкі дадатковае змесціва, не парушаючы асноўны тэкст.

Каб стварыць вынаску, дадайце `[!info]` у першы радок цытаты, дзе `info` — _ідэнтыфікатар тыпу_. Ідэнтыфікатар тыпу вызначае выгляд вынаскі. Усе даступныя тыпы пералічаны ў раздзеле [[#Падтрымліваемыя тыпы]]. Вынаскі таксама падтрымліваюцца на [[Уводзіны ў Obsidian Publish|Obsidian Publish]].

```markdown
> [!info] Загаловак вынаскі
> Гэта блок вынаскі.
> Ён падтрымлівае **Markdown**, [[Internal link|Wiki-спасылкі]] і [[Убудаванне файлаў|убудаванне]]!
> ![[Engelbart.jpg]]
```

> [!info] Загаловак вынаскі
> Гэта блок вынаскі.
> Ён падтрымлівае **Markdown**, [[Унутраныя спасылкі|Wiki-спасылкі]] і [[Убудаванне файлаў|убудаванне]]!
> ![[Engelbart.jpg]]

Прадвызначаную вынаску `[!note]` можна ўставіць [[Меню каманд|камандай]] `Уставіць вынаску`. Курсор аўтаматычна апынецца ў полі назвы вынаскі: можна выдаліць прадвызначаную назву і ўвесці новую, а потым рэдагаваць змесціва.

Каб змясціць існуючае змесціва ў вынаску, вылучыце тэкст (у тым ліку спісы, блокі кода і г. д.) і выканайце каманду `Уставіць вынаску`. Вылучанае змесціва аўтаматычна апынецца ўнутры вынаскі.

У [[Рэжымы прагляду і рэдагавання#Дынамічны прагляд|Дынамічным праглядзе]] тып вынаскі можна змяніць, пстрыкнуўшы правай кнопкай мышы па яе назве.


### Змена загалоўка

Па змаўчанні загаловак вынаскі — гэта яе ідэнтыфікатар тыпу з вялікай літары. Каб змяніць яго, дадайце тэкст пасля ідэнтыфікатара тыпу:

```markdown
> [!tip] Вынаскі могуць мець уласныя загалоўкі
> Як гэтая.
```

> [!tip] Вынаскі могуць мець уласныя загалоўкі
> Як гэтая.

Можна нават прапусціць асноўны тэкст і стварыць вынаску толькі з загалоўкам:

```markdown
> [!tip] Вынаска толькі з загалоўкам
```

> [!tip] Вынаска толькі з загалоўкам

### Згортвальныя вынаскі

Каб вынаску можна было згортваць, дадайце плюс (`+`) або мінус (`-`) адразу пасля ідэнтыфікатара тыпу.

Плюс робіць вынаску разгорнутай па змаўчанні, а мінус — згорнутай.

```markdown
> [!faq]- Ці можна згортваць вынаскі?
> Так! У згорнутай вынасцы змесціва схавана.
```

> [!faq]- Ці можна згортваць вынаскі?
> Так! У згорнутай вынасцы змесціва схавана.

### Укладзеныя вынаскі

Вынаскі можна ўкладаць адна ў адну на некалькі ўзроўняў.

```markdown
> [!question] Ці можна ўкладаць вынаскі?
> > [!todo] Так, можна.
> > > [!example]  Можна нават рабіць некалькі ўзроўняў укладзенасці.
```

> [!question] Ці можна ўкладаць вынаскі?
> > [!todo] Так, можна.
> > > [!example]  Можна нават рабіць некалькі ўзроўняў укладзенасці.

### Уласныя вынаскі

[[CSS-сніпеты|CSS-сніпеты]] і [[Плагіны супольнасці|плагіны супольнасці]] могуць ствараць уласныя вынаскі і нават перавызначаць прадвызначаныя.

Каб стварыць уласную вынаску, дадайце наступны блок CSS:

```css
.callout[data-callout="custom-question-type"] {
    --callout-color: #000000;
    --callout-icon: lucide-alert-circle;
}
```

Значэнне атрыбута `data-callout` — гэта ідэнтыфікатар тыпу, які вы хочаце выкарыстоўваць, напрыклад `[!custom-question-type]`.

- `--callout-color` задае колер фону. Падыходзіць любы дапушчальны колер CSS, напрыклад шаснаццатковы код (`#000000`) або значэнне `rgb()`.
- `--callout-icon` можа быць ідэнтыфікатарам значка з [lucide.dev](https://lucide.dev) або элементам SVG.

> [!warning] Пра версіі значкоў Lucide
> Obsidian перыядычна абнаўляе значкі Lucide. Бягучая ўключаная версія паказана ніжэй — выкарыстоўвайце ва ўласных вынасках значкі з гэтай або ранейшых версій.
> ![[Падзякі#^lucide]]

> [!tip] Значкі SVG
> Замест значка Lucide для вынаскі можна выкарыстаць элемент SVG.
>
> ```css
> --callout-icon: '<svg>...уласны svg...</svg>';
> ```

> [!tip]- Дадатковае наладжванне
> Магчымасці не абмяжоўваюцца `--callout-color` і `--callout-icon`. Вынаскі падтрымліваюць стандартныя селектары і ўласцівасці CSS, а таксама дадатковыя зменныя CSS, напрыклад для мяжы і стылю загалоўка.
> 
> Напрыклад, каб схаваць загаловак вынаскі:
> 
> ```css
> .callout[data-callout="custom-question-type"] .callout-title {
>     display: none;
> }
> ```
> 
> Або каб змяніць яе мяжу:
> 
> ```css
> .callout[data-callout="custom-question-type"] {
>     --callout-border-width: 2px;
>     --callout-border-opacity: 0.25;
> }
> ```
> 
> Іншыя магчымасці — у поўным спісе [зменных CSS для вынасак](https://docs.obsidian.md/Reference/CSS+variables/Editor/Callout).

### Падтрымліваемыя тыпы

Можна выкарыстоўваць некалькі тыпаў вынасак і іх псеўданімы. Кожны тып мае свой колер фону і значок.

Каб выкарыстаць гэтыя прадвызначаныя стылі, заменіце `info` у прыкладах на любы з гэтых тыпаў, напрыклад `[!tip]` або `[!warning]`. Тып вынаскі можна таксама змяніць, пстрыкнуўшы па ёй правай кнопкай мышы ў Дынамічным праглядзе.

Калі вы не [[#Уласныя вынаскі|стварылі ўласную вынаску]], любы непадтрымліваемы тып паказваецца як тып `note`. Ідэнтыфікатар тыпу не адрознівае рэгістр.

> [!note]
> ```md
> > [!note]
> > Lorem ipsum dolor sit amet
> ```

---

> [!abstract]-
> ```md
> > [!abstract]
> > Lorem ipsum dolor sit amet
> ```

Псеўданімы: `summary`, `tldr`

> [!info]-
> ```md
> > [!info]

> ```

> [!todo]-

> ```

> > Lorem ipsum dolor sit amet
> ```

Псеўданімы: `hint`, `important`

> ```

---

> ```
