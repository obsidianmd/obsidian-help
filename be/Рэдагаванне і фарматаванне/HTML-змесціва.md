Obsidian падтрымлівае HTML, каб вы маглі паказваць нататкі так, як хочаце, і нават [[Убудаванне вэб-старонак|ўбудоўваць вэб-старонкі]]. Аднак HTML у нататках нясе рызыкі. Каб шкоднасны код не нанёс шкоды, Obsidian _ачышчае_ любы HTML у нататках.

> [!example] 
> Элемент `<script>` звычайна дазваляе выконваць JavaScript пры загрузцы. Калі б Obsidian не ачышчаў HTML, зламыснік мог бы ўгаварыць вас уставіць тэкст з JavaScript, які выцягвае канфідэнцыйныя звесткі з вашага камп'ютара і адпраўляе іх яму.

Разам з тым сінтаксіс Markdown падтрымлівае не ўсе віды афармлення, таму ачышчаны HTML — яшчэ адзін спосаб палепшыць нататкі. Ніжэй сабраны некаторыя распаўсюджаныя спосабы выкарыстання HTML.

## Абмежаванні HTML

У Obsidian ёсць пэўныя абмежаванні пры выкарыстанні HTML у нататках:

### Без Markdown унутры HTML

Obsidian не апрацоўвае сінтаксіс Markdown унутры HTML-элементаў. Гэта свядомае рашэнне дзеля хуткасці і каб не ўскладняць парсер пры працы з вялікімі дакументамі.

Напрыклад, гэта не будзе працаваць так, як чакаецца:

```md
<div>
Гэта **не будзе** тлустым, а гэта `не будзе` кодам.
</div>
```

### Блокі HTML павінны быць цэласнымі

Блокі HTML павінны быць завершанымі і не могуць змяшчаць пустых радкоў. Пусты радок разрывае блок HTML.

Так будзе працаваць:

```md
<table>
<tr>
<td>Змесціва</td>
</tr>
</table>
```

А так — не:

```md
<table>

<tr>

<td>Змесціва</td>

</tr>

</table>
```

### Калі здаецца, што Markdown працуе ў HTML

Некаторыя ўбудаваныя HTML-тэгі, напрыклад `<span>` або `<a>`, маюць абмежаваную функцыянальнасць, і можа здацца, што яны апрацоўваюць Markdown. Але насамрэч Markdown апрацоўваецца па-за кантэкстам HTML.

Падрабязней пра тое, як Obsidian апрацоўвае Markdown, — у раздзеле [[Obsidian Flavored Markdown]].

## Распаўсюджаныя спосабы выкарыстання HTML

> [!info] Падрабязней пра `<iframe>` — у раздзеле [[Убудаванне вэб-старонак]].

### Каментарыі

Для схаваных каментарыяў у нататках лепш выкарыстоўваць [[Асноўны сінтаксіс фарматавання#Каментарыі|каментарыі Markdown]]. Аднак некаторыя спосабы канвертавання нататак Markdown, напрыклад [Pandoc](https://pandoc.org), абмежавана падтрымліваюць каментарыі Markdown. У такіх выпадках можна выкарыстаць `<!-- HTML-каментарый -->`!

### Падкрэсліванне

Каб хутка падкрэсліць нешта ў нататцы, выкарыстоўвайце `<u>Прыклад</u>` — атрымаецца <u>падкрэслены тэкст</u>.

### Span/Div

Тэгі span і div дазваляюць прымяняць да фрагмента тэксту ўласныя класы з [[CSS-сніпеты|CSS-сніпета]] або ўласныя стылі. Напрыклад, `<span style="font-family: cursive">ваш тэкст</span>` дазваляе хутка <span style="font-family: cursive">змяніць шрыфт</span>.

## Закрэсліванне

Трэба закрэсліць <s>частку тэксту</s>? Выкарыстоўвайце `<s>вось так</s>`.
