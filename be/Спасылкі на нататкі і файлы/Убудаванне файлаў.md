Убудаваныя файлы паказваюць сваё змесціва непасрэдна ў нататцы і абнаўляюцца, калі змяняецца зыходны файл.

Каб убудаваць файл са сховішча, пастаўце клічнік (`!`) перад [[Унутраныя спасылкі|унутранай спасылкай]]. Убудоўваць можна файлы любога з [[Падтрымліваемыя фарматы файлаў|падтрымліваемых фарматаў]].

> [!tip]- Убудаванне перацягваннем
> На камп'ютары падтрымліваемыя файлы можна проста перацягнуць у нататку — яны ўбудуюцца аўтаматычна.

## Убудаванне нататкі ў іншую нататку

Каб убудаваць нататку:

```md
![[Унутраныя спасылкі]]
```

Таксама можна ўбудоўваць асобныя [[Унутраныя спасылкі#Спасылка на загаловак у нататцы|загалоўкі]] і [[Унутраныя спасылкі#Спасылка на блок у нататцы|блокі]].

```md
![[Унутраныя спасылкі#^b15695]]
```

Ніжэй паказаны прыклад убудаванага блока:

![[Унутраныя спасылкі#^b15695]]

## Убудаванне відарыса ў нататку

Каб убудаваць відарыс:

```md
![[Engelbart.jpg]]
```

![[Engelbart.jpg#outline]]

Каб змяніць памеры відарыса, дадайце да адраса спасылкі `|640x480`, дзе 640 — шырыня, а 480 — вышыня.

```md
![[Engelbart.jpg|100x145]]
```

Калі ўказаць толькі шырыню, відарыс маштабуецца прапарцыйна. Напрыклад, `![[Engelbart.jpg|100]]`.

![[Engelbart.jpg#outline|100]]

Таксама можна ўбудаваць відарыс з іншага сайта з дапамогай спасылкі Markdown. Шырыню і вышыню можна задаць тым жа сінтаксісам, што і для Wiki-спасылкі.

```md
![250](https://publish-01.obsidian.md/access/f786db9fac45774fa4f0d8112e232d67/Attachments/Engelbart.jpg)
```

![250](https://publish-01.obsidian.md/access/f786db9fac45774fa4f0d8112e232d67/Attachments/Engelbart.jpg)

## Убудаванне PDF у нататку

Каб убудаваць PDF:

```md
![[Дакумент.pdf]]
```

Каб адкрыць пэўную старонку PDF, дадайце да адраса спасылкі `#page=N`, дзе `N` — нумар старонкі:

```md
![[Дакумент.pdf#page=3]]
```

Таксама можна задаць вышыню ўбудаванага праглядальніка PDF у пікселях, дадаўшы да спасылкі `#height=[лік]`. Напрыклад:

```md
![[Дакумент.pdf#height=400]]
```

Каб спалучыць параметры старонкі і вышыні, раздзяліце іх знакам `&`:

```md
![[Дакумент.pdf#page=3&height=400]]
```

Падрабязней пра прагляд і пошук у PDF — на старонцы [[PDF-файлы]].

## Убудаванне палатна ў нататку

Каб убудаваць [[Палатно|палатно]]:

```md
![[Маё палатно.canvas]]
```

> [!info]+ Убудаванае палатно паказвае толькі фігуры
> Убудаванае палатно паказвае фігуры, але не тэкст унутры картак. Каб убачыць палатно цалкам, адкрыйце яго непасрэдна.

## Убудаванне спіса ў нататку

Каб убудаваць спіс з іншай нататкі, спачатку дадайце да спіса [[Унутраныя спасылкі#Спасылка на блок у нататцы|ідэнтыфікатар блока]]:

```md

- элемент спіса 1
- элемент спіса 2

^my-list-id
```

Потым спашліцеся на спіс праз ідэнтыфікатар блока:

```md
![[Мая нататка#^my-list-id]]
```
