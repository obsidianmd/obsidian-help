Сайты [[Уводзіны ў Obsidian Publish|Obsidian Publish]] аўтаматычна аптымізаваны для пошукавых сістэм і [[Перадпрагляд спасылак у сацсетках|картак перадпрагляду ў сацсетках]]. Таксама можна наладжваць метаданыя старонак: апісанні, пастаянныя спасылкі і відарысы.

Звярніце ўвагу: індэксацыю пошукавымі сістэмамі можна забараніць у [[Кіраванне сайтамі#Налады сайта|наладах сайта]].

### Google Search Console

Каб сачыць за SEO у Google, зарэгіструйце сайт у [Google Search Console](https://search.google.com/search-console). Таксама можна выканаць нашы рэкамендаваныя крокі, каб [[Аналітыка|наладзіць Google Analytics]].

### Карта сайта

Карта сайта Publish даступная па адрасе `/sitemap.xml`, напрыклад:
https://help.obsidian.md/sitemap.xml

Карта сайта таксама даступная як RSS-канал па адрасе `/rss.xml`:
https://help.obsidian.md/rss.xml

### Пастаянныя спасылкі

Выкарыстоўвайце [[Пастаянныя спасылкі|пастаянныя спасылкі]], каб задаваць на сайце пастаянныя URL.

### Метаданыя

Метаданыя старонак можна наладжваць з дапамогай [[Уласцівасці#Уласцівасці для Obsidian Publish|уласцівасцяў]], што карысна для [[Перадпрагляд спасылак у сацсетках|картак перадпрагляду ў сацсетках]].

| Уласцівасць   | Апісанне                                                                                                          |
| ------------- | ----------------------------------------------------------------------------------------------------------------- |
| `publish`     | Глядзіце [[Публікацыя змесціва#Аўтаматычны выбар даных для публікацыі\|Аўтаматычны выбар даных для публікацыі]]. |
| `permalink`   | Глядзіце [[Пастаянныя спасылкі\|Пастаянныя спасылкі]].                                                                     |
| `description` | Глядзіце [[Перадпрагляд спасылак у сацсетках#Апісанне\|Апісанне]].                                                    |
| `image`       | Глядзіце [[Перадпрагляд спасылак у сацсетках#Відарыс\|Відарыс]].                                                           |
| `cover`       | Глядзіце [[Перадпрагляд спасылак у сацсетках#Відарыс\|Відарыс]].                                                           |
