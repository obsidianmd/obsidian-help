[[Уводзіны ў Obsidian Sync|Obsidian Sync]] мае кліент без графічнага інтэрфейсу для сінхранізацыі сховішчаў без настольнай праграмы. Ён карысны для канвеераў CI, агентаў і аўтаматызаваных працэсаў. Можна сінхранізаваць апошнія змены або пастаянна падтрымліваць файлы ў актуальным стане.

Усталюйце [[Obsidian Headless]] **(адкрытая бэта-версія)**, каб працаваць з [[Уводзіны ў Obsidian Sync|Obsidian Sync]] з каманднага радка без настольнай праграмы Obsidian. Headless Sync выкарыстоўвае тую ж [[Obsidian Sync/Бяспека і прыватнасць|абарону шыфраваннем і прыватнасць]], што і настольная праграма, у тым ліку скразное шыфраванне.

## Хуткі старт

> [!error] Перш чым пачаць, зрабіце рэзервовую копію даных
> 1. Заўсёды рабіце рэзервовую копію даных перад пачаткам на выпадак, калі нешта пойдзе не так.
> 2. Не выкарыстоўвайце на адной прыладзе *адначасова* Sync у настольнай праграме і Headless Sync — гэта можа выклікаць канфлікты даных. Выкарыстоўвайце на кожнай прыладзе толькі адзін спосаб сінхранізацыі.

Усталюйце [[Obsidian Headless|Obsidian Headless]] **(адкрытая бэта-версія)**:

```shell
npm install -g obsidian-headless
```

Патрэбна актыўная [[Тарыфы і ліміты сховішча|падпіска на Obsidian Sync]].

```shell
# Уваход
ob login

# Спіс аддаленых сховішчаў
ob sync-list-remote

# Наладжванне сховішча для сінхранізацыі
cd ~/vaults/my-vault
ob sync-setup --vault "My Vault"

# Аднаразовая сінхранізацыя
ob sync

# Бесперапынная сінхранізацыя (сочыць за зменамі)
ob sync --continuous
```

## Каманды

### `ob sync-list-remote`

Паказвае ўсе аддаленыя сховішчы, даступныя вашаму ўліковаму запісу, у тым ліку агульныя.

### `ob sync-list-local`

Паказвае лакальна наладжаныя сховішчы і шляхі да іх.

### `ob sync-create-remote`

Стварае новае аддаленае сховішча.

```
ob sync-create-remote --name "Vault Name" [--encryption <standard|e2ee>] [--password <password>] [--region <region>]
```

| Параметр | Апісанне |
| --- | --- |
| `--name` | Назва сховішча (абавязкова) |
| `--encryption` | `standard` — шыфраванне, якім кіруе Obsidian, `e2ee` — скразное шыфраванне |
| `--password` | Пароль скразнога шыфравання (калі не ўказаць, будзе запытаны) |
| `--region` | [[Рэгіёны сінхранізацыі\|Рэгіён]] сервера (калі не ўказаць, выбіраецца аўтаматычна) |

### `ob sync-setup`

Наладжвае сінхранізацыю паміж лакальным і аддаленым сховішчам.

```
ob sync-setup --vault <id-or-name> [--path <local-path>] [--password <password>] [--device-name <name>] [--config-dir <name>]
```

| Параметр | Апісанне |
| --- | --- |
| `--vault` | Ідэнтыфікатар або назва аддаленага сховішча (абавязкова) |
| `--path` | Лакальны каталог (па змаўчанні — бягучы каталог) |
| `--password` | Пароль скразнога шыфравання (калі не ўказаць, будзе запытаны) |
| `--device-name` | Назва прылады, якая паказваецца ў [[Гісторыя змен\|гісторыі змен сінхранізацыі]] |
| `--config-dir` | Назва [[Папка канфігурацыі\|папкі канфігурацыі]] (па змаўчанні `.obsidian`) |

### `ob sync`

Запускае сінхранізацыю наладжанага сховішча.

```
ob sync [--path <local-path>] [--continuous]
```

| Параметр | Апісанне |
| --- | --- |
| `--path` | Шлях да лакальнага сховішча (па змаўчанні — бягучы каталог) |
| `--continuous` | Працаваць бесперапынна, сочачы за зменамі |

### `ob sync-config`

Праглядае або змяняе [[Налады Sync і выбарачная сінхранізацыя|налады сінхранізацыі]] сховішча. Без параметраў паказвае бягучую канфігурацыю.

```
ob sync-config [--path <local-path>] [options]
```

| Параметр              | Апісанне                                                                                                                                                                                                       |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--path`              | Шлях да лакальнага сховішча (па змаўчанні — бягучы каталог)                                                                                                                                                    |
| `--mode`              | Рэжым сінхранізацыі: `bidirectional` (па змаўчанні), `pull-only` (толькі спампоўка, лакальныя змены ігнаруюцца) або `mirror-remote` (толькі спампоўка, лакальныя змены адкочваюцца)                            |
| `--conflict-strategy` | `merge` або `conflict`                                                                                                                                                                                         |
| `--file-types`        | Тыпы далучэнняў для сінхранізацыі: `image`, `audio`, `video`, `pdf`, `unsupported` (праз коску; пуста — ачысціць)                                                                                              |
| `--configs`           | Катэгорыі канфігурацыі для сінхранізацыі: `app`, `appearance`, `appearance-data`, `hotkey`, `core-plugin`, `core-plugin-data`, `community-plugin`, `community-plugin-data` (праз коску; пуста — адключыць сінхранізацыю канфігурацыі) |
| `--excluded-folders`  | Папкі для выключэння (праз коску; пуста — ачысціць)                                                                                                                                                            |
| `--device-name`       | Назва прылады для ідэнтыфікацыі гэтага кліента ў гісторыі змен сінхранізацыі                                                                                                                                   |
| `--config-dir`        | Назва папкі канфігурацыі (па змаўчанні `.obsidian`)                                                                                                                                                            |

### `ob sync-status`

Паказвае стан сінхранізацыі і канфігурацыю сховішча.

```
ob sync-status [--path <local-path>]
```

### `ob sync-unlink`

Адключае сховішча ад сінхранізацыі і выдаляе захаваныя ўліковыя даныя.

```
ob sync-unlink [--path <local-path>]
```

## Убудаваныя модулі

Obsidian Headless уключае загадзя сабраны ўбудаваны модуль для задання часу стварэння файла (birthtime) на Windows і macOS. Ён захоўвае зыходныя пазнакі часу стварэння пры спампоўцы файлаў з сервера.

Модуль выкарыстоўвае N-API версіі 3, таму скампіляваныя файлы маюць стабільны ABI і працуюць з рознымі версіямі Node.js без перакампіляцыі.

На Linux birthtime не падтрымліваецца — модуль туды не ўключаны, і сінхранізацыя працуе без яго.

Загадзя сабраныя файлы ўключаны для:

- `win32-x64`
- `win32-arm64`
- `win32-ia32`
- `darwin-x64`
- `darwin-arm64`
