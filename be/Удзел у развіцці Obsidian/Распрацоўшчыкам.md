Калі вы распрацоўшчык, вы можаце рабіць свой унёсак у Obsidian рознымі спосабамі.

### Плагіны і тэмы

Вы можаце распрацоўваць [[Плагіны супольнасці|плагіны супольнасці]] і [[Тэмы|тэмы]] на TypeScript і CSS. Падрабязней глядзіце ў [дакументацыі для распрацоўшчыкаў Obsidian](https://docs.obsidian.md).

### Праекты з адкрытым кодам

Obsidian распрацоўвае і падтрымлівае некалькі праектаў з адкрытым кодам. Вы можаце адпраўляць pull request'ы з выпраўленнямі памылак і паляпшэннямі ў наступныя рэпазіторыі GitHub:

- [Pele](https://github.com/obsidianmd/pele) (MIT) — рэндэрар, якім Obsidian малюе дыяграмы Mermaid.
- [JSON Canvas](https://github.com/obsidianmd/jsoncanvas) (MIT) — адкрыты фармат файлаў для даных бясконцага палатна.
- [Knap](https://github.com/obsidianmd/knap) (MIT) — мова шаблонаў для генерацыі Markdown.
- [Obsidian Importer](https://github.com/obsidianmd/obsidian-importer) (MIT) — плагін, які пераўтварае даныя з мноства фарматаў у звычайныя Markdown-файлы.
- [Obsidian Maps](https://github.com/obsidianmd/obsidian-maps) (MIT) — плагін, які паказвае карты ў Базах Obsidian.
- [Obsidian Web Clipper](https://github.com/obsidianmd/obsidian-clipper) (MIT) — пашырэнне для браўзера, каб вылучаць і захоўваць вэб-старонкі ў звычайныя Markdown-файлы.
- [Defuddle](https://github.com/kepano/defuddle) (MIT) — парсер HTML у Markdown, які выкарыстоўвае Obsidian Web Clipper.

### Дакументацыя

Каб дапамагчы палепшыць [дакументацыю для распрацоўшчыкаў](https://docs.obsidian.md/Home), адпраўце pull request у рэпазіторый [obsidian-developer-docs](https://github.com/obsidianmd/obsidian-developer-docs).

Каб дапамагчы палепшыць гэтую дакументацыю, адпраўце pull request у рэпазіторый [obsidian-help](https://github.com/obsidianmd/obsidian-help).

### Супольнасць

На нашым афіцыйным серверы Discord ёсць канал [plugin-dev](https://discord.com/channels/686053708261228577/840286264964022302), дзе можна абмяркоўваць распрацоўку плагінаў і дапамагаць іншым распрацоўшчыкам з іх плагінамі.
