Obsidian Headless **(адкрытае бэта-тэсціраванне)** — гэта headless-кліент для сэрвісаў Obsidian. Ён дазваляе [[Headless Sync|сінхранізаваць сховішчы]] з каманднага радка без праграмы для камп'ютара, захоўваючы ўсе перавагі [[Уводзіны ў Obsidian Sync|Obsidian Sync]]: хуткасць, прыватнасць і скразное шыфраванне.

Для чаго можа спатрэбіцца Obsidian Headless:

- Аўтаматызаваць аддаленае рэзервовае капіраванне.
- Аўтаматызаваць публікацыю сайта.
- Даць агентным інструментам доступ да сховішча без доступу да ўсяго камп'ютара.
- Сінхранізаваць агульнае сховішча каманды з серверам, які перадае даныя іншым інструментам.
- Запускаць аўтаматызацыі па раскладзе, напрыклад збіраць штодзённыя нататкі ў штотыднёвыя зводкі, аўтаматычна ставіць тэгі і г.д.

> [!info] Obsidian Headless і Obsidian CLI
> [[Obsidian CLI]] кіруе праграмай Obsidian для камп'ютара з тэрмінала. Obsidian Headless — гэта асобны кліент, які працуе самастойна, без праграмы для камп'ютара.

## Усталяванне

Для Obsidian Headless **(адкрытае бэта-тэсціраванне)** патрэбны Node.js 22 або навейшы. Усталюйце яго з [npm](https://www.npmjs.com/package/obsidian-headless):

```shell
npm install -g obsidian-headless
```

## Аўтэнтыфікацыя

### Уваход

```shell
ob login
```

Калі вы ўжо ўвайшлі, `ob login` паказвае звесткі пра ўліковы запіс. Каб змяніць уліковы запіс, перадайце `--email` і/або `--password`, каб увайсці зноў.

```
ob login [--email <email>] [--password <password>] [--mfa <code>]
```

Калі параметры не ўказаны, яны запытваюцца інтэрактыўна: праграма папросіць увесці электронную пошту і пароль, а код 2FA запытае аўтаматычна, калі двухфактарная аўтэнтыфікацыя ўключана для ўліковага запісу.

Каб выйсці і выдаліць захаваныя ўліковыя даныя:

```shell
ob logout
```
