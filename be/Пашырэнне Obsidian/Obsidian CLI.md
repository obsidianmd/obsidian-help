Obsidian CLI — гэта інтэрфейс каманднага радка, які дазваляе кіраваць Obsidian з тэрмінала для сцэнарыяў, аўтаматызацыі і інтэграцыі са знешнімі інструментамі.

Усё, што можна зрабіць у Obsidian, можна зрабіць і з каманднага радка. У Obsidian CLI ёсць нават [[#Каманды для распрацоўшчыкаў|каманды для распрацоўшчыкаў]], каб адкрываць інструменты распрацоўшчыка, правяраць элементы, рабіць здымкі экрана, перазагружаць плагіны і іншае.

> [!warning] Патрабуецца ўсталёўшчык Obsidian 1.12
> Для выкарыстання CLI патрэбны ўсталёўшчык Obsidian 1.12. Глядзіце [[Абнаўленне Obsidian#Абнаўленне ўсталёўшчыка|кіраўніцтва па абнаўленні версіі ўсталёўшчыка]].

## Усталяванне Obsidian CLI

Абнавіцеся да апошняй [[Абнаўленне Obsidian|версіі ўсталёўшчыка Obsidian]] (1.12.7+).

Уключыце Obsidian CLI ў Obsidian:

1. Перайдзіце ў **Налады** → **Асноўныя**.
2. Уключыце **Інтэрфейс каманднага радка**.
3. Выконвайце падказкі, каб зарэгістраваць Obsidian CLI.

Калі пры ўсталяванні Obsidian CLI ўзніклі праблемы, глядзіце [[#Вырашэнне праблем]].

## Пачатак працы

Obsidian CLI падтрымлівае як асобныя каманды, так і тэкставы інтэрфейс у тэрмінале (TUI) з інтэрактыўнай даведкай і аўтазапаўненнем.

> [!info] Праграма Obsidian павінна быць запушчана
> Для працы Obsidian CLI праграма Obsidian павінна быць запушчана. Калі Obsidian не запушчаны, першая выкананая каманда запусціць яго.
>
> Хочаце сінхранізаваць без праграмы для камп'ютара? Глядзіце [[Obsidian Headless|Obsidian Headless]].

### Выкананне каманды

Выканайце асобную каманду, не адкрываючы TUI:

```shell
# Выканаць каманду help
obsidian help
```

### Тэрмінальны інтэрфейс

Каб адкрыць TUI, увядзіце `obsidian`. Наступныя каманды можна ўводзіць без `obsidian`.

```shell
# Адкрыць TUI і выканаць help
obsidian
help
```

TUI падтрымлівае аўтазапаўненне, гісторыю каманд і зваротны пошук. Націсніце `Ctrl+R`, каб шукаць у гісторыі каманд. Усе даступныя спалучэнні глядзіце ў [[#Спалучэнні клавіш]].

## Прыклады

Вось некалькі прыкладаў таго, што ўмее Obsidian CLI.

### Штодзённае выкарыстанне

```shell
# Адкрыць сённяшнюю штодзённую нататку
obsidian daily

# Дадаць задачу ў штодзённую нататку
obsidian daily:append content="- [ ] Buy groceries"

# Пошук у сховішчы
obsidian search query="meeting notes"

# Прачытаць актыўны файл
obsidian read

# Паказаць усе задачы са штодзённай нататкі
obsidian tasks daily

# Стварыць новую нататку з шаблона
obsidian create name="Trip to Paris" template=Travel

# Паказаць усе тэгі ў сховішчы з колькасцю
obsidian tags counts

# Параўнаць дзве версіі файла
obsidian diff file=README from=1 to=3
```

### Для распрацоўшчыкаў

Для распрацоўкі плагінаў і тэм даступна шмат [[#Каманды для распрацоўшчыкаў|каманд для распрацоўшчыкаў]]. Яны дазваляюць агентным інструментам праграмавання аўтаматычна тэсціраваць і адладжваць код.

```shell
# Адкрыць інструменты распрацоўшчыка
obsidian devtools

# Перазагрузіць плагін супольнасці, які вы распрацоўваеце
obsidian plugin:reload id=my-plugin

# Зрабіць здымак экрана праграмы
obsidian dev:screenshot path=screenshot.png

# Выканаць JavaScript у кансолі праграмы
obsidian eval code="app.vault.getFiles().length"
```

## Як карыстацца

### Параметры і сцягі

Каманды могуць выкарыстоўваць **параметры** і **сцягі**. Большасці каманд не патрэбны ні параметры, ні сцягі. Абавязковыя параметры пазначаны як `required`. Напрыклад:

```shell
# Стварыць новую нататку з назвай па змаўчанні «Untitled»
obsidian create
```

**Параметр** прымае значэнне і запісваецца як `parameter=value`. Калі значэнне змяшчае прабелы, вазьміце яго ў двукоссі:

```shell
# Стварыць новую нататку «Note» са змесцівам «Hello world»
obsidian create name=Note content="Hello world"
```

**Сцяг** — гэта лагічны пераключальнік без значэння. Дадайце яго, каб уключыць; напрыклад, `open` і `overwrite` — сцягі:

```shell
# Стварыць нататку і адкрыць яе
obsidian create name=Note content="Hello" open overwrite
```

Для шматрадковага змесціва выкарыстоўвайце `\n` для новага радка і `\t` для табуляцыі.

```bash
obsidian create name=Note content="# Title\n\nBody text"
```

### Выбар сховішча

Калі бягучая працоўная папка тэрмінала — папка сховішча, па змаўчанні выкарыстоўваецца гэтае сховішча. Інакш выкарыстоўваецца актыўнае сховішча.

Каб выбраць пэўнае сховішча, выкарыстоўвайце `vault=<name>` або `vault=<id>`. Гэты параметр павінен ісці першым, перад камандай:

```shell
obsidian vault=Notes daily
obsidian vault="My Vault" search query="test"
```

У TUI выкарыстоўвайце `vault:open <name>` або `<id>`, каб пераключыцца на іншае сховішча.

### Выбар файла

Многія каманды прымаюць параметры `file` і `path`, каб выбраць пэўны файл. Калі ні адзін не ўказаны, каманда працуе з актыўным файлам.

- `file=<name>` знаходзіць файл гэтак жа, як [[Унутраныя спасылкі|wiki-спасылкі]]: па назве файла, без поўнага шляху і пашырэння.
- `path=<path>` патрабуе дакладнага шляху ад кораня сховішча, напрыклад `folder/note.md`.

```shell
# Гэтыя каманды раўназначныя, калі «Recipe.md» — адзіны файл з такой назвай
obsidian read file=Recipe
obsidian read path="Templates/Recipe.md"
```

### Капіяванне вываду

Дадайце `--copy` да любой каманды, каб скапіяваць вывад у буфер абмену:

```shell
read --copy
search query="TODO" --copy
```


## Агульныя каманды

### `help`

Паказвае спіс усіх даступных каманд.

| Параметр | Апісанне |
| ----------- | --------------------------------- |
| `<command>` | Паказаць даведку па пэўнай камандзе. |

### `version`

Паказвае версію Obsidian.

### `reload`

Перазагружае акно праграмы.

### `restart`

Перазапускае праграму.


## Базы

Каманды для [[Уводзіны ў Базы|Баз]].

### `bases`

Паказвае ўсе файлы `.base` у сховішчы.

### `base:views`

Паказвае прагляды ў бягучым файле базы.

### `base:create`

Стварае новы элемент у базе. Калі файл не ўказаны, выкарыстоўваецца актыўны прагляд базы.

```bash
file=<name>        # назва файла базы
path=<path>        # шлях да файла базы
view=<name>        # назва прагляду
name=<name>        # назва новага файла
content=<text>     # пачатковае змесціва

open               # адкрыць файл пасля стварэння
newtab             # адкрыць у новай укладцы
```

### `base:query`

Выконвае запыт да базы і вяртае вынікі.

```bash
file=<name>                    # назва файла базы
path=<path>                    # шлях да файла базы
view=<name>                    # назва прагляду для запыту
format=json|csv|tsv|md|paths   # фармат вываду (па змаўчанні: json)
```

## Закладкі

Каманды для [[Закладкі|закладак]].

### `bookmarks`

Паказвае закладкі.

```bash
total              # вярнуць колькасць закладак
verbose            # уключыць тыпы закладак
format=json|tsv|csv  # фармат вываду (па змаўчанні: tsv)
```

### `bookmark`

Дадае закладку.

```bash
file=<path>        # файл для закладкі
subpath=<subpath>  # падшлях (загаловак або блок) у файле
folder=<path>      # папка для закладкі
search=<query>     # пошукавы запыт для закладкі
url=<url>          # URL для закладкі
title=<title>      # назва закладкі
```

## Меню каманд

Каманды для [[Меню каманд|меню каманд]] і [[Гарачыя клавішы|гарачых клавіш]]. Уключае ўсе каманды, зарэгістраваныя плагінамі.

### `commands`

Паказвае ID даступных каманд.

```bash
filter=<prefix>    # фільтр па прэфіксе ID
```

### `command`

Выконвае каманду Obsidian.

```bash
id=<command-id>    # (абавязковы) ID каманды для выканання
```

### `hotkeys`

Паказвае гарачыя клавішы для ўсіх каманд.

```bash
total              # вярнуць колькасць гарачых клавіш
verbose            # паказаць, ці гарачая клавіша зменена карыстальнікам
format=json|tsv|csv  # фармат вываду (па змаўчанні: tsv)
```

### `hotkey`

Паказвае гарачую клавішу для каманды.

```bash
id=<command-id>    # (абавязковы) ID каманды

verbose            # паказаць, уласная ці па змаўчанні
```

## Штодзённыя нататкі

Каманды для [[Штодзённыя нататкі|штодзённых нататак]].

### `daily`

Адкрывае штодзённую нататку.

```bash
paneType=tab|split|window    # тып панэлі для адкрыцця
```

### `daily:path`

Паказвае шлях да штодзённай нататкі. Вяртае чаканы шлях, нават калі файл яшчэ не створаны.

### `daily:read`

Чытае змесціва штодзённай нататкі.

### `daily:append`

Дадае змесціва ў канец штодзённай нататкі.

```bash
content=<text>     # (абавязковы) змесціва для дадавання
heading=<name>     # мэтавы раздзел па загалоўку
paneType=tab|split|window    # тып панэлі для адкрыцця

inline             # дадаць без новага радка
open               # адкрыць файл пасля дадавання
```

### `daily:prepend`

Дадае змесціва ў пачатак штодзённай нататкі.

```bash
content=<text>     # (абавязковы) змесціва для дадавання
heading=<name>     # мэтавы раздзел па загалоўку
paneType=tab|split|window    # тып панэлі для адкрыцця

inline             # дадаць без новага радка
open               # адкрыць файл пасля дадавання
```

## Гісторыя файлаў

### `diff`

Паказвае або параўноўвае версіі з лакальнага [[Аднаўленне файлаў|аднаўлення файлаў]] і [[Уводзіны ў Obsidian Sync|Sync]]. Версіі нумаруюцца ад навейшай да старэйшай.

```bash
file=<name>          # назва файла
path=<path>          # шлях да файла
from=<n>             # нумар версіі, ад якой параўноўваць
to=<n>               # нумар версіі, з якой параўноўваць
filter=local|sync    # фільтр па крыніцы версіі
```

**Прыклады:**

```shell
# Паказаць усе версіі актыўнага файла
diff

# Паказаць усе версіі пэўнага файла
diff file=Recipe

# Параўнаць апошнюю версію з бягучым файлам
diff file=Recipe from=1

# Параўнаць дзве версіі
diff file=Recipe from=2 to=1

# Паказаць толькі версіі Sync
diff filter=sync
```

### `history`

Паказвае версіі толькі з [[Аднаўленне файлаў|аднаўлення файлаў]]. Аналагічную каманду для Sync глядзіце ў [[#Сінхранізацыя|sync:history]].

```bash
file=<name>        # назва файла
path=<path>        # шлях да файла
```

### `history:list`

Паказвае ўсе файлы з лакальнай гісторыяй.

### `history:read`

Чытае версію з лакальнай гісторыі.

```bash
file=<name>        # назва файла
path=<path>        # шлях да файла
version=<n>        # нумар версіі (па змаўчанні: 1)
```

### `history:restore`

Аднаўляе версію з лакальнай гісторыі.

```bash
file=<name>        # назва файла
path=<path>        # шлях да файла
version=<n>        # (абавязковы) нумар версіі
```

### `history:open`

Адкрывае аднаўленне файлаў.

```bash
file=<name>        # назва файла
path=<path>        # шлях да файла
```

## Файлы і папкі

### `file`

Паказвае звесткі пра файл (па змаўчанні: актыўны файл).

```bash
file=<name>        # назва файла
path=<path>        # шлях да файла
```

Прыклад:

```
path       Notes/Recipe.md
name       Recipe
extension  md
size       1024
created    1700000000000
modified   1700001000000
```

### `files`

Паказвае файлы ў сховішчы.

```bash
folder=<path>      # фільтр па папцы
ext=<extension>    # фільтр па пашырэнні

total              # вярнуць колькасць файлаў
```

### `folder`

Паказвае звесткі пра папку.

```bash
path=<path>              # (абавязковы) шлях да папкі
info=files|folders|size  # вярнуць толькі пэўныя звесткі
```

### `folders`

Паказвае папкі ў сховішчы.

```bash
folder=<path>      # фільтр па бацькоўскай папцы

total              # вярнуць колькасць папак
```

### `open`

Адкрывае файл.

```bash
file=<name>        # назва файла
path=<path>        # шлях да файла

newtab             # адкрыць у новай укладцы
```

### `create`

Стварае або перазапісвае файл.

```bash
name=<name>        # назва файла
path=<path>        # шлях да файла
content=<text>     # пачатковае змесціва
template=<name>    # шаблон

overwrite          # перазапісаць, калі файл існуе
open               # адкрыць файл пасля стварэння
newtab             # адкрыць у новай укладцы
```

### `read`

Чытае змесціва файла (па змаўчанні: актыўны файл).

```bash
file=<name>        # назва файла
path=<path>        # шлях да файла
```

### `append`

Дадае змесціва ў канец файла (па змаўчанні: актыўны файл).

```bash
file=<name>        # назва файла
path=<path>        # шлях да файла
content=<text>     # (абавязковы) змесціва для дадавання
heading=<name>     # мэтавы раздзел па загалоўку

inline             # дадаць без новага радка
```

### `prepend`

Дадае змесціва пасля frontmatter (па змаўчанні: актыўны файл).

```bash
file=<name>        # назва файла
path=<path>        # шлях да файла
content=<text>     # (абавязковы) змесціва для дадавання
heading=<name>     # мэтавы раздзел па загалоўку

inline             # дадаць без новага радка
```

### `move`

Перамяшчае або перайменоўвае файл (па змаўчанні: актыўны файл). Калі ў [[Налады#Заўжды абнаўляць унутраныя спасылкі|наладах сховішча]] гэта ўключана, [[Унутраныя спасылкі|унутраныя спасылкі]] абнаўляюцца аўтаматычна.

```bash
file=<name>        # назва файла
path=<path>        # шлях да файла
to=<path>          # (абавязковы) мэтавая папка або шлях
```

### `rename`

Перайменоўвае файл (па змаўчанні: актыўны файл). Калі ў новай назве не ўказана пашырэнне, яно захоўваецца аўтаматычна. Каб адначасова перайменаваць і перамясціць файл, выкарыстоўвайце [[#`move`|move]]. Калі ў [[Налады#Заўжды абнаўляць унутраныя спасылкі|наладах сховішча]] гэта ўключана, [[Унутраныя спасылкі|унутраныя спасылкі]] абнаўляюцца аўтаматычна.

```bash
file=<name>        # назва файла
path=<path>        # шлях да файла
name=<name>        # (абавязковы) новая назва файла
```

### `delete`

Выдаляе файл (па змаўчанні: актыўны файл; па змаўчанні ў кошык).

```bash
file=<name>        # назва файла
path=<path>        # шлях да файла

permanent          # выдаліць назаўсёды, мінаючы кошык
```

## Спасылкі

Каманды для [[Зваротныя спасылкі|зваротных спасылак]] і [[Выходныя спасылкі|выходных спасылак]].

### `backlinks`

Паказвае зваротныя спасылкі на файл (па змаўчанні: актыўны файл).

```bash
file=<name>        # назва мэтавага файла
path=<path>        # шлях да мэтавага файла

counts             # уключыць колькасць спасылак
total              # вярнуць колькасць зваротных спасылак
format=json|tsv|csv  # фармат вываду (па змаўчанні: tsv)
```

### `links`

Паказвае выходныя спасылкі з файла (па змаўчанні: актыўны файл).

```bash
file=<name>        # назва файла
path=<path>        # шлях да файла

total              # вярнуць колькасць спасылак
```

### `unresolved`

Паказвае неразвязаныя спасылкі ў сховішчы.

```bash
total              # вярнуць колькасць неразвязаных спасылак
counts             # уключыць колькасць спасылак
verbose            # уключыць зыходныя файлы
format=json|tsv|csv  # фармат вываду (па змаўчанні: tsv)
```

## Задачы

Каманды для кіравання задачамі.

### `tasks`

Паказвае задачы ў сховішчы. Выкарыстоўвайце `active` або `file`/`path`, каб паказаць задачы пэўнага файла.

```bash
file=<name>        # фільтр па назве файла
path=<path>        # фільтр па шляху да файла
status="<char>"    # фільтр па сімвале статусу

total              # вярнуць колькасць задач
done               # паказаць выкананыя задачы
todo               # паказаць невыкананыя задачы
verbose            # групаваць па файлах з нумарамі радкоў
format=json|tsv|csv  # фармат вываду (па змаўчанні: text)
active             # паказаць задачы актыўнага файла
daily              # паказаць задачы са штодзённай нататкі
```

**Прыклады:**

```bash
# Паказаць усе задачы ў сховішчы
tasks

# Паказаць невыкананыя задачы ў сховішчы
tasks todo

# Паказаць выкананыя задачы з пэўнага файла
tasks file=Recipe done

# Паказаць задачы з сённяшняй штодзённай нататкі
tasks daily

# Падлічыць задачы ў штодзённай нататцы
tasks daily total

# Паказаць задачы са шляхамі да файлаў і нумарамі радкоў
tasks verbose

# Фільтр па ўласным статусе (спецыяльныя сімвалы — у двукоссях)
tasks 'status=?'
```

### `task`

Паказвае або абнаўляе задачу.

```bash
ref=<path:line>    # спасылка на задачу (path:line)
file=<name>        # назва файла
path=<path>        # шлях да файла
line=<n>           # нумар радка
status="<char>"    # задаць сімвал статусу

toggle             # пераключыць статус задачы
daily              # штодзённая нататка
done               # пазначыць як выкананую
todo               # пазначыць як невыкананую
```

**Прыклады:**

```bash
# Паказаць звесткі пра задачу
task file=Recipe line=8
task ref="Recipe.md:8"

# Пераключыць выкананне задачы
task ref="Recipe.md:8" toggle

# Пераключыць задачу ў штодзённай нататцы
task daily line=3 toggle

# Задаць статус задачы
task file=Recipe line=8 done      # → [x]
task file=Recipe line=8 todo      # → [ ]
task file=Recipe line=8 status=-  # → [-]
task daily line=3 done            # Пазначыць задачу ў штодзённай нататцы як выкананую
```

Уключае або выключае інструменты распрацоўшчыка Electron.

### `dev:debug`

Падключае або адключае адладчык Chrome DevTools Protocol.

```bash
on                 # падключыць адладчык
off                # адключыць адладчык
```

### `dev:cdp`

Выконвае каманду Chrome DevTools Protocol.

```bash
method=<CDP.method>  # (абавязковы) метад CDP для выкліку
params=<json>        # параметры метаду ў JSON
```

### `dev:errors`

Паказвае перахопленыя памылкі JavaScript.

```bash
clear              # ачысціць буфер памылак
```

### `dev:screenshot`

Робіць здымак экрана (вяртае PNG у base64).

```bash
path=<filename>    # шлях да файла вываду
```

### `dev:console`

Паказвае перахопленыя паведамленні кансолі.

```bash
limit=<n>                        # максімальная колькасць паведамленняў (па змаўчанні 50)
level=log|warn|error|info|debug  # фільтр па ўзроўні

clear                            # ачысціць буфер кансолі
```

### `dev:css`

Правярае CSS з указаннем месцаў у зыходным кодзе.

```bash
selector=<css>     # (абавязковы) CSS-селектар
prop=<name>        # фільтр па назве ўласцівасці
```

### `dev:dom`

Выконвае запыт да элементаў DOM.

```bash
selector=<css>     # (абавязковы) CSS-селектар
attr=<name>        # атрымаць значэнне атрыбута
css=<prop>         # атрымаць значэнне CSS-уласцівасці

total              # вярнуць колькасць элементаў
text               # вярнуць тэкставае змесціва
inner              # вярнуць innerHTML замест outerHTML
all                # вярнуць усе супадзенні, а не першае
```

### `dev:mobile`

Уключае або выключае эмуляцыю мабільнай прылады.

```bash
on                 # уключыць эмуляцыю мабільнай прылады
off                # выключыць эмуляцыю мабільнай прылады
```

### `eval`

Выконвае JavaScript і вяртае вынік.

```bash
code=<javascript>  # (абавязковы) код JavaScript для выканання
```

## Вырашэнне праблем

Калі ўзніклі праблемы з запускам Obsidian CLI:

- Пераканайцеся, што вы карыстаецеся апошняй [[Абнаўленне Obsidian|версіяй усталёўшчыка Obsidian]] (1.12.7 або навейшай).
- Калі вы толькі што абнавілі Obsidian з ранейшай версіі, выключыце наладу CLI і зноў уключыце яе, а потым дазвольце Obsidian аўтаматычна зарэгістраваць PATH.
- Пасля рэгістрацыі CLI перазапусціце тэрмінал, каб змены PATH уступілі ў сілу.
- Obsidian павінен быць запушчаны. CLI падключаецца да запушчанага экзэмпляра Obsidian.

### Windows

У Windows выкарыстоўваецца тэрмінальны перанакіроўшчык, які правільна злучае Obsidian са stdin/stdout. Гэта неабходна, бо Obsidian звычайна працуе як праграма з графічным інтэрфейсам, несумяшчальная з тэрмінальным вывадам у Windows. Пры ўсталяванні Obsidian 1.12.7+ тэрмінальны перанакіроўшчык `Obsidian.com` дадаецца ў папку, дзе знаходзіцца файл `Obsidian.exe`.

Рэгістрацыя CLI дадае Obsidian у зменную PATH вашага карыстальніка; змены ўступаюць у сілу толькі пасля перазапуску тэрмінала.

### macOS

Рэгістрацыя CLI стварае сімвалічную спасылку `/usr/local/bin/obsidian` на выканальны файл CLI ўнутры праграмы. Для гэтага патрэбны правы адміністратара — сістэма запытае іх у дыялогавым акне.

Праверце, што сімвалічная спасылка існуе і паказвае на правільны файл:

```
ls -l /usr/local/bin/obsidian
```

Калі сімвалічнай спасылкі няма, стварыце яе ўручную:

```
sudo ln -sf /Applications/Obsidian.app/Contents/MacOS/obsidian-cli /usr/local/bin/obsidian
```

> [!note] Калі вы раней рэгістравалі CLI ў старэйшай версіі Obsidian, у `~/.zprofile` мог застацца запіс PATH. Новы працэс рэгістрацыі выдаляе яго аўтаматычна, але калі ён застаўся, можна бяспечна выдаліць з `~/.zprofile` радкі, якія пачынаюцца з `# Added by Obsidian`.

### Linux

Рэгістрацыя CLI капіюе выканальны файл CLI ў `~/.local/bin/obsidian`. Так зроблена таму, што некаторыя спосабы ўсталявання ў Linux запускаюць праграму з часовых папак, на якія нельга стварыць сталую сімвалічную спасылку.

Пераканайцеся, што `~/.local/bin` ёсць у PATH. Калі няма, дадайце ў `~/.bashrc` або `~/.zshrc` наступнае:

```
export PATH="$PATH:$HOME/.local/bin"
```

Праверце, што файл існуе:

```
ls -l ~/.local/bin/obsidian
```

Калі файла няма, скапіюйце яго ўручную з папкі ўсталявання Obsidian:

```
cp /path/to/Obsidian/obsidian-cli ~/.local/bin/obsidian
chmod 755 ~/.local/bin/obsidian
```
