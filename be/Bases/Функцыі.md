Функцыі Баз паводзяць сябе як у JavaScript. Поўную даведачную дакументацыю глядзіце ў [MDN Web Docs](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference).

Акрамя [[#Глабальныя|глабальных]] функцый, большасць функцый залежыць ад тыпу значэння, якое трэба змяніць:

## Глабальныя

Глабальныя функцыі выкарыстоўваюцца без тыпу.

### `escapeHTML()`

`escapeHTML(html: string): string`

- Экраніруе спецыяльныя сімвалы ў радку, каб яго можна было бяспечна ўставіць у HTML.

### `date()`

`date(date: string): date`

- `date(string): date` разбірае зададзены радок і вяртае аб'ект даты.
- Радок `date` павінен мець фармат `YYYY-MM-DD HH:mm:ss`.

### `duration()`

`duration(value: string): duration`

- Разбірае радок як працягласць. Фармат радка `value` апісаны ў раздзеле [[Сінтаксіс Баз#Арыфметыка дат|арыфметыкі дат]].
- Для арыфметыкі дат яўны разбор не патрэбны (напрыклад, `now() + '1d'`), але ён неабходны пры арыфметычных дзеяннях з працягласцямі (напрыклад, `now() + (duration('1d') * 2)`).
- Пры арыфметычных дзеяннях з працягласцю і лікам працягласць павінна быць злева. Напрыклад, `duration('5h') * 2`, а не `2 * duration('5h')`.

### `file()`

`file(path: string | file | url): file`

- Вяртае аб'ект файла для зададзенага файла або шляху.
- Прыклад: `file(link("[[filename]]"))` або `file("path to file")`.

### `html()`

`html(html: string): html`

- Пераўтварае радок у фрагмент кода, які адлюстроўваецца як HTML.

### `if()`

`if(condition: any, trueResult: any, falseResult?: any): any`

- `condition` — выраз, які правяраецца.
- `trueResult` — вынік, калі `condition` праўдзівы.
- `falseResult` — неабавязковы вынік, калі `condition` непраўдзівы. Калі не ўказаны, па змаўчанні `null`.
- Вяртае `trueResult`, калі `condition` праўдзівы, інакш вяртае `falseResult`.
- Прыклад: `if(isModified, "Modified", "Unmodified")`

### `image()`

`image(path: string | file | url): image`

- Вяртае аб'ект выявы, які паказвае выяву ў праглядзе.
- Прыклад: `image(image-property)` або `image("https://obsidian.md/images/obsidian-logo-gradient.svg")`.

### `icon()`

`icon(name: string): icon`

- Вяртае значэнне, якое паказваецца ў праглядзе як значок. Назва павінна адпавядаць падтрымліваемаму значку Lucide.
- Прыклад: `icon("arrow-right")`.

### `link()`

`link(path: string | file, display?: value): Link | URL`

- Разбірае радок `path` і вяртае аб'ект Link, які паказваецца як спасылка на зададзены шлях.
- Калі `path` — URL, замест гэтага вяртае аб'ект URL.
- Неабавязковы параметр `display` задае тэкст спасылкі.

### `list()`

`list(element: any): List`

- Калі зададзены элемент — спіс, вяртае яго без змен.
- Інакш абгортвае `element` у спіс, ствараючы спіс з адным элементам.
- Карысна, калі ўласцівасць у розных нататках сховішча змяшчае то радкі, то спісы.
- Прыклад: `list("value")` вяртае `["value"]`.

### `max()`

`max(value1: number, value2: number...): number`

- Вяртае найбольшы з зададзеных лікаў.

### `min()`

`min(value1: number, value2: number...): number`

- Вяртае найменшы з зададзеных лікаў.

### `now()`

`now(): date`

- Вяртае аб'ект даты для бягучага моманту.

### `number()`

`number(input: any): number`

- Спрабуе вярнуць зададзенае значэнне як лік.
- Аб'екты дат вяртаюцца як колькасць мілісекунд ад пачатку эпохі Unix.
- Лагічныя значэнні вяртаюцца як `1` або `0`.
- Радкі разбіраюцца як лікі; калі радок не з'яўляецца сапраўдным лікам, вяртаецца памылка.
- Прыклад: `number("3.4")` вяртае `3.4`.

### `today()`

`today(): date`

- Вяртае аб'ект даты для бягучага дня. Час усталёўваецца на поўнач.

### `random()`

`random(): number`

- Вяртае выпадковы лік ад 0 да 1.
- Лік генеруецца нанова пры кожнай загрузцы прагляду. Пры пераходзе паміж праглядамі выпадковы лік змяняецца.

## Любы тып

Функцыі, якія можна выкарыстоўваць з любым значэннем: радкамі (напрыклад, `"hello"`), лікамі (напрыклад, `42`), спісамі (напрыклад, `[1,2,3]`), аб'ектамі і іншым.

### `isTruthy()`

`any.isTruthy(): boolean`

- Вяртае значэнне, пераўтворанае ў лагічнае.
- Прыклад: `(1).isTruthy()` вяртае `true`.

### `isType()`

`any.isType(type: string): boolean`

- Вяртае true, калі значэнне мае зададзены тып.
- Прыклад: `"example".isType("string")` і `true.isType("boolean")` абодва вяртаюць true.

### `toString()`

`any.toString(): string`

- Вяртае радковае прадстаўленне любога значэння.
- Прыклад: `(123).toString()` вяртае `"123"`.

## Тып «Дата»

Функцыі для дат і часу, напрыклад `date("2025-05-27")`. Параўноўваць даты можна з дапамогай [[Сінтаксіс Баз#Арыфметыка дат|арыфметыкі дат]].

### Палі

Для дат даступныя наступныя палі:

| Поле | Тып | Апісанне |
| --- | --- | --- |
| `date.year`        | `number` | Год даты |
| `date.month`       | `number` | Месяц даты (1–12) |
| `date.day`         | `number` | Дзень месяца |
| `date.hour`        | `number` | Гадзіна (0–23) |
| `date.minute`      | `number` | Хвіліна (0–59) |
| `date.second`      | `number` | Секунда (0–59) |
| `date.millisecond` | `number` | Мілісекунда (0–999) |

### `date()`

`date.date(): date`

- Вяртае аб'ект даты без часу.
- Прыклад: `now().date().format("YYYY-MM-DD HH:mm:ss")` вяртае радок накшталт "2025-12-31 00:00:00".

### `format()`

`date.format(format: string): string`

- `format` — радок фармату (напрыклад, `"YYYY-MM-DD"`).
- Вяртае дату, адфарматаваную паводле радка фармату Moment.js.
- Прыклад: `date.format("YYYY-MM-DD")` вяртае `"2025-05-27"`.

### `time()`

`date.time(): string`

- Вяртае частку з часам у выглядзе радка.
- Прыклад: `now().time()` вяртае радок накшталт "23:59:59".

### `relative()`

`date.relative(): string`

- Вяртае зручнае для чытання параўнанне даты з бягучымі датай і часам.
- Прыклад: `file.mtime.relative()` вяртае значэнне накшталт `3 days ago`.

### `isEmpty()`

`date.isEmpty(): boolean`

- Вяртае false.

## Тып «Радок»

Функцыі для паслядоўнасцей сімвалаў, напрыклад `"hello"`.

### Палі

| Поле | Тып | Апісанне |
| --- | --- | --- |
| `string.length` | `number` | Колькасць сімвалаў у радку |

### `contains()`

`string.contains(value: string): boolean`

- `value` — падрадок, які трэба знайсці.
- Вяртае true, калі радок змяшчае `value`.
- Прыклад: `"hello".contains("ell")` вяртае `true`.

### `containsAll()`

`string.containsAll(...values: string): boolean`

- `values` — адзін або некалькі падрадкоў, якія трэба знайсці.
- Вяртае true, калі радок змяшчае ўсе `values`.
- Прыклад: `"hello".containsAll("h", "e")` вяртае `true`.

### `containsAny()`

`string.containsAny(...values: string): boolean`

- `values` — адзін або некалькі падрадкоў, якія трэба знайсці.
- Вяртае true, калі радок змяшчае хаця б адзін з `values`.
- Прыклад: `"hello".containsAny("x", "y", "e")` вяртае `true`.

### `endsWith()`

`string.endsWith(query: string): boolean`

- `query` — радок, які правяраецца ў канцы.
- Вяртае true, калі радок заканчваецца на `query`.
- Прыклад: `"hello".endsWith("lo")` вяртае `true`.

### `isEmpty()`

`string.isEmpty(): boolean`

- Вяртае true, калі ў радку няма сімвалаў або ён адсутнічае.
- Прыклад: `"Hello world".isEmpty()` вяртае `false`.
- Прыклад: `"".isEmpty()` вяртае `true`.

### `lower()`

`string.lower(): string`

- Вяртае радок, пераўтвораны ў малыя літары.

### `replace()`

`string.replace(pattern: string | Regexp, replacement: string): string`

- `pattern` — значэнне, якое трэба знайсці ў радку.
- `replacement` — значэнне, якім замяняюцца знойдзеныя ўваходжанні. Калі `pattern` — Regexp, у `replacement` можна спасылацца на групы захопу праз `$1`, `$2` і г.д.
- Калі `pattern` — радок, замяняюцца ўсе ўваходжанні.
- Калі `pattern` — Regexp, сцяг `g` вызначае, ці замяняецца толькі першае ўваходжанне, ці ўсе.
- Прыклад: `"a:b:c:d".replace(/:/, "-")` вяртае `"a-b:c:d"`, а `"a:b:c:d".replace(/:/g, "-")` вяртае `"a-b-c-d"`.
- Прыклад з групамі захопу: `"John Smith".replace(/(\w+) (\w+)/, "$2, $1")` вяртае `"Smith, John"`.

### `repeat()`

`string.repeat(count: number): string`

- `count` — колькі разоў паўтарыць радок.
- Прыклад: `"123".repeat(2)` вяртае `"123123"`.

### `reverse()`

`string.reverse(): string`

- Перастаўляе сімвалы радка ў адваротным парадку.
- Прыклад: `"hello".reverse()` вяртае `"olleh"`.

### `slice()`

`string.slice(start: number, end?: number): string`

- `start` — пачатковы індэкс (уключна).
- `end` — неабавязковы канчатковы індэкс (не ўключаецца).
- Вяртае падрадок ад `start` (уключна) да `end` (не ўключна).
- Прыклад: `"hello".slice(1, 4)` вяртае `"ell"`.
- Калі `end` не ўказаны, бярэцца частка да канца радка.

### `split()`

`string.split(separator: string | Regexp, n?: number): list`

- `separator` — раздзяляльнік для падзелу радка.
- `n` — неабавязковы лік. Калі ўказаны, вынік будзе змяшчаць першыя `n` элементаў.
- Вяртае спіс падрадкоў.
- Прыклад: `"a,b,c,d".split(",", 3)` або `"a,b,c,d".split(/,/, 3)` вяртае `["a", "b", "c"]`.

### `startsWith()`

`string.startsWith(query: string): boolean`

- `query` — радок, які правяраецца ў пачатку.
- Вяртае true, калі радок пачынаецца з `query`.
- Прыклад: `"hello".startsWith("he")` вяртае `true`.

### `title()`

`string.title(): string`

- Пераўтварае радок у Title Case (першая літара кожнага слова вялікая).
- Прыклад: `"hello world".title()` вяртае `"Hello World"`.

### `trim()`

`string.trim(): string`

- Выдаляе прабелы з абодвух канцоў радка.
- Прыклад: `"  hi  ".trim()` вяртае `"hi"`.

## Тып «Лік»

Функцыі для лікавых значэнняў, напрыклад `42`, `3.14`.

### `abs()`

`number.abs(): number`

- Вяртае модуль ліку.
- Прыклад: `(-5).abs()` вяртае `5`.

### `ceil()`

`number.ceil(): number`

- Акругляе лік уверх да бліжэйшага цэлага.
- Прыклад: `(2.1).ceil()` вяртае `3`.

### `floor()`

`number.floor(): number`

- Акругляе лік уніз да бліжэйшага цэлага.
- Прыклад: `(2.9).floor()` вяртае `2`.

### `isEmpty()`

`number.isEmpty(): boolean`

- Вяртае true, калі лік адсутнічае.
- Прыклад: `(5).isEmpty()` вяртае `false`.

### `round()`

`number.round(digits: number): number`

- Акругляе лік да бліжэйшага цэлага.
- Неабавязковы параметр `digits` задае колькасць знакаў пасля коскі.
- Прыклад: `(2.5).round()` вяртае `3`, а `(2.3333).round(2)` вяртае `2.33`.

### `toFixed()`

`number.toFixed(precision: number): string`

- `precision` — колькасць знакаў пасля коскі.
- Вяртае радок з лікам у запісе з фіксаванай коскай.
- Прыклад: `(3.14159).toFixed(2)` вяртае `"3.14"`.

## Тып «Спіс»

Функцыі для ўпарадкаваных спісаў элементаў, напрыклад `[1, 2, 3]`.

### Палі

| Поле | Тып | Апісанне |
| --- | --- | --- |
| `list.length` | `number` | Колькасць элементаў у спісе |

### `contains()`

`list.contains(value: any): boolean`
- `value` — элемент, які трэба знайсці.
- Вяртае true, калі спіс змяшчае `value`.
- Прыклад: `[1,2,3].contains(2)` вяртае `true`.

### `containsAll()`

`list.containsAll(...values: any): boolean`

- `values` — адзін або некалькі элементаў, якія трэба знайсці.
- Вяртае true, калі спіс змяшчае ўсе `values`.
- Прыклад: `[1,2,3].containsAll(2,3)` вяртае `true`.

### `containsAny()`

`list.containsAny(...values: any): boolean`

- `values` — адзін або некалькі элементаў, якія трэба знайсці.
- Вяртае true, калі спіс змяшчае хаця б адзін з `values`.
- Прыклад: `[1,2,3].containsAny(3,4)` вяртае `true`.

### `filter()`

`list.filter(value: Boolean): list`

- Фільтруе спіс і пакідае толькі элементы, для якіх выраз праўдзівы.
- `value` — значэнне элемента спіса.
- `index` — індэкс бягучага значэння.
- Прыклад: `[1,2,3,4].filter(value > 2)` вяртае `[3,4]`.

### `flat()`

`list.flat(): list`

- Ператварае ўкладзены спіс у адзін плоскі спіс.
- Прыклад: `[1,[2,3]].flat()` вяртае `[1,2,3]`.

### `isEmpty()`

`list.isEmpty(): boolean`

- Вяртае true, калі ў спісе няма элементаў.
- Прыклад: `[1,2,3].isEmpty()` вяртае `false`.

### `join()`

`list.join(separator: string): string`

- `separator` — радок, які ўстаўляецца паміж элементамі.
- Аб'ядноўвае ўсе элементы спіса ў адзін радок.
- Прыклад: `[1,2,3].join(",")` вяртае `"1,2,3"`.

### `map()`

`list.map(value: Any): list`

- Пераўтварае кожны элемент спіса з дапамогай выразу.
- `value` — значэнне элемента спіса.
- `index` — індэкс бягучага значэння.
- Прыклад: `[1,2,3,4].map(value + 1)` вяртае `[2,3,4,5]`.

### `reduce()`

`list.reduce(expression: Any, acc: Any): Any`

- Згортвае спіс у адно значэнне, выконваючы выраз для кожнага элемента. Выраз павінен вяртаць наступнае значэнне `acc`. Выкарыстоўвайце `value` для бягучага элемента, `index` для яго пазіцыі і `acc` для назапашанага выніку.
- `expression` вылічваецца для кожнага элемента спіса.
- `value` — значэнне бягучага элемента спіса.
- `index` — індэкс бягучага элемента.
- `acc` — назапашанае значэнне.
- Прыклад (сума): `[1,2,3].reduce(acc + value, 0)` вяртае `6`.
- Прыклад (максімум): `values.filter(value.isType("number")).reduce(if(acc == null || value > acc, value, acc), null)` вяртае найбольшы лік або `null`, калі лікаў няма.

### `reverse()`

`list.reverse(): list`

- Перастаўляе элементы спіса ў адваротным парадку.
- Прыклад: `[1,2,3].reverse()` вяртае `[3,2,1]`.

### `slice()`

`list.slice(start: number, end?: number): list`

- `start` — пачатковы індэкс (уключна).
- `end` — неабавязковы канчатковы індэкс (не ўключаецца).
- Вяртае павярхоўную копію часткі спіса ад `start` (уключна) да `end` (не ўключна).
- Прыклад: `[1,2,3,4].slice(1,3)` вяртае `[2,3]`.
- Калі `end` не ўказаны, бярэцца частка да канца спіса.

### `sort()`

`list.sort(): list`

- Сартуе элементы спіса ад найменшага да найбольшага.
- Прыклад: `[3, 1, 2].sort()` вяртае `[1, 2, 3]`.
- Прыклад: `["c", "a", "b"].sort()` вяртае `["a", "b", "c"]`.

### `unique()`

`list.unique(): list`

- Выдаляе паўторныя элементы.
- Прыклад: `[1,2,2,3].unique()` вяртае `[1,2,3]`.

## Тып «Спасылка»

Функцыі для спасылак. Спасылкі можна ствараць з файла (`file.asLink()`) або са шляху (`link("path")`).

### `asFile()`

`link.asFile(): file`

- Вяртае аб'ект файла, калі спасылка паказвае на існуючы лакальны файл.
- Прыклад: `link("[[filename]]").asFile()`.

### `linksTo()`

`link.linksTo(file): boolean`

- Вяртае `true`, калі файл, на які паказвае `link`, змяшчае спасылку на `file`.

## Тып «URL»

Функцыі для URL, напрыклад `link("https://obsidian.md")`. Для URL даступныя ўсе функцыі [[#Тып «Радок»|тыпу «Радок»]], але не функцыі [[#Тып «Спасылка»|тыпу «Спасылка»]].

## Тып «Файл»

Функцыі для файлаў у сховішчы.

### Палі

Для файлаў даступныя наступныя палі:

| Поле | Тып | Апісанне |
| --- | --- | --- |
| `file.name`       | `string` | Назва файла. |
| `file.basename`   | `string` | Назва файла без пашырэння. |
| `file.path`       | `string` | Поўны шлях да файла адносна кораня сховішча. |
| `file.folder`     | `string` | Поўны шлях да бацькоўскай папкі. |
| `file.ext`        | `string` | Пашырэнне файла. |
| `file.size`       | `number` | Памер файла ў байтах. |
| `file.properties` | `object` | Уласцівасці нататкі для гэтага файла. |
| `file.tags`       | `list`   | Тэгі файла, уключаючы тэгі ў тэксце. |
| `file.links`      | `list`   | Унутраныя спасылкі ў файле. |
| `file.ctime`      | `date`   | Час стварэння файла. |
| `file.mtime`      | `date`   | Час апошняга змянення файла. |

### `asLink()`

`file.asLink(display?: string): Link`

- `display` — неабавязковы тэкст спасылкі.
- Вяртае аб'ект Link, які паказваецца як працоўная спасылка.
- Прыклад: `file.asLink()`

### `hasLink()`

`file.hasLink(otherFile: file | string): boolean`

- `otherFile` — іншы аб'ект файла або шлях у выглядзе радка.
- Вяртае true, калі `file` спасылаецца на `otherFile`.
- Прыклад: `file.hasLink(otherFile)` вяртае `true`, калі ў `file` ёсць спасылка на `otherFile`.

### `hasProperty()`

`file.hasProperty(name: string): boolean`

- Вяртае `true`, калі ў файла ёсць зададзеная ўласцівасць.

### `hasTag()`

`file.hasTag(...values: string): boolean`

- `values` — адна або некалькі назваў тэгаў.
- Вяртае true, калі ў файла ёсць любы з тэгаў у `values`.
- Прыклад: `file.hasTag("tag1", "tag2")` вяртае `true`, калі ў файла ёсць тэг `#tag1` або `#tag2`. Улічваюцца таксама [[Тэгі#Укладзеныя тэгі|укладзеныя тэгі]], напрыклад `#tag1/a` або `#tag2/b`.

### `inFolder()`

`file.inFolder(folder: string): boolean`

- `folder` — назва папкі для праверкі.
- Вяртае true, калі файл знаходзіцца ў зададзенай папцы або ў адной з яе падпапак.
- Прыклад: `file.inFolder("notes")` вяртае `true`.

## Тып «Аб'ект»

Функцыі для аб'ектаў, напрыклад `file.properties`, якія змяшчаюць набор пар ключ-значэнне.

### `isEmpty()`

`object.isEmpty(): boolean`

- Вяртае true, калі ў аб'екта няма ўласных уласцівасцей.
- Прыклад: `file.properties.isEmpty()` вяртае `true`, калі ў файла няма ўласцівасцей.

### `keys()`

`object.keys(): list`

- Вяртае спіс ключоў аб'екта.

### `values()`

`object.values(): list`

- Вяртае спіс значэнняў аб'екта.

## Тып «Рэгулярны выраз»

Функцыі для рэгулярных выразаў. Прыклад: `/abc/`.

### `matches()`

`regexp.matches(value: string): boolean`

- `value` — радок для праверкі.
- Вяртае true, калі рэгулярны выраз адпавядае `value`.
- Прыклад: `/abc/.matches("abcde")` вяртае `true`.
