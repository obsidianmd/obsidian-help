Obsidian выкарыстоўвае файлы Markdown `.md` як асноўны фармат нататак. Таму імпартаваць файлы Markdown у Obsidian лёгка. Многія праграмы ўмеюць рэдагаваць файлы Markdown або экспартаваць у гэты фармат.

Дадаць файлы Markdown у сховішча Obsidian можна некалькімі спосабамі:

1. Перацягніце файлы або папкі ў акно [[Праваднік|правадніка]]
2. Скарыстайцеся сістэмным файлавым менеджарам (напрыклад, Правадыром Windows або Finder на macOS) і перамясціце файлы непасрэдна ў папку сховішча Obsidian.

## Імпарт файлаў Markdown з дапамогай Імпарцёра

Выкарыстоўвайце афіцыйны [[Імпарцёр|плагін Імпарцёр]], калі хочаце выбраць папкі ўнутры імпарту, імпартаваць архіў `.zip`, уніфікаваць фарматаванне, перанесці ўбудаваныя тэгі ва [[Уласцівасці|ўласцівасці]] або прымяніць шаблон.

1. Адкрыйце **[[Налады|Налады]] → Плагіны супольнасці** і [усталюйце Importer](obsidian://show-plugin?id=obsidian-importer).
2. Уключыце плагін Importer.
3. Адкрыйце Importer у наладах або праз [[Меню каманд|меню каманд]].
4. У пункце **File format** выберыце **Markdown (.md, .zip)**.
5. Выберыце асобныя файлы Markdown, папкі або zip-архівы.
6. Праверце знойдзеныя папкі, параметры вываду, створаны шаблон і прыклады.
7. Выберыце **Import** і дачакайцеся завяршэння імпарту.

Як наладзіць назву, уласцівасці і змесціва імпартаваных нататак, глядзіце ў раздзеле [[Шаблоны імпарту]].
