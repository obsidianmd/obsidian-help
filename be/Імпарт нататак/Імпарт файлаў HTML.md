Obsidian дазваляе лёгка імпартаваць асобныя файлы HTML і цэлыя папкі з файламі HTML з дапамогай афіцыйнага [[Імпарцёр|плагіна Імпарцёр]]. Гэта карысна, калі вы хочаце захаваць цэлыя сайты ў фармаце [[Obsidian Flavored Markdown|Markdown]] або імпартаваць даныя з інструмента, які экспартуе ў HTML.

Калі вы імпартуеце нататкі з пэўнай праграмы, спачатку праглядзіце спіс праграм, якія падтрымлівае [[Імпарцёр|плагін Імпарцёр]]: магчыма, для яе ёсць асобны канвертар, які лепш захавае вашы даныя.

## Імпарт даных HTML у Obsidian

Вам спатрэбіцца афіцыйны плагін Obsidian [[Імпарцёр|Імпарцёр]], які можна [усталяваць тут](obsidian://show-plugin?id=obsidian-importer).

1. Адкрыйце **[[Налады|Налады]]**.
2. Перайдзіце ў **Плагіны супольнасці** і [усталюйце Importer](obsidian://show-plugin?id=obsidian-importer).
3. Уключыце плагін Importer.
4. Адкрыйце Importer у наладах або праз [[Меню каманд|меню каманд]].
5. У пункце **File format** выберыце **HTML (.html).**
6. Укажыце, дзе знаходзяцца файлы або папкі HTML.
7. Выберыце **Import**, каб праглядзець створаны шаблон і прыклады з вашых файлаў.
8. Зноў выберыце **Import** і дачакайцеся завяршэння імпарту.

### Налады імпарту

- **Attachment size limit**: не імпартаваць далучэнні, большыя за зададзены памер.
- **Minimum image size**: не імпартаваць відарысы, меншыя за зададзены памер па любым з вымярэнняў. Дазваляе прапускаць значкі і лагатыпы.

## Шаблоны

Каб цалкам наладзіць імпарт даных, выкарыстоўвайце [[Шаблоны імпарту|шаблоны Імпарцёра]].

![[Шаблоны імпарту#Зменныя]]

Акрамя таго, імпарт HTML дае многія з тых жа зменных, што і [[Уводзіны ў Obsidian Web Clipper|Web Clipper]]:

| Зменная | Апісанне |
| --- | --- |
| `{{author}}` | Аўтар старонкі. |
| `{{contentHtml}}` | Вынятае змесціва старонкі ў фармаце HTML. |
| `{{description}}` | Апісанне або ўрывак старонкі. |
| `{{domain}}` | Дамен старонкі. |
| `{{favicon}}` | URL значка сайта (favicon). |
| `{{fullHtml}}` | Неапрацаваны HTML усёй старонкі. |
| `{{image}}` | URL відарыса для сацсетак. |
| `{{language}}` | Мова старонкі. |
| `{{published}}` | Дата публікацыі; яе можна адфарматаваць фільтрам `date`. |
| `{{site}}` | Назва сайта або выдаўца. |
| `{{url}}` | URL крыніцы, знойдзены ў імпартаваным дакуменце, калі ён ёсць. |
| `{{words}}` | Колькасць слоў. |
