[[Імпарцёр|Імпарцёр]] дазваляе задаваць шаблоны, якія вызначаюць, як імпартуюцца нататкі з іншых праграм. З іх дапамогай можна змяняць назву, уласцівасці і змесціва імпартаваных нататак.

## Рэдагаванне шаблона імпарту

Выберыце **Edit** над перадпраглядам, каб адрэдагаваць прадвызначаны шаблон. Можна змяняць:

- Назву нататкі, якая паказваецца як убудаваная назва.
- Уласцівасці ў пачатку нататкі.
- Змесціва нататкі ў Markdown.

Выберыце **Save**, каб вярнуцца да перадпрагляду. Імпарцёр запамінае адрэдагаваны шаблон для наступных імпартаў у тым жа фармаце.

Таксама можна загрузіць шаблон з файла Markdown у бягучым сховішчы.

## Перадпрагляд вынікаў

Перадпрагляд паказвае да дзесяці прыкладаў з выбраных даных. Пераходзьце паміж імі кнопкамі са стрэлкамі. Змены ў наладах імпарту і шаблоне адразу адлюстроўваюцца ў перадпраглядзе, яшчэ да таго, як нешта будзе дададзена ў сховішча.

Некаторыя далучэнні, аддаленыя элементы і спасылкі паміж нататкамі нельга цалкам вызначыць да запуску імпарту. У такіх выпадках перадпрагляд можа пакідаць спасылку на крыніцу або паказваць запаўняльнік.

## Сінтаксіс шаблонаў

Шаблоны Імпарцёра выкарыстоўваюць сінтаксіс, які складаецца са зменных, [[Фільтры|фільтраў]] і [[Логіка|логікі]]. Гэта той жа сінтаксіс [Knap](https://github.com/obsidianmd/knap), што і ў [[Уводзіны ў Obsidian Web Clipper|Web Clipper]].

Зменныя ўстаўляюцца ў падвойных фігурных дужках, напрыклад `{{title}}`, `{{content}}` або `{{date}}`. Іх можна выкарыстоўваць у назве нататкі, уласцівасцях і змесціве.

Зменныя можна змяняць з дапамогай [[Фільтры|фільтраў]]. Напрыклад, каб змяніць фармат даты: `{{date|date:"YYYY-MM-DD"}}`. Для складанейшых умоў, цыклаў і прысвойвання зменных выкарыстоўвайце [[Логіка|логіку]].

## Зменныя

У любым шаблоне Імпарцёра даступныя наступныя зменныя:

| Зменная          | Апісанне                                                                                            |
| ---------------- | --------------------------------------------------------------------------------------------------- |
| `{{body}}`       | Цела Markdown без уласцівасцяў (без frontmatter).                                                   |
| `{{content}}`    | Увесь Markdown да прымянення выбранага шаблона.                                                     |
| `{{ctime}}`      | Час стварэння ў крыніцы ў фармаце ISO 8601; пуста, калі недаступны.                                 |
| `{{date}}`       | Бягучыя дата і час на момант апрацоўкі шаблона ў фармаце ISO 8601.                                  |
| `{{importer}}`   | Ідэнтыфікатар імпарцёра, напрыклад `keep`, `html` або `notion-api`.                                 |
| `{{folder}}`     | Канчатковая бацькоўская папка адносна сховішча. Пуста, калі нататка ў корані сховішча.              |
| `{{mtime}}`      | Час змены ў крыніцы ў фармаце ISO 8601; пуста, калі недаступны.                                     |
| `{{noteName}}`   | Канчатковая назва нататкі пасля выдалення недапушчальных сімвалаў і дадавання суфіксаў для дублікатаў. |
| `{{path}}`       | Канчатковы шлях адносна сховішча, разам з пашырэннем `.md`.                                         |
| `{{properties}}` | Аб'ект з уласцівасцямі frontmatter.                                                                 |
| `{{source}}`     | Аб'ект са створанымі ўласцівасцямі і значэннямі, характэрнымі для крыніцы.                          |
| `{{sourceId}}`   | Сталы ідэнтыфікатар крыніцы, калі імпарцёр яго дае; інакш пуста.                                     |
| `{{time}}`       | Псеўданім для `{{date}}`.                                                                           |
| `{{title}}`      | Зыходная назва нататкі да ачысткі і выдалення дублікатаў.                                           |

## Значэнні крыніцы для ўласцівасцяў

Для фарматаў імпарту, якія падтрымліваюць [[Уласцівасці|уласцівасці]], значэнні крыніцы для зручнасці даступныя і як зменныя верхняга ўзроўню.

Калі значэнне крыніцы мае такую ж назву, як агульная зменная, звяртайцеся да яго праз `{{source}}`. Напрыклад, калі ў крыніцы імпарту ёсць уласцівасць `content`, яна даступная як `{{source.content}}`, а `{{content}}` застаецца прадвызначанай зменнай Імпарцёра.

Калі назва поля змяшчае прабелы, знакі прыпынку або іншыя спецыяльныя сімвалы, выкарыстоўвайце запіс у квадратных дужках:

```twig
{{source["Project: status"]}}
```

## Прыклад шаблона

Вось прыклад шаблона са зменнымі і [[Фільтры|фільтрамі]]:

```twig
---
created: {{ctime | date:"YYYY-MM-DD"}}
modified: {{mtime | date:"YYYY-MM-DD"}}
source: {{importer}}
---
# {{title}}

{{body}}
```

Даныя можна дадаваць у нататку па ўмове з дапамогай [[Логіка|логікі]]:

```twig
{% if tags %}
## Тэгі
{% for tag in tags %}
- {{tag}}
{% endfor %}
{% endif %}
```
