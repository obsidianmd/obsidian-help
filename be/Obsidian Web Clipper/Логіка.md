[[Уводзіны ў Obsidian Web Clipper|Web Clipper]] падтрымлівае логіку ў шаблонах: умовы, цыклы і прысвойванне зменных. Гэты сінтаксіс называецца [Knap](https://github.com/obsidianmd/knap).

## Умовы

Выкарыстоўвайце `{% if %}`, каб уключаць змесціва ў залежнасці ад зменных або выразаў.

```twig
{% if author %}
Author: {{author}}
{% endif %}
```

Выкарыстоўвайце `{% else %}` для запасного змесціва і `{% elseif %}`, каб аб'ядноўваць некалькі ўмоў у ланцужок:

```twig
{% if status == "published" %}
Live article
{% elseif status == "draft" %}
Draft article
{% else %}
Unknown status
{% endif %}
```

### Аператары параўнання

Падтрымліваюцца наступныя аператары параўнання:

| Аператар | Апісанне |
|----------|-------------|
| `==` | Роўна |
| `!=` | Не роўна |
| `>` | Больш |
| `<` | Менш |
| `>=` | Больш або роўна |
| `<=` | Менш або роўна |
| `contains` | Правярае, ці змяшчае радок падрадок або масіў — значэнне |

Прыклады:
- `{% if title == "Home" %}` — роўнасць радкоў
- `{% if price >= 100 %}` — параўнанне лікаў
- `{% if title contains "Review" %}` — праверка падрадка
- `{% if tags contains "important" %}` — прыналежнасць да масіву

### Лагічныя аператары

Аб'ядноўвайце ўмовы з дапамогай лагічных аператараў:

| Аператар | Альтэрнатыва | Апісанне |
| -------- | ----------- | ----------------------------------- |
| `and`    | `&&`        | Абедзве ўмовы павінны быць праўдзівымі |
| `or`     | \|\|        | Хаця б адна ўмова павінна быць праўдзівай |
| `not`    | `!`         | Адмаўляе ўмову |

Прыклады:
- `{% if author and published %}` — павінны існаваць абодва
- `{% if draft or archived %}` — любая з умоў
- `{% if not hidden %}` — адмаўленне
- `{% if (premium or featured) and published %}` — згрупаваныя ўмовы

### Праўдзівасць

Калі зменная выкарыстоўваецца без аператара параўнання, правяраецца яе «праўдзівасць»:

- `false`, `null`, `undefined`, пусты радок `""` і `0` лічацца **непраўдзівымі** (falsy).
- Пустыя масівы `[]` лічацца **непраўдзівымі**.
- Усё астатняе — **праўдзівае** (truthy).

```twig
{% if content %}
Has content
{% endif %}
```

## Прысвойванне зменнай

Выкарыстоўвайце `{% set %}`, каб ствараць або змяняць зменныя ў шаблоне:

```twig
{% set slug = title|lower|replace:" ":"-" %}
File: {{slug}}.md
```

Зменнай можна прысвоіць:
- Іншыя зменныя: `{% set name = author %}`
- Літэралы: `{% set count = 5 %}` або `{% set label = "Draft" %}`
- Выразы з фільтрамі: `{% set excerpt = content|truncate:100 %}`
- Вынікі селектараў: `{% set comments = selector:.comment %}`

Зменныя, зададзеныя праз `{% set %}`, можна выкарыстоўваць у далейшай логіцы шаблона і ў вывадзе `{{variable}}`.

## Запасныя значэнні

Выкарыстоўвайце аператар `??`, каб задаць запаснае значэнне, калі зменная пустая або не вызначана:

```twig
{{title ?? "Untitled"}}
```

Калі `title` пустая, не вызначана або непраўдзівая, замест яе будзе выкарыстана запаснае значэнне `"Untitled"`.

Гэта скарочаны запіс для раўназначнай канструкцыі `if`:

```twig
{% if title %}{{title}}{% else %}Untitled{% endif %}
```

### Ланцужкі запасных значэнняў

Можна задаць некалькі запасных значэнняў запар:

```twig
{{title ?? headline ?? "No title"}}
```

Будзе выкарыстана `title`, калі яна ёсць, інакш `headline`, інакш радок `"No title"`.

### З фільтрамі

Фільтры маюць больш высокі прыярытэт, чым `??`, таму яны ўжываюцца да праверкі запаснога значэння:

```twig
{{title|upper ?? "UNTITLED"}}
```

Тут спачатку да `title` ужываецца `upper`, а калі вынік пусты, выкарыстоўваецца `"UNTITLED"`. Каб ужыць фільтры да запаснога значэння, выкарыстоўвайце дужкі або асобныя выразы:

```twig
{{title ?? "Untitled"|lower}}
```

Будзе выкарыстана `title`, калі яна ёсць, інакш да запаснога значэння ўжываецца `lower`, і атрымліваецца `"untitled"`.

## Цыклы

Выкарыстоўвайце `{% for %}`, каб перабіраць масівы:

```twig
{% for item in schema:author %}
- {{item.name}}
{% endfor %}
```

### Крыніцы для цыклаў

Перабіраць можна:
- Масівы схемы: `{% for item in schema:author %}`
- Вынікі селектараў: `{% for comment in selector:.comment %}`
- Зменныя, зададзеныя раней: `{% set items = selector:.item %}{% for item in items %}`

### Зменныя цыкла

Унутры цыкла даступны аб'ект `loop` з наступнымі ўласцівасцямі:

| Зменная | Апісанне |
|----------|-------------|
| `loop.index` | Нумар бягучай ітэрацыі (адлік ад 1) |
| `loop.index0` | Нумар бягучай ітэрацыі (адлік ад 0) |
| `loop.first` | `true` на першай ітэрацыі |
| `loop.last` | `true` на апошняй ітэрацыі |
| `loop.length` | Агульная колькасць элементаў |

```twig
{% for tag in tags %}
{{loop.index}}. {{tag}}
{% if loop.last %} (end of list){% endif %}
{% endfor %}
```

Для зваротнай сумяшчальнасці можна таксама выкарыстоўваць `item_index` (дзе `item` — назва вашай зменнай цыкла), каб атрымаць пазіцыю з адлікам ад 0:

```twig
{% for tag in tags %}
{{tag_index}}. {{tag}}
{% endfor %}
```

### Доступ да элементаў масіву па індэксе

Каб атрымаць элемент масіву па індэксе, выкарыстоўвайце квадратныя дужкі:

```twig
{{items[0]}}
{{items[loop.index0]}}
```

Гэта зручна, калі трэба паралельна працаваць з элементамі некалькіх масіваў:

```twig
{% set transcripts = selector:.transcript-text %}
{% set timestamps = selector:.timestamp %}

{% for line in transcripts %}
{{timestamps[loop.index0]}} - {{line}}
{% endfor %}
```

Квадратныя дужкі працуюць і з уласцівасцямі аб'ектаў:

```twig
{{user["name"]}}
{{data["my-key"]}}
```

### Укладзеныя цыклы

Для складаных структур даных цыклы можна ўкладаць адзін у адзін:

```twig
{% for section in sections %}
## {{section.title}}
{% for item in section.items %}
- {{item}}
{% endfor %}
{% endfor %}
```

## Спалучэнне логікі

Умовы і цыклы можна спалучаць:

```twig
{% for item in items %}
{% if item.active %}
- {{item.name}}
{% endif %}
{% endfor %}
```

## Парадак апрацоўкі

Логіка шаблона апрацоўваецца ў такім парадку:

1. **Логіка шаблона** — спачатку апрацоўваюцца `{% if %}`, `{% for %}`, `{% set %}` і `{{variables}}`
2. **Зменныя-запыты** — [[Зменныя#Зменныя-запыты|зменныя-запыты]] накшталт `{{"summarize this"|prompt}}` адпраўляюцца інтэрпрэтатару пасля завяршэння логікі шаблона

Гэта значыць, што логікай шаблона можна дынамічна складаць запыты, але вынікі запытаў нельга выкарыстоўваць ва ўмовах або цыклах.
