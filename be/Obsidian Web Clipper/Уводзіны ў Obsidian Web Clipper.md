Obsidian Web Clipper — бясплатнае пашырэнне для браўзера, якое дазваляе вылучаць тэкст на старонках і захоўваць вэб-змесціва ў сховішча.

## Усталяванне Web Clipper

Усталюйце пашырэнне Obsidian Web Clipper з афіцыйнага каталога для вашага браўзера:

- [Chrome Web Store](https://chromewebstore.google.com/detail/obsidian-web-clipper/cnjifjpddelmedmihgijeibhnjfabmlf)
	- Для Chrome, Brave, Arc, Orion і іншых браўзераў на аснове Chromium.
- [Firefox Add-Ons](https://addons.mozilla.org/en-US/firefox/addon/web-clipper-obsidian/)
	- Для Firefox і Firefox Mobile.
- [Safari Extensions](https://apps.apple.com/us/app/obsidian-web-clipper/id6720708363)
	- Для macOS, iOS і iPadOS.
- [Edge Add-Ons](https://microsoftedge.microsoft.com/addons/detail/obsidian-web-clipper/eigdjhmgnaaeaonimdklocfekkaanfme)
	- Для Microsoft Edge.

## Прыватнасць

Obsidian Web Clipper захоўвае змесціва лакальна ў вашым сховішчы Obsidian і выконвае нашу [палітыку прыватнасці](https://obsidian.md/privacy). Вашы даныя не збіраюцца, і мы не збіраем ніякай статыстыкі выкарыстання. Код [адкрыты](https://github.com/obsidianmd/obsidian-clipper) і даступны для праверкі.
