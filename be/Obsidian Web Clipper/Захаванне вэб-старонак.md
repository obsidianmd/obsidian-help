Пасля ўсталявання пашырэння [[Уводзіны ў Obsidian Web Clipper|Web Clipper]] яго можна выклікаць некалькімі спосабамі, у залежнасці ад браўзера:

1. Значок Obsidian на панэлі інструментаў браўзера.
2. Гарачыя клавішы, каб запускаць пашырэнне з клавіятуры.
3. Кантэкстнае меню — праз правую кнопку мышы на старонцы, якую вы праглядаеце.

Каб захаваць старонку ў Obsidian, націсніце кнопку **Add to Obsidian**.

## Захаванне старонкі

Калі вы адкрываеце пашырэнне, Web Clipper здабывае даныя з бягучай вэб-старонкі паводле налад вашага [[Шаблоны Web Clipper|шаблона]]. Вы можаце ствараць уласныя шаблоны і наладжваць вынік з дапамогай [[Зменныя|зменных]] і [[Фільтры|фільтраў]].

Па змаўчанні Web Clipper імкнецца разумна здабыць толькі асноўны тэкст артыкула, без іншых элементаў старонкі. Але гэтыя паводзіны можна змяніць:

- Калі ёсць уласны шаблон, выкарыстоўваецца ваш шаблон.
- Калі на старонцы ёсць вылучэнне, выкарыстоўваецца вылучаны фрагмент. Каб вылучыць усю старонку, націсніце `Ctrl/Cmd+A`.
- Калі ёсць [[Вылучэнне|пазнакі вылучэння]], выкарыстоўваюцца яны.

## Загрузка выяў

Пры выкарыстанні Web Clipper выявы не загружаюцца аўтаматычна. Замест гэтага яны спасылаюцца на свой адрас у інтэрнэце. Так эканоміцца месца ў сховішчы, але выявы не будуць даступныя без інтэрнэту або калі адрас перастане працаваць.

Загрузіць выявы для любога файла ў Obsidian можна [[Меню каманд|камандай]] **Загрузіць далучэнні для бягучага файла**. Гэтай камандзе таксама можна прызначыць гарачую клавішу ў Obsidian.

## Гарачыя клавішы

У Web Clipper ёсць спалучэнні клавіш, якія паскараюць працу. Каб змяніць іх, перайдзіце ў **Web Clipper Settings** → **General** і выконвайце інструкцыі для свайго браўзера. Спалучэнні можна змяняць ва ўсіх браўзерах, акрамя Safari, які не падтрымлівае рэдагаванне гарачых клавіш.

| Дзеянне | macOS | Windows/Linux |
| --- | --- | --- |
| Адкрыць Clipper | `Cmd+Shift+O` | `Ctrl+Shift+O` |
| Хуткае захаванне | `Opt+Shift+O` | `Alt+Shift+O` |
| Уключыць/выключыць вылучэнне | `Opt+Shift+H` | `Alt+Shift+H` |
| Уключыць/выключыць рэжым чытання | `Opt+Shift+R` | `Alt+Shift+R` |

## Магчымасці інтэрфейсу

Інтэрфейс Web Clipper складаецца з чатырох частак:

1. **Загаловак** — тут можна пераключаць шаблоны, уключаць [[Вылучэнне|вылучэнне]] і [[Рэжым чытання|рэжым чытання]], а таксама адкрываць налады.
2. **Уласцівасці** — [[Уласцівасці|метаданыя]], здабытыя са старонкі, якія будуць захаваны ў Obsidian як [[Уласцівасці|уласцівасці]].
3. **Змесціва нататкі**, якое будзе захавана ў Obsidian.
4. **Ніжняя панэль** — тут можна выбраць сховішча і папку і дадаць нататку ў Obsidian.

У загалоўку ёсць:

- ![[lucide-chevrons-up-down.svg#icon]] Пераключальнік **Template**, каб выкарыстоўваць [[Шаблоны Web Clipper|шаблоны]], дададзеныя ў наладах пашырэння.
- ![[lucide-more-horizontal.svg#icon]] Кнопка **More**, якая паказвае зменныя старонкі для выкарыстання ў шаблонах.
- ![[lucide-highlighter.svg#icon]] Кнопка **Highlighter**, якая ўключае [[Вылучэнне|вылучэнне]].
- ![[lucide-book-icon.svg#icon]] Кнопка **Reader**, якая ўключае [[Рэжым чытання|рэжым чытання]].
- ![[lucide-picture-in-picture-2.svg#icon]] Кнопка **Embed**, якая перамяшчае Web Clipper з усплывальнага акна на старонку.
- ![[lucide-settings.svg#icon]] Кнопка **Settings**, якая адкрывае налады пашырэння.

На ніжняй панэлі ёсць:

- Кнопка **Add to Obsidian**, каб захаваць даныя ў Obsidian.
- Выпадальны спіс **Vault**, каб пераключацца паміж сховішчамі, дададзенымі ў наладах Web Clipper.
- Поле **Folder**, каб указаць папку для захавання.
- **Interpreter**, каб выконваць на старонцы [[Інтэрпрэтатар|запыты на натуральнай мове]].
