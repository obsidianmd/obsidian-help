[[Шаблоны Web Clipper|Шаблоны Web Clipper]] могуць выкарыстоўваць зменныя, каб аўтаматычна падстаўляць у шаблон даныя са старонкі. Зменныя можна выкарыстоўваць у **назве нататкі**, **месцы захавання нататкі**, **уласцівасцях** і **змесціве нататкі**. Таксама зменныя можна змяняць з дапамогай [[Фільтры|фільтраў]].

Каб убачыць зменныя бягучай старонкі для выкарыстання ў шаблонах, націсніце значок `...` у пашырэнні [[Уводзіны ў Obsidian Web Clipper|Web Clipper]]. Ёсць пяць тыпаў зменных:

- [[#Убудаваныя зменныя|Убудаваныя зменныя]]
- [[#Зменныя-запыты|Зменныя-запыты]]
- [[#Метазменныя|Метазменныя]]
- [[#Зменныя-селектары|Зменныя-селектары]]
- [[#Зменныя Schema.org|Зменныя Schema.org]]

## Убудаваныя зменныя

Убудаваныя зменныя ствараюцца аўтаматычна на аснове змесціва старонкі. Звычайна яны працуюць на большасці сайтаў.

Асноўная зменная змесціва — `{{content}}`. Яна змяшчае тэкст артыкула, [[Вылучэнне|вылучэнні]] або вылучаны фрагмент, калі на старонцы вылучаны тэкст. Улічвайце, што `{{content}}` спрабуе здабыць асноўнае змесціва старонкі, і гэта не заўсёды тое, што вам трэба. У такім выпадку выкарыстоўвайце іншыя ўбудаваныя зменныя або зменныя-селектары, каб здабыць патрэбнае змесціва.

| Зменная | Апісанне |
| --- | --- |
| `{{author}}`        | Аўтар старонкі |
| `{{content}}`       | Тэкст артыкула, [[Вылучэнне\|вылучэнні]] або вылучаны фрагмент у фармаце Markdown |
| `{{contentHtml}}`   | Тэкст артыкула, [[Вылучэнне\|вылучэнні]] або вылучаны фрагмент у фармаце HTML |
| `{{date}}`          | Бягучая дата; фармат можна змяніць фільтрам `date` |
| `{{description}}`   | Апісанне або ўрывак |
| `{{domain}}`        | Дамен |
| `{{favicon}}`       | URL значка сайта |
| `{{fullHtml}}`      | Неапрацаваны HTML усяго змесціва старонкі |
| `{{highlights}}`    | [[Вылучэнне\|Вылучэнні]] з тэкстам і часам стварэння |
| `{{image}}`         | URL выявы для сацыяльных сетак |
| `{{language}}`      | Мова старонкі |
| `{{model}}`         | Назва мадэлі [[Інтэрпрэтатар\|інтэрпрэтатара]] |
| `{{modelId}}`       | ID мадэлі [[Інтэрпрэтатар\|інтэрпрэтатара]] |
| `{{modelProvider}}` | Пастаўшчык мадэлі [[Інтэрпрэтатар\|інтэрпрэтатара]] |
| `{{published}}`     | Дата публікацыі; фармат можна змяніць фільтрам `date` |
| `{{selection}}`     | Вылучаны фрагмент у фармаце Markdown |
| `{{selectionHtml}}` | Вылучаны фрагмент у фармаце HTML |
| `{{site}}`          | Назва сайта або выдаўца |
| `{{title}}`         | Загаловак старонкі |
| `{{time}}`          | Бягучыя дата і час |
| `{{url}}`           | Бягучы URL |
| `{{words}}`         | Колькасць слоў |

## Зменныя-запыты

Зменныя-запыты выкарыстоўваюць моўныя мадэлі, каб здабываць і змяняць даныя з дапамогай натуральнай мовы. Для іх павінен быць уключаны і наладжаны [[Інтэрпрэтатар|інтэрпрэтатар]].

Зменныя-запыты запісваюцца так: `{{"a summary of the page"}}`. Падвойныя двукоссі вакол запыту важныя: яны адрозніваюць запыты ад убудаваных зменных. Адказы на запыты можна дадаткова апрацаваць [[Фільтры|фільтрамі]], напрыклад `{{"a summary of the page"|blockquote}}`.

### Калі выкарыстоўваць зменныя-запыты

Зменныя-запыты вельмі гнуткія і простыя ў напісанні, але маюць і недахопы: яны працуюць павольней, а таксама могуць каштаваць грошай і закранаць прыватнасць — у залежнасці ад выбранага [[Інтэрпрэтатар#Мадэлі|пастаўшчыка]].

У адрозненне ад іншых тыпаў зменных, зменныя-запыты апрацоўвае знешняя моўная мадэль, таму яны замяняюцца толькі пасля таго, як спрацуе [[Інтэрпрэтатар|інтэрпрэтатар]].

Лепш *не* выкарыстоўваць зменныя-запыты, калі патрэбныя даныя маюць сталы фармат і іх можна здабыць іншымі тыпамі зменных. 

З іншага боку, зменныя-запыты карысныя, калі патрэбныя даныя маюць *розны* фармат на розных сайтах. Напрыклад, можна зрабіць [[Шаблоны Web Clipper|шаблон]] для захавання кніг, які не залежыць ад кніжнага сайта. Зменныя-запыты накшталт `{{"author of the book"}}` будуць працаваць на любым кніжным сайце, тады як зменныя-селектары звычайна працуюць толькі на адным.

### Прыклады

У запытах можна выкарыстоўваць амаль любы запыт на натуральнай мове. У залежнасці ад мадэлі запыты могуць шукаць або перакладаць даныя на розныя мовы.

- `{{"a three bullet point summary, translated to French"}}` — каб атрымаць тры тэзісы пра старонку і перакласці іх на французскую.
- `{{"un resumé de la page en trois points"}}` — каб атрымаць тры тэзісы з дапамогай запыту на французскай мове.

Запыты могуць ператвараць змесціва старонкі ў JSON, які потым можна апрацаваць [[Фільтры|фільтрамі]]. Напрыклад:

```
{{"return a JSON object for each tweet, that includes the author, tweet_text, date in YYYY-MM-DD format, and images array (if there are any)"|map:tweet => ({text: tweet.tweet_text, author: tweet.author, date: tweet.date})|template:"${text}\n— [[@${author}]], [[${date}]]\n"}}
```


## Метазменныя

Метазменныя дазваляюць здабываць даныя з [мета-элементаў](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/meta) старонкі, у тым ліку даныя [Open Graph](https://ogp.me/), з якіх ствараюцца прадпрагляды для сацыяльных сетак.

- `{{meta:name}}` вяртае змесціва метатэга name з зададзенай назвай, напрыклад `{{meta:name:description}}` для метатэга `description`.
- `{{meta:property}}` вяртае змесціва метатэга property з зададзенай уласцівасцю, напрыклад `{{meta:property:og:title}}` для метатэга `og:title`.

## Зменныя-селектары

Зменныя-селектары дазваляюць здабываць тэкставае змесціва элементаў старонкі з дапамогай [CSS-селектараў](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_selectors/Selectors_and_combinators).

Сінтаксіс: `{{selector:cssSelector?attribute}}`, дзе `?attribute` неабавязковы. Калі атрыбут не ўказаны, вяртаецца тэкставае змесціва элемента. Каб атрымаць HTML-змесціва элемента, выкарыстоўвайце `{{selectorHtml:cssSelector}}`. Зменныя-селектары лепш за ўсё працуюць на пэўным сайце або групе сайтаў са сталай структурай HTML.

- `{{selector:h1}}` вяртае тэкставае змесціва ўсіх элементаў `h1` на старонцы.
- `{{selector:.author}}` вяртае тэкставае змесціва ўсіх элементаў `.author` на старонцы.
- `{{selector:img.hero?src}}` вяртае атрыбут `src` выявы з класам `hero`.
- `{{selector:a.main-link?href}}` вяртае атрыбут `href` спасылкі з класам `main-link`.
- `{{selectorHtml:body|markdown}}` вяртае ўвесь HTML элемента `body`, ператвораны ў Markdown [[Фільтры#Апрацоўка HTML|фільтрам]] `markdown`.
- Калі патрэбна большая дакладнасць, падтрымліваюцца ўкладзеныя CSS-селектары і камбінатары.
- Калі селектару адпавядае некалькі элементаў, вяртаецца масіў, які можна апрацаваць [[Фільтры#Масівы і аб'екты|фільтрамі для масіваў і аб'ектаў]], напрыклад `join` або `map`.

Зменныя-селектары таксама можна выкарыстоўваць непасрэдна ў [[Логіка|логіцы шаблона]]:

- У цыклах: `{% for comment in selector:.comment %}...{% endfor %}`
- Ва ўмовах: `{% if selector:.premium-badge %}...{% endif %}`
- Пры прысвойванні зменных: `{% set items = selector:.list-item %}`

## Зменныя Schema.org

Зменныя схемы дазваляюць здабываць даныя з JSON-LD [schema.org](https://schema.org/) на старонцы. Даныя Schema.org таксама можна выкарыстоўваць, каб аўтаматычна [[Шаблоны Web Clipper#Супадзенне па Schema.org|выбіраць шаблон]].

- `{{schema:@Type:key}}` вяртае значэнне ключа са схемы.
- `{{schema:@Type:parent.child}}` вяртае значэнне ўкладзенай уласцівасці.
- `{{schema:@Type:arrayKey}}` вяртае першы элемент масіву.
- `{{schema:@Type:arrayKey[index].property}}` вяртае элемент масіву з указаным індэксам.
- `{{schema:@Type:arrayKey[*].property}}` вяртае пэўную ўласцівасць усіх элементаў масіву.

Таксама можна выкарыстоўваць скарочаны запіс без указання тыпу схемы:

- `{{schema:author}}` знойдзе першую ўласцівасць `author` у любым тыпе схемы.
- `{{schema:name}}` знойдзе першую ўласцівасць `name` у любым тыпе схемы.

Скарочаны запіс асабліва зручны, калі вы не ведаеце або вам няважна, які менавіта тып схемы, але вядома назва ўласцівасці, якую вы шукаеце.

Укладзеныя ўласцівасці і доступ да масіваў таксама працуюць — як з указаннем `@Type` схемы, так і без яго:

- `{{schema:author.name}}` знойдзе першую ўласцівасць `author` і зверне да яе падуласцівасці `name`.
- `{{schema:author[0].name}}` зверне да `name` першага аўтара ў масіве аўтараў.
- `{{schema:author[*].name}}` верне масіў імёнаў усіх аўтараў.
