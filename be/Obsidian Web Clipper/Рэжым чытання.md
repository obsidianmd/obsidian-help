У [[Уводзіны ў Obsidian Web Clipper|Web Clipper]] ёсць убудаваны рэжым чытання **Reader**, які прыбірае з вэб-старонак усё лішняе і паказвае толькі асноўны тэкст артыкула ў чыстым і зручным для чытання выглядзе.

## Уключэнне рэжыму чытання

Уключыць Reader можна некалькімі спосабамі:

- ![[lucide-book-icon.svg#icon]] **Значок кнігі** на панэлі пашырэння.
- **Спалучэнне клавіш**, якое можна змяніць у наладах пашырэння.
- **Кантэкстнае меню** — праз правую кнопку мышы на старонцы, якую вы праглядаеце.

Таксама можна зрабіць так, каб кнопка пашырэння ![[obsidian.svg#icon]] адкрывала Reader адным націскам. У наладах Web Clipper перайдзіце ў **General** → **Behavior** → **Open behavior** і абярыце **Reader**.

Усімі пералічанымі спосабамі можна таксама выйсці з Reader і вярнуць першапачатковую старонку.

## Як гэта працуе

Reader здабывае са старонкі асноўнае змесціва. Першапачатковая старонка замяняецца чыстым выглядам для чытання, які ўключае:

- Загаловак артыкула, аўтара, дату публікацыі і дамен крыніцы.
- Асноўны тэкст артыкула з захаваннем выяў і фарматавання.
- Структуру ў бакавой панэлі для артыкулаў з некалькімі загалоўкамі.
- Падсвятленне сінтаксісу ў блоках кода.
- Зноскі, якія адкрываюцца ўсплывальным акном пры націсканні.

## Налада выгляду для чытання

Наладзіць Reader можна ў наладах пашырэння. Некаторыя параметры даступныя і ў самім рэжыме чытання праз значок ![[lucide-case-sensitive.svg#icon]].

| Параметр | Апісанне |
| --- | --- |
| Font | Дадайце шрыфты, усталяваныя ў вашай сістэме. |
| Font size | Змяніце памер тэксту. |
| Line&nbsp;height | Інтэрвал паміж радкамі. |
| Line&nbsp;width | Максімальная шырыня вобласці змесціва. |
| Appearance | Абярыце светлы або цёмны выгляд. |
| Theme | Абярыце колеры. |
| Custom CSS | Дадатковы CSS для старонкі. |
