[[匯入工具]]可讓你定義範本來控制從其他應用程式匯入筆記的方式。這表示你可以修改匯入筆記的標題、屬性和內容。

## 編輯匯入範本

選擇預覽上方的**編輯**來編輯預設範本。你可以編輯：

- 以行內標題顯示的筆記名稱。
- 筆記開頭的屬性。
- 筆記的 Markdown 內容。

選擇**儲存**以返回預覽。匯入工具會記住已編輯的行內範本，供未來使用相同格式的匯入使用。

你也可以從目前保管庫中的 Markdown 檔案載入範本。

## 預覽結果

預覽會顯示你所選資料中最多十個範例。使用箭頭按鈕在範例之間切換。匯入設定和範本的變更會在任何內容加入保管庫之前更新預覽。

部分附件、遠端項目和跨筆記參考在匯入執行前無法完全解析。在這些情況下，預覽可能會保留原始連結或顯示佔位符。

## 範本語法

匯入工具範本使用由變數、[[過濾設定]]和[[邏輯]]組成的語法。它使用與 [[Obsidian Web Clipper 簡介|Web Clipper]] 相同的 [Knap](https://github.com/obsidianmd/knap) 語法。

使用雙大括號插入變數，例如 `{{title}}`、`{{content}}` 或 `{{date}}`。變數可用於筆記名稱、屬性和內容中。

你可以使用[[過濾設定]]修改變數。例如使用 `{{date|date:"YYYY-MM-DD"}}` 來變更日期格式。使用[[邏輯]]來處理更進階的條件判斷、迴圈和變數指定。

## 變數

以下變數可在任何匯入工具範本中使用：

| 變數               | 說明                                                                                     |
| ---------------- | -------------------------------------------------------------------------------------- |
| `{{body}}`       | 不含屬性的 Markdown 本文（無前置中繼資料）。                                                            |
| `{{content}}`    | 套用所選範本之前的完整 Markdown。                                                                  |
| `{{ctime}}`      | 原始檔案的建立時間，以 ISO 8601 時間戳記表示；無法取得時為空值。                                                  |
| `{{date}}`       | 範本渲染時的目前日期和時間，以 ISO 8601 時間戳記表示。                                                       |
| `{{importer}}`   | 匯入工具 ID，例如 `keep`、`html` 或 `notion-api`。                                               |
| `{{folder}}`     | 最終的保管庫相對父資料夾。當筆記位於保管庫根目錄時為空值。                                                         |
| `{{mtime}}`      | 原始檔案的修改時間，以 ISO 8601 時間戳記表示；無法取得時為空值。                                                  |
| `{{noteName}}`   | 最終解析的筆記名稱，移除無效字元並為重複項目加上後綴之後的結果。                                                       |
| `{{path}}`       | 最終的保管庫相對路徑，包含 `.md` 副檔名。                                                               |
| `{{properties}}` | 包含前置中繼資料屬性的物件。                                                                         |
| `{{source}}`     | 包含產生的屬性和來源特定值的物件。                                                                      |
| `{{sourceId}}`   | 匯入工具提供的穩定來源識別碼；否則為空值。                                                                  |
| `{{time}}`       | `{{date}}` 的別名。                                                                        |
| `{{title}}`      | 清理和去重複之前的原始筆記標題。                                                                       |

## 屬性的來源值

對於支援[[屬性]]的匯入格式，來源值也可作為頂層變數直接使用，以方便存取。

如果來源值與共用變數名稱相同，請透過 `{{source}}` 存取。例如，如果你的匯入來源有一個名為 `content` 的屬性，可透過 `{{source.content}}` 存取，而 `{{content}}` 仍為預設的匯入工具變數。

當欄位名稱包含空格、標點符號或其他特殊字元時，請使用方括號表示法：

```twig
{{source["Project: status"]}}
```

## 範本範例

以下是使用變數和[[過濾設定]]的範本範例：

```twig
---
created: {{ctime | date:"YYYY-MM-DD"}}
modified: {{mtime | date:"YYYY-MM-DD"}}
source: {{importer}}
---
# {{title}}

{{body}}
```

你可以使用[[邏輯]]有條件地將資料加入筆記：

```twig
{% if tags %}
## 標籤
{% for tag in tags %}
- {{tag}}
{% endfor %}
{% endif %}
```
