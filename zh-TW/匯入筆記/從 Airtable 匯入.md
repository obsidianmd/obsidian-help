Obsidian 讓你可以使用[[匯入工具|匯入工具外掛]]從 Airtable 匯入資料。這會將你的 Airtable 資料庫轉換為持久的 Markdown 檔案，你可以在離線狀態下使用 Obsidian 及其他許多應用程式來操作這些檔案。

每個表格會成為一個筆記資料夾，每筆記錄對應一則筆記，另外還會產生一個[[資料庫介紹|資料庫]]檔案來重建表格及其檢視。由於使用了 Airtable API，匯入時需要個人存取權杖和網路連線。

## 建立 Airtable 個人存取權杖

要透過 API 存取你的 Airtable 資料，你需要一個個人存取權杖。此步驟大約需要兩分鐘完成。

權杖是一串由數字和字母組成的長字串，通常以 `pat...` 開頭，可讓你從 Airtable 下載你的資料。

1. 登入 Airtable 並前往帳號設定中的[個人存取權杖](https://airtable.com/create/tokens)頁面。
2. 選擇 **Create new token**。
3. 為你的權杖命名，例如「Obsidian」。可以使用任何名稱。
4. 在 **Scopes** 下，新增 `data.records:read` 和 `schema.bases:read`。
5. 在 **Access** 下，新增你要匯入的資料庫，或選擇工作區中的所有資料庫。
6. 選擇 **Create token**，然後 **Copy** 權杖。
7. 將權杖儲存到安全的地方，例如你的密碼管理器。

Airtable 只會顯示權杖一次。如果遺失了，請建立一個新的。

## 匯入你的 Airtable 資料

你需要官方的 Obsidian [[匯入工具]]外掛，你可以[在此安裝](obsidian://show-plugin?id=obsidian-importer)。

1. 開啟**[[設定]]**。
2. 前往**社群外掛程式**並[安裝匯入工具](obsidian://show-plugin?id=obsidian-importer)。
3. 啟用匯入工具外掛。
4. 使用命令面板或功能區圖示開啟**匯入工具**外掛。
5. 在**檔案格式**下選擇 **Airtable**。
6. 在 **Airtable Personal Access Token** 下，點選 **Link...** 以新增密鑰。在 **ID** 中輸入名稱，例如 `airtable`，在 **Secret** 中貼上你的個人存取權杖。
7. 點選**載入**來瀏覽你的資料庫，然後選擇你要匯入的表格。
8. 檢閱並編輯匯入選項。
9. 選擇**匯入**來設定你的欄位如何轉換為帶有[[屬性]]的筆記。
10. 選擇**繼續**來檢閱產生的範本並預覽你記錄中的範例。
11. 選擇**匯入**並等待匯入完成。

## 匯入選項

- **轉換公式** — 選擇公式、查閱、彙總和計數欄位是否要重寫為[[公式|資料庫公式]]，在沒有對應函式時則使用 Airtable 計算的值作為後備，或僅匯入為靜態值。
- **下載附件** — 將附件檔案儲存到你的保管庫中，使用你的附件資料夾和連結格式設定。停用時，或下載失敗時，筆記會連結到檔案在 Airtable 上的 URL。
- **檢視屬性名稱** — 記錄一筆記錄所屬 Airtable 檢視的屬性。產生的資料庫中的每個檢視都會依此屬性篩選。預設為 `Views`。
- **儲存 Airtable 記錄 ID** — 新增 `airtable-id` 屬性，使後續匯入可以在筆記被搬移或重新命名後仍能識別記錄。

## 設定 Airtable 欄位的匯入方式

在欄位設定步驟中，你可以選擇每個欄位的匯入方式。

預設情況下，每個 Airtable 欄位都會成為一個屬性。你可以在繼續到範本預覽之前重新命名或移除屬性並變更它們的值。

每個表格的主要欄位提供預設的筆記名稱。你可以在預覽步驟中編輯筆記名稱範本。記錄始終放在以其表格命名的資料夾中。

請參閱[[匯入工具範本]]來自訂產生的 Markdown。

## 匯入的內容

對於一個名為 `Projects` 並包含 `Tasks` 表格的資料庫，匯入工具會建立：

```
Airtable/
	Projects/
		Tasks.base
		Tasks/
			Write the proposal.md
			Review the draft.md
```

- 每筆記錄對應一則筆記，以主要欄位作為筆記標題，記錄的其他欄位作為[[屬性]]。
- 每個表格對應一個 `.base` 檔案，每個 Airtable 檢視會對應至一個[[檢視|資料庫檢視]]：
	- **Grid** 成為[[表格檢視]]。
	- **Gallery** 成為[[卡片檢視]]。
	- **List** 成為[[清單檢視]]。
	- **Kanban** 在 Obsidian 1.14 及更新版本中成為[[看板檢視]]。Airtable 不會指出看板依哪個欄位分組，因此匯入後請[[看板檢視#將卡片分組到欄位|選擇用於分組的屬性]]。再次匯入會保留你的選擇。
- Airtable 欄位類型會對應至 Obsidian 屬性類型，不會覆蓋你已設定的類型。
- 連結的記錄會成為指向對應筆記的連結。
- 附件會根據你的保管庫設定下載到保管庫中。


## 限制

由於 Airtable API 速率限制，匯入大型資料庫可能需要相當長的時間。請耐心等待。

由於 Airtable API 的限制，部分資料無法取得或轉換：

- 彙總值不會被匯入。API 不會公開彙總計算值所使用的聚合方式，因此只會寫入屬性名稱，以及在欄位結構公開運算式時附帶的資料庫公式。
- 使用 Obsidian 沒有對應函式的公式，例如 `SWITCH`、`FIND`、`REGEX_EXTRACT` 和 `SQRT`，會使用 Airtable 的靜態值作為後備。
- 只有 grid、gallery、list 和 kanban 檢視會被匯入。其他檢視類型，如日曆、時間軸和甘特圖，會被忽略。
- 連結到你未選擇匯入的表格中的記錄，會變成該記錄的純文字標題而非連結。
- 介面設計、自動化、評論和修訂歷史不會被匯入。
