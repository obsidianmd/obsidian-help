Obsidian 使用 Markdown `.md` 檔案作為筆記的主要格式。這使得將 Markdown 檔案匯入 Obsidian 變得十分容易。許多應用程式可以編輯 Markdown 檔案或匯出為此格式。

有幾種方式可以將 Markdown 檔案加入你的 Obsidian 保管庫：

1. 將檔案或資料夾拖放到[[檔案管理器]]視窗中
2. 使用系統的檔案瀏覽器（例如 Windows 檔案總管或 macOS 的 Finder），將檔案直接移動到 Obsidian 儲存庫的根目錄中。

## 使用 Importer 匯入 Markdown 檔案

當你想要在匯入時選擇資料夾、匯入 `.zip` 壓縮檔、標準化格式、將行內標籤移至[[屬性|屬性]]，或套用範本時，請使用官方的 [[匯入工具|Importer 外掛]]。

1. 開啟 **[[設定|設定]] → 社群外掛程式**，然後[安裝 Importer](obsidian://show-plugin?id=obsidian-importer)。
2. 啟用 Importer 外掛。
3. 在設定中開啟 Importer，或使用[[命令面板|命令面板]]開啟。
4. 在 **File format** 下，選擇 **Markdown (.md, .zip)**。
5. 選擇個別的 Markdown 檔案、資料夾或 zip 壓縮檔。
6. 檢視偵測到的資料夾、輸出選項、產生的範本和預覽範例。
7. 選擇 **Import** 並等待匯入完成。

參閱 [[匯入器模板]] 以自訂匯入的筆記名稱、屬性和內容。
