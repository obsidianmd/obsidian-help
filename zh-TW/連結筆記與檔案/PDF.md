Obsidian 使用內建檢視器開啟 PDF 檔案。你也可以在筆記中嵌入 PDF、連結到其中的段落，以及將任何筆記匯出為 PDF。關於 Obsidian 支援的檔案類型，請參閱[[支援的檔案格式]]。

> [!info]+ 部分功能僅限桌面版
> 行動裝置上的 Obsidian 應用程式無法在 PDF 內搜尋、複製引文或所選連結，也無法將筆記匯出為 PDF。

## 開啟 PDF

在[[檔案管理器]]中，選取一個 PDF 即可在分頁中開啟。

> [!info]+ 不支援註釋功能
> Obsidian 不支援在 PDF 中新增註釋或反白標記。若要標記 PDF，請使用其他應用程式，然後在保管庫中開啟更新後的檔案。

檢視器頂部有一個工具列，包含以下控制項。行動裝置上的 Obsidian 應用程式也有相同的工具列。

- **切換側邊欄**可顯示或隱藏側邊欄，而**側邊欄選項**可變更側邊欄顯示的內容。
- **縮小**和**放大**可變更頁面大小。
- **顯示選項**可變更頁面的排列方式。
- 頁碼欄位顯示目前頁面。輸入頁碼即可跳至該頁。

若要對 PDF 檔案本身進行操作（例如重新命名或搬移），請選取**更多選項** ![[lucide-more-horizontal.svg#icon]]。PDF 在此選單中的項目比筆記少。請參閱[[更多選項選單]]。

## 瀏覽 PDF

選取**側邊欄選項**，然後選擇要顯示的內容。

- **縮圖**顯示每頁的小型預覽。
- **目錄**顯示 PDF 的大綱（如果有的話）。
- **在目錄中顯示頁面**會在目錄中醒目提示目前頁面。

若要連結到某一頁，請右鍵點擊其縮圖，然後選取**複製第 N 頁的連結**，其中 N 為頁碼。將連結貼到筆記中即可。

若要連結到某個章節，請右鍵點擊目錄中的項目，然後選取**複製「標題」的連結**，其中「標題」為該項目的名稱。在行動裝置上，請長按該項目。

## 變更 PDF 的外觀

選取**顯示選項**以變更佈局。

- **符合寬度**和**符合高度**會將頁面調整至檢視器大小。
- **單頁**一次顯示一頁。
- **雙頁 (奇數頁)** 並排顯示頁面，左邊從奇數頁開始。例如，第 1 頁和第 2 頁一起顯示，接著是第 3 頁和第 4 頁。
- **雙頁 (偶數頁)** 並排顯示頁面，左邊從偶數頁開始。例如，第 1 頁單獨顯示，接著第 2 頁和第 3 頁一起顯示。
- **配合主題**會在 Obsidian 使用暗黑主題時將 PDF 的顏色調暗。

## 搜尋 PDF

在 PDF 內搜尋僅限桌面版使用。行動裝置上的 Obsidian 應用程式在 PDF 檢視器中沒有搜尋功能。

1. 按下 `Ctrl+F`（Windows 和 Linux）或 `Command+F`（macOS）。
2. 在**輸入並開始搜尋…**中，輸入你要尋找的文字。
3. 選取上或下方向箭頭以在結果之間移動。

若要變更搜尋方式，請使用以下選項。

- **區分大小寫**精確比對大寫和小寫字母。它是搜尋欄位中的 **Aa** 按鈕。
- **全部醒目提示**會醒目提示每個符合項目。選取方向箭頭旁的設定按鈕即可找到此選項。
- **讀音符號須相符**將帶有重音符號的字母視為不同的字母。此選項在同一個設定選單中。
- **全字拼寫須相符**僅尋找完整的單字。此選項在同一個設定選單中。

選取關閉按鈕以離開搜尋。

## 從 PDF 複製文字

在桌面版上，選取 PDF 中的文字，然後右鍵點擊。

- **複製**複製文字。
- **以引文複製**將文字作為引用複製，後面附帶一個指向該段落的連結。
- **複製所選連結**複製指向該段落的連結，方便你貼到筆記中。

當你將引文貼到筆記中時，看起來像這樣。

```md
> Obsidian is awesome

[[Gemmy.pdf#page=1&selection=32,0,32,14|Gemmy, page 1]]
```

所選連結則單獨包含相同的連結。

```md
[[Gemmy.pdf#page=1&selection=32,0,32,14|Gemmy, page 1]]
```

在行動裝置上，選取 PDF 中的文字會顯示裝置的標準文字選單。**以引文複製**和**複製所選連結**不可用。

## 嵌入 PDF

若要在筆記中顯示 PDF，請參閱如何[[嵌入檔案#在筆記中嵌入 PDF|在筆記中嵌入 PDF]]。嵌入的 PDF 擁有與檢視器相同的工具列。選取**編輯區塊**以變更嵌入連結。

## 將筆記匯出為 PDF

你可以在桌面版將任何筆記匯出為 PDF。行動裝置上的 Obsidian 應用程式不支援匯出為 PDF。

1. 開啟你要匯出的筆記。
2. 開啟[[命令面板]]並選取**匯出 PDF**。你也可以在筆記中選取**更多選項** ![[lucide-more-horizontal.svg#icon]]，然後選取**匯出 PDF**。
3. 選擇你的設定。
    - **將檔名作為標題**會在 PDF 頂部加入檔案名稱。
    - **紙張大小**設定紙張尺寸。你可以選擇 A3、A4、A5、Legal、Letter 或 Tabloid。
    - **橫向**將頁面轉為橫向。
    - **邊界**設定頁面邊界為**預設**、**最小**或**無**。
    - **縮小百分比**調整每頁內容的縮放比例。100 時內容保持原始大小。較低的值會使文字和圖片變小，讓每頁容納更多內容。
4. 選取**匯出 PDF**。
5. 選擇儲存檔案的位置。

> [!tip]- 使用暗黑主題匯出筆記
> 匯出時總是使用明亮樣式，即使你的主題是暗黑的。若要變更匯出的外觀，你可以使用 [[CSS 片段]]。Obsidian 論壇上有列印和匯出的程式碼片段範例。[^1]

[^1]: 請參閱 [How can I make export pdf look the same as my theme?](https://forum.obsidian.md/t/how-can-i-make-export-pdf-look-the-same-as-my-theme/75849) 和 [PDF and print style reset with code syntax highlighting](https://forum.obsidian.md/t/pdf-and-print-style-reset-with-code-syntax-highlighting/31761)。
