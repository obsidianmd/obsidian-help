連接器讓你輕鬆地將代理連接到 Obsidian，同時完全掌控你的資料所有權。Obsidian 連接器適用於多種應用程式，包括 Claude、ChatGPT、Antigravity、Cursor、GitHub Copilot、Grok Bot、Hermes、Kiro、Muse、OpenCode 以及[更多](https://agentskills.io/clients)。

這意味著你的代理可以學習如何：

- 使用 [[Obsidian 風格 Markdown]] 撰寫筆記，包括 [[內部連結|Wiki 連結]]、嵌入、標註塊和[[屬性|屬性]]。
- 建立與編輯[[資料庫介紹|資料庫]]和 [[Canvas]] 檔案。
- 透過 [[Obsidian CLI]] 在執行中的應用程式中搜尋、讀取和管理筆記。
- 使用 [[Obsidian Headless]] 在不需要桌面應用程式的情況下同步與發佈保管庫。

Obsidian 連接器與開放原始碼技能可在 [obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills) 取得。

## 安裝

你可以在代理應用程式的市集或外掛目錄中搜尋找到 Obsidian 連接器。你也可以將此頁面的連結發送給你的代理。

### Claude

從官方 Claude 外掛目錄新增 [Obsidian](https://claude.ai/customize/plugins/id/a38fa062-ebd3-48e0-9a0a-1875a6e94ad5%40anthropic-plugin-directory)。

若使用 Claude Code CLI：

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

之後要取得新技能，執行 `claude plugin update obsidian@obsidian-skills`。

### ChatGPT

從 ChatGPT 外掛目錄新增 [Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096)。此外掛適用於 ChatGPT、Codex 和 Dots。

### Antigravity

在 Antigravity CLI 中執行：

```shell
agy plugin install https://github.com/obsidianmd/obsidian-skills
```

### Grok Bot

開啟 [Obsidian for Grok Bot](https://x.ai/bot/plugin/88871845) 並選擇 **Add to Grok Bot**。

### Muse

要求 Muse 從 https://github.com/obsidianmd/obsidian-skills 安裝技能。

Muse 在 Meta 的雲端執行，因此 `obsidian-cli` 技能無法在此環境中運作。如果你在 Muse 中使用 Obsidian Headless，你將在 Meta 的雲端登入並同步你的保管庫。

### Cursor

從 Cursor Marketplace 安裝 [Obsidian](https://cursor.com/marketplace/obsidian)。

### Hermes Agent

從 Hermes Marketplace 安裝 [Obsidian](https://hermes-agent.nousresearch.com/marketplace/obsidian)，或執行：

```shell
hermes plugins install obsidian
```

### Kiro

```shell
kiro-cli powers install obsidian
```

### GitHub Copilot、OpenCode 及其他代理

使用 [npx skills](https://github.com/vercel-labs/skills) 安裝，它會詢問要安裝到哪些代理：

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

若要手動安裝，將 `plugins/obsidian/skills/` 中的資料夾複製到代理的技能資料夾，例如 GitHub Copilot 的 `~/.copilot/skills/`。

## 包含的技能

| 技能               | 功能說明                                                                                                                  |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `obsidian-markdown` | 建立與編輯 [[Obsidian 風格 Markdown]] 筆記。                                                                         |
| `obsidian-bases`    | 建立與編輯[[資料庫語法|資料庫]]，支援檢視、過濾設定、公式和摘要。                                         |
| `json-canvas`       | 使用 [JSON Canvas](https://jsoncanvas.org/) 格式建立與編輯 [[Canvas]] 檔案。                                     |
| `obsidian-cli`      | 透過 [[Obsidian CLI]] 與你的保管庫互動，包括外掛和主題開發。                                    |
| `obsidian-headless` | 使用 [[Obsidian Headless]] 從命令列同步與發佈保管庫。                                                     |
| `defuddle`          | 使用 [Defuddle](https://github.com/kepano/defuddle) 從網頁中擷取乾淨的 Markdown。                                   |
| `knap`              | 使用 [Knap](https://github.com/obsidianmd/knap) 從 JSON 或 CSV 資料渲染 Markdown 範本。                             |

## 需求

`obsidian-cli` 技能需要 Obsidian 桌面應用程式在執行中，且已[[Obsidian CLI#安裝 Obsidian CLI|開啟 Obsidian CLI]]，以及一個能在你的電腦上執行命令的代理。

Markdown、資料庫和 Canvas 技能僅描述檔案格式，因此它們可在任何能讀寫保管庫中檔案的代理中運作。

Defuddle、Knap 和 Obsidian Headless 是獨立工具，不與技能捆綁在一起。當缺少某個工具時，技能會在從 npm 安裝前先詢問。

## 隱私

Obsidian 連接器本身不會發送任何內容。當代理使用它們時，它讀取的筆記會成為對話的一部分，並由你使用的 AI 模型處理。在將代理指向包含敏感筆記的保管庫之前，請先查閱你所使用代理的隱私政策。
