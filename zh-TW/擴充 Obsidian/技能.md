Obsidian Skills 是教導 AI 代理如何使用 Obsidian 的指令。它們遵循開放的 [Agent Skills](https://agentskills.io/specification) 格式，因此可以在任何支援技能的代理上運作，包括 Claude Code、Claude、ChatGPT、Antigravity、Cursor、GitHub Copilot、Grok Bot、Hermes Agent、OpenCode，以及[更多代理](https://agentskills.io/clients)。

透過 Obsidian Skills，代理可以：

- 使用 [[Obsidian 風格 Markdown]] 撰寫筆記，包含 [[內部連結|Wiki 連結]]、嵌入、標註塊和[[屬性|屬性]]。
- 建立和編輯[[資料庫介紹|資料庫]]與 [[Canvas]] 檔案。
- 透過 [[Obsidian CLI]] 在執行中的應用程式中搜尋、讀取和管理筆記。
- 使用 [[Obsidian Headless]] 在不開啟桌面應用程式的情況下同步和發佈保管庫。

這些技能以開放原始碼形式發佈於 [obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills)。

## 安裝

Obsidian 是 Claude、ChatGPT、Dots、Cursor、Grok Bot 和 Hermes 的官方外掛。大多數其他代理可以從 GitHub 安裝技能。

### Claude

從 Claude 官方外掛目錄中新增 [Obsidian](https://claude.ai/customize/plugins/id/a38fa062-ebd3-48e0-9a0a-1875a6e94ad5%40anthropic-plugin-directory)。

若使用 Claude Code CLI，請執行：

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

之後若要取得新技能，請執行 `claude plugin update obsidian@obsidian-skills`。

### ChatGPT

從 ChatGPT 外掛目錄中新增 [Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096)。該外掛在 ChatGPT、Codex 和 Dots 中均可使用。

### Antigravity

在 Antigravity CLI 中執行：

```shell
agy plugin install https://github.com/obsidianmd/obsidian-skills
```

### Grok Bot

開啟 [Obsidian for Grok Bot](https://x.ai/bot/plugin/88871845) 並選擇 **Add to Grok Bot**。

### Cursor

從 Cursor Marketplace 安裝 [Obsidian](https://cursor.com/marketplace/obsidian)。

### Hermes Agent

```shell
hermes plugins install obsidian
```

### GitHub Copilot、OpenCode 及其他代理

使用 [npx skills](https://github.com/vercel-labs/skills) 安裝，它會詢問你要安裝到哪些代理中：

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

若要手動安裝，請將 `plugins/obsidian/skills/` 中的資料夾複製到你的代理技能資料夾中，例如 GitHub Copilot 的 `~/.copilot/skills/`。

## 包含的技能

| 技能               | 功能                                                                                                                  |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `obsidian-markdown` | 建立和編輯 [[Obsidian 風格 Markdown]] 筆記。                                                                         |
| `obsidian-bases`    | 建立和編輯[[資料庫語法|資料庫]]，包含檢視、過濾設定、公式和摘要。                                         |
| `json-canvas`       | 使用 [JSON Canvas](https://jsoncanvas.org/) 格式建立和編輯 [[Canvas]] 檔案。                                     |
| `obsidian-cli`      | 透過 [[Obsidian CLI]] 與你的保管庫互動，包括外掛和主題開發。                                    |
| `obsidian-headless` | 使用 [[Obsidian Headless]] 從命令列同步和發佈保管庫。                                                     |
| `defuddle`          | 使用 [Defuddle](https://github.com/kepano/defuddle) 從網頁中擷取乾淨的 Markdown。                                   |
| `knap`              | 使用 [Knap](https://github.com/obsidianmd/knap) 從 JSON 或 CSV 資料渲染 Markdown 範本。                             |

## 需求

`obsidian-cli` 技能需要 Obsidian 桌面應用程式正在執行且已[[Obsidian CLI#安裝 Obsidian CLI|開啟 Obsidian CLI]]，以及一個能在你電腦上執行命令的代理。

Markdown、資料庫和 Canvas 技能只描述檔案格式，因此在任何能讀寫保管庫檔案的代理中都可運作。

Defuddle、Knap 和 Obsidian Headless 是獨立的工具，不隨技能一起提供。當缺少某個工具時，技能會在從 npm 安裝前先詢問確認。

## 隱私

Obsidian Skills 本身不會傳送任何資料。當代理使用它們時，它所讀取的筆記會成為對話的一部分，並由你使用的 AI 模型處理。在將代理指向包含敏感筆記的保管庫之前，請先查閱你的代理隱私政策。
