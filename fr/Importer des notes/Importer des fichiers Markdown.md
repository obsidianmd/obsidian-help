Obsidian utilise des fichiers Markdown `.md` comme format principal pour les notes. Cela facilite l'importation de fichiers Markdown dans Obsidian. De nombreuses applications peuvent éditer des fichiers Markdown ou exporter vers ce format.

Il existe plusieurs façons d'ajouter des fichiers Markdown à votre coffre Obsidian :

1. Glisser-déposer des fichiers ou des dossiers dans la fenêtre de l'[[Explorateur de fichiers]]
2. Utiliser le gestionnaire de fichiers de votre système (par exemple l'Explorateur Windows ou le Finder sur macOS), et déplacer vos fichiers directement dans le dossier du coffre Obsidian.

## Importer des fichiers Markdown avec Importer

Utilisez le [[Importer|module Importer]] officiel lorsque vous souhaitez sélectionner des dossiers au sein d'une importation, importer une archive `.zip`, standardiser le formatage, déplacer les mots-clés en ligne vers les [[Propriétés|propriétés]], ou appliquer un modèle.

1. Ouvrez **[[Paramètres|Paramètres]] → Modules complémentaires** et [installez Importer](obsidian://show-plugin?id=obsidian-importer).
2. Activez le module Importer.
3. Ouvrez **Importer** en utilisant la [[Palette de commandes|palette de commandes]] ou l'icône du ruban.
4. Sous **Format de fichier**, sélectionnez **Markdown (.md, .zip)**.
5. Choisissez des fichiers Markdown individuels, des dossiers ou des archives zip.
6. Vérifiez les dossiers détectés, les options de sortie, le modèle généré et les exemples de prévisualisation.
7. Sélectionnez **Importer** et attendez la fin de l'importation.

Consultez [[Importer des modèles|Modèles d'importation]] pour personnaliser le nom de la note importée, les propriétés et le contenu.
