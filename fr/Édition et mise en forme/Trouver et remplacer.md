Utilisez Trouver et remplacer pour rechercher à l'intérieur de la note active. Pour rechercher dans l'ensemble de votre coffre, utilisez [[Rechercher]].

## Ouvrir Trouver et remplacer

- Pour chercher du texte dans la note active, ouvrez la [[Palette de commandes]] et sélectionnez **Rechercher dans le fichier courant**.
- Pour chercher et remplacer du texte dans la note active, sélectionnez **Rechercher & remplacer dans le fichier courant** depuis la palette de commandes.
- Vous pouvez aussi sélectionner **Plus d'options** ![[lucide-more-horizontal.svg#icon]] dans la note, puis sélectionner **Chercher...** ou **Remplacer...**. Voir [[Menu Plus d'options]].

> [!tip]- Raccourcis clavier
> Voici les raccourcis clavier par défaut.
>
> - `Ctrl+F` (Windows et Linux) ou `Command+F` (macOS) pour **Rechercher dans le fichier courant**.
> - `Ctrl+H` (Windows et Linux) ou `Command+Option+F` (macOS) pour **Rechercher & remplacer dans le fichier courant**.
>
> Vous pouvez les modifier dans [[Raccourcis clavier]].

## Trouver des correspondances

1. Lancez une recherche en utilisant l'une des méthodes ci-dessus.
2. Saisissez le texte que vous souhaitez rechercher.
3. Sélectionnez **Précédent** ou **Suivant** pour naviguer entre les correspondances.
4. Sélectionnez **Trouver tout** pour sélectionner toutes les correspondances dans la note active.

## Remplacer des correspondances

1. Lancez un remplacement en utilisant l'une des méthodes ci-dessus.
2. Dans le champ **Chercher...**, saisissez le texte que vous souhaitez remplacer.
3. Dans le champ **Remplacer...**, saisissez le texte de remplacement.
4. Sélectionnez **Remplacer** pour remplacer la correspondance actuelle, ou **Remplacer tout** pour remplacer toutes les correspondances dans la note active.
