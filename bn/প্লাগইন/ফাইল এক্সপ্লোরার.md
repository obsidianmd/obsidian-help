ফাইল এক্সপ্লোরার একটি [[কোর প্লাগইন|কোর প্লাগইন]] যা আপনাকে আপনার ভল্টের ভেতরে ফাইল এবং ফোল্ডার পরিচালনা করতে দেয়। আপনি আপনার ভল্টে নোট এবং অন্যান্য [[গ্রহণযোগ্য ফাইল ফরম্যাট]] ব্রাউজ করতে পারেন এবং অনেক সাধারণ ফাইল অপারেশন সম্পাদন করতে পারেন:

- ফাইল এবং ফোল্ডার তৈরি, মোছা এবং নাম পরিবর্তন করুন।
- ড্র্যাগ অ্যান্ড ড্রপ দিয়ে ফাইল এবং ফোল্ডার সরান।
- সব উপলব্ধ অপারেশনে প্রবেশের জন্য [[#কনটেক্সট মেনু ব্যবহার করুন|কনটেক্সট মেনু]] ব্যবহার করুন।

> [!tip]- ফাইল ড্র্যাগ অ্যান্ড ড্রপ করুন
> আপনি একটি লিঙ্ক তৈরি করতে ফাইল এক্সপ্লোরার থেকে একটি ফাইল আপনার নোটে টেনে আনতে পারেন, অথবা এটি কপি করতে ফাইল এক্সপ্লোরারে একটি ফাইলকে একটি ফোল্ডারে টেনে আনতে পারেন।

## একটি নতুন নোট তৈরি করুন

নতুন নোটের জন্য ডিফল্ট অবস্থানে একটি নতুন নোট তৈরি করতে:

1. ফাইল এক্সপ্লোরারের উপরে **New note** ![[lucide-pen-line.svg#icon]] নির্বাচন করুন।
2. নোটের নাম টাইপ করুন, এবং তারপর `Enter` চাপুন।

> [!tip]- ডিফল্ট অবস্থান পরিবর্তন করুন
> আপনি **[[সেটিংস]] → [[সেটিংস#Files and links|Files and links]] → [[সেটিংস#Default location for new notes|Default location for new notes]]**-এর অধীনে নতুন নোটের জন্য ডিফল্ট অবস্থান পরিবর্তন করতে পারেন।

একটি নির্দিষ্ট ফোল্ডারে একটি নতুন নোট তৈরি করতে:

1. ফোল্ডারে ডান-ক্লিক করুন এবং তারপর **New note** নির্বাচন করুন।
2. নোটের নাম টাইপ করুন, এবং তারপর `Enter` চাপুন।

## একটি নতুন ফোল্ডার তৈরি করুন

আপনার ভল্টের রুটে একটি নতুন ফোল্ডার তৈরি করতে:

1. ফাইল এক্সপ্লোরারের উপরে **New folder** ![[lucide-folder-plus.svg#icon]] নির্বাচন করুন।
2. ফোল্ডারের নাম টাইপ করুন, এবং তারপর `Enter` চাপুন।

একটি সাবফোল্ডার তৈরি করতে:

1. আপনি যে ফোল্ডারে সাবফোল্ডার তৈরি করতে চান সেখানে ডান-ক্লিক করুন, এবং তারপর **New folder** নির্বাচন করুন।
2. ফোল্ডারের নাম টাইপ করুন, এবং তারপর `Enter` চাপুন।

## সাজানোর ক্রম পরিবর্তন করুন

আপনার ফাইলগুলির সাজানোর ক্রম পরিবর্তন করতে:

1.  ফাইল এক্সপ্লোরারের উপরে **Change sort order** ![[lucide-arrow-up-narrow-wide.svg#icon]] নির্বাচন করুন।
2. আপনি কীভাবে আপনার ফাইলগুলি সাজাতে চান তা বেছে নিন। আপনি ফাইলের নাম, পরিবর্তনের সময়, বা তৈরির সময় অনুযায়ী ঊর্ধ্বক্রম বা নিম্নক্রমে সাজাতে পারেন।

## সক্রিয় ফাইল স্বয়ংক্রিয়ভাবে প্রকাশ করুন

আপনি একটি নোট খুললে, ফাইল এক্সপ্লোরার স্বয়ংক্রিয়ভাবে ফোল্ডার ট্রিতে সেই নোটে স্ক্রল করে এবং হাইলাইট করতে পারে। এটি আপনাকে আপনার ভল্টের ভেতরে আপনার সক্রিয় নোট কোথায় অবস্থিত তা ট্র্যাক রাখতে সহায়তা করে।

স্বয়ংক্রিয়-প্রকাশ টগল করতে:

- ফাইল এক্সপ্লোরারের উপরে **Auto-reveal active file** ![[lucide-gallery-vertical.svg#icon]] নির্বাচন করুন।

সক্রিয় থাকলে, ফাইল এক্সপ্লোরার স্বয়ংক্রিয়ভাবে সক্রিয় নোটটি অনুসরণ করবে এবং প্রকাশ করবে।

## সব ফোল্ডার প্রসারিত বা সংকুচিত করুন

আপনি একবারে ফাইল এক্সপ্লোরারের সব ফোল্ডার প্রসারিত বা সংকুচিত করতে পারেন।

সব ফোল্ডার প্রসারিত করতে:

- ফাইল এক্সপ্লোরারের উপরে **Expand all** ![[lucide-chevrons-up-down.svg#icon]] নির্বাচন করুন।

সব ফোল্ডার সংকুচিত করতে:

- ফাইল এক্সপ্লোরারের উপরে **Collapse all** ![[lucide-chevrons-down-up.svg#icon]] নির্বাচন করুন।

## একটি ফাইল বা ফোল্ডার মুছুন

1. আপনি যে ফাইলটি মুছতে চান সেটিতে ডান-ক্লিক করুন, এবং তারপর **Delete** নির্বাচন করুন।
2. আপনি ফাইলটি মুছতে চান কিনা তা নিশ্চিত করতে বলা হলে, **Delete** নির্বাচন করুন।

আরও তথ্যের জন্য, [[নোট পরিচালনা#Delete a note|একটি নোট মুছুন]] দেখুন।

## একটি ফাইল বা ফোল্ডারের নাম পরিবর্তন করুন

1. আপনি যে ফাইলটির নাম পরিবর্তন করতে চান সেটিতে ডান-ক্লিক করুন, এবং তারপর **Rename** নির্বাচন করুন।
2. নতুন নাম টাইপ করুন, এবং তারপর `Enter` চাপুন।

আরও তথ্যের জন্য, [[নোট পরিচালনা#Rename a note|একটি নোটের নাম পরিবর্তন করুন]] দেখুন।

## একটি ফাইল বা ফোল্ডার সরান

একটি ফাইল বা ফোল্ডার সরাতে, আপনি ড্র্যাগ-অ্যান্ড-ড্রপ বা কনটেক্সট মেনু ব্যবহার করতে পারেন।

**ড্র্যাগ অ্যান্ড ড্রপ:**

- একটি ফাইল বা ফোল্ডার যেখানে সরাতে চান সেই ফোল্ডারে টেনে আনুন।
- `Alt-Click` (Windows/Linux) বা `Opt-Click` (macOS) দিয়ে আপনি একাধিক পৃথক ফাইল নির্বাচন করে অন্য ফোল্ডারে টেনে আনতে পারেন। যদি সেগুলি সব একটি সারিতে থাকে, তাহলে আপনি এর জন্য `Shift-Click` ব্যবহার করতে পারেন।

**কনটেক্সট মেনু:**

1. একটি ফাইলে ডান-ক্লিক করুন, এবং তারপর **Move file to...** নির্বাচন করুন।
2. আপনি যে ফোল্ডারে ফাইলটি সরাতে চান তার নাম খুঁজুন, এবং তারপর তালিকা থেকে সেটি নির্বাচন করুন।

## কনটেক্সট মেনু ব্যবহার করুন

কনটেক্সট মেনু একটি ফাইল বা ফোল্ডারের জন্য উপলব্ধ ক্রিয়াগুলি তালিকাভুক্ত করে। ফাইল আইটেমগুলির অনেকগুলি [[আরও অপশন মেনু]]-তেও দেখা যায়।

### ডেস্কটপ

ফাইল এক্সপ্লোরারে একটি ফাইল বা ফোল্ডারে ডান-ক্লিক করুন।

**ফাইল**

- **Open in new tab** এবং **Open to the right** ফাইলটি একটি নতুন ট্যাবে বা ডান পাশে একটি প্যানে খোলে।
- **Open in new window** ফাইলটি তার নিজস্ব উইন্ডোতে খোলে। [[পপ-আউট উইন্ডো]] দেখুন।
- **Duplicate** ফাইলটির একটি কপি তৈরি করে।
- **Move file to...** ফাইলটি অন্য ফোল্ডারে সরায়। [[#একটি ফাইল বা ফোল্ডার সরান]] দেখুন।
- **Bookmark...** ফাইলটি আপনার বুকমার্কে যোগ করে। এটির জন্য Bookmarks প্লাগইন প্রয়োজন। [[বুকমার্ক#Add a bookmark]] দেখুন।
- **Merge entire file with...** নোটটিকে অন্য একটির সাথে একত্রিত করে। এটির জন্য Note composer প্লাগইন প্রয়োজন। [[নোট কম্পোজার#Merge notes]] দেখুন।
- **Publish current file** নোটটি আপনার সাইটে প্রকাশ করে। এটির জন্য Obsidian Publish প্রয়োজন। [[Obsidian Publish পরিচিতি|Publish]] দেখুন।
- **Copy path** ফাইলের অবস্থান একটি Obsidian URL, ভল্ট ফোল্ডার থেকে, বা সিস্টেম রুট থেকে কপি করে।
- **Open version history** ফাইলের পূর্ববর্তী সংস্করণগুলি দেখায়। এটির জন্য একটি সক্রিয় Obsidian Sync সাবস্ক্রিপশন প্রয়োজন। [[ভার্সন ইতিহাস]] দেখুন।
- **Open in default app** ফাইলটি আপনার কম্পিউটার সেই ফাইল টাইপের জন্য যে অ্যাপ ব্যবহার করে সেটিতে খোলে।
- **Reveal in Filesystem** ফাইলটি আপনার ফাইল ম্যানেজারে দেখায়। macOS-এ, এই আইটেমটি **Reveal in Finder** হিসেবে দেখায়। Windows এবং Linux-এ, এটি **Show in system explorer** হিসেবে দেখায়।
- **Rename...** ফাইলের নাম পরিবর্তন করে। [[#একটি ফাইল বা ফোল্ডারের নাম পরিবর্তন করুন]] দেখুন।
- **Delete** ফাইলটি মুছে ফেলে। [[#একটি ফাইল বা ফোল্ডার মুছুন]] দেখুন।

**ফোল্ডার**

- **New note** এবং **New folder** ফোল্ডারের ভেতরে একটি নোট বা ফোল্ডার তৈরি করে। [[#একটি নতুন নোট তৈরি করুন]] এবং [[#একটি নতুন ফোল্ডার তৈরি করুন]] দেখুন।
- **New canvas** ফোল্ডারে একটি ক্যানভাস তৈরি করে। [[Canvas]] দেখুন।
- **New base** ফোল্ডারে একটি বেস তৈরি করে। [[বেসেস পরিচিতি]] দেখুন।
- **Duplicate** ফোল্ডারের একটি কপি তৈরি করে।
- **Move folder to...** ফোল্ডারটি অন্য ফোল্ডারে সরায়।
- **Search in folder** শুধুমাত্র ফোল্ডারের ফাইলগুলিতে অনুসন্ধান করে। [[অনুসন্ধান]] দেখুন।
- **Bookmark...** ফোল্ডারটি আপনার বুকমার্কে যোগ করে।
- **Copy path** ভল্ট ফোল্ডার থেকে বা সিস্টেম রুট থেকে ফোল্ডারের অবস্থান কপি করে।
- **Reveal in Filesystem** ফোল্ডারটি আপনার ফাইল ম্যানেজারে দেখায়, এবং ফাইলের মতোই একই নামে দেখায়।
- **Rename...** এবং **Delete** ফোল্ডারের নাম পরিবর্তন করে বা ফোল্ডার মুছে ফেলে।

### মোবাইল

ফাইল এক্সপ্লোরারে একটি ফোল্ডারে টিপে ধরে রাখুন। মেনুতে ডেস্কটপ ফোল্ডার মেনুর মতো একই আইটেম রয়েছে, **Bookmark...** এবং **Reveal in Filesystem** ব্যতীত।
