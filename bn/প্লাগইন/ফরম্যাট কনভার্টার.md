Markdown ফরম্যাট ইম্পোর্টার [[প্রপার্টি#ডেপ্রিকেটেড প্রপার্টি|ডেপ্রিকেটেড প্রপার্টি ফরম্যাটগুলিকে]] Obsidian-এর বর্তমান ফরম্যাটে রূপান্তর করে।

> [!warning] আপনার ভল্ট ব্যাকআপ করুন
> রূপান্তর আপনার সম্পূর্ণ ভল্টে প্রযোজ্য। শুরু করার আগে [[আপনার Obsidian ফাইল ব্যাকআপ করুন]]।

আপনার নোটের প্রপার্টি রূপান্তর করতে:

1. [[কমান্ড প্যালেট]] খুলুন।
2. **Format converter: Frontmatter migration** নির্বাচন করুন।
3. **Start conversion** নির্বাচন করুন।

## সমর্থিত প্রপার্টি ফরম্যাট

ইম্পোর্টারটি ডেপ্রিকেটেড ফরম্যাট থেকে aliases, tags এবং CSS classes আপডেট করে:

**Aliases**

```yaml
# Before

alias: My Note Title

# After

aliases:
  - My Note Title
```

**Tags**

```yaml
# Before

tag: project, important

# After

tags:
  - project
  - important
```

**CSS Classes**

```yaml
# Before

cssclass: custom-style

# After

cssclasses:
  - custom-style
```
