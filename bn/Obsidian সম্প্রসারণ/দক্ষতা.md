Obsidian Skills হলো নির্দেশাবলী যা AI এজেন্টদের Obsidian-এর সাথে কাজ করতে শেখায়। এগুলো ওপেন [Agent Skills](https://agentskills.io/specification) ফরম্যাট অনুসরণ করে, তাই দক্ষতা সমর্থন করে এমন যেকোনো এজেন্টের সাথে কাজ করে, যার মধ্যে রয়েছে Claude Code, Claude, ChatGPT, Antigravity, Cursor, GitHub Copilot, Grok Bot, Hermes Agent, OpenCode, এবং [আরো অনেক](https://agentskills.io/clients)।

Obsidian Skills-এর মাধ্যমে একটি এজেন্ট পারে:

- [[Obsidian Flavored Markdown]]-এ নোট লিখতে, [[ইন্টারনাল লিঙ্ক|উইকিলিঙ্ক]], এম্বেড, কলআউট, এবং [[প্রপার্টি|প্রপার্টি]] সহ।
- [[বেসেস পরিচিতি|বেসেস]] এবং [[Canvas]] ফাইল তৈরি ও সম্পাদনা করতে।
- চলমান অ্যাপে [[Obsidian CLI]] দিয়ে নোট অনুসন্ধান, পড়া এবং পরিচালনা করতে।
- [[Obsidian Headless]] ব্যবহার করে ডেস্কটপ অ্যাপ ছাড়াই ভল্ট সিঙ্ক ও প্রকাশ করতে।

দক্ষতাসমূহ ওপেন সোর্স, পাওয়া যাবে [obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills)-এ।

## ইনস্টল

Obsidian হলো Claude, ChatGPT, Dots, Cursor, Grok Bot, এবং Hermes-এর একটি অফিসিয়াল প্লাগইন। অন্যান্য বেশিরভাগ এজেন্ট GitHub থেকে দক্ষতাসমূহ ইনস্টল করতে পারে।

### Claude

অফিসিয়াল Claude প্লাগইন ডিরেক্টরি থেকে [Obsidian](https://claude.ai/customize/plugins/id/a38fa062-ebd3-48e0-9a0a-1875a6e94ad5%40anthropic-plugin-directory) যোগ করুন।

Claude Code CLI-এর জন্য ব্যবহার করুন:

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

পরে নতুন দক্ষতা পেতে, `claude plugin update obsidian@obsidian-skills` চালান।

### ChatGPT

ChatGPT প্লাগইন ডিরেক্টরি থেকে [Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096) যোগ করুন। প্লাগইনটি ChatGPT, Codex, এবং Dots-এ কাজ করে।

### Antigravity

Antigravity CLI-তে চালান:

```shell
agy plugin install https://github.com/obsidianmd/obsidian-skills
```

### Grok Bot

[Obsidian for Grok Bot](https://x.ai/bot/plugin/88871845) খুলুন এবং **Add to Grok Bot** নির্বাচন করুন।

### Cursor

Cursor Marketplace থেকে [Obsidian](https://cursor.com/marketplace/obsidian) ইনস্টল করুন।

### Hermes Agent

```shell
hermes plugins install obsidian
```

### GitHub Copilot, OpenCode, এবং অন্যান্য এজেন্ট

[npx skills](https://github.com/vercel-labs/skills) দিয়ে ইনস্টল করুন, যা জিজ্ঞেস করবে কোন এজেন্টে ইনস্টল করতে হবে:

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

ম্যানুয়ালি ইনস্টল করতে, `plugins/obsidian/skills/`-এর ফোল্ডারগুলো আপনার এজেন্টের দক্ষতা ফোল্ডারে কপি করুন, যেমন GitHub Copilot-এর জন্য `~/.copilot/skills/`।

## অন্তর্ভুক্ত দক্ষতাসমূহ

| দক্ষতা               | এটি কী করে                                                                                                                  |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `obsidian-markdown` | [[Obsidian Flavored Markdown]] নোট তৈরি ও সম্পাদনা করুন।                                                                         |
| `obsidian-bases`    | ভিউ, ফিল্টার, ফর্মুলা, এবং সারাংশ সহ [[বেসেস সিনট্যাক্স\|বেসেস]] তৈরি ও সম্পাদনা করুন।                                         |
| `json-canvas`       | [JSON Canvas](https://jsoncanvas.org/) ফরম্যাট ব্যবহার করে [[Canvas]] ফাইল তৈরি ও সম্পাদনা করুন।                                     |
| `obsidian-cli`      | প্লাগইন ও থিম ডেভেলপমেন্ট সহ [[Obsidian CLI]]-এর মাধ্যমে আপনার ভল্টের সাথে ইন্টারঅ্যাক্ট করুন।                                    |
| `obsidian-headless` | [[Obsidian Headless]] দিয়ে কমান্ড লাইন থেকে ভল্ট সিঙ্ক ও প্রকাশ করুন।                                                     |
| `defuddle`          | [Defuddle](https://github.com/kepano/defuddle) ব্যবহার করে ওয়েব পেজ থেকে পরিষ্কার Markdown বের করুন।                                   |
| `knap`              | [Knap](https://github.com/obsidianmd/knap) ব্যবহার করে JSON বা CSV ডেটা থেকে Markdown টেমপ্লেট রেন্ডার করুন।                             |

## প্রয়োজনীয়তা

`obsidian-cli` দক্ষতার জন্য [[Obsidian CLI#Install Obsidian CLI|Obsidian CLI চালু]] সহ Obsidian ডেস্কটপ অ্যাপ চলমান থাকতে হবে, এবং এমন একটি এজেন্ট প্রয়োজন যা আপনার কম্পিউটারে কমান্ড চালাতে পারে।

Markdown, বেসেস, এবং Canvas দক্ষতাগুলো শুধুমাত্র ফাইল ফরম্যাট বর্ণনা করে, তাই আপনার ভল্টে ফাইল পড়তে ও লিখতে পারে এমন যেকোনো এজেন্টে কাজ করে।

Defuddle, Knap, এবং Obsidian Headless আলাদা টুল যা দক্ষতাসমূহের সাথে বান্ডেল করা নেই। কোনোটি অনুপস্থিত থাকলে, দক্ষতাটি npm থেকে ইনস্টল করার আগে অনুমতি নেয়।

## গোপনীয়তা

Obsidian Skills নিজে থেকে কিছু পাঠায় না। যখন কোনো এজেন্ট এগুলো ব্যবহার করে, তখন যে নোটগুলো পড়ে সেগুলো কথোপকথনের অংশ হয়ে যায় এবং আপনি যে AI মডেল ব্যবহার করেন সেটি দ্বারা প্রক্রিয়া করা হয়। সংবেদনশীল নোট সম্বলিত ভল্টে এজেন্ট নির্দেশ করার আগে আপনার এজেন্টের গোপনীয়তা নীতি পর্যালোচনা করুন।
