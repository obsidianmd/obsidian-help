সংযোগকারীগুলো আপনাকে সহজেই এজেন্টগুলোকে Obsidian-এ অ্যাক্সেস দিতে দেয়, আপনার ডেটার উপর সম্পূর্ণ মালিকানা বজায় রেখে। Obsidian সংযোগকারীগুলো পাওয়া যায় Claude, ChatGPT, Antigravity, Cursor, GitHub Copilot, Grok Bot, Hermes, Kiro, Muse, OpenCode, এবং [আরও অনেক](https://agentskills.io/clients) অ্যাপের জন্য।

এর মানে হলো আপনার এজেন্টগুলো শিখতে পারে কীভাবে:

- [[Obsidian Flavored Markdown]]-এ নোট লিখতে হয়, যেখানে [[ইন্টারনাল লিঙ্ক|উইকিলিঙ্ক]], এম্বেড, কলআউট, এবং [[প্রপার্টি|প্রপার্টি]] অন্তর্ভুক্ত।
- [[বেসেস পরিচিতি|বেসেস]] এবং [[Canvas|Canvas]] ফাইল তৈরি ও সম্পাদনা করতে হয়।
- চলমান অ্যাপে [[Obsidian CLI]] দিয়ে নোট অনুসন্ধান, পড়া এবং পরিচালনা করতে হয়।
- ডেস্কটপ অ্যাপ ছাড়াই [[Obsidian Headless]] ব্যবহার করে ভল্ট সিঙ্ক ও প্রকাশ করতে হয়।

Obsidian সংযোগকারী এবং ওপেন সোর্স স্কিলগুলো পাওয়া যায় [obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills)-এ।

## ইনস্টল

আপনি আপনার এজেন্টের অ্যাপের মার্কেটপ্লেস বা প্লাগইন ডিরেক্টরিতে অনুসন্ধান করে Obsidian সংযোগকারী খুঁজে পাবেন। আপনি আপনার এজেন্টকে এই পৃষ্ঠার লিঙ্কও পাঠাতে পারেন।

### Claude

অফিসিয়াল Claude প্লাগইন ডিরেক্টরি থেকে [Obsidian](https://claude.ai/customize/plugins/id/a38fa062-ebd3-48e0-9a0a-1875a6e94ad5%40anthropic-plugin-directory) যোগ করুন।

Claude Code CLI-এর জন্য ব্যবহার করুন:

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

পরে নতুন স্কিল পেতে, চালান `claude plugin update obsidian@obsidian-skills`।

### ChatGPT

ChatGPT প্লাগইন ডিরেক্টরি থেকে [Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096) যোগ করুন। প্লাগইনটি ChatGPT, Codex, এবং Dots-এ কাজ করে।

### Antigravity

Antigravity CLI-তে চালান:

```shell
agy plugin install https://github.com/obsidianmd/obsidian-skills
```

### Grok Bot

[Obsidian for Grok Bot](https://x.ai/bot/plugin/88871845) খুলুন এবং **Add to Grok Bot** নির্বাচন করুন।

### Muse

Muse-কে https://github.com/obsidianmd/obsidian-skills থেকে স্কিল ইনস্টল করতে বলুন।

Muse Meta-র ক্লাউডে চলে, তাই `obsidian-cli` স্কিল সেখানে কাজ করে না। আপনি যদি Muse-এ Obsidian Headless ব্যবহার করেন, তাহলে আপনি Meta-র ক্লাউডে সাইন ইন করে আপনার ভল্ট সিঙ্ক করবেন।

### Cursor

Cursor Marketplace থেকে [Obsidian](https://cursor.com/marketplace/obsidian) ইনস্টল করুন।

### Hermes Agent

Hermes Marketplace থেকে [Obsidian](https://hermes-agent.nousresearch.com/marketplace/obsidian) ইনস্টল করুন, অথবা চালান:

```shell
hermes plugins install obsidian
```

### Kiro

```shell
kiro-cli powers install obsidian
```

### GitHub Copilot, OpenCode, এবং অন্যান্য এজেন্ট

[npx skills](https://github.com/vercel-labs/skills) দিয়ে ইনস্টল করুন, যা জিজ্ঞেস করবে কোন এজেন্টে ইনস্টল করতে হবে:

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

ম্যানুয়ালি ইনস্টল করতে, `plugins/obsidian/skills/`-এর ফোল্ডারগুলো আপনার এজেন্টের স্কিল ফোল্ডারে কপি করুন, যেমন GitHub Copilot-এর জন্য `~/.copilot/skills/`।

## অন্তর্ভুক্ত স্কিল

| স্কিল               | এটি যা করে                                                                                                                  |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `obsidian-markdown` | [[Obsidian Flavored Markdown]] নোট তৈরি ও সম্পাদনা করুন।                                                                         |
| `obsidian-bases`    | ভিউ, ফিল্টার, ফর্মুলা, এবং সারাংশসহ [[বেসেস সিনট্যাক্স\|বেসেস]] তৈরি ও সম্পাদনা করুন।                                         |
| `json-canvas`       | [JSON Canvas](https://jsoncanvas.org/) ফরম্যাট ব্যবহার করে [[Canvas]] ফাইল তৈরি ও সম্পাদনা করুন।                                     |
| `obsidian-cli`      | [[Obsidian CLI]]-এর মাধ্যমে আপনার ভল্টের সাথে ইন্টারঅ্যাক্ট করুন, প্লাগইন এবং থিম ডেভেলপমেন্ট সহ।                                    |
| `obsidian-headless` | [[Obsidian Headless]] দিয়ে কমান্ড লাইন থেকে ভল্ট সিঙ্ক ও প্রকাশ করুন।                                                     |
| `defuddle`          | [Defuddle](https://github.com/kepano/defuddle) ব্যবহার করে ওয়েব পেজ থেকে পরিষ্কার Markdown বের করুন।                                   |
| `knap`              | [Knap](https://github.com/obsidianmd/knap) ব্যবহার করে JSON বা CSV ডেটা থেকে Markdown টেমপ্লেট রেন্ডার করুন।                             |

## প্রয়োজনীয়তা

`obsidian-cli` স্কিলের জন্য [[Obsidian CLI#Install Obsidian CLI|Obsidian CLI চালু]] থাকা অবস্থায় Obsidian ডেস্কটপ অ্যাপ চলমান থাকতে হবে, এবং এমন একটি এজেন্ট প্রয়োজন যা আপনার কম্পিউটারে কমান্ড চালাতে পারে।

Markdown, বেসেস, এবং Canvas স্কিলগুলো শুধুমাত্র ফাইল ফরম্যাট বর্ণনা করে, তাই এগুলো যেকোনো এজেন্টে কাজ করে যা আপনার ভল্টে ফাইল পড়তে ও লিখতে পারে।

Defuddle, Knap, এবং Obsidian Headless আলাদা টুল যা স্কিলগুলোর সাথে বান্ডেল করা নেই। যখন কোনোটি অনুপস্থিত থাকে, স্কিলটি npm থেকে ইনস্টল করার আগে অনুমতি চায়।

## গোপনীয়তা

Obsidian সংযোগকারীগুলো নিজে থেকে কিছু পাঠায় না। যখন কোনো এজেন্ট এগুলো ব্যবহার করে, তখন যে নোটগুলো এটি পড়ে সেগুলো কথোপকথনের অংশ হয়ে যায় এবং আপনি যে AI মডেল ব্যবহার করছেন তার দ্বারা প্রক্রিয়া করা হয়। সংবেদনশীল নোট সম্বলিত ভল্টে এজেন্ট নির্দেশ করার আগে আপনার এজেন্টের গোপনীয়তা নীতি পর্যালোচনা করুন।
