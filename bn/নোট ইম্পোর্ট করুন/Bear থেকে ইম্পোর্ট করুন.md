Obsidian আপনাকে [[ইম্পোর্টার|Importer প্লাগইন]] ব্যবহার করে সহজেই Bear থেকে আপনার নোট মাইগ্রেট করতে দেয়। এটি আপনার Bear ডেটাকে টেকসই Markdown ফাইলে রূপান্তরিত করে, যা আপনি Obsidian এবং আরও অনেক অ্যাপের সাথে ব্যবহার করতে পারবেন।

## Bear থেকে আপনার ডেটা এক্সপোর্ট করুন

Obsidian Bear-এর ব্যাকআপ ফরম্যাট `.bear2bk` বা `ApplicationData.zip` ব্যবহার করতে পারে।

### iOS

1. Bear খুলুন।
2. **Settings** → **Advanced** → **Share Application Data**-এ যান।
3. আপনার ব্যাকআপ ফাইলের জন্য একটি অবস্থান বেছে নিন।
4. এখন আপনার কাছে একটি `ApplicationData.zip` ফাইল থাকা উচিত যাতে আপনার সমস্ত নোট রয়েছে।

### macOS

1. Bear খুলুন।
2. **File** → **Backup notes**-এ যান।
3. আপনার ব্যাকআপ ফাইলের জন্য একটি অবস্থান বেছে নিন।
4. **Export notes**-এ ক্লিক করুন।
5. এখন আপনার কাছে একটি `.bear2bk` ফাইল থাকা উচিত যাতে আপনার সমস্ত নোট রয়েছে।

## Obsidian-এ আপনার Bear ডেটা ইম্পোর্ট করুন

আপনার অফিসিয়াল Obsidian [[ইম্পোর্টার]] প্লাগইন প্রয়োজন হবে, যা আপনি [এখানে ইনস্টল করতে পারেন](obsidian://show-plugin?id=obsidian-importer)।

1. **[[সেটিংস]]** খুলুন।
2. **Community Plugins**-এ যান এবং [Importer ইনস্টল করুন](obsidian://show-plugin?id=obsidian-importer)।
3. Importer প্লাগইন চালু করুন।
4. কমান্ড প্যালেট বা রিবন আইকন ব্যবহার করে **Importer** প্লাগইন খুলুন।
5. **File format**-এর অধীনে **Bear (.bear2bk, .zip)** নির্বাচন করুন।
6. আপনার Bear ব্যাকআপ ফাইলের অবস্থান নির্বাচন করুন।
7. তৈরি হওয়া টেমপ্লেট পর্যালোচনা করতে এবং আপনার নোটের প্রিভিউ উদাহরণ দেখতে **Import** নির্বাচন করুন।
8. আবার **Import** নির্বাচন করুন এবং ইম্পোর্ট শেষ হওয়া পর্যন্ত অপেক্ষা করুন।

## টেমপ্লেট
