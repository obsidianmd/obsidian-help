Obsidian আপনাকে অফিসিয়াল [[ইম্পোর্টার|Importer প্লাগইন]] ব্যবহার করে সহজেই পৃথক HTML ফাইল এবং HTML ফাইলের সম্পূর্ণ ফোল্ডার ইম্পোর্ট করতে দেয়। এটি তখন কাজে আসে যখন আপনি সম্পূর্ণ ওয়েবসাইট [[Obsidian Flavored Markdown|Markdown]] ফরম্যাটে সংরক্ষণ করতে চান, অথবা এমন কোনো টুল থেকে ডেটা ইম্পোর্ট করতে চান যা HTML-এ এক্সপোর্ট করে। 

আপনি যদি কোনো নির্দিষ্ট অ্যাপ থেকে নোট ইম্পোর্ট করছেন, তাহলে প্রথমে [[ইম্পোর্টার|Importer প্লাগইন]] দ্বারা সমর্থিত অ্যাপের তালিকা পর্যালোচনা করে দেখে নিতে পারেন যে কোনো নির্দিষ্ট কনভার্টার আছে কিনা যা আপনার মাইগ্রেট করা ডেটা আরও ভালোভাবে সংরক্ষণ করবে।

## Obsidian-এ HTML ডেটা ইম্পোর্ট করুন

আপনার অফিসিয়াল Obsidian [[ইম্পোর্টার]] প্লাগইন প্রয়োজন হবে, যা আপনি [এখানে ইনস্টল করতে পারেন](obsidian://show-plugin?id=obsidian-importer)।

1. **[[সেটিংস]]** খুলুন।
2. **Community Plugins**-এ যান এবং [Importer ইনস্টল করুন](obsidian://show-plugin?id=obsidian-importer)।
3. Importer প্লাগইন চালু করুন।
4. কমান্ড প্যালেট বা রিবন আইকন ব্যবহার করে **Importer** প্লাগইন খুলুন।
5. **File format**-এর অধীনে **HTML (.html)** নির্বাচন করুন।
6. আপনার HTML ফাইল বা ফোল্ডারের অবস্থান নির্বাচন করুন।
7. তৈরি করা টেমপ্লেট পর্যালোচনা করতে এবং আপনার ফাইলের প্রিভিউ উদাহরণ দেখতে **Import** নির্বাচন করুন।
8. আবার **Import** নির্বাচন করুন এবং ইম্পোর্ট শেষ হওয়া পর্যন্ত অপেক্ষা করুন।

### ইম্পোর্ট সেটিংস

- **Attachment size limit**: নির্দিষ্ট আকারের চেয়ে বড় সংযুক্তি ইম্পোর্ট করা বাদ দিন।
- **Minimum image size**: উভয় মাত্রায় নির্দিষ্ট আকারের চেয়ে ছোট ছবি ইম্পোর্ট করা বাদ দিন। আইকন এবং লোগো বাদ দিতে এটি ব্যবহার করা যেতে পারে।

## টেমপ্লেট

আপনার ডেটা কীভাবে ইম্পোর্ট হবে তা সম্পূর্ণরূপে কনফিগার করতে [[ইম্পোর্টার টেমপ্লেট|Importer টেমপ্লেট]] ব্যবহার করুন।

![[ইম্পোর্টার টেমপ্লেট#Variables]]

এছাড়াও, HTML ইম্পোর্ট [[Obsidian Web Clipper পরিচিতি|Web Clipper]]-এর মতো অনেক একই ভ্যারিয়েবল প্রদান করে:

| ভ্যারিয়েবল | বিবরণ |
| --- | --- |
| `{{author}}` | পৃষ্ঠার লেখক। |
| `{{contentHtml}}` | HTML ফরম্যাটে নিষ্কাশিত পৃষ্ঠার বিষয়বস্তু। |
| `{{description}}` | পৃষ্ঠার বিবরণ বা সংক্ষিপ্তসার। |
| `{{domain}}` | পৃষ্ঠার ডোমেইন। |
| `{{favicon}}` | ফ্যাভিকন URL। |
| `{{fullHtml}}` | সম্পূর্ণ পৃষ্ঠার অপ্রক্রিয়াকৃত HTML। |
| `{{image}}` | সোশ্যাল শেয়ার ইমেজ URL। |
| `{{language}}` | পৃষ্ঠার ভাষা। |
| `{{published}}` | প্রকাশের তারিখ, যা `date` ফিল্টার দিয়ে ফরম্যাট করা যায়। |
| `{{site}}` | সাইটের নাম বা প্রকাশক। |
| `{{url}}` | ইম্পোর্ট করা ডকুমেন্টে পাওয়া সোর্স URL, যখন উপলব্ধ। |
| `{{words}}` | শব্দ সংখ্যা। |
