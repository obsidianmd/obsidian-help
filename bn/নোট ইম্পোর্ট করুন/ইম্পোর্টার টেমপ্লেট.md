[[ইম্পোর্টার]] আপনাকে টেমপ্লেট তৈরি করতে দেয় যা নিয়ন্ত্রণ করে কিভাবে অন্য অ্যাপ থেকে আপনার নোট ইম্পোর্ট করা হবে। এর মাধ্যমে আপনি ইম্পোর্ট করা নোটের শিরোনাম, প্রপার্টি এবং বিষয়বস্তু পরিবর্তন করতে পারেন।

## ইম্পোর্ট টেমপ্লেট সম্পাদনা করুন

ডিফল্ট টেমপ্লেট সম্পাদনা করতে প্রিভিউয়ের উপরে **Edit** নির্বাচন করুন। আপনি সম্পাদনা করতে পারেন:

- ইনলাইন শিরোনাম হিসেবে প্রদর্শিত নোটের নাম।
- নোটের শুরুতে থাকা প্রপার্টি।
- নোটের Markdown বিষয়বস্তু।

প্রিভিউতে ফিরে যেতে **Save** নির্বাচন করুন। ইম্পোর্টার একই ফরম্যাট ব্যবহার করে ভবিষ্যৎ ইম্পোর্টের জন্য সম্পাদিত ইনলাইন টেমপ্লেট মনে রাখে।

বিকল্পভাবে আপনি বর্তমান ভল্টের একটি Markdown ফাইল থেকে টেমপ্লেট লোড করতে পারেন।

## ফলাফল প্রিভিউ করুন

প্রিভিউ আপনার নির্বাচিত ডেটা থেকে সর্বোচ্চ দশটি নমুনা দেখায়। নমুনাগুলোর মধ্যে সরাতে তীর বোতামগুলো ব্যবহার করুন। ইম্পোর্ট সেটিংস এবং টেমপ্লেটের পরিবর্তনগুলো আপনার ভল্টে কিছু যোগ করার আগেই প্রিভিউ আপডেট করে।

কিছু অ্যাটাচমেন্ট, রিমোট আইটেম এবং নোট-মধ্যবর্তী রেফারেন্স ইম্পোর্ট সম্পন্ন না হওয়া পর্যন্ত পুরোপুরি সমাধান করা সম্ভব নয়। সেসব ক্ষেত্রে, প্রিভিউ সোর্স লিঙ্ক বজায় রাখতে পারে বা একটি প্লেসহোল্ডার দেখাতে পারে।

## টেমপ্লেট সিনট্যাক্স

ইম্পোর্টার টেমপ্লেট এমন একটি সিনট্যাক্স ব্যবহার করে যা ভেরিয়েবল, [[ফিল্টার]], এবং [[লজিক]] নিয়ে গঠিত। এটি [[Obsidian Web Clipper পরিচিতি|Web Clipper]]-এর মতো একই [Knap](https://github.com/obsidianmd/knap) সিনট্যাক্স ব্যবহার করে।

ডবল কার্লি ব্র্যাকেট দিয়ে ভেরিয়েবল যোগ করুন, যেমন `{{title}}`, `{{content}}`, বা `{{date}}`। ভেরিয়েবল নোটের নাম, প্রপার্টি এবং বিষয়বস্তুতে ব্যবহার করা যায়।

আপনি [[ফিল্টার]] ব্যবহার করে ভেরিয়েবল পরিবর্তন করতে পারেন। উদাহরণস্বরূপ `{{date|date:"YYYY-MM-DD"}}` ব্যবহার করে তারিখের ফরম্যাট পরিবর্তন করতে পারেন। আরও উন্নত শর্তাধীন বিবৃতি, লুপ এবং ভেরিয়েবল বরাদ্দের জন্য [[লজিক]] ব্যবহার করুন।

## ভেরিয়েবল

যেকোনো ইম্পোর্টার টেমপ্লেটে ব্যবহারের জন্য নিম্নলিখিত ভেরিয়েবলগুলো উপলব্ধ:

| ভেরিয়েবল         | বিবরণ                                                                                         |
| ---------------- | --------------------------------------------------------------------------------------------------- |
| `{{body}}`       | প্রপার্টি ছাড়া Markdown বডি (ফ্রন্টম্যাটার নেই)।                                                  |
| `{{content}}`    | নির্বাচিত টেমপ্লেট প্রয়োগের আগে সম্পূর্ণ Markdown।                                          |
| `{{ctime}}`      | ISO 8601 টাইমস্ট্যাম্প হিসেবে সোর্স তৈরির সময়; অনুপলব্ধ হলে খালি।                              |
| `{{date}}`       | টেমপ্লেট রেন্ডার হওয়ার সময় বর্তমান তারিখ ও সময়, ISO 8601 টাইমস্ট্যাম্প হিসেবে।                      |
| `{{importer}}`   | ইম্পোর্টার আইডি, যেমন `keep`, `html`, বা `notion-api`।                                               |
| `{{folder}}`     | চূড়ান্ত ভল্ট-আপেক্ষিক প্যারেন্ট ফোল্ডার। নোট ভল্টের রুটে থাকলে খালি।                       |
| `{{mtime}}`      | ISO 8601 টাইমস্ট্যাম্প হিসেবে সোর্স পরিবর্তনের সময়; অনুপলব্ধ হলে খালি।                          |
| `{{noteName}}`   | অবৈধ অক্ষর সরানো এবং ডুপ্লিকেটের জন্য প্রত্যয় যোগ করার পর চূড়ান্ত সমাধানকৃত নোটের নাম। |
| `{{path}}`       | `.md` এক্সটেনশনসহ চূড়ান্ত ভল্ট-আপেক্ষিক পাথ।                                           |
| `{{properties}}` | ফ্রন্টম্যাটার প্রপার্টি ধারণকারী অবজেক্ট।                                                       |
| `{{source}}`     | জেনারেট করা প্রপার্টি এবং সোর্স-নির্দিষ্ট মান ধারণকারী অবজেক্ট।                                  |
| `{{sourceId}}`   | ইম্পোর্টার প্রদান করলে স্থিতিশীল সোর্স শনাক্তকারী; অন্যথায় খালি।                           |
| `{{time}}`       | `{{date}}`-এর ছদ্মনাম।                                                                               |
| `{{title}}`      | স্যানিটাইজেশন এবং ডিডুপ্লিকেশনের আগে মূল নোটের শিরোনাম।                                          |

## প্রপার্টির জন্য সোর্স মান

যেসব ইম্পোর্ট ফরম্যাট [[প্রপার্টি]] সমর্থন করে, সেসব ক্ষেত্রে সোর্স মানগুলো সুবিধার জন্য শীর্ষ-স্তরের ভেরিয়েবল হিসেবেও উপলব্ধ।

যদি কোনো সোর্স মানের নাম শেয়ার্ড ভেরিয়েবলের সাথে একই হয়, তাহলে `{{source}}`-এর মাধ্যমে অ্যাক্সেস করুন। উদাহরণস্বরূপ, যদি আপনার ইম্পোর্ট সোর্সে `content` নামে একটি প্রপার্টি থাকে তাহলে সেটি `{{source.content}}` হিসেবে উপলব্ধ, যখন `{{content}}` ডিফল্ট ইম্পোর্টার ভেরিয়েবল হিসেবেই থাকবে।

ফিল্ডের নামে স্পেস, বিরাম চিহ্ন বা অন্যান্য বিশেষ অক্ষর থাকলে ব্র্যাকেট নোটেশন ব্যবহার করুন:

```twig
{{source["Project: status"]}}
```

## উদাহরণ টেমপ্লেট

এখানে ভেরিয়েবল এবং [[ফিল্টার]] ব্যবহার করে একটি টেমপ্লেটের উদাহরণ দেওয়া হলো:

```twig
---
created: {{ctime | date:"YYYY-MM-DD"}}
modified: {{mtime | date:"YYYY-MM-DD"}}
source: {{importer}}
---
# {{title}}

{{body}}
```

আপনি [[লজিক]] ব্যবহার করে শর্তসাপেক্ষে নোটে ডেটা যোগ করতে পারেন:

```twig
{% if tags %}
## ট্যাগ
{% for tag in tags %}
- {{tag}}
{% endfor %}
{% endif %}
```
