Obsidian নোটের প্রধান ফরম্যাট হিসেবে Markdown `.md` ফাইল ব্যবহার করে। এটি Obsidian-এ Markdown ফাইল ইম্পোর্ট করা সহজ করে তোলে। অনেক অ্যাপ Markdown ফাইল সম্পাদনা করতে পারে বা এই ফরম্যাটে এক্সপোর্ট করতে পারে।

আপনার Obsidian ভল্টে Markdown ফাইল যোগ করার বেশ কয়েকটি উপায় রয়েছে:

1. [[ফাইল এক্সপ্লোরার]] উইন্ডোতে ফাইল বা ফোল্ডার টেনে এনে ছেড়ে দিন
2. আপনার সিস্টেম ফাইল ব্রাউজার ব্যবহার করুন (যেমন Windows-এ Windows Explorer বা macOS-এ Finder), এবং আপনার ফাইলগুলি সরাসরি Obsidian ভল্ট ফোল্ডারে সরিয়ে নিন।

## Importer দিয়ে Markdown ফাইল ইম্পোর্ট করুন

আপনি যখন ইম্পোর্টের মধ্যে ফোল্ডার নির্বাচন করতে, `.zip` আর্কাইভ ইম্পোর্ট করতে, ফরম্যাটিং প্রমিতকরণ করতে, ইনলাইন ট্যাগ [[প্রপার্টি|প্রপার্টিতে]] সরাতে, বা টেমপ্লেট প্রয়োগ করতে চান তখন অফিসিয়াল [[ইম্পোর্টার|Importer প্লাগইন]] ব্যবহার করুন।

1. **[[সেটিংস]] → কমিউনিটি প্লাগইন** খুলুন এবং [Importer ইনস্টল করুন](obsidian://show-plugin?id=obsidian-importer)।
2. Importer প্লাগইন সক্রিয় করুন।
3. [[কমান্ড প্যালেট]] বা রিবন আইকন ব্যবহার করে **Importer** খুলুন।
4. **File format** এর অধীনে **Markdown (.md, .zip)** নির্বাচন করুন।
5. পৃথক Markdown ফাইল, ফোল্ডার বা zip আর্কাইভ নির্বাচন করুন।
6. শনাক্তকৃত ফোল্ডার, আউটপুট বিকল্প, তৈরি করা টেমপ্লেট এবং প্রিভিউ উদাহরণ পর্যালোচনা করুন।
7. **Import** নির্বাচন করুন এবং ইম্পোর্ট শেষ হওয়া পর্যন্ত অপেক্ষা করুন।

ইম্পোর্ট করা নোটের নাম, প্রপার্টি এবং কনটেন্ট কাস্টমাইজ করতে [[ইম্পোর্টার টেমপ্লেট]] দেখুন।

## টেমপ্লেট

আপনার ডেটা কীভাবে ইম্পোর্ট হবে তা সম্পূর্ণভাবে কনফিগার করতে [[ইম্পোর্টার টেমপ্লেট|Importer টেমপ্লেট]] ব্যবহার করুন।
