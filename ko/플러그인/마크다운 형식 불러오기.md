마크다운 형식 불러오기는 [[속성#사용 중단된 속성|사용 중단된 속성 형식]]을 Obsidian에서 사용하는 현재 형식으로 변환해요.

> [!warning] 보관함을 백업하세요
> 변환은 전체 보관함에 적용돼요. 시작하기 전에 [[Obsidian 파일 백업|Obsidian 파일을 백업]]하세요.

노트의 속성을 변환하려면:

1. [[명령어 팔레트]]를 열어요.
2. **마크다운 형식 불러오기: Frontmatter 이전**을 선택해요.
3. **변환 시작**을 선택해요.

## 지원되는 속성 형식

변환기는 별칭, 태그, CSS 클래스를 사용 중단된 형식에서 업데이트해요:

**별칭**

```yaml
# 변환 전

alias: My Note Title

# 변환 후

aliases:
  - My Note Title
```

**태그**

```yaml
# 변환 전

tag: project, important

# 변환 후

tags:
  - project
  - important
```

**CSS 클래스**

```yaml
# 변환 전

cssclass: custom-style

# 변환 후

cssclasses:
  - custom-style
```
