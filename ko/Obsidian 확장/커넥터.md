커넥터를 사용하면 데이터의 완전한 소유권을 유지하면서 에이전트에 Obsidian 접근 권한을 쉽게 부여할 수 있어요. Obsidian 커넥터는 Claude, ChatGPT, Antigravity, Cursor, GitHub Copilot, Grok Bot, Hermes, Kiro, Muse, OpenCode 등 다양한 앱에서 사용할 수 있어요. [지원되는 전체 목록은 여기에서](https://agentskills.io/clients) 확인할 수 있어요.

에이전트가 다음과 같은 작업을 배울 수 있어요:

- [[Obsidian 스타일 Markdown]]으로 노트 작성하기. [[내부 링크|위키 링크]], 임베드, 콜아웃, [[속성|속성]]을 포함해요.
- [[베이스 소개|베이스]] 및 [[Canvas]] 파일 생성 및 편집하기.
- [[Obsidian CLI]]를 사용하여 실행 중인 앱에서 노트를 검색, 읽기, 관리하기.
- [[Obsidian Headless]]를 사용하여 데스크톱 앱 없이 보관함을 동기화하고 게재하기.

스킬은 [obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills)에서 오픈 소스로 제공돼요.

## 설치

Claude, ChatGPT, Dots, Cursor, Grok Bot, Hermes, Kiro의 플러그인 목록에서 Obsidian을 검색하면 찾을 수 있어요. 대부분의 다른 에이전트는 이 페이지 링크를 보내면 스킬을 설치할 수 있어요.

### Claude

공식 Claude 플러그인 디렉터리에서 [Obsidian](https://claude.ai/customize/plugins/id/a38fa062-ebd3-48e0-9a0a-1875a6e94ad5%40anthropic-plugin-directory)을 추가하세요.

Claude Code CLI를 사용하는 경우:

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

나중에 새 스킬을 받으려면 `claude plugin update obsidian@obsidian-skills`를 실행하세요.

### ChatGPT

ChatGPT 플러그인 디렉터리에서 [Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096)을 추가하세요. 이 플러그인은 ChatGPT, Codex, Dots에서 작동해요.

### Antigravity

Antigravity CLI에서 다음을 실행하세요:

```shell
agy plugin install https://github.com/obsidianmd/obsidian-skills
```

### Grok Bot

[Obsidian for Grok Bot](https://x.ai/bot/plugin/88871845)을 열고 **Add to Grok Bot**을 선택하세요.

### Muse

Muse에 https://github.com/obsidianmd/obsidian-skills에서 스킬을 설치하도록 요청하세요.

Muse는 Meta의 클라우드에서 실행되므로 `obsidian-cli` 스킬은 작동하지 않아요. Muse에서 Obsidian Headless를 사용하면 Meta의 클라우드에서 로그인하고 보관함을 동기화하게 돼요.

### Cursor

Cursor Marketplace에서 [Obsidian](https://cursor.com/marketplace/obsidian)을 설치하세요.

### Hermes Agent

```shell
hermes plugins install obsidian
```

### Kiro

```shell
kiro-cli powers install obsidian
```

### GitHub Copilot, OpenCode 및 기타 에이전트

[npx skills](https://github.com/vercel-labs/skills)로 설치하면 어떤 에이전트에 설치할지 물어봐요:

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

수동으로 설치하려면 `plugins/obsidian/skills/`의 폴더를 에이전트의 스킬 폴더에 복사하세요. 예를 들어 GitHub Copilot의 경우 `~/.copilot/skills/`예요.

## 포함된 스킬

| 스킬                | 기능                                                                                                                          |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `obsidian-markdown` | [[Obsidian 스타일 Markdown]] 노트를 생성하고 편집해요.                                                                         |
| `obsidian-bases`    | 보기, 필터, 수식, 요약이 포함된 [[베이스 구문|베이스]]를 생성하고 편집해요.                                                     |
| `json-canvas`       | [JSON Canvas](https://jsoncanvas.org/) 형식을 사용하여 [[Canvas]] 파일을 생성하고 편집해요.                                     |
| `obsidian-cli`      | [[Obsidian CLI]]를 통해 보관함과 상호작용해요. 플러그인 및 테마 개발도 포함돼요.                                                |
| `obsidian-headless` | [[Obsidian Headless]]를 사용하여 명령줄에서 보관함을 동기화하고 게재해요.                                                       |
| `defuddle`          | [Defuddle](https://github.com/kepano/defuddle)을 사용하여 웹 페이지에서 깔끔한 Markdown을 추출해요.                             |
| `knap`              | [Knap](https://github.com/obsidianmd/knap)을 사용하여 JSON 또는 CSV 데이터에서 Markdown 템플릿을 렌더링해요.                    |

## 요구 사항

`obsidian-cli` 스킬은 [[Obsidian CLI#Obsidian CLI 설치|Obsidian CLI가 켜진]] 상태로 Obsidian 데스크톱 앱이 실행 중이어야 하고, 컴퓨터에서 명령을 실행할 수 있는 에이전트가 필요해요.

Markdown, 베이스, Canvas 스킬은 파일 형식만 설명하므로 보관함에서 파일을 읽고 쓸 수 있는 모든 에이전트에서 작동해요.

Defuddle, Knap, Obsidian Headless는 스킬에 번들되지 않는 별도의 도구예요. 도구가 없는 경우 스킬이 npm에서 설치할지 물어봐요.

## 개인정보 보호

Obsidian 커넥터는 자체적으로 아무것도 전송하지 않아요. 에이전트가 사용할 때 읽는 노트가 대화의 일부가 되어 사용 중인 AI 모델에 의해 처리돼요. 민감한 노트가 있는 보관함에 에이전트를 연결하기 전에 에이전트의 개인정보 보호 정책을 검토하세요.
