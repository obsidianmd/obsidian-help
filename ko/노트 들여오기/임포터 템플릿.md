[[들여오기]]를 사용하면 다른 앱에서 노트를 가져올 때 가져오기 방식을 제어하는 템플릿을 정의할 수 있어요. 가져오는 노트의 제목, 속성, 콘텐츠를 수정할 수 있어요.

## 가져오기 템플릿 편집

미리보기 위의 **편집**을 선택하면 기본 템플릿을 편집할 수 있어요. 편집 가능한 항목은 다음과 같아요:

- 인라인 제목으로 표시되는 노트 이름.
- 노트 시작 부분의 속성.
- 노트의 Markdown 콘텐츠.

**저장**을 선택하면 미리보기로 돌아가요. 들여오기는 같은 서식을 사용하는 이후 가져오기를 위해 편집된 인라인 템플릿을 기억해요.

또는 현재 보관함의 Markdown 파일에서 템플릿을 불러올 수도 있어요.

## 결과 미리보기

미리보기에는 선택한 데이터에서 최대 10개의 샘플이 표시돼요. 화살표 버튼을 사용해 샘플 간에 이동할 수 있어요. 가져오기 설정이나 템플릿 변경 사항은 보관함에 추가되기 전에 미리보기에 반영돼요.

일부 첨부 파일, 원격 항목, 노트 간 참조는 가져오기가 실행될 때까지 완전히 확인되지 않을 수 있어요. 이 경우 미리보기에 원본 링크가 유지되거나 플레이스홀더가 표시될 수 있어요.

## 템플릿 구문

들여오기 템플릿은 [[변수]], [[필터]], [[로직]]으로 구성된 구문을 사용해요. [[Obsidian Web Clipper 소개|Web Clipper]]와 동일한 [Knap](https://github.com/obsidianmd/knap) 구문을 사용해요.

이중 중괄호를 사용해 변수를 삽입해요. 예를 들어 `{{title}}`, `{{content}}`, `{{date}}` 등이 있어요. 변수는 노트 이름, 속성, 콘텐츠에서 사용할 수 있어요.

[[필터]]를 사용해 변수를 수정할 수 있어요. 예를 들어 `{{date|date:"YYYY-MM-DD"}}`를 사용해 날짜 형식을 변경할 수 있어요. 더 고급 조건문, 반복문, 변수 할당은 [[로직]]을 사용해요.

## 변수

다음 변수는 모든 들여오기 템플릿에서 사용할 수 있어요:

| 변수               | 설명                                                                                                |
| ---------------- | --------------------------------------------------------------------------------------------------- |
| `{{body}}`       | 속성 없는 Markdown 본문 (프런트매터 제외).                                                          |
| `{{content}}`    | 선택한 템플릿이 적용되기 전의 전체 Markdown.                                                        |
| `{{ctime}}`      | 원본 생성 시간(ISO 8601 타임스탬프). 사용할 수 없으면 비어 있어요.                                  |
| `{{date}}`       | 템플릿이 렌더링될 때의 현재 날짜와 시간(ISO 8601 타임스탬프).                                       |
| `{{importer}}`   | 들여오기 ID. 예: `keep`, `html`, `notion-api`.                                                      |
| `{{folder}}`     | 최종 보관함 기준 상위 폴더. 노트가 보관함 루트에 있으면 비어 있어요.                                |
| `{{mtime}}`      | 원본 수정 시간(ISO 8601 타임스탬프). 사용할 수 없으면 비어 있어요.                                  |
| `{{noteName}}`   | 잘못된 문자를 제거하고 중복 접미사를 추가한 후의 최종 확정 노트 이름.                               |
| `{{path}}`       | `.md` 확장자를 포함한 최종 보관함 기준 경로.                                                        |
| `{{properties}}` | 프런트매터 속성을 포함하는 객체.                                                                    |
| `{{source}}`     | 생성된 속성과 원본별 값을 포함하는 객체.                                                            |
| `{{sourceId}}`   | 들여오기에서 제공하는 안정적인 원본 식별자. 없으면 비어 있어요.                                     |
| `{{time}}`       | `{{date}}`의 별칭.                                                                                  |
| `{{title}}`      | 정리 및 중복 처리 전의 원래 노트 제목.                                                              |

## 속성의 원본 값

[[속성]]을 지원하는 가져오기 서식의 경우, 원본 값도 편의를 위해 최상위 변수로 사용할 수 있어요.

원본 값이 공유 변수와 같은 이름을 가진 경우, `{{source}}`를 통해 접근해요. 예를 들어, 가져오기 원본에 `content`라는 속성이 있으면 `{{source.content}}`로 사용할 수 있고, `{{content}}`는 기본 들여오기 변수로 유지돼요.

필드 이름에 공백, 구두점 또는 기타 특수 문자가 포함된 경우 대괄호 표기법을 사용해요:

```twig
{{source["Project: status"]}}
```

## 예시 템플릿

변수와 [[필터]]를 사용한 템플릿 예시예요:

```twig
---
created: {{ctime | date:"YYYY-MM-DD"}}
modified: {{mtime | date:"YYYY-MM-DD"}}
source: {{importer}}
---
# {{title}}

{{body}}
```

[[로직]]을 사용해 조건부로 노트에 데이터를 추가할 수 있어요:

```twig
{% if tags %}
## 태그
{% for tag in tags %}
- {{tag}}
{% endfor %}
{% endif %}
```
