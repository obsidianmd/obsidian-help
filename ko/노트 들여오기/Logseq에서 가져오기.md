Obsidian에서는 공식 [[들여오기|Importer 플러그인]]을 사용해 파일 기반 Logseq 그래프(현재 "Logseq OG"로 불리는 버전)에서 노트를 가져올 수 있어요. Importer는 Logseq의 Markdown 파일을 직접 읽어 Logseq 전용 서식을 Obsidian 및 다른 앱에서 오프라인으로 사용할 수 있는 범용 파일로 변환해요.

## 시작하기 전에

- Logseq 그래프와 Obsidian 보관함을 백업하세요.
- Logseq 그래프의 루트 폴더를 확인하세요. 일반적으로 `pages`, `journals`, `assets`, `logseq` 폴더가 포함되어 있어요.
- 파일 기반 Logseq 그래프를 사용하고 있는지 확인하세요. Logseq 데이터베이스 그래프는 아직 지원되지 않아요.

## Logseq 그래프 가져오기

공식 Obsidian [[들여오기|Importer]] 플러그인이 필요하며, [여기에서 설치](obsidian://show-plugin?id=obsidian-importer)할 수 있어요.

1. **[[설정]] → 커뮤니티 플러그인**을 열고 [Importer를 설치](obsidian://show-plugin?id=obsidian-importer)하세요.
2. Importer 플러그인을 활성화하세요.
3. [[명령어 팔레트]] 또는 리본 아이콘을 사용해 **Importer**를 여세요.
4. **File format**에서 **Logseq**를 선택하세요.
5. **Choose folders**에서 그래프의 루트 폴더를 선택하세요. `pages`나 `journals` 폴더 개별이 아니라, 이 폴더들을 포함하는 상위 폴더를 선택하세요.
6. 감지된 폴더를 확인하고 가져오지 않을 폴더를 제외하세요.
7. 출력 폴더와 가져온 첨부 파일을 저장할 위치를 선택하세요.
8. 가져오기 옵션을 검토하고 변환된 노트의 미리보기 예시를 확인하세요.
9. **Import**를 선택하고 가져오기가 완료될 때까지 기다리세요.

## 제한 사항

- 화이트보드는 가져오지 않아요.
- 쿼리는 유지를 선택하면 코드 블록으로 보존돼요.
- 동적 Logseq 템플릿 매크로는 리터럴 텍스트로 남아요.
- Logseq 플래시카드 스케줄링, PDF 주석 및 기타 앱 전용 데이터는 이동되지 않아요.

## 설정

Importer는 다음을 포함한 일반적인 Logseq 규칙을 변환해요:

- 페이지 속성을 Obsidian [[속성]]으로 변환.
- 페이지 별칭, 태그, 네임스페이스, 링크.
- 워크플로 상태를 체크박스 목록 마커로 변환하고, 우선순위와 날짜는 읽기 쉬운 텍스트로 보존.
- 블록 ID, 블록 참조, 블록 임베드를 Obsidian 링크와 임베드로 변환.
- 저널 파일명과 날짜 링크.
- 강조 표시, 번호 매기기 목록, Org 블록, 미디어 임베드, 그래프 `assets` 폴더의 연결된 파일.

### 저널

기본적으로 **Use daily notes settings**가 활성화되어 있어요. 가져온 저널은 [[일일 노트]] 코어 플러그인에서 설정한 폴더와 날짜 형식을 사용해요. 이로 인해 저널이 Importer에서 선택한 출력 폴더 밖에 배치될 수 있어요.

이 옵션을 비활성화하면, 저널은 선택한 출력 폴더 내의 `Journals` 폴더에 기록되며 `YYYY-MM-DD` 노트 이름 형식을 사용해요.

### 아웃라인 펼치기

Logseq는 중첩된 글머리 기호를 페이지 구조로 사용해요. 기본적으로 Importer는 이 아웃라인 구조를 유지해요. **Flatten outlines**를 활성화하면 아웃라인 블록을 문단, 제목, 일반 목록의 조합으로 변환해요. 작업과 목록 형태의 항목 그룹은 목록 항목으로 유지되지만, 변환은 휴리스틱 방식이에요. 큰 그래프를 가져오기 전에 미리보기에서 여러 예시를 검토하세요.

### 호환되지 않는 데이터 보존

Logseq 쿼리, 플래시카드, 시간 추적 항목은 Obsidian에 직접적인 대응 기능이 없어요. 가져오기 옵션에서 각 종류의 콘텐츠를 유지할지 선택할 수 있어요. 유지하면 일반 텍스트로 남아요.

- **Keep queries**는 쿼리를 펜스 코드 블록 또는 인라인 코드로 보존해요.
- **Keep flashcards**는 `#card` 마커와 클로즈 래퍼를 일반 텍스트로 보존해요.
- **Keep time tracking**은 `LOGBOOK`과 `CLOCK` 항목을 일반 텍스트로 보존해요.

## 문제 해결

Importer가 노트를 찾지 못하는 경우, 그래프의 루트 폴더를 선택했는지, 설정된 페이지 또는 저널 폴더에 Markdown 파일이 있는지 확인하세요.

첨부 파일이 누락으로 보고되는 경우, 참조된 파일이 그래프의 `assets` 폴더에 여전히 존재하는지 확인하세요.

기타 문제는 [Importer 이슈 트래커](https://github.com/obsidianmd/obsidian-importer/issues)에서 검색하거나 작은 예시 그래프와 함께 버그 리포트를 제출하세요.
