Obsidian은 내장 뷰어로 PDF 파일을 열어요. PDF를 노트에 임베드하거나, 특정 구절에 링크하거나, 노트를 PDF로 내보낼 수도 있어요. Obsidian이 지원하는 파일 형식에 대해서는 [[지원 파일 형식]]을 참고해 주세요.

> [!info]+ 일부 기능은 데스크톱 전용이에요
> 모바일 Obsidian 앱에서는 PDF 내 검색, 인용으로 복사 또는 선택 항목에 대한 링크 복사, 노트를 PDF로 내보내기를 사용할 수 없어요.

## PDF 열기

[[파일 탐색기]]에서 PDF를 선택하면 탭에서 열려요.

> [!info]+ 주석은 지원하지 않아요
> Obsidian은 PDF에 주석이나 강조 표시를 추가하는 것을 지원하지 않아요. PDF에 표시를 하려면 다른 앱을 사용한 후 보관함에서 업데이트된 파일을 열어 주세요.

뷰어에는 다음 컨트롤이 있는 툴바가 있어요. 모바일 Obsidian 앱에도 동일한 툴바가 있어요.

- **사이드바 활성화/비활성화**는 사이드바를 표시하거나 숨기고, **사이드바 옵션**은 사이드바에 표시할 내용을 변경해요.
- **축소**와 **확대**는 페이지 크기를 변경해요.
- **옵션 표시**는 페이지 레이아웃 방식을 변경해요.
- 페이지 상자는 현재 페이지를 표시해요. 페이지 번호를 입력하면 해당 페이지로 이동해요.

PDF 파일 자체의 이름 바꾸기나 옮기기 같은 작업을 하려면 **다른 옵션** ![[lucide-more-horizontal.svg#icon]]을 선택하세요. PDF는 노트보다 이 메뉴에 항목이 적어요. [[다른 옵션 메뉴]]를 참고해 주세요.

## PDF 탐색하기

**사이드바 옵션**을 선택한 후 표시할 항목을 선택하세요.

- **미리보기 이미지**는 각 페이지의 작은 미리보기를 표시해요.
- **목차**는 PDF에 개요가 있는 경우 이를 표시해요.
- **페이지를 목차에 표시하기**는 목차에서 현재 페이지를 강조 표시해요.

페이지에 링크하려면 미리보기 이미지를 오른쪽 클릭하고 **Copy link to page N**을 선택하세요. 여기서 N은 페이지 번호예요. 링크를 노트에 붙여넣으세요.

섹션에 링크하려면 목차에서 항목을 오른쪽 클릭하고 **Copy link to "Title"**을 선택하세요. 여기서 Title은 항목의 이름이에요. 모바일에서는 항목을 길게 누르세요.

## PDF 표시 방식 변경하기

**옵션 표시**를 선택하여 레이아웃을 변경하세요.

- **너비 맞추기**와 **높이 맞추기**는 페이지를 뷰어에 맞춰 조정해요.
- **한 페이지**는 한 번에 한 페이지를 표시해요.
- **두 페이지 (홀수)**는 왼쪽에 홀수 페이지부터 시작하여 페이지를 나란히 표시해요. 예를 들어, 1페이지와 2페이지가 함께 표시되고, 그 다음 3페이지와 4페이지가 표시돼요.
- **두 페이지 (짝수)**는 왼쪽에 짝수 페이지부터 시작하여 페이지를 나란히 표시해요. 예를 들어, 1페이지가 단독으로 표시되고, 그 다음 2페이지와 3페이지가 함께 표시돼요.
- **테마에 색 맞추기**는 Obsidian 테마가 다크일 때 PDF의 색상을 어둡게 해요.

## PDF 검색하기

PDF 내 검색은 데스크톱에서만 사용할 수 있어요. 모바일 Obsidian 앱의 PDF 뷰어에는 검색 기능이 없어요.

1. `Ctrl+F`(Windows 및 Linux) 또는 `Command+F`(macOS)를 누르세요.
2. **입력하여 검색하기...**에 찾고 싶은 텍스트를 입력하세요.
3. 위 또는 아래 화살표를 선택하여 일치 항목 사이를 이동하세요.

검색 작동 방식을 변경하려면 다음 옵션을 사용하세요.

- **대소문자 구분**은 대문자와 소문자를 정확히 일치시켜요. 검색 필드의 **Aa** 버튼이에요.
- **모두 하이라이트하기**는 모든 일치 항목을 강조 표시해요. 화살표 옆의 설정 버튼을 선택하면 이 옵션을 찾을 수 있어요.
- **다이어크리틱 일치시키기**는 악센트가 있는 글자를 다른 글자로 취급해요. 같은 설정 메뉴에 있어요.
- **완전한 단어들**은 완전한 단어만 찾아요. 같은 설정 메뉴에 있어요.

닫기 버튼을 선택하면 검색을 종료해요.

## PDF에서 텍스트 복사하기

데스크톱에서는 PDF의 텍스트를 선택한 후 오른쪽 클릭하세요.

- **복사**는 텍스트를 복사해요.
- **인용으로 복사**는 텍스트를 인용으로 복사하고, 해당 구절에 대한 링크를 뒤에 추가해요.
- **선택한 내용을 가리키는 링크 복사**는 해당 구절에 대한 링크를 복사하여 노트에 붙여넣을 수 있게 해요.

인용을 노트에 붙여넣으면 다음과 같이 보여요.

```md
> Obsidian is awesome

[[Gemmy.pdf#page=1&selection=32,0,32,14|Gemmy, page 1]]
```

선택 항목에 대한 링크는 동일한 링크 단독으로 나타나요.

```md
[[Gemmy.pdf#page=1&selection=32,0,32,14|Gemmy, page 1]]
```

모바일에서는 PDF의 텍스트를 선택하면 기기의 기본 텍스트 메뉴가 표시돼요. **인용으로 복사**와 **선택한 내용을 가리키는 링크 복사**는 사용할 수 없어요.

## PDF 임베드하기

노트 안에 PDF를 표시하려면 [[파일 임베드#노트에 PDF 임베드하기|노트에 PDF 임베드하기]]를 참고하세요. 임베드된 PDF에는 뷰어와 동일한 툴바가 있어요. **이 블럭 수정**을 선택하면 임베드 링크를 변경할 수 있어요.

## 노트를 PDF로 내보내기

데스크톱에서 모든 노트를 PDF로 내보낼 수 있어요. 모바일 Obsidian 앱에서는 PDF로 내보내기를 사용할 수 없어요.

1. 내보내려는 노트를 여세요.
2. [[명령어 팔레트]]를 열고 **PDF로 내보내기**를 선택하세요. 노트에서 **다른 옵션** ![[lucide-more-horizontal.svg#icon]]을 선택한 후 **PDF로 내보내기**를 선택할 수도 있어요.
3. 설정을 선택하세요.
    - **파일 이름을 제목으로 포함**은 PDF 상단에 파일 이름을 추가해요.
    - **페이지 크기**는 용지 크기를 설정해요. A3, A4, A5, Legal, Letter, Tabloid 중에서 선택할 수 있어요.
    - **가로**는 페이지를 가로 방향으로 전환해요.
    - **여백**은 페이지 여백을 **기본값**, **최소**, **없음** 중에서 설정해요.
    - **축소 배율**은 각 페이지의 콘텐츠 크기를 조절해요. 100이면 콘텐츠가 원래 크기를 유지해요. 값을 낮추면 텍스트와 이미지가 작아져서 각 페이지에 더 많은 내용이 들어가요.
4. **PDF로 내보내기**를 선택하세요.
5. 파일을 저장할 위치를 선택하세요.

> [!tip]- 다크 테마로 노트 내보내기
> 내보내기는 테마가 다크인 경우에도 항상 라이트 스타일을 사용해요. 내보내기 모양을 변경하려면 [[CSS 스니펫|CSS 스니펫]]을 사용할 수 있어요. Obsidian 포럼에 인쇄 및 내보내기용 스니펫 예제가 있어요.[^1]

[^1]: [How can I make export pdf look the same as my theme?](https://forum.obsidian.md/t/how-can-i-make-export-pdf-look-the-same-as-my-theme/75849)와 [PDF and print style reset with code syntax highlighting](https://forum.obsidian.md/t/pdf-and-print-style-reset-with-code-syntax-highlighting/31761)을 참고하세요.
