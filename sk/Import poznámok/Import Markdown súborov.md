Obsidian používa Markdown súbory `.md` ako primárny formát pre poznámky. Vďaka tomu je jednoduché importovať Markdown súbory do Obsidian. Mnohé aplikácie dokážu upravovať Markdown súbory alebo exportovať do tohto formátu.

Existuje niekoľko spôsobov, ako pridať Markdown súbory do vášho trezoru Obsidian:

1. Presuňte súbory alebo priečinky do okna [[Prieskumník súborov|Prieskumníka súborov]]
2. Použite systémový prehliadač súborov (napr. Windows Explorer alebo Finder v macOS) a presuňte súbory priamo do priečinka trezoru Obsidian.

## Import Markdown súborov pomocou Importéra

Použite oficiálny [[Importér|plugin Importer]], keď chcete vybrať priečinky v rámci importu, importovať archív `.zip`, štandardizovať formátovanie, presunúť inline značky do [[Vlastnosti|vlastností]] alebo aplikovať šablónu.

1. Otvorte **[[Nastavenia|Nastavenia]] → Pluginy tretích strán** a [nainštalujte Importer](obsidian://show-plugin?id=obsidian-importer).
2. Povoľte plugin Importer.
3. Otvorte **Importer** pomocou [[Paleta príkazov|palety príkazov]] alebo ikony na paneli nástrojov.
4. V časti **File format** vyberte **Markdown (.md, .zip)**.
5. Vyberte jednotlivé Markdown súbory, priečinky alebo zip archívy.
6. Skontrolujte zistené priečinky, možnosti výstupu, vygenerovanú šablónu a ukážky náhľadu.
7. Vyberte **Import** a počkajte na dokončenie importu.

Pozrite si [[Šablóny importéra|Šablóny Importéra]] na prispôsobenie názvu importovanej poznámky, vlastností a obsahu.
