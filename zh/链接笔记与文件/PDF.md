Obsidian 内置了 PDF 查看器，可以直接打开 PDF 文件。你还可以将 PDF 嵌入到笔记中、链接到其中的段落，以及将任意笔记导出为 PDF。关于 Obsidian 支持的文件类型，请参见[[支持的文件格式]]。

> [!info]+ 部分功能仅在桌面端可用
> 移动端应用无法在 PDF 中搜索、复制引用或复制到选区的链接，也无法将笔记导出为 PDF。

## 打开 PDF

在[[文件列表]]中，选择一个 PDF 文件即可在标签页中打开它。

> [!info]+ 不支持批注
> Obsidian 不支持在 PDF 中添加批注或高亮。如需标注 PDF，请使用其他应用，然后在仓库中打开更新后的文件。

查看器顶部有一个工具栏，包含以下控件。移动端应用具有相同的工具栏。

- **切换侧边栏**用于显示或隐藏侧边栏，**侧边栏选项**用于更改侧边栏显示的内容。
- **缩小**和**放大**用于更改页面大小。
- **显示选项**用于更改页面的布局方式。
- 页码框显示当前页码。输入页码可跳转到该页。

如需对 PDF 文件本身进行操作（如重命名或移动），请选择**更多选项** ![[lucide-more-horizontal.svg#icon]]。PDF 的此菜单中的选项比笔记少。参见[[更多选项菜单]]。

## 导航 PDF

选择**侧边栏选项**，然后选择要显示的内容。

- **缩略图**显示每页的小预览图。
- **目录**显示 PDF 的大纲（如果有的话）。
- **显示当前所在目录**在目录中高亮当前页面。

要链接到某一页，右键点击其缩略图并选择**复制到第 N 页的链接**（N 为页码）。然后将链接粘贴到笔记中。

要链接到某个章节，右键点击目录中的条目并选择**复制到"标题"的链接**（标题为条目名称）。在移动端，长按该条目即可。

## 更改 PDF 的显示方式

选择**显示选项**来更改布局。

- **适应宽度**和**适应高度**将页面调整为适合查看器的大小。
- **单页**一次显示一页。
- **双页（奇数）**并排显示两页，左侧从奇数页开始。例如，第 1 页和第 2 页一起显示，然后是第 3 页和第 4 页。
- **双页（偶数）**并排显示两页，左侧从偶数页开始。例如，第 1 页单独显示，然后第 2 页和第 3 页一起显示。
- **适应主题**在 Obsidian 使用深色主题时将 PDF 的颜色变暗。

## 搜索 PDF

在 PDF 中搜索仅在桌面端可用。移动端应用的 PDF 查看器没有搜索功能。

1. 按 `Ctrl+F`（Windows 和 Linux）或 `Command+F`（macOS）。
2. 在**输入并开始搜索…**中输入要查找的文本。
3. 选择上箭头或下箭头在匹配项之间跳转。

使用以下选项来更改搜索方式。

- **区分大小写**精确匹配大小写。该选项是搜索栏中的 **Aa** 按钮。
- **高亮所有**高亮每个匹配项。选择箭头旁边的设置按钮可找到此选项。
- **匹配变音符号**将带重音符号的字母视为不同的字母。此选项在同一设置菜单中。
- **全字匹配**仅查找完整的单词。此选项在同一设置菜单中。

选择关闭按钮退出搜索。

## 从 PDF 中复制文本

在桌面端，选中 PDF 中的文本，然后右键点击。

- **复制**复制文本。
- **复制为引用**将文本作为引用复制，后面附带指向该段落的链接。
- **复制到选区的链接**复制指向该段落的链接，以便粘贴到笔记中。

将引用粘贴到笔记中时，效果如下：

```md
> Obsidian is awesome

[[Gemmy.pdf#page=1&selection=32,0,32,14|Gemmy, page 1]]
```

选区链接则只有链接本身：

```md
[[Gemmy.pdf#page=1&selection=32,0,32,14|Gemmy, page 1]]
```

在移动端，选中 PDF 中的文本会显示设备的标准文本菜单。**复制为引用**和**复制到选区的链接**不可用。

## 嵌入 PDF

要在笔记中显示 PDF，请参见如何[[插入文件#在笔记中嵌入 PDF|在笔记中嵌入 PDF]]。嵌入的 PDF 具有与查看器相同的工具栏。选择**编辑这个区块**可修改嵌入链接。

## 将笔记导出为 PDF

你可以在桌面端将任意笔记导出为 PDF。移动端应用不支持导出为 PDF。

1. 打开要导出的笔记。
2. 打开[[命令面板]]并选择**导出 PDF**。你也可以在笔记中选择**更多选项** ![[lucide-more-horizontal.svg#icon]]，然后选择**导出 PDF**。
3. 选择设置。
    - **将笔记名作为标题**在 PDF 顶部添加文件名。
    - **页面尺寸**设置纸张大小。可选择 A3、A4、A5、Legal、Letter 或 Tabloid。
    - **横向打印**将页面横向排列。
    - **页边距**将页边距设置为**默认**、**小**或**无**。
    - **缩放百分比**缩放每页的内容。100 时内容保持原始大小。较低的值会使文字和图片变小，从而在每页中容纳更多内容。
4. 选择**导出**。
5. 选择保存文件的位置。

> [!tip]- 使用深色主题导出笔记
> 导出始终使用浅色样式，即使你的主题是深色的。要更改导出的外观，你可以使用 [[CSS 代码片段|CSS 样式代码片段]]。Obsidian 论坛上有打印和导出相关的片段示例。[^1]

[^1]: 参见 [How can I make export pdf look the same as my theme?](https://forum.obsidian.md/t/how-can-i-make-export-pdf-look-the-same-as-my-theme/75849) 和 [PDF and print style reset with code syntax highlighting](https://forum.obsidian.md/t/pdf-and-print-style-reset-with-code-syntax-highlighting/31761)。
