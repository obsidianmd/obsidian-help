[[迁移助手]]允许你定义模板来控制从其他应用导入笔记时的处理方式。这意味着你可以修改导入笔记的标题、属性和内容。

## 编辑导入模板

在预览上方选择**编辑**来编辑默认模板。你可以编辑：

- 显示为页面内标题的笔记名称。
- 笔记开头的属性。
- 笔记的 Markdown 内容。

选择**保存**返回预览。迁移助手会记住编辑过的内联模板，以便将来使用相同格式进行导入时使用。

你也可以从当前仓库中的 Markdown 文件加载模板。

## 预览结果

预览会显示你所选数据中最多十个样本。使用箭头按钮在样本之间切换。对导入设置和模板的更改会在任何内容添加到仓库之前更新预览。

某些附件、远程项目和跨笔记引用在导入运行之前无法完全解析。在这些情况下，预览可能会保留源链接或显示占位符。

## 模板语法

迁移助手模板使用由变量、[[过滤器]]和[[逻辑]]组成的语法。它使用与 [[Obsidian Web Clipper 简介|Web Clipper]] 相同的 [Knap](https://github.com/obsidianmd/knap) 语法。

使用双花括号插入变量，例如 `{{title}}`、`{{content}}` 或 `{{date}}`。变量可以在笔记名称、属性和内容中使用。

你可以使用[[过滤器]]修改变量。例如使用 `{{date|date:"YYYY-MM-DD"}}` 来更改日期格式。使用[[逻辑]]来实现更高级的条件判断、循环和变量赋值。

## 变量

以下变量可在任何迁移助手模板中使用：

| 变量               | 描述                                                                                               |
| ---------------- | --------------------------------------------------------------------------------------------------- |
| `{{body}}`       | 不含属性的 Markdown 正文（无前置元数据）。                                                             |
| `{{content}}`    | 应用所选模板之前的完整 Markdown。                                                                     |
| `{{ctime}}`      | 源文件创建时间，ISO 8601 时间戳格式；不可用时为空。                                                     |
| `{{date}}`       | 渲染模板时的当前日期和时间，ISO 8601 时间戳格式。                                                       |
| `{{importer}}`   | 迁移助手 ID，例如 `keep`、`html` 或 `notion-api`。                                                    |
| `{{folder}}`     | 最终的仓库相对父文件夹。当笔记位于仓库根目录时为空。                                                     |
| `{{mtime}}`      | 源文件修改时间，ISO 8601 时间戳格式；不可用时为空。                                                     |
| `{{noteName}}`   | 最终解析的笔记名称，已移除无效字符并为重复项添加后缀。                                                   |
| `{{path}}`       | 最终的仓库相对路径，包含 `.md` 扩展名。                                                                |
| `{{properties}}` | 包含前置元数据属性的对象。                                                                             |
| `{{source}}`     | 包含生成的属性和特定源值的对象。                                                                       |
| `{{sourceId}}`   | 迁移助手提供的稳定源标识符；否则为空。                                                                  |
| `{{time}}`       | `{{date}}` 的别名。                                                                                  |
| `{{title}}`      | 清理和去重之前的原始笔记标题。                                                                         |

## 属性的源值

对于支持[[属性]]的导入格式，源值也可作为顶层变量方便使用。

如果源值与共享变量同名，请通过 `{{source}}` 访问。例如，如果你的导入源有一个名为 `content` 的属性，可通过 `{{source.content}}` 访问，而 `{{content}}` 仍然是默认的迁移助手变量。

当字段名包含空格、标点符号或其他特殊字符时，请使用方括号表示法：

```twig
{{source["Project: status"]}}
```

## 模板示例

以下是一个使用变量和[[过滤器]]的模板示例：

```twig
---
created: {{ctime | date:"YYYY-MM-DD"}}
modified: {{mtime | date:"YYYY-MM-DD"}}
source: {{importer}}
---
# {{title}}

{{body}}
```

你可以使用[[逻辑]]有条件地向笔记中添加数据：

```twig
{% if tags %}
## 标签
{% for tag in tags %}
- {{tag}}
{% endfor %}
{% endif %}
```
