Obsidian Skills 是一组指令，用于教 AI 代理如何使用 Obsidian。它们遵循开放的 [Agent Skills](https://agentskills.io/specification) 格式，因此适用于任何支持 skills 的代理，包括 Claude Code、Claude、ChatGPT、Cursor、Gemini CLI、GitHub Copilot、Grok Bot、OpenCode 以及[更多代理](https://agentskills.io/clients)。

通过 Obsidian Skills，代理可以：

- 使用 [[Obsidian 风格的 Markdown 语法]]编写笔记，支持 [[内部链接|Wiki 链接]]、嵌入、标注和[[属性]]。
- 创建和编辑 [[Bases 简介|数据库]] 和 [[白板]] 文件。
- 通过 [[Obsidian CLI]] 在运行中的应用内搜索、读取和管理笔记。
- 使用 [[Obsidian Headless]] 在无需桌面应用的情况下同步和发布仓库。

这些技能在 [obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills) 开源。

## 安装

Obsidian 是 ChatGPT、Codex、Cursor 和 Grok Bot 的官方插件。其他代理可从 GitHub 安装技能。

### ChatGPT 和 Codex

从 ChatGPT 插件目录添加 [Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096)。该插件在 ChatGPT 和 Codex 中均可使用。

### Cursor

从 Cursor 市场安装 [Obsidian](https://cursor.com/marketplace/obsidian)。

### Grok Bot

打开 [Obsidian for Grok Bot](https://x.ai/bot/plugin/88871845) 并选择 **Add to Grok Bot**。

### Claude Code

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

之后如需获取新技能，运行 `claude plugin update obsidian@obsidian-skills`。

### Claude

Claude 以 ZIP 文件形式上传每个技能，因此请仅添加所需的技能：

1. 下载 [obsidian-skills](https://github.com/obsidianmd/obsidian-skills/archive/refs/heads/main.zip) 并解压。
2. 在 `plugins/obsidian/skills/` 中，将需要的每个技能文件夹压缩为 ZIP 文件，例如 `obsidian-markdown.zip`。
3. 在 Claude 中，前往 **Customize** → **Skills**，选择 **+** → **Create skill** → **Upload a skill**，然后选择 ZIP 文件。

参阅 [Using skills in Claude](https://support.claude.com/en/articles/12512180-using-skills-in-claude) 了解支持技能的订阅计划。

### Gemini CLI

```shell
gemini extensions install https://github.com/obsidianmd/obsidian-skills
```

### GitHub Copilot、OpenCode 及其他代理

使用 [npx skills](https://github.com/vercel-labs/skills) 安装，它会询问要安装到哪些代理中：

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

如需手动安装，将 `plugins/obsidian/skills/` 中的文件夹复制到代理的技能文件夹中，例如 GitHub Copilot 的 `~/.copilot/skills/`。

## 包含的技能

| 技能               | 功能说明                                                                                                                  |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `obsidian-markdown` | 创建和编辑 [[Obsidian 风格的 Markdown 语法]] 笔记。                                                                         |
| `obsidian-bases`    | 创建和编辑[[Bases 语法|数据库]]，支持视图、筛选、公式和汇总。                                         |
| `json-canvas`       | 使用 [JSON Canvas](https://jsoncanvas.org/) 格式创建和编辑 [[白板]] 文件。                                     |
| `obsidian-cli`      | 通过 [[Obsidian CLI]] 与仓库交互，包括插件和主题开发。                                    |
| `obsidian-headless` | 使用 [[Obsidian Headless]] 从命令行同步和发布仓库。                                                     |
| `defuddle`          | 使用 [Defuddle](https://github.com/kepano/defuddle) 从网页中提取干净的 Markdown。                                   |
| `knap`              | 使用 [Knap](https://github.com/obsidianmd/knap) 从 JSON 或 CSV 数据渲染 Markdown 模板。                             |

## 要求

`obsidian-cli` 技能需要 Obsidian 桌面应用正在运行且已[[Obsidian CLI#安装 Obsidian CLI|开启 Obsidian CLI]]，同时需要能在计算机上执行命令的代理。

Markdown、Bases 和 Canvas 技能仅描述文件格式，因此在任何能够读写仓库文件的代理中均可使用。

Defuddle、Knap 和 Obsidian Headless 是独立工具，未随技能一起打包。当缺少某个工具时，技能会在通过 npm 安装前征得同意。

## 隐私

Obsidian Skills 本身不会发送任何数据。当代理使用它们时，代理读取的笔记会成为对话的一部分，并由您使用的 AI 模型进行处理。在将代理指向包含敏感笔记的仓库之前，请查阅代理的隐私政策。
