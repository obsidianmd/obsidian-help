连接器让你可以将 Obsidian 连接到任何 AI 代理，包括 Claude、ChatGPT、Antigravity、Cursor、GitHub Copilot、Grok Bot、Hermes、Kiro、Muse、OpenCode 以及[更多](https://agentskills.io/clients)。

这意味着你的代理可以学会如何：

- 使用 [[Obsidian 风格的 Markdown 语法]]编写笔记，包括 [[内部链接|Wiki 链接]]、嵌入、标注和[[属性|属性]]。
- 创建和编辑[[Bases 简介|数据库]]和 [[白板|Canvas]] 文件。
- 通过 [[Obsidian CLI]] 在运行中的应用里搜索、阅读和管理笔记。
- 使用 [[Obsidian Headless]] 在无桌面应用的情况下同步和发布仓库。

这些技能在 [obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills) 开源。

## 安装

你可以在 Claude、ChatGPT、Dots、Cursor、Grok Bot、Hermes 和 Kiro 的插件列表中搜索找到 Obsidian。大多数其他代理可以通过向其发送本页面的链接来安装这些技能。

### Claude

从官方 Claude 插件目录添加 [Obsidian](https://claude.ai/customize/plugins/id/a38fa062-ebd3-48e0-9a0a-1875a6e94ad5%40anthropic-plugin-directory)。

对于 Claude Code CLI，使用：

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

要在之后获取新技能，运行 `claude plugin update obsidian@obsidian-skills`。

### ChatGPT

从 ChatGPT 插件目录添加 [Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096)。该插件适用于 ChatGPT、Codex 和 Dots。

### Antigravity

在 Antigravity CLI 中运行：

```shell
agy plugin install https://github.com/obsidianmd/obsidian-skills
```

### Grok Bot

打开 [Obsidian for Grok Bot](https://x.ai/bot/plugin/88871845) 并选择 **Add to Grok Bot**。

### Muse

让 Muse 从 https://github.com/obsidianmd/obsidian-skills 安装技能。

Muse 在 Meta 的云上运行，因此 `obsidian-cli` 技能在那里无法使用。如果你在 Muse 中使用 Obsidian Headless，你会在 Meta 的云上登录并同步你的仓库。

### Cursor

从 Cursor Marketplace 安装 [Obsidian](https://cursor.com/marketplace/obsidian)。

### Hermes Agent

```shell
hermes plugins install obsidian
```

### Kiro

```shell
kiro-cli powers install obsidian
```

### GitHub Copilot、OpenCode 及其他代理

使用 [npx skills](https://github.com/vercel-labs/skills) 安装，它会询问要安装到哪些代理中：

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

要手动安装，将 `plugins/obsidian/skills/` 中的文件夹复制到你的代理的技能文件夹中，例如 GitHub Copilot 的 `~/.copilot/skills/`。

## 包含的技能

| 技能                | 功能                                                                                                                          |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `obsidian-markdown` | 创建和编辑 [[Obsidian 风格的 Markdown 语法]]笔记。                                                                             |
| `obsidian-bases`    | 创建和编辑包含视图、筛选、公式和汇总的[[Bases 语法|数据库]]。                                                                    |
| `json-canvas`       | 使用 [JSON Canvas](https://jsoncanvas.org/) 格式创建和编辑 [[白板|Canvas]] 文件。                                               |
| `obsidian-cli`      | 通过 [[Obsidian CLI]] 与你的仓库交互，包括插件和主题开发。                                                                       |
| `obsidian-headless` | 使用 [[Obsidian Headless]] 从命令行同步和发布仓库。                                                                             |
| `defuddle`          | 使用 [Defuddle](https://github.com/kepano/defuddle) 从网页中提取干净的 Markdown。                                               |
| `knap`              | 使用 [Knap](https://github.com/obsidianmd/knap) 从 JSON 或 CSV 数据渲染 Markdown 模板。                                        |

## 要求

`obsidian-cli` 技能需要 Obsidian 桌面应用正在运行且[[Obsidian CLI#安装 Obsidian CLI|已开启 Obsidian CLI]]，以及一个可以在你计算机上运行命令的代理。

Markdown、数据库和 Canvas 技能仅描述文件格式，因此它们适用于任何可以在你的仓库中读写文件的代理。

Defuddle、Knap 和 Obsidian Headless 是独立的工具，不与技能捆绑在一起。当缺少某个工具时，技能会在从 npm 安装之前先询问。

## 隐私

Obsidian 连接器本身不会发送任何内容。当代理使用它们时，它读取的笔记会成为对话的一部分，并由你使用的 AI 模型处理。在将代理指向包含敏感笔记的仓库之前，请查看你的代理的隐私政策。
