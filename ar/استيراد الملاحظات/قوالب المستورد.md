يتيح لك [[المستورد]] تحديد قوالب تتحكم في كيفية استيراد ملاحظاتك من التطبيقات الأخرى. هذا يعني أنه يمكنك تعديل العنوان والخصائص ومحتوى الملاحظات التي تستوردها.

## تحرير قالب الاستيراد

حدد **تحرير** أعلى المعاينة لتحرير القالب الافتراضي. يمكنك تحرير:

- اسم الملاحظة الظاهر كعنوان ضمن السطر.
- الخصائص في بداية الملاحظة.
- محتوى Markdown الخاص بالملاحظة.

حدد **حفظ** للعودة إلى المعاينة. يتذكر المستورد القالب المُعدَّل ضمنيًا لعمليات الاستيراد المستقبلية التي تستخدم نفس التنسيق.

بدلاً من ذلك، يمكنك تحميل قالب من ملف Markdown في الخزنة الحالية.

## معاينة النتائج

تعرض المعاينة ما يصل إلى عشر عينات من البيانات التي حددتها. استخدم أزرار الأسهم للتنقل بين العينات. تُحدّث التغييرات على إعدادات الاستيراد والقالب المعاينة قبل إضافة أي شيء إلى خزنتك.

لا يمكن حل بعض المرفقات والعناصر البعيدة والمراجع بين الملاحظات بالكامل حتى يتم تشغيل عملية الاستيراد. في هذه الحالات، قد تحتفظ المعاينة بالرابط المصدري أو تعرض عنصرًا نائبًا.

## صيغة القالب

تستخدم قوالب المستورد صيغة تتكون من متغيرات و[[تصفية|مرشحات]] و[[المنطق]]. تستخدم نفس صيغة [Knap](https://github.com/obsidianmd/knap) المستخدمة في [[مقدمة عن قاصّ أوبسيديان للويب|قاصّ الويب]].

أدرج المتغيرات باستخدام أقواس مزدوجة، مثل `{{title}}` أو `{{content}}` أو `{{date}}`. يمكن استخدام المتغيرات في اسم الملاحظة والخصائص والمحتوى.

يمكنك تعديل المتغيرات باستخدام [[تصفية|المرشحات]]. على سبيل المثال لتغيير تنسيق التاريخ باستخدام `{{date|date:"YYYY-MM-DD"}}`. استخدم [[المنطق]] للعبارات الشرطية والحلقات وتعيين المتغيرات الأكثر تقدمًا.

## المتغيرات

المتغيرات التالية متاحة للاستخدام في أي قالب من قوالب المستورد:

| المتغير         | الوصف                                                                                         |
| ---------------- | --------------------------------------------------------------------------------------------------- |
| `{{body}}`       | محتوى Markdown بدون خصائص (بدون بيانات وصفية في بداية الملف).                                                  |
| `{{content}}`    | محتوى Markdown الكامل قبل تطبيق القالب المحدد.                                          |
| `{{ctime}}`      | وقت إنشاء المصدر كطابع زمني بتنسيق ISO 8601؛ فارغ عند عدم التوفر.                              |
| `{{date}}`       | التاريخ والوقت الحاليان عند عرض القالب، كطابع زمني بتنسيق ISO 8601.                      |
| `{{importer}}`   | معرّف المستورد، مثل `keep` أو `html` أو `notion-api`.                                               |
| `{{folder}}`     | المجلد الأب النهائي بالنسبة للخزنة. فارغ عندما تكون الملاحظة في جذر الخزنة.                       |
| `{{mtime}}`      | وقت تعديل المصدر كطابع زمني بتنسيق ISO 8601؛ فارغ عند عدم التوفر.                          |
| `{{noteName}}`   | اسم الملاحظة النهائي المُحلَّل، بعد إزالة الأحرف غير الصالحة وإضافة أي لواحق للتكرارات. |
| `{{path}}`       | المسار النهائي بالنسبة للخزنة، بما في ذلك امتداد `.md`.                                           |
| `{{properties}}` | كائن يحتوي على خصائص البيانات الوصفية في بداية الملف.                                                       |
| `{{source}}`     | كائن يحتوي على الخصائص المُولَّدة والقيم الخاصة بالمصدر.                                  |
| `{{sourceId}}`   | معرّف مصدر ثابت عندما يوفره المستورد؛ وإلا فارغ.                           |
| `{{time}}`       | اسم بديل لـ `{{date}}`.                                                                               |
| `{{title}}`      | عنوان الملاحظة الأصلي قبل التنظيف وإزالة التكرارات.                                          |

## القيم المصدرية للخصائص

بالنسبة لتنسيقات الاستيراد التي تدعم [[الخصائص]]، تتوفر القيم المصدرية أيضًا كمتغيرات عالية المستوى للسهولة.

إذا كان للقيمة المصدرية نفس اسم متغير مشترك، يمكنك الوصول إليها من خلال `{{source}}`. على سبيل المثال، إذا كان مصدر الاستيراد الخاص بك يحتوي على خاصية باسم `content` فهي متاحة كـ `{{source.content}}`، بينما يبقى `{{content}}` متغير المستورد الافتراضي.

استخدم صيغة الأقواس المربعة عندما يحتوي اسم الحقل على مسافات أو علامات ترقيم أو أحرف خاصة أخرى:

```twig
{{source["Project: status"]}}
```

## مثال على قالب

إليك مثالاً على قالب يستخدم متغيرات و[[تصفية|مرشحات]]:

```twig
---
created: {{ctime | date:"YYYY-MM-DD"}}
modified: {{mtime | date:"YYYY-MM-DD"}}
source: {{importer}}
---
# {{title}}

{{body}}
```

يمكنك إضافة بيانات إلى ملاحظة بشكل شرطي باستخدام [[المنطق]]:

```twig
{% if tags %}
## وسوم
{% for tag in tags %}
- {{tag}}
{% endfor %}
{% endif %}
```
