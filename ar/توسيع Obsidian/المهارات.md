مهارات Obsidian هي تعليمات تُعلّم وكلاء الذكاء الاصطناعي كيفية العمل مع Obsidian. تتبع تنسيق [Agent Skills](https://agentskills.io/specification) المفتوح، لذا تعمل مع أي وكيل يدعم المهارات، بما في ذلك Claude Code وClaude وChatGPT وCursor وGemini CLI وGitHub Copilot وGrok Bot وOpenCode و[غيرها الكثير](https://agentskills.io/clients).

مع مهارات Obsidian يمكن للوكيل:

- كتابة ملاحظات بتنسيق [[Markdown بنكهة Obsidian]]، مع [[روابط داخلية|روابط ويكي]] وتضمينات ومربعات تنبيه و[[الخصائص|الخصائص]].
- إنشاء وتحرير ملفات [[مقدمة إلى قواعد البيانات|قواعد البيانات]] و[[اللوحة|Canvas]].
- البحث والقراءة وإدارة الملاحظات في التطبيق قيد التشغيل باستخدام [[Obsidian CLI]].
- مزامنة ونشر الخزائن بدون تطبيق سطح المكتب باستخدام [[Obsidian Headless]].

المهارات مفتوحة المصدر على [obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills).

## التثبيت

Obsidian هو مكوّن إضافي رسمي لـ ChatGPT وCodex وCursor وGrok Bot. الوكلاء الآخرون يثبّتون المهارات من GitHub.

### ChatGPT و Codex

أضف [Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096) من دليل إضافات ChatGPT. يعمل المكوّن الإضافي في كل من ChatGPT وCodex.

### Cursor

ثبّت [Obsidian](https://cursor.com/marketplace/obsidian) من سوق Cursor.

### Grok Bot

افتح [Obsidian for Grok Bot](https://x.ai/bot/plugin/88871845) واختر **Add to Grok Bot**.

### Claude Code

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

للحصول على مهارات جديدة لاحقًا، شغّل `claude plugin update obsidian@obsidian-skills`.

### Claude

يرفع Claude كل مهارة كملف ZIP، لذا أضف فقط المهارات التي تحتاجها:

1. نزّل [obsidian-skills](https://github.com/obsidianmd/obsidian-skills/archive/refs/heads/main.zip) وفك ضغطه.
2. في `plugins/obsidian/skills/`، اضغط مجلد كل مهارة تريدها في ملف ZIP، مثل `obsidian-markdown.zip`.
3. في Claude، انتقل إلى **Customize** ← **Skills**، اختر **+** ← **Create skill** ← **Upload a skill**، واختر ملف ZIP.

راجع [Using skills in Claude](https://support.claude.com/en/articles/12512180-using-skills-in-claude) للخطط التي تدعم المهارات.

### Gemini CLI

```shell
gemini extensions install https://github.com/obsidianmd/obsidian-skills
```

### GitHub Copilot وOpenCode ووكلاء آخرون

ثبّت باستخدام [npx skills](https://github.com/vercel-labs/skills)، الذي يسألك عن الوكلاء المراد التثبيت فيها:

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

للتثبيت يدويًا، انسخ المجلدات في `plugins/obsidian/skills/` إلى مجلد مهارات وكيلك، مثل `~/.copilot/skills/` لـ GitHub Copilot.

## المهارات المضمّنة

| المهارة              | ما تفعله                                                                                                                      |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `obsidian-markdown`  | إنشاء وتحرير ملاحظات [[Markdown بنكهة Obsidian]].                                                                            |
| `obsidian-bases`     | إنشاء وتحرير [[صيغة قواعد البيانات|قواعد البيانات]] مع العروض والتصفية والمعادلات والملخصات.                                  |
| `json-canvas`        | إنشاء وتحرير ملفات [[اللوحة|Canvas]] باستخدام تنسيق [JSON Canvas](https://jsoncanvas.org/).                                   |
| `obsidian-cli`       | التفاعل مع خزنتك عبر [[Obsidian CLI]]، بما في ذلك تطوير الإضافات والسمات.                                                    |
| `obsidian-headless`  | مزامنة ونشر الخزائن من سطر الأوامر باستخدام [[Obsidian Headless]].                                                            |
| `defuddle`           | استخراج Markdown نظيف من صفحات الويب باستخدام [Defuddle](https://github.com/kepano/defuddle).                                 |
| `knap`               | عرض قوالب Markdown من بيانات JSON أو CSV باستخدام [Knap](https://github.com/obsidianmd/knap).                                 |

## المتطلبات

تحتاج مهارة `obsidian-cli` إلى تشغيل تطبيق Obsidian لسطح المكتب مع [[Obsidian CLI#Install Obsidian CLI|تفعيل Obsidian CLI]]، ووكيل يمكنه تشغيل الأوامر على جهازك.

مهارات Markdown وقواعد البيانات وCanvas تصف تنسيقات الملفات فقط، لذا تعمل في أي وكيل يمكنه قراءة وكتابة الملفات في خزنتك.

Defuddle وKnap وObsidian Headless هي أدوات منفصلة غير مضمّنة مع المهارات. عندما تكون إحداها مفقودة، تسأل المهارة قبل تثبيتها من npm.

## الخصوصية

لا ترسل مهارات Obsidian أي شيء بنفسها. عندما يستخدمها وكيل، تصبح الملاحظات التي يقرأها جزءًا من المحادثة ويعالجها نموذج الذكاء الاصطناعي الذي تستخدمه. راجع سياسة خصوصية وكيلك قبل توجيهه إلى خزنة تحتوي على ملاحظات حساسة.
