تتيح لك أدوات الاتصال ربط Obsidian بأي وكيل ذكاء اصطناعي بما في ذلك Claude وChatGPT وAntigravity وCursor وGitHub Copilot وGrok Bot وHermes وKiro وMuse وOpenCode و[غيرها الكثير](https://agentskills.io/clients).

هذا يعني أن وكلاءك يمكنهم تعلم كيفية:

- كتابة ملاحظات بتنسيق [[Markdown بنكهة Obsidian]]، مع [[روابط داخلية|روابط ويكي]] وتضمينات ومربعات تنبيه و[[الخصائص|خصائص]].
- إنشاء وتحرير ملفات [[مقدمة إلى قواعد البيانات|قواعد البيانات]] و[[اللوحة|Canvas]].
- البحث والقراءة وإدارة الملاحظات في التطبيق قيد التشغيل باستخدام [[Obsidian CLI]].
- مزامنة ونشر الخزائن بدون تطبيق سطح المكتب باستخدام [[Obsidian Headless]].

المهارات مفتوحة المصدر على [obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills).

## التثبيت

يمكنك العثور على Obsidian بالبحث في قائمة الإضافات في Claude وChatGPT وDots وCursor وGrok Bot وHermes وKiro. معظم الوكلاء الآخرين يمكنهم تثبيت المهارات إذا أرسلت لهم رابطًا لهذه الصفحة.

### Claude

أضف [Obsidian](https://claude.ai/customize/plugins/id/a38fa062-ebd3-48e0-9a0a-1875a6e94ad5%40anthropic-plugin-directory) من دليل إضافات Claude الرسمي.

لواجهة سطر أوامر Claude Code استخدم:

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

للحصول على مهارات جديدة لاحقًا، شغّل `claude plugin update obsidian@obsidian-skills`.

### ChatGPT

أضف [Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096) من دليل إضافات ChatGPT. تعمل الإضافة في ChatGPT وCodex وDots.

### Antigravity

في واجهة سطر أوامر Antigravity، شغّل:

```shell
agy plugin install https://github.com/obsidianmd/obsidian-skills
```

### Grok Bot

افتح [Obsidian for Grok Bot](https://x.ai/bot/plugin/88871845) واختر **Add to Grok Bot**.

### Muse

اطلب من Muse تثبيت المهارات من https://github.com/obsidianmd/obsidian-skills.

يعمل Muse في سحابة Meta، لذا لا تعمل مهارة `obsidian-cli` هناك. إذا استخدمت Obsidian Headless في Muse، فإنك تسجل الدخول وتزامن خزنتك في سحابة Meta.

### Cursor

ثبّت [Obsidian](https://cursor.com/marketplace/obsidian) من متجر Cursor.

### Hermes Agent

```shell
hermes plugins install obsidian
```

### Kiro

```shell
kiro-cli powers install obsidian
```

### GitHub Copilot وOpenCode ووكلاء آخرون

ثبّت باستخدام [npx skills](https://github.com/vercel-labs/skills)، الذي يسألك عن الوكلاء التي تريد التثبيت فيها:

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

للتثبيت يدويًا، انسخ المجلدات في `plugins/obsidian/skills/` إلى مجلد مهارات وكيلك، مثلاً `~/.copilot/skills/` لـ GitHub Copilot.

## المهارات المُضمّنة

| المهارة             | ما تفعله                                                                                                                      |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `obsidian-markdown` | إنشاء وتحرير ملاحظات [[Markdown بنكهة Obsidian]].                                                                            |
| `obsidian-bases`    | إنشاء وتحرير [[صيغة قواعد البيانات|قواعد البيانات]] مع العروض والتصفية والمعادلات والملخصات.                                  |
| `json-canvas`       | إنشاء وتحرير ملفات [[اللوحة|Canvas]] باستخدام تنسيق [JSON Canvas](https://jsoncanvas.org/).                                   |
| `obsidian-cli`      | التفاعل مع خزنتك عبر [[Obsidian CLI]]، بما في ذلك تطوير الإضافات والسمات.                                                    |
| `obsidian-headless` | مزامنة ونشر الخزائن من سطر الأوامر باستخدام [[Obsidian Headless]].                                                            |
| `defuddle`          | استخراج Markdown نظيف من صفحات الويب باستخدام [Defuddle](https://github.com/kepano/defuddle).                                 |
| `knap`              | عرض قوالب Markdown من بيانات JSON أو CSV باستخدام [Knap](https://github.com/obsidianmd/knap).                                 |

## المتطلبات

تحتاج مهارة `obsidian-cli` إلى تطبيق Obsidian لسطح المكتب قيد التشغيل مع [[Obsidian CLI#Install Obsidian CLI|تفعيل Obsidian CLI]]، ووكيل يمكنه تشغيل الأوامر على حاسوبك.

مهارات Markdown وقواعد البيانات وCanvas تصف فقط تنسيقات الملفات، لذا تعمل في أي وكيل يمكنه قراءة وكتابة الملفات في خزنتك.

Defuddle وKnap وObsidian Headless هي أدوات منفصلة غير مُضمّنة مع المهارات. عندما تكون إحداها مفقودة، تسأل المهارة قبل تثبيتها من npm.

## الخصوصية

لا ترسل أدوات اتصال Obsidian أي شيء من تلقاء نفسها. عندما يستخدمها وكيل، تصبح الملاحظات التي يقرأها جزءًا من المحادثة ويعالجها نموذج الذكاء الاصطناعي الذي تستخدمه. راجع سياسة خصوصية وكيلك قبل توجيهه إلى خزنة تحتوي على ملاحظات حساسة.
