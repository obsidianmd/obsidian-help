يقوم محول التنسيقات بترحيل [[الخصائص#الخصائص المهملة|تنسيقات الخصائص المهملة]] إلى التنسيق الحالي المستخدم في Obsidian.

> [!warning] انسخ خزنتك احتياطيًا
> يُطبّق التحويل على خزنتك بالكامل. قم بـ[[النسخ الاحتياطي لملفات Obsidian]] قبل البدء.

لتحويل الخصائص في ملاحظاتك:

1. افتح [[لوحة الأوامر]].
2. اختر **مستورد تنسيق Markdown: ترحيل الترويسة (Frontmatter)**.
3. اختر **إبدء التحويل**.

## تنسيقات الخصائص المدعومة

يقوم المحوّل بتحديث الأسماء المستعارة والوسوم وأصناف CSS من التنسيقات المهملة:

**الأسماء المستعارة**

```yaml
# قبل

alias: My Note Title

# بعد

aliases:
  - My Note Title
```

**الوسوم**

```yaml
# قبل

tag: project, important

# بعد

tags:
  - project
  - important
```

**أصناف CSS**

```yaml
# قبل

cssclass: custom-style

# بعد

cssclasses:
  - custom-style
```
