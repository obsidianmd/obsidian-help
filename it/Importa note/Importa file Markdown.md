Obsidian utilizza file Markdown `.md` come formato principale per le note. Questo rende facile importare file Markdown in Obsidian. Molte app possono modificare file Markdown o esportare in questo formato.

Esistono diversi modi per aggiungere file Markdown alla tua cassaforte di Obsidian:

1. Trascina e rilascia file o cartelle nella finestra dell'[[Esplora file]]
2. Usa il file browser del tuo sistema (ad esempio Esplora risorse su Windows o Finder su macOS) e sposta i tuoi file direttamente nella cartella della cassaforte di Obsidian.

## Importare file Markdown con Importer

Usa il [[Importatore|plugin Importer]] ufficiale quando vuoi selezionare cartelle all'interno di un'importazione, importare un archivio `.zip`, standardizzare la formattazione, spostare le etichette inline nelle [[Proprietà|proprietà]] o applicare un modello.

1. Apri **[[Impostazioni|Impostazioni]] → Plugin di terze parti** e [installa Importer](obsidian://show-plugin?id=obsidian-importer).
2. Abilita il plugin Importer.
3. Apri **Importer** usando il [[Riquadro comandi|riquadro comandi]] o l'icona nella barra multifunzione.
4. Sotto **Formato file**, seleziona **Markdown (.md, .zip)**.
5. Scegli singoli file Markdown, cartelle o archivi zip.
6. Controlla le cartelle rilevate, le opzioni di output, il modello generato e gli esempi di anteprima.
7. Seleziona **Importa** e attendi il completamento dell'importazione.

Consulta [[Modelli per l'importazione|Modelli di Importer]] per personalizzare il nome della nota importata, le proprietà e il contenuto.
