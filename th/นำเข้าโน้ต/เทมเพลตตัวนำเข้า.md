[[ตัวนำเข้า]] ช่วยให้คุณกำหนดเทมเพลตที่ควบคุมวิธีการนำเข้าโน้ตจากแอปอื่นได้ ซึ่งหมายความว่าคุณสามารถแก้ไขชื่อ คุณสมบัติ และเนื้อหาของโน้ตที่คุณนำเข้าได้

## แก้ไขเทมเพลตการนำเข้า

เลือก **แก้ไข** เหนือพรีวิวเพื่อแก้ไขเทมเพลตค่าเริ่มต้น คุณสามารถแก้ไข:

- ชื่อโน้ตที่แสดงเป็นชื่อเรื่องแบบอินไลน์
- คุณสมบัติที่อยู่ตอนต้นของโน้ต
- เนื้อหา Markdown ของโน้ต

เลือก **เซฟ** เพื่อกลับไปยังพรีวิว ตัวนำเข้าจะจำเทมเพลตอินไลน์ที่แก้ไขแล้วสำหรับการนำเข้าในอนาคตที่ใช้รูปแบบเดียวกัน

อีกทางเลือกหนึ่ง คุณสามารถโหลดเทมเพลตจากไฟล์ Markdown ในห้องนิรภัยปัจจุบันได้

## พรีวิวผลลัพธ์

พรีวิวจะแสดงตัวอย่างสูงสุดสิบรายการจากข้อมูลที่คุณเลือก ใช้ปุ่มลูกศรเพื่อย้ายระหว่างตัวอย่าง การเปลี่ยนแปลงการตั้งค่าการนำเข้าและเทมเพลตจะอัปเดตพรีวิวก่อนที่จะเพิ่มอะไรลงในห้องนิรภัยของคุณ

ไฟล์แนบบางรายการ รายการระยะไกล และการอ้างอิงข้ามโน้ตอาจไม่สามารถแก้ไขได้อย่างสมบูรณ์จนกว่าการนำเข้าจะทำงาน ในกรณีเหล่านั้น พรีวิวอาจยังคงแสดงลิงก์ต้นทางหรือแสดงตัวยึดตำแหน่ง

## ไวยากรณ์เทมเพลต

เทมเพลตตัวนำเข้าใช้ไวยากรณ์ที่ประกอบด้วยตัวแปร [[ตัวกรอง]] และ [[ลอจิก]] โดยใช้ไวยากรณ์ [Knap](https://github.com/obsidianmd/knap) เดียวกับ [[แนะนำ Obsidian Web Clipper|Web Clipper]]

แทรกตัวแปรด้วยวงเล็บปีกกาคู่ เช่น `{{title}}`, `{{content}}` หรือ `{{date}}` ตัวแปรสามารถใช้ในชื่อโน้ต คุณสมบัติ และเนื้อหาได้

คุณสามารถแก้ไขตัวแปรโดยใช้ [[ตัวกรอง]] ตัวอย่างเช่น เปลี่ยนฟอร์แมตวันที่โดยใช้ `{{date|date:"YYYY-MM-DD"}}` ใช้ [[ลอจิก]] สำหรับเงื่อนไข ลูป และการกำหนดค่าตัวแปรขั้นสูง

## ตัวแปร

ตัวแปรต่อไปนี้สามารถใช้ได้ในเทมเพลตตัวนำเข้าทุกรายการ:

| ตัวแปร           | คำอธิบาย                                                                                            |
| ---------------- | --------------------------------------------------------------------------------------------------- |
| `{{body}}`       | เนื้อหา Markdown โดยไม่มีคุณสมบัติ (ไม่มีเมทาดาทาตอนต้น)                                          |
| `{{content}}`    | Markdown ทั้งหมดก่อนที่จะใช้เทมเพลตที่เลือก                                                        |
| `{{ctime}}`      | เวลาสร้างต้นทางเป็น ISO 8601 timestamp; ว่างเมื่อไม่มีข้อมูล                                       |
| `{{date}}`       | วันที่และเวลาปัจจุบันเมื่อเรนเดอร์เทมเพลต เป็น ISO 8601 timestamp                                 |
| `{{importer}}`   | ID ตัวนำเข้า เช่น `keep`, `html` หรือ `notion-api`                                                  |
| `{{folder}}`     | โฟลเดอร์แม่สัมพัทธ์กับห้องนิรภัยสุดท้าย ว่างเมื่อโน้ตอยู่ที่รากของห้องนิรภัย                      |
| `{{mtime}}`      | เวลาแก้ไขต้นทางเป็น ISO 8601 timestamp; ว่างเมื่อไม่มีข้อมูล                                       |
| `{{noteName}}`   | ชื่อโน้ตสุดท้ายที่แก้ไขแล้ว หลังจากลบอักขระที่ไม่ถูกต้องและเพิ่มส่วนต่อท้ายสำหรับรายการที่ซ้ำกัน  |
| `{{path}}`       | เส้นทางสัมพัทธ์กับห้องนิรภัยสุดท้าย รวมถึงนามสกุล `.md`                                            |
| `{{properties}}` | อ็อบเจกต์ที่ประกอบด้วยคุณสมบัติเมทาดาทาตอนต้น                                                      |
| `{{source}}`     | อ็อบเจกต์ที่ประกอบด้วยคุณสมบัติที่สร้างขึ้นและค่าเฉพาะของแหล่งต้นทาง                               |
| `{{sourceId}}`   | ตัวระบุแหล่งต้นทางคงที่เมื่อตัวนำเข้าจัดเตรียมให้; มิฉะนั้นจะว่าง                                  |
| `{{time}}`       | นามแฝงสำหรับ `{{date}}`                                                                             |
| `{{title}}`      | ชื่อโน้ตดั้งเดิมก่อนการทำความสะอาดและการกำจัดรายการซ้ำ                                              |

## ค่าต้นทางสำหรับคุณสมบัติ

สำหรับรูปแบบการนำเข้าที่รองรับ [[คุณสมบัติ]] ค่าต้นทางจะมีให้ใช้เป็นตัวแปรระดับบนสุดเพื่อความสะดวก

หากค่าต้นทางมีชื่อเดียวกับตัวแปรที่ใช้ร่วมกัน ให้เข้าถึงผ่าน `{{source}}` ตัวอย่างเช่น หากแหล่งนำเข้าของคุณมีคุณสมบัติชื่อ `content` จะสามารถเข้าถึงได้เป็น `{{source.content}}` ในขณะที่ `{{content}}` ยังคงเป็นตัวแปรค่าเริ่มต้นของตัวนำเข้า

ใช้เครื่องหมายวงเล็บเหลี่ยมเมื่อชื่อฟิลด์มีช่องว่าง เครื่องหมายวรรคตอน หรืออักขระพิเศษอื่นๆ:

```twig
{{source["Project: status"]}}
```

## ตัวอย่างเทมเพลต

นี่คือตัวอย่างเทมเพลตที่ใช้ตัวแปรและ [[ตัวกรอง]]:

```twig
---
created: {{ctime | date:"YYYY-MM-DD"}}
modified: {{mtime | date:"YYYY-MM-DD"}}
source: {{importer}}
---
# {{title}}

{{body}}
```

คุณสามารถเพิ่มข้อมูลลงในโน้ตแบบมีเงื่อนไขโดยใช้ [[ลอจิก]]:

```twig
{% if tags %}
## แท็ก
{% for tag in tags %}
- {{tag}}
{% endfor %}
{% endif %}
```
