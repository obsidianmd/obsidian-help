เมนู**ตัวเลือกเพิ่มเติม**แสดงรายการการดำเนินการที่คุณสามารถทำกับโน้ตที่ใช้งานอยู่ บางรายการจะปรากฏเฉพาะเมื่อ[[ปลั๊กอินหลัก|ปลั๊กอินหลัก]]หรือบริการเช่น [[แนะนำ Obsidian Publish|Obsidian Publish]] ถูกเปิดใช้งาน

## เปิดเมนู

ที่มุมขวาบนของโน้ต เลือก **ตัวเลือกเพิ่มเติม** ![[lucide-more-horizontal.svg#icon]]

บนเดสก์ท็อป คุณยังสามารถคลิกขวาที่แท็บของโน้ตได้ด้วย เมนูนั้นจะมีรายการเดียวกันรวมถึงรายการเพิ่มเติมอีกบางส่วน ดู [[#เมนูแท็บ]]

> [!info]+ รายการเปลี่ยนแปลงตามมุมมอง
> เมนูขึ้นอยู่กับมุมมองที่ใช้งานอยู่ เช่น โน้ตหรือผืนผ้าใบ หน้านี้อธิบายเกี่ยวกับโน้ต Markdown รายการบางอย่างยังเปลี่ยนแปลงตามระบบปฏิบัติการของคุณด้วย

## เดสก์ท็อป

### มุมมองและเลย์เอาต์

- **แบ็คลิงค์ในเอกสาร** แสดงแบ็คลิงค์ของโน้ตภายในโน้ต ต้องใช้ปลั๊กอิน Backlinks ดู [[แบ็คลิงค์#แสดงแบ็คลิงค์ในโน้ต|แสดงแบ็คลิงค์ในโน้ต]]
- **โหมดอ่าน** และ **โหมดซอร์ส** เปลี่ยนลักษณะการแสดงผลของโน้ตและวิธีที่คุณแก้ไข ดู [[มุมมองและโหมดแก้ไข]]
- **แบ่งทางขวา** และ **แบ่งลงล่าง** เปิดโน้ตในบานหน้าต่างใหม่ ดู [[แท็บ]]
- **เปิดในหน้าต่างใหม่** เปิดโน้ตในหน้าต่างของตัวเอง ดู [[หน้าต่างแยก]]

### จัดการโน้ต

- **เปลี่ยนชื่อ** เปลี่ยนชื่อโน้ต ดู [[จัดการโน้ต#เปลี่ยนชื่อโน้ต|เปลี่ยนชื่อโน้ต]]
- **ย้ายไฟล์ไปที่...** ย้ายโน้ตไปยังโฟลเดอร์อื่น ดู [[ตัวจัดการไฟล์]]
- **เพิ่มบุ๊กมาร์ก...** เพิ่มโน้ตไปยังบุ๊กมาร์กของคุณ ต้องใช้ปลั๊กอิน Bookmarks ดู [[บุ๊กมาร์ก#เพิ่มบุ๊กมาร์ก|เพิ่มบุ๊กมาร์ก]]
- **รวมไฟล์ทั้งไฟล์กับ...** รวมโน้ตกับโน้ตอื่น ต้องใช้ปลั๊กอิน Note composer ดู [[Note composer#ผสานโน้ต|ผสานโน้ต]]
- **เผยแพร่ไฟล์ปัจจุบัน** เผยแพร่โน้ตไปยังเว็บไซต์ของคุณ ต้องใช้ Obsidian Publish
- **คัดลอก URL ที่เผยแพร่** คัดลอกที่อยู่ของโน้ตที่เผยแพร่ ต้องใช้ Obsidian Publish
- **เพิ่มคุณสมบัติของไฟล์** เพิ่มคุณสมบัติให้กับโน้ต ดู [[คุณสมบัติ]]
- **Export PDF** บันทึกโน้ตเป็น PDF ดู [[ไฟล์ PDF#ส่งออกโน้ตเป็น PDF|ส่งออกโน้ตเป็น PDF]]
- **ลบไฟล์** ลบโน้ต ดู [[จัดการโน้ต#ลบโน้ต|ลบโน้ต]]

### ค้นหา

- **ค้นหา...** และ **แทนที่...** ค้นหาข้อความในโน้ตและแทนที่ ดู [[ค้นหาและแทนที่]]

### เส้นทาง ประวัติ และมุมมองที่ลิงก์

- **คัดลอกพาธ** คัดลอกตำแหน่งของโน้ตเป็น URL ของ Obsidian จากโฟลเดอร์ห้องนิรภัย หรือจากรูทของระบบ
- **เปิดประวัติเวอร์ชัน** แสดงเวอร์ชันก่อนหน้าของโน้ต ต้องมีการสมัครสมาชิก Obsidian Sync ที่ใช้งานอยู่ ดู [[ประวัติเวอร์ชัน]]
- **เปิดมุมมองที่ลิงก์** เปิดมุมมองที่ติดตามโน้ต เช่น กราฟเฉพาะที่ ดู [[แท็บ#มุมมองที่ลิงก์|มุมมองที่ลิงก์]]

### คอมพิวเตอร์ของคุณ

- **เปิดด้วยโปรแกรมมาตฐาน** เปิดไฟล์ด้วยแอปที่คอมพิวเตอร์ของคุณใช้สำหรับไฟล์ประเภทนั้น
- **แสดงในระบบไฟล์** แสดงไฟล์ในตัวจัดการไฟล์ของคุณ บน macOS รายการนี้จะอ่านว่า **แสดงใน Finder** บน Windows และ Linux จะอ่านว่า **แสดงในโฟลเดอร์**
- **แสดงไฟล์ทั้งหมดใน file explorer** ไฮไลต์โน้ตในตัวจัดการไฟล์

### เมนูแท็บ

คลิกขวาที่แท็บเพื่อดูรายการทั้งหมดข้างต้น รวมถึงรายการเหล่านี้

- **ปิด** ปิดแท็บ
- **ปักหมุด** ปักหมุดแท็บ ดู [[แท็บ#ปักหมุดแท็บ|ปักหมุดแท็บ]]
- **ลิงก์กับแท็บ...** ลิงก์แท็บกับมุมมอง เช่น กราฟเฉพาะที่หรือเค้าโครง เพื่อให้มุมมองนั้นติดตามแท็บนี้
- **ย้ายไปยังหน้าต่างใหม่** ย้ายแท็บไปยังหน้าต่างของตัวเอง

## มือถือ

บนมือถือ เลือก **ตัวเลือกเพิ่มเติม** ในโน้ต เมนูรวมรายการจากเมนูแท็บบนเดสก์ท็อปและเมนู**ตัวเลือกเพิ่มเติม**บนเดสก์ท็อป และมีรายการน้อยกว่า

รายการเหล่านี้ทำงานเหมือนกับบนเดสก์ท็อป

- **โหมดอ่าน** และ **โหมดซอร์ส**
- **เปลี่ยนชื่อ**
- **ย้ายไฟล์ไปที่...**
- **รวมไฟล์ทั้งไฟล์กับ...**
- **เพิ่มคุณสมบัติของไฟล์**
- **ค้นหา...** และ **แทนที่...**
- **คัดลอกพาธ** พร้อมตัวเลือก **เป็น URL ของ Obsidian** และ **จากโฟลเดอร์ห้องนิรภัย**
- **เปิดประวัติเวอร์ชัน**
- **เปิดมุมมองที่ลิงก์**
- **คัดลอก URL ที่เผยแพร่**
- **ลบไฟล์**

เมนูมือถือยังมีรายการเหล่านี้ด้วย

- **ปิด** ปิดโน้ต
- **ปักหมุด** ปักหมุดแท็บ
- **แชร์** แชร์โน้ต บน iOS จะเปิดหน้าแชร์
