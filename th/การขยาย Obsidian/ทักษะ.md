ทักษะ Obsidian (Obsidian Skills) คือคำสั่งที่สอนเอเจนต์ AI ให้ทำงานกับ Obsidian ได้ โดยใช้รูปแบบ [Agent Skills](https://agentskills.io/specification) แบบเปิด จึงทำงานได้กับเอเจนต์ใดก็ได้ที่รองรับทักษะ รวมถึง Claude Code, Claude, ChatGPT, Cursor, Gemini CLI, GitHub Copilot, Grok Bot, OpenCode และ[อื่นๆ อีกมากมาย](https://agentskills.io/clients)

ด้วยทักษะ Obsidian เอเจนต์สามารถ:

- เขียนโน้ตใน [[Obsidian Flavored Markdown]] พร้อม[[ลิงค์ภายใน|ลิงก์วิกิ]] การฝัง บล็อกเน้น และ[[คุณสมบัติ|คุณสมบัติ]]
- สร้างและแก้ไข[[แนะนำฐาน|ฐาน]]และ[[Canvas|Canvas]] ไฟล์
- ค้นหา อ่าน และจัดการโน้ตในแอปที่กำลังทำงานด้วย [[Obsidian CLI]]
- ซิงค์และเผยแพร่ห้องนิรภัยโดยไม่ต้องใช้แอปเดสก์ท็อปด้วย [[Obsidian Headless]]

ทักษะเหล่านี้เป็นโอเพนซอร์สที่ [obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills)

## ติดตั้ง

Obsidian เป็นปลั๊กอินอย่างเป็นทางการสำหรับ ChatGPT, Codex, Cursor และ Grok Bot เอเจนต์อื่นๆ จะติดตั้งทักษะจาก GitHub

### ChatGPT และ Codex

เพิ่ม [Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096) จากไดเรกทอรีปลั๊กอินของ ChatGPT ปลั๊กอินนี้ใช้งานได้ทั้งใน ChatGPT และ Codex

### Cursor

ติดตั้ง [Obsidian](https://cursor.com/marketplace/obsidian) จาก Cursor Marketplace

### Grok Bot

เปิด [Obsidian for Grok Bot](https://x.ai/bot/plugin/88871845) แล้วเลือก **Add to Grok Bot**

### Claude Code

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

หากต้องการรับทักษะใหม่ในภายหลัง ให้รัน `claude plugin update obsidian@obsidian-skills`

### Claude

Claude อัปโหลดแต่ละทักษะเป็นไฟล์ ZIP ดังนั้นให้เพิ่มเฉพาะทักษะที่คุณต้องการ:

1. ดาวน์โหลด [obsidian-skills](https://github.com/obsidianmd/obsidian-skills/archive/refs/heads/main.zip) แล้วแตกไฟล์
2. ใน `plugins/obsidian/skills/` ให้บีบอัดโฟลเดอร์ของแต่ละทักษะที่ต้องการเป็นไฟล์ ZIP เช่น `obsidian-markdown.zip`
3. ใน Claude ไปที่ **Customize** → **Skills** เลือก **+** → **Create skill** → **Upload a skill** แล้วเลือกไฟล์ ZIP

ดู [Using skills in Claude](https://support.claude.com/en/articles/12512180-using-skills-in-claude) สำหรับแผนที่รองรับทักษะ

### Gemini CLI

```shell
gemini extensions install https://github.com/obsidianmd/obsidian-skills
```

### GitHub Copilot, OpenCode และเอเจนต์อื่นๆ

ติดตั้งด้วย [npx skills](https://github.com/vercel-labs/skills) ซึ่งจะถามว่าต้องการติดตั้งลงในเอเจนต์ใด:

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

หากต้องการติดตั้งด้วยตนเอง ให้คัดลอกโฟลเดอร์ใน `plugins/obsidian/skills/` ไปยังโฟลเดอร์ทักษะของเอเจนต์ เช่น `~/.copilot/skills/` สำหรับ GitHub Copilot

## ทักษะที่รวมอยู่

| ทักษะ               | สิ่งที่ทำ                                                                                                                  |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `obsidian-markdown` | สร้างและแก้ไขโน้ต [[Obsidian Flavored Markdown]]                                                                         |
| `obsidian-bases`    | สร้างและแก้ไข[[ไวยากรณ์ฐาน\|ฐาน]]พร้อมมุมมอง ตัวกรอง สูตร และสรุป                                         |
| `json-canvas`       | สร้างและแก้ไขไฟล์ [[Canvas]] โดยใช้รูปแบบ [JSON Canvas](https://jsoncanvas.org/)                                     |
| `obsidian-cli`      | โต้ตอบกับห้องนิรภัยของคุณผ่าน [[Obsidian CLI]] รวมถึงการพัฒนาปลั๊กอินและธีม                                    |
| `obsidian-headless` | ซิงค์และเผยแพร่ห้องนิรภัยจากบรรทัดคำสั่งด้วย [[Obsidian Headless]]                                                     |
| `defuddle`          | ดึง Markdown ที่สะอาดจากหน้าเว็บโดยใช้ [Defuddle](https://github.com/kepano/defuddle)                                   |
| `knap`              | เรนเดอร์เทมเพลต Markdown จากข้อมูล JSON หรือ CSV โดยใช้ [Knap](https://github.com/obsidianmd/knap)                             |

## ข้อกำหนด

ทักษะ `obsidian-cli` ต้องมีแอปเดสก์ท็อป Obsidian ที่กำลังทำงานพร้อม[[Obsidian CLI#ติดตั้ง Obsidian CLI|เปิดใช้งาน Obsidian CLI]] และเอเจนต์ที่สามารถรันคำสั่งบนคอมพิวเตอร์ของคุณ

ทักษะ Markdown, ฐาน และ Canvas อธิบายเฉพาะรูปแบบไฟล์เท่านั้น จึงทำงานได้ในเอเจนต์ใดก็ได้ที่สามารถอ่านและเขียนไฟล์ในห้องนิรภัยของคุณ

Defuddle, Knap และ Obsidian Headless เป็นเครื่องมือแยกต่างหากที่ไม่ได้รวมมากับทักษะ เมื่อขาดเครื่องมือใด ทักษะจะถามก่อนติดตั้งจาก npm

## ความเป็นส่วนตัว

ทักษะ Obsidian ไม่ส่งข้อมูลใดๆ ด้วยตัวเอง เมื่อเอเจนต์ใช้ทักษะเหล่านี้ โน้ตที่อ่านจะกลายเป็นส่วนหนึ่งของการสนทนาและถูกประมวลผลโดยโมเดล AI ที่คุณใช้ กรุณาตรวจสอบนโยบายความเป็นส่วนตัวของเอเจนต์ก่อนที่จะชี้ไปยังห้องนิรภัยที่มีโน้ตข้อมูลที่ละเอียดอ่อน
