ตัวเชื่อมต่อช่วยให้คุณเชื่อมต่อ Obsidian กับ AI agent ใดก็ได้ รวมถึง Claude, ChatGPT, Antigravity, Cursor, GitHub Copilot, Grok Bot, Hermes, Kiro, Muse, OpenCode และ[อื่นๆ อีกมากมาย](https://agentskills.io/clients)

นั่นหมายความว่า agent ของคุณสามารถเรียนรู้วิธี:

- เขียนโน้ตใน [[Obsidian Flavored Markdown]] พร้อม [[ลิงค์ภายใน|ลิงก์วิกิ]] การฝัง บล็อกเน้น และ[[คุณสมบัติ|คุณสมบัติ]]
- สร้างและแก้ไขไฟล์ [[แนะนำฐาน|ฐาน]] และ [[Canvas|Canvas]]
- ค้นหา อ่าน และจัดการโน้ตในแอปที่ทำงานอยู่ด้วย [[Obsidian CLI]]
- ซิงค์และเผยแพร่ห้องนิรภัยโดยไม่ต้องใช้แอปเดสก์ท็อปด้วย [[Obsidian Headless]]

สกิลเหล่านี้เป็นโอเพนซอร์สที่ [obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills)

## ติดตั้ง

คุณสามารถค้นหา Obsidian ได้โดยค้นหาในรายการปลั๊กอินของ Claude, ChatGPT, Dots, Cursor, Grok Bot, Hermes และ Kiro agent อื่นๆ ส่วนใหญ่สามารถติดตั้งสกิลได้หากคุณส่งลิงก์ไปยังหน้านี้ให้

### Claude

เพิ่ม [Obsidian](https://claude.ai/customize/plugins/id/a38fa062-ebd3-48e0-9a0a-1875a6e94ad5%40anthropic-plugin-directory) จากไดเรกทอรีปลั๊กอินทางการของ Claude

สำหรับ Claude Code CLI ใช้:

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

หากต้องการรับสกิลใหม่ในภายหลัง ให้รัน `claude plugin update obsidian@obsidian-skills`

### ChatGPT

เพิ่ม [Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096) จากไดเรกทอรีปลั๊กอิน ChatGPT ปลั๊กอินนี้ใช้งานได้ใน ChatGPT, Codex และ Dots

### Antigravity

ใน Antigravity CLI ให้รัน:

```shell
agy plugin install https://github.com/obsidianmd/obsidian-skills
```

### Grok Bot

เปิด [Obsidian for Grok Bot](https://x.ai/bot/plugin/88871845) แล้วเลือก **Add to Grok Bot**

### Muse

ขอให้ Muse ติดตั้งสกิลจาก https://github.com/obsidianmd/obsidian-skills

Muse ทำงานบนคลาวด์ของ Meta ดังนั้นสกิล `obsidian-cli` จะไม่ทำงานที่นั่น หากคุณใช้ Obsidian Headless ใน Muse คุณจะเข้าสู่ระบบและซิงค์ห้องนิรภัยของคุณบนคลาวด์ของ Meta

### Cursor

ติดตั้ง [Obsidian](https://cursor.com/marketplace/obsidian) จาก Cursor Marketplace

### Hermes Agent

```shell
hermes plugins install obsidian
```

### Kiro

```shell
kiro-cli powers install obsidian
```

### GitHub Copilot, OpenCode และ agent อื่นๆ

ติดตั้งด้วย [npx skills](https://github.com/vercel-labs/skills) ซึ่งจะถามว่าต้องการติดตั้งให้ agent ใดบ้าง:

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

หากต้องการติดตั้งด้วยตนเอง ให้คัดลอกโฟลเดอร์ใน `plugins/obsidian/skills/` ไปยังโฟลเดอร์สกิลของ agent ของคุณ เช่น `~/.copilot/skills/` สำหรับ GitHub Copilot

## สกิลที่รวมมา

| สกิล               | สิ่งที่ทำ                                                                                                                  |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `obsidian-markdown` | สร้างและแก้ไขโน้ต [[Obsidian Flavored Markdown]]                                                                         |
| `obsidian-bases`    | สร้างและแก้ไข [[ไวยากรณ์ฐาน\|ฐาน]] พร้อมมุมมอง ตัวกรอง สูตร และสรุปผล                                         |
| `json-canvas`       | สร้างและแก้ไขไฟล์ [[Canvas]] โดยใช้รูปแบบ [JSON Canvas](https://jsoncanvas.org/)                                     |
| `obsidian-cli`      | โต้ตอบกับห้องนิรภัยของคุณผ่าน [[Obsidian CLI]] รวมถึงการพัฒนาปลั๊กอินและธีม                                    |
| `obsidian-headless` | ซิงค์และเผยแพร่ห้องนิรภัยจากบรรทัดคำสั่งด้วย [[Obsidian Headless]]                                                     |
| `defuddle`          | ดึง Markdown ที่สะอาดจากหน้าเว็บโดยใช้ [Defuddle](https://github.com/kepano/defuddle)                                   |
| `knap`              | เรนเดอร์เทมเพลต Markdown จากข้อมูล JSON หรือ CSV โดยใช้ [Knap](https://github.com/obsidianmd/knap)                             |

## ข้อกำหนด

สกิล `obsidian-cli` ต้องการแอปเดสก์ท็อป Obsidian ที่กำลังทำงานอยู่โดย[[Obsidian CLI#ติดตั้ง Obsidian CLI|เปิดใช้งาน Obsidian CLI]] และ agent ที่สามารถรันคำสั่งบนคอมพิวเตอร์ของคุณ

สกิล Markdown, ฐาน และ Canvas เป็นเพียงการอธิบายรูปแบบไฟล์ ดังนั้นจึงใช้งานได้ใน agent ใดก็ได้ที่สามารถอ่านและเขียนไฟล์ในห้องนิรภัยของคุณ

Defuddle, Knap และ Obsidian Headless เป็นเครื่องมือแยกต่างหากที่ไม่ได้รวมมากับสกิล เมื่อขาดตัวใดตัวหนึ่ง สกิลจะถามก่อนติดตั้งจาก npm

## ความเป็นส่วนตัว

ตัวเชื่อมต่อ Obsidian ไม่ส่งข้อมูลใดๆ ด้วยตัวเอง เมื่อ agent ใช้งาน โน้ตที่อ่านจะกลายเป็นส่วนหนึ่งของการสนทนาและถูกประมวลผลโดยโมเดล AI ที่คุณใช้ ตรวจสอบนโยบายความเป็นส่วนตัวของ agent ของคุณก่อนที่จะชี้ไปที่ห้องนิรภัยที่มีโน้ตที่เป็นข้อมูลอ่อนไหว
