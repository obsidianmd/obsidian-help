ปลั๊กอินและธีมทุกตัวมีหน้ารายการสาธารณะบน [ไดเรกทอรีชุมชน Obsidian](https://community.obsidian.md) เลือกปลั๊กอินจาก[[ปลั๊กอินโดยชุมชน#เรียกดูปลั๊กอินชุมชน|เลือกดู]] หรือธีมจาก[[ธีม#เลือกดูธีม|เลือกดู]] ใน Obsidian หรือเรียกดู [community.obsidian.md](https://community.obsidian.md) โดยตรง เพื่อเปิดหน้ารายการ

หน้านี้จะช่วยให้คุณเข้าใจว่าแต่ละส่วนทำอะไร จากมุมมองของผู้ใช้ Obsidian

> [!tip]- คุณเป็นนักพัฒนาปลั๊กอินหรือธีมใช่ไหม?
> เรียนรู้วิธีส่งและจัดการปลั๊กอินและธีมของคุณเองใน[เอกสารประกอบไดเรกทอรีชุมชน](https://docs.obsidian.md/community-directory)

## ส่วนหัว

ส่วนหัวแสดงไอคอนและชื่อของรายการ พร้อมป้าย **Official** หากสร้างโดยผู้สร้างดั้งเดิมของปลั๊กอินหรือธีม รวมถึงไอคอนและชื่อของผู้เขียน และจำนวนดาวน์โหลดทั้งหมดของรายการ

เลือก **Add to Obsidian** เพื่อเปิดรายการใน Obsidian โดยตรงและติดตั้ง

## ภาพรวม

แท็บ **Overview** แสดงภาพหน้าจอของรายการ คำอธิบายแบบยาว ข้อความบางส่วนจากไฟล์ README และตารางของปลั๊กอินหรือธีมที่เกี่ยวข้องในหมวดหมู่เดียวกัน

## การ์ดคะแนน

แท็บ **Scorecard** แสดงเมตริกสุขภาพและการตรวจสอบอัตโนมัติสำหรับรายการ

คะแนนสุขภาพโดยรวม เช่น Excellent จะถูกแยกย่อยเป็น hygiene (ว่ามี README, ใบอนุญาต, คู่มือการมีส่วนร่วม และคำอธิบายหรือไม่), maintenance (กิจกรรม commit และ release ล่าสุด), responsiveness (มี issue กี่รายการที่ถูกปิด และมีผู้มีส่วนร่วมกี่คนที่ใช้งานล่าสุด) และ adoption (จำนวนการติดตั้งและจำนวนดาว)

ส่วนการตรวจสอบแสดงผลลัพธ์ของการสแกนอัตโนมัติล่าสุด เช่น Passed จัดกลุ่มเป็นการตรวจที่ผ่าน (เช่น ไม่มี dependency ที่มีช่องโหว่ที่ทราบ ไม่มีโค้ดที่ถูกทำให้อ่านยาก มี GitHub artifact attestation ที่ยืนยันแล้ว และ API ของ Obsidian ที่รายการใช้ เช่น Vault Read หรือ Vault Write), การเปิดเผย (สิ่งที่รายการทำซึ่งไม่จำเป็นต้องเป็นปัญหา แต่คุณควรทราบ เช่น การเข้าถึงคลิปบอร์ดหรือการส่งคำขอไปยังโดเมนภายนอก) และหมายเหตุอื่นๆ (เช่น การใช้ browser storage แทน API ข้อมูลปลั๊กอินของ Obsidian)

> [!info]+ การตีความคะแนนที่ต่ำ
> ปลั๊กอินหรือธีมที่มีคะแนนสุขภาพหรือการตรวจสอบต่ำไม่จำเป็นต้องไม่ปลอดภัย แต่ควรตรวจสอบการเปิดเผยให้ละเอียดก่อนติดตั้ง ลองนึกภาพเหมือนสัญญาณไฟจราจร:
> - 🟢 การเปิดเผยน้อยหรือไม่มีเลย หมายถึงความเสี่ยงต่ำ
> - 🟡 มีการเปิดเผยบางรายการ ควรตรวจสอบสิ่งต่างๆ เช่น การเข้าถึงคลิปบอร์ดหรือเครือข่าย
> - 🔴 มีการเปิดเผยหรือคำเตือนหลายรายการ หมายความว่าคุณควรตรวจสอบอย่างละเอียดว่ารายการนั้นทำอะไรก่อนติดตั้ง

## อัปเดต

แท็บ **Updates** แสดงประวัติ release ของรายการ พร้อมเวอร์ชั่นและวันที่ของแต่ละ release เลือก **View all releases on GitHub** เพื่อดูประวัติทั้งหมดในรีโพซิทอรีของรายการ

## แถบด้านข้าง

ข้างแท็บต่างๆ แถบด้านข้างแสดงสรุปสุขภาพและการตรวจสอบที่ตรงกับแท็บ Scorecard คำอธิบายแบบยาวของรายการ และรายละเอียดเช่น เวอร์ชั่นปัจจุบัน วันที่อัปเดตล่าสุดและวันที่สร้าง จำนวนอัปเดตและดาวน์โหลด เวอร์ชั่น Obsidian ที่รองรับ แพลตฟอร์มที่รองรับ และใบอนุญาต หากรายการไม่ใช่ Free จะมีส่วน Payments อธิบายว่าราคาทำงานอย่างไร เช่น ระดับที่ต้องจ่ายเงินหรือขีดจำกัดการใช้งาน หากผู้เขียนเพิ่มลิงก์สนับสนุน จะมีลิงก์ Support ปรากฏที่นี่ด้วย พร้อมกับไอคอน ชื่อ และลิงก์ไปยังโปรไฟล์อื่นๆ ของผู้เขียนหรือองค์กร

## คำถามที่พบบ่อย

**ความแตกต่างระหว่าง Free, Optional payment และ Paid บนรายการคืออะไร?**
Free หมายถึงไม่มีการชำระเงินใดๆ Optional payment หมายถึงรายการนั้นพึ่งพาบริการของบุคคลที่สามที่ต้องจ่ายเงิน หรือล็อกฟีเจอร์บางอย่างไว้หลังการชำระเงิน ขณะที่ยังสามารถใช้งานได้ฟรี Paid หมายถึงรายการนั้นเข้าถึงได้เฉพาะเมื่อชำระเงินเท่านั้น

ตรวจสอบส่วน Payments ของรายการในแถบด้านข้างเพื่อดูรายละเอียดว่าราคาของรายการนั้นทำงานอย่างไร

**ทำไมฉันหาหรือติดตั้งปลั๊กอินหรือธีมที่เคยเห็นถูกกล่าวถึงที่อื่นไม่ได้?**
ผู้เขียนอาจเก็บถาวรไปแล้ว การเก็บถาวรจะลบรายการออกจากไดเรกทอรีชุมชนและป้องกันการติดตั้งใหม่

**ความแตกต่างระหว่างคะแนน Health และ Review บนรายการคืออะไร?**
Health สะท้อนถึง hygiene และ maintenance อย่างต่อเนื่องของรายการ เช่น commit ล่าสุดและการตอบสนองต่อ issue ส่วน Review สะท้อนผลลัพธ์ของการสแกนอัตโนมัติล่าสุดของ release
