[[Імпортер]] дозволяє визначати шаблони, які контролюють, як ваші нотатки імпортуються з інших застосунків. Це означає, що ви можете змінювати назву, властивості та вміст нотаток, які імпортуєте.

## Редагування шаблону імпорту

Натисніть **Редагувати** над попереднім переглядом, щоб відредагувати шаблон за замовчуванням. Ви можете редагувати:

- Назву нотатки, що відображається як вбудований заголовок.
- Властивості на початку нотатки.
- Markdown-вміст нотатки.

Натисніть **Зберегти**, щоб повернутися до попереднього перегляду. Імпортер запам'ятовує відредагований вбудований шаблон для майбутніх імпортів, що використовують той самий формат.

Крім того, ви можете завантажити шаблон із Markdown-файлу в поточному сховищі.

## Попередній перегляд результатів

Попередній перегляд показує до десяти зразків з обраних вами даних. Використовуйте кнопки зі стрілками для переміщення між зразками. Зміни в налаштуваннях імпорту та шаблоні оновлюють попередній перегляд до того, як щось буде додано до вашого сховища.

Деякі вкладення, віддалені елементи та перехресні посилання між нотатками не можуть бути повністю розв'язані до виконання імпорту. У таких випадках попередній перегляд може зберігати посилання на джерело або показувати заповнювач.

## Синтаксис шаблону

Шаблони імпортера використовують синтаксис, що складається зі змінних, [[Фільтри|фільтрів]] та [[Логіка|логіки]]. Він використовує той самий синтаксис [Knap](https://github.com/obsidianmd/knap), що й [[Вступ до Obsidian Web Clipper|Web Clipper]].

Вставляйте змінні за допомогою подвійних фігурних дужок, наприклад `{{title}}`, `{{content}}` або `{{date}}`. Змінні можна використовувати в назві нотатки, властивостях та вмісті.

Ви можете модифікувати змінні за допомогою [[Фільтри|фільтрів]]. Наприклад, щоб змінити формат дати, використовуйте `{{date|date:"YYYY-MM-DD"}}`. Використовуйте [[Логіка|логіку]] для більш складних умов, циклів та присвоєння змінних.

## Змінні

Наступні змінні доступні для використання в будь-якому шаблоні імпортера:

| Змінна           | Опис                                                                                                     |
| ---------------- | -------------------------------------------------------------------------------------------------------- |
| `{{body}}`       | Markdown-тіло без властивостей (без початкових метаданих).                                               |
| `{{content}}`    | Повний Markdown до застосування обраного шаблону.                                                        |
| `{{ctime}}`      | Час створення джерела як мітка часу ISO 8601; порожнє, якщо недоступно.                                  |
| `{{date}}`       | Поточна дата та час під час відтворення шаблону, як мітка часу ISO 8601.                                 |
| `{{importer}}`   | Ідентифікатор імпортера, наприклад `keep`, `html` або `notion-api`.                                      |
| `{{folder}}`     | Кінцева батьківська тека відносно сховища. Порожнє, якщо нотатка знаходиться в корені сховища.           |
| `{{mtime}}`      | Час модифікації джерела як мітка часу ISO 8601; порожнє, якщо недоступно.                                |
| `{{noteName}}`   | Кінцева розв'язана назва нотатки після видалення недопустимих символів та додавання суфіксів для дублікатів. |
| `{{path}}`       | Кінцевий шлях відносно сховища, включаючи розширення `.md`.                                              |
| `{{properties}}` | Об'єкт, що містить властивості початкових метаданих.                                                     |
| `{{source}}`     | Об'єкт, що містить згенеровані властивості та значення, специфічні для джерела.                          |
| `{{sourceId}}`   | Стабільний ідентифікатор джерела, якщо імпортер його надає; інакше порожнє.                               |
| `{{time}}`       | Псевдонім для `{{date}}`.                                                                                |
| `{{title}}`      | Оригінальна назва нотатки до очищення та дедуплікації.                                                   |

## Значення джерела для властивостей

Для форматів імпорту, що підтримують [[Властивості]], значення джерела також доступні як змінні верхнього рівня для зручності.

Якщо значення джерела має таку саму назву, як спільна змінна, отримуйте доступ до нього через `{{source}}`. Наприклад, якщо ваше джерело імпорту має властивість з назвою `content`, вона доступна як `{{source.content}}`, тоді як `{{content}}` залишається стандартною змінною імпортера.

Використовуйте дужкову нотацію, коли назва поля містить пробіли, розділові знаки або інші спеціальні символи:

```twig
{{source["Project: status"]}}
```

## Приклад шаблону

Ось приклад шаблону з використанням змінних та [[Фільтри|фільтрів]]:

```twig
---
created: {{ctime | date:"YYYY-MM-DD"}}
modified: {{mtime | date:"YYYY-MM-DD"}}
source: {{importer}}
---
# {{title}}

{{body}}
```

Ви можете додавати дані в нотатку умовно за допомогою [[Логіка|логіки]]:

```twig
{% if tags %}
## Мітки
{% for tag in tags %}
- {{tag}}
{% endfor %}
{% endif %}
```
