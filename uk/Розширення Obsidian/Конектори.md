Конектори дозволяють під'єднати Obsidian до будь-якого AI-агента, включаючи Claude, ChatGPT, Antigravity, Cursor, GitHub Copilot, Grok Bot, Hermes, Kiro, Muse, OpenCode та [багато інших](https://agentskills.io/clients).

Це означає, що ваші агенти можуть навчитися:

- Писати нотатки у [[Obsidian Flavored Markdown]], з [[Внутрішні посилання|wiki-посиланнями]], вбудовуваннями, виносками та [[Властивості|властивостями]].
- Створювати й редагувати файли [[Вступ до Баз|Баз]] та [[Полотно|Canvas]].
- Шукати, читати та керувати нотатками у запущеному застосунку за допомогою [[Obsidian CLI]].
- Синхронізувати та публікувати сховища без настільного застосунку за допомогою [[Obsidian Headless]].

Навички мають відкритий джерельний код на [obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills).

## Встановлення

Ви можете знайти Obsidian через пошук у списку додатків у Claude, ChatGPT, Dots, Cursor, Grok Bot, Hermes та Kiro. Більшість інших агентів можуть встановити навички, якщо надіслати їм посилання на цю сторінку.

### Claude

Додайте [Obsidian](https://claude.ai/customize/plugins/id/a38fa062-ebd3-48e0-9a0a-1875a6e94ad5%40anthropic-plugin-directory) з офіційного каталогу додатків Claude.

Для CLI Claude Code використовуйте:

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

Щоб отримати нові навички пізніше, виконайте `claude plugin update obsidian@obsidian-skills`.

### ChatGPT

Додайте [Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096) з каталогу додатків ChatGPT. Додаток працює у ChatGPT, Codex та Dots.

### Antigravity

У CLI Antigravity виконайте:

```shell
agy plugin install https://github.com/obsidianmd/obsidian-skills
```

### Grok Bot

Відкрийте [Obsidian for Grok Bot](https://x.ai/bot/plugin/88871845) і виберіть **Add to Grok Bot**.

### Muse

Попросіть Muse встановити навички з https://github.com/obsidianmd/obsidian-skills.

Muse працює у хмарі Meta, тому навичка `obsidian-cli` там не працює. Якщо ви використовуєте Obsidian Headless у Muse, ви входите в систему та синхронізуєте своє сховище у хмарі Meta.

### Cursor

Встановіть [Obsidian](https://cursor.com/marketplace/obsidian) з Cursor Marketplace.

### Hermes Agent

```shell
hermes plugins install obsidian
```

### Kiro

```shell
kiro-cli powers install obsidian
```

### GitHub Copilot, OpenCode та інші агенти

Встановіть за допомогою [npx skills](https://github.com/vercel-labs/skills), який запитає, до яких агентів встановлювати:

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

Для встановлення вручну скопіюйте теки з `plugins/obsidian/skills/` у теку навичок вашого агента, наприклад `~/.copilot/skills/` для GitHub Copilot.

## Включені навички

| Навичка             | Що вона робить                                                                                                                |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `obsidian-markdown` | Створення та редагування нотаток у [[Obsidian Flavored Markdown]].                                                            |
| `obsidian-bases`    | Створення та редагування [[Синтаксис Бази|Баз]] з поданнями, фільтрами, формулами та підсумками.                             |
| `json-canvas`       | Створення та редагування файлів [[Полотно|Canvas]] у форматі [JSON Canvas](https://jsoncanvas.org/).                         |
| `obsidian-cli`      | Взаємодія зі сховищем через [[Obsidian CLI]], включаючи розробку додатків і тем.                                              |
| `obsidian-headless` | Синхронізація та публікація сховищ з командного рядка за допомогою [[Obsidian Headless]].                                      |
| `defuddle`          | Витягування чистого Markdown з вебсторінок за допомогою [Defuddle](https://github.com/kepano/defuddle).                       |
| `knap`              | Рендеринг шаблонів Markdown з даних JSON або CSV за допомогою [Knap](https://github.com/obsidianmd/knap).                     |

## Вимоги

Навичка `obsidian-cli` потребує запущеного настільного застосунку Obsidian з [[Obsidian CLI#Встановлення Obsidian CLI|увімкненим Obsidian CLI]] та агента, який може виконувати команди на вашому комп'ютері.

Навички Markdown, Баз та Canvas лише описують формати файлів, тому працюють у будь-якому агенті, який може читати та записувати файли у вашому сховищі.

Defuddle, Knap та Obsidian Headless — це окремі інструменти, які не постачаються разом із навичками. Коли якийсь із них відсутній, навичка запитує дозвіл перед встановленням його з npm.

## Конфіденційність

Конектори Obsidian самі по собі нічого не відправляють. Коли агент їх використовує, нотатки, які він читає, стають частиною розмови та обробляються моделлю ШІ, яку ви використовуєте. Перегляньте політику конфіденційності вашого агента, перш ніж направляти його до сховища з конфіденційними нотатками.
