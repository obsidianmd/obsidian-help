Obsidian Skills — це інструкції, що навчають ШІ-агентів працювати з Obsidian. Вони відповідають відкритому формату [Agent Skills](https://agentskills.io/specification), тому працюють з будь-яким агентом, що підтримує навички, включаючи Claude Code, Claude, ChatGPT, Cursor, Gemini CLI, GitHub Copilot, Grok Bot, OpenCode та [багато інших](https://agentskills.io/clients).

З Obsidian Skills агент може:

- Писати нотатки у [[Obsidian Flavored Markdown]], з [[Внутрішні посилання|wiki-посиланнями]], вбудовуваннями, виносками та [[Властивості|властивостями]].
- Створювати та редагувати файли [[Вступ до Баз|Баз]] і [[Полотно|Canvas]].
- Шукати, читати та керувати нотатками у запущеному застосунку за допомогою [[Obsidian CLI]].
- Синхронізувати та публікувати сховища без настільного застосунку за допомогою [[Obsidian Headless]].

Навички мають відкритий джерельний код на [obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills).

## Встановлення

Obsidian є офіційним додатком для ChatGPT, Codex, Cursor та Grok Bot. Інші агенти встановлюють навички з GitHub.

### ChatGPT та Codex

Додайте [Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096) з каталогу додатків ChatGPT. Додаток працює як у ChatGPT, так і в Codex.

### Cursor

Встановіть [Obsidian](https://cursor.com/marketplace/obsidian) з Cursor Marketplace.

### Grok Bot

Відкрийте [Obsidian for Grok Bot](https://x.ai/bot/plugin/88871845) та натисніть **Add to Grok Bot**.

### Claude Code

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

Щоб отримати нові навички пізніше, виконайте `claude plugin update obsidian@obsidian-skills`.

### Claude

Claude завантажує кожну навичку як ZIP-файл, тому додавайте лише ті навички, які вам потрібні:

1. Завантажте [obsidian-skills](https://github.com/obsidianmd/obsidian-skills/archive/refs/heads/main.zip) та розархівуйте.
2. У `plugins/obsidian/skills/` стисніть теку кожної потрібної навички у ZIP-файл, наприклад, `obsidian-markdown.zip`.
3. У Claude перейдіть до **Customize** → **Skills**, натисніть **+** → **Create skill** → **Upload a skill** та оберіть ZIP-файл.

Дивіться [Using skills in Claude](https://support.claude.com/en/articles/12512180-using-skills-in-claude), щоб дізнатися, які плани підтримують навички.

### Gemini CLI

```shell
gemini extensions install https://github.com/obsidianmd/obsidian-skills
```

### GitHub Copilot, OpenCode та інші агенти

Встановіть за допомогою [npx skills](https://github.com/vercel-labs/skills), який запитає, до яких агентів встановити:

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

Для ручного встановлення скопіюйте теки з `plugins/obsidian/skills/` до теки навичок вашого агента, наприклад, `~/.copilot/skills/` для GitHub Copilot.

## Включені навички

| Навичка             | Що вона робить                                                                                                                |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `obsidian-markdown` | Створення та редагування нотаток у [[Obsidian Flavored Markdown]].                                                            |
| `obsidian-bases`    | Створення та редагування [[Синтаксис Бази|Баз]] з поданнями, фільтрами, формулами та підсумками.                              |
| `json-canvas`       | Створення та редагування файлів [[Полотно|Canvas]] у форматі [JSON Canvas](https://jsoncanvas.org/).                          |
| `obsidian-cli`      | Взаємодія зі сховищем через [[Obsidian CLI]], включаючи розробку додатків та тем.                                             |
| `obsidian-headless` | Синхронізація та публікація сховищ з командного рядка за допомогою [[Obsidian Headless]].                                      |
| `defuddle`          | Вилучення чистого Markdown з вебсторінок за допомогою [Defuddle](https://github.com/kepano/defuddle).                          |
| `knap`              | Рендеринг шаблонів Markdown з даних JSON або CSV за допомогою [Knap](https://github.com/obsidianmd/knap).                      |

## Вимоги

Навичка `obsidian-cli` потребує запущеного настільного застосунку Obsidian з [[Obsidian CLI#Встановлення Obsidian CLI|увімкненим Obsidian CLI]] та агента, який може виконувати команди на вашому комп'ютері.

Навички Markdown, Баз та Canvas лише описують формати файлів, тому працюють у будь-якому агенті, що може читати та записувати файли у вашому сховищі.

Defuddle, Knap та Obsidian Headless — це окремі інструменти, які не постачаються разом з навичками. Коли якийсь із них відсутній, навичка запитує дозвіл перед встановленням його з npm.

## Конфіденційність

Obsidian Skills самі по собі нічого не надсилають. Коли агент їх використовує, нотатки, які він читає, стають частиною розмови і обробляються моделлю ШІ, яку ви використовуєте. Ознайомтеся з політикою конфіденційності вашого агента, перш ніж направляти його до сховища з конфіденційними нотатками.
