Імпорт Markdown-файлів мігрує [[Властивості#Застарілі властивості|застарілі формати властивостей]] у поточний формат, що використовується Obsidian.

> [!warning] Створіть резервну копію сховища
> Конвертація застосовується до всього сховища. [[Резервне копіювання файлів Obsidian|Створіть резервну копію ваших файлів Obsidian]] перед початком.

Щоб конвертувати властивості у ваших нотатках:

1. Відкрийте [[Меню команд|меню команд]].
2. Виберіть **Імпорт Markdown-файлів: Міграція початкових метаданих**.
3. Натисніть **Почати конвертацію**.

## Підтримувані формати властивостей

Конвертер оновлює псевдоніми, мітки та CSS-класи із застарілих форматів:

**Псевдоніми**

```yaml
# До

alias: My Note Title

# Після

aliases:
  - My Note Title
```

**Мітки**

```yaml
# До

tag: project, important

# Після

tags:
  - project
  - important
```

**CSS-класи**

```yaml
# До

cssclass: custom-style

# Після

cssclasses:
  - custom-style
```
