Obsidian משתמש בקבצי Markdown בפורמט `.md` כפורמט העיקרי להערות. זה מקל על ייבוא קבצי Markdown אל Obsidian. אפליקציות רבות יכולות לערוך קבצי Markdown או לייצא לפורמט זה.

ישנן מספר דרכים להוסיף קבצי Markdown לכספת ה-Obsidian שלך:

1. גרור ושחרר קבצים או תיקיות לחלון [[סייר קבצים|סייר הקבצים]]
2. השתמש בסייר הקבצים של המערכת שלך (למשל סייר Windows או Finder ב-macOS), והעבר את הקבצים ישירות לתיקיית כספת ה-Obsidian.

## ייבוא קבצי Markdown עם Importer

השתמש ב-[[ייבוא|תוסף Importer]] הרשמי כשברצונך לבחור תיקיות בתוך ייבוא, לייבא ארכיון `.zip`, לתקנן עיצוב, להעביר תגיות מוטבעות ל[[מאפיינים|מאפיינים]], או להחיל תבנית.

1. פתח **[[הגדרות|הגדרות]] → תוספים קהילתיים** ו[התקן את Importer](obsidian://show-plugin?id=obsidian-importer).
2. הפעל את תוסף Importer.
3. פתח את **Importer** באמצעות [[לוח פקודות|לוח הפקודות]] או סמל סרגל הכלים.
4. תחת **File format**, בחר **Markdown (.md, .zip)**.
5. בחר קבצי Markdown בודדים, תיקיות או ארכיוני zip.
6. סקור את התיקיות שזוהו, אפשרויות הפלט, התבנית שנוצרה ודוגמאות התצוגה המקדימה.
7. בחר **Import** והמתן לסיום הייבוא.

ראה [[תבניות ייבוא|תבניות Importer]] כדי להתאים אישית את שם ההערה המיובאת, המאפיינים והתוכן.
