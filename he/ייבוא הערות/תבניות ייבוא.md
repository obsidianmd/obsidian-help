[[ייבוא]] מאפשר לך להגדיר תבניות ששולטות באופן שבו ההערות שלך מיובאות מאפליקציות אחרות. המשמעות היא שאתה יכול לשנות את הכותרת, המאפיינים והתוכן של הערות שאתה מייבא.

## עריכת תבנית הייבוא

בחר **ערוך** מעל התצוגה המקדימה כדי לערוך את תבנית ברירת המחדל. ניתן לערוך:

- שם ההערה המוצג ככותרת מוטבעת.
- מאפיינים בתחילת ההערה.
- תוכן ה-Markdown של ההערה.

בחר **שמור** כדי לחזור לתצוגה המקדימה. הייבוא זוכר תבנית מוטבעת שנערכה לייבואים עתידיים שמשתמשים באותו עיצוב.

לחלופין, ניתן לטעון תבנית מקובץ Markdown בכספת הנוכחית.

## תצוגה מקדימה של תוצאות

התצוגה המקדימה מציגה עד עשר דוגמאות מהנתונים שבחרת. השתמש בלחצני החצים כדי לנוע בין הדוגמאות. שינויים בהגדרות הייבוא ובתבנית מעדכנים את התצוגה המקדימה לפני שמשהו נוסף לכספת שלך.

חלק מהקבצים המצורפים, פריטים מרוחקים והפניות בין הערות לא ניתנים לפתרון מלא עד שהייבוא מתבצע. במקרים כאלה, התצוגה המקדימה עשויה לשמור על קישור המקור או להציג מציין מיקום.

## תחביר תבנית

תבניות ייבוא משתמשות בתחביר המורכב ממשתנים, [[מסננים]] ו[[לוגיקה]]. הן משתמשות באותו תחביר [Knap](https://github.com/obsidianmd/knap) כמו [[מבוא ל-Obsidian Web Clipper|Web Clipper]].

הוסף משתנים עם סוגריים מסולסלים כפולים, כגון `{{title}}`, `{{content}}` או `{{date}}`. ניתן להשתמש במשתנים בשם ההערה, במאפיינים ובתוכן.

ניתן לשנות משתנים באמצעות [[מסננים]]. לדוגמה, לשנות את פורמט התאריך באמצעות `{{date|date:"YYYY-MM-DD"}}`. השתמש ב[[לוגיקה]] עבור תנאים מתקדמים יותר, לולאות והקצאת משתנים.

## משתנים

המשתנים הבאים זמינים לשימוש בכל תבנית ייבוא:

| משתנה            | תיאור                                                                                              |
| ---------------- | --------------------------------------------------------------------------------------------------- |
| `{{body}}`       | טקסט רגיל ב-Markdown ללא מאפיינים (ללא מטא-נתונים בתחילת הקובץ).                                  |
| `{{content}}`    | Markdown מלא לפני שהתבנית שנבחרה מיושמת.                                                           |
| `{{ctime}}`      | זמן יצירה במקור כחותמת זמן ISO 8601; אין ערך כאשר לא זמין.                                        |
| `{{date}}`       | תאריך ושעה נוכחיים כאשר התבנית מעובדת, כחותמת זמן ISO 8601.                                       |
| `{{importer}}`   | מזהה ייבוא, כגון `keep`, `html` או `notion-api`.                                                   |
| `{{folder}}`     | תיקיית האב הסופית ביחס לכספת. אין ערך כאשר ההערה נמצאת בשורש הכספת.                               |
| `{{mtime}}`      | זמן שינוי במקור כחותמת זמן ISO 8601; אין ערך כאשר לא זמין.                                        |
| `{{noteName}}`   | שם ההערה הסופי שנפתר, לאחר הסרת תווים לא חוקיים והוספת סיומות לכפילויות.                          |
| `{{path}}`       | נתיב סופי ביחס לכספת, כולל סיומת `.md`.                                                            |
| `{{properties}}` | אובייקט המכיל את מאפייני המטא-נתונים בתחילת הקובץ.                                                |
| `{{source}}`     | אובייקט המכיל מאפיינים שנוצרו וערכים ספציפיים למקור.                                              |
| `{{sourceId}}`   | מזהה מקור יציב כאשר הייבוא מספק כזה; אחרת אין ערך.                                               |
| `{{time}}`       | כינוי ל-`{{date}}`.                                                                                |
| `{{title}}`      | כותרת ההערה המקורית לפני ניקוי והסרת כפילויות.                                                     |

## ערכי מקור עבור מאפיינים

עבור פורמטי ייבוא שתומכים ב[[מאפיינים]], ערכי המקור זמינים גם כמשתנים ברמה העליונה לנוחות.

אם לערך מקור יש שם זהה למשתנה משותף, ניתן לגשת אליו דרך `{{source}}`. לדוגמה, אם למקור הייבוא שלך יש מאפיין בשם `content`, הוא זמין כ-`{{source.content}}`, בעוד ש-`{{content}}` נשאר משתנה ברירת המחדל של הייבוא.

השתמש בסימון סוגריים מרובעים כאשר שם השדה מכיל רווחים, סימני פיסוק או תווים מיוחדים אחרים:

```twig
{{source["Project: status"]}}
```

## דוגמה לתבנית

הנה דוגמה לתבנית המשתמשת במשתנים ו[[מסננים]]:

```twig
---
created: {{ctime | date:"YYYY-MM-DD"}}
modified: {{mtime | date:"YYYY-MM-DD"}}
source: {{importer}}
---
# {{title}}

{{body}}
```

ניתן להוסיף נתונים להערה באופן מותנה באמצעות [[לוגיקה]]:

```twig
{% if tags %}
## תגיות
{% for tag in tags %}
- {{tag}}
{% endfor %}
{% endif %}
```
