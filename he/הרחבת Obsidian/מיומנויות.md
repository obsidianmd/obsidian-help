Obsidian Skills הן הוראות שמלמדות סוכני AI כיצד לעבוד עם Obsidian. הן עוקבות אחרי פורמט [Agent Skills](https://agentskills.io/specification) הפתוח, כך שהן עובדות עם כל סוכן שתומך במיומנויות, כולל Claude Code, Claude, ChatGPT, Antigravity, Cursor, GitHub Copilot, Grok Bot, Hermes Agent, Kiro, OpenCode, [ועוד רבים](https://agentskills.io/clients).

עם Obsidian Skills סוכן יכול:

- לכתוב הערות ב-[[Obsidian Flavored Markdown]], עם [[קישורים פנימיים|קישורי ויקי]], הטמעות, תיבות הערה, ו[[מאפיינים|מאפיינים]].
- ליצור ולערוך קבצי [[מבוא ל-Bases|Bases]] ו-[[קנבס|Canvas]].
- לחפש, לקרוא ולנהל הערות באפליקציה הפעילה באמצעות [[Obsidian CLI]].
- לסנכרן ולפרסם כספות ללא אפליקציית שולחן העבודה באמצעות [[Obsidian Headless]].

המיומנויות הן קוד פתוח ב-[obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills).

## התקנה

Obsidian הוא תוסף רשמי עבור Claude, ChatGPT, Dots, Cursor, Grok Bot, Hermes, ו-Kiro. רוב הסוכנים האחרים יכולים להתקין את המיומנויות מ-GitHub.

### Claude

הוסיפו את [Obsidian](https://claude.ai/customize/plugins/id/a38fa062-ebd3-48e0-9a0a-1875a6e94ad5%40anthropic-plugin-directory) מספריית התוספים הרשמית של Claude.

עבור Claude Code CLI השתמשו ב:

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

כדי לקבל מיומנויות חדשות מאוחר יותר, הריצו `claude plugin update obsidian@obsidian-skills`.

### ChatGPT

הוסיפו את [Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096) מספריית התוספים של ChatGPT. התוסף עובד ב-ChatGPT, Codex, ו-Dots.

### Antigravity

ב-Antigravity CLI, הריצו:

```shell
agy plugin install https://github.com/obsidianmd/obsidian-skills
```

### Grok Bot

פתחו את [Obsidian for Grok Bot](https://x.ai/bot/plugin/88871845) ובחרו **Add to Grok Bot**.

### Cursor

התקינו את [Obsidian](https://cursor.com/marketplace/obsidian) מה-Cursor Marketplace.

### Hermes Agent

```shell
hermes plugins install obsidian
```

### Kiro

```shell
kiro-cli powers install obsidian
```

### GitHub Copilot, OpenCode, וסוכנים אחרים

התקינו באמצעות [npx skills](https://github.com/vercel-labs/skills), שמבקש לאילו סוכנים להתקין:

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

כדי להתקין ידנית, העתיקו את התיקיות ב-`plugins/obsidian/skills/` לתיקיית המיומנויות של הסוכן שלכם, למשל `~/.copilot/skills/` עבור GitHub Copilot.

## מיומנויות כלולות

| מיומנות             | מה היא עושה                                                                                                                  |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `obsidian-markdown` | יצירה ועריכה של הערות [[Obsidian Flavored Markdown]].                                                                        |
| `obsidian-bases`    | יצירה ועריכה של [[תחביר Bases|Bases]] עם תצוגות, מסננים, נוסחאות וסיכומים.                                                   |
| `json-canvas`       | יצירה ועריכה של קבצי [[קנבס|Canvas]] בפורמט [JSON Canvas](https://jsoncanvas.org/).                                         |
| `obsidian-cli`      | אינטראקציה עם הכספת שלכם דרך [[Obsidian CLI]], כולל פיתוח תוספים וערכות נושא.                                                |
| `obsidian-headless` | סנכרון ופרסום כספות משורת הפקודה באמצעות [[Obsidian Headless]].                                                               |
| `defuddle`          | חילוץ Markdown נקי מדפי אינטרנט באמצעות [Defuddle](https://github.com/kepano/defuddle).                                     |
| `knap`              | עיבוד תבניות Markdown מנתוני JSON או CSV באמצעות [Knap](https://github.com/obsidianmd/knap).                                 |

## דרישות

מיומנות `obsidian-cli` דורשת שאפליקציית שולחן העבודה של Obsidian תהיה פעילה עם [[Obsidian CLI#התקנת Obsidian CLI|Obsidian CLI מופעל]], וסוכן שיכול להריץ פקודות על המחשב שלכם.

מיומנויות Markdown, Bases ו-Canvas מתארות רק פורמטי קבצים, כך שהן עובדות בכל סוכן שיכול לקרוא ולכתוב קבצים בכספת שלכם.

Defuddle, Knap ו-Obsidian Headless הם כלים נפרדים שאינם מצורפים למיומנויות. כאשר אחד מהם חסר, המיומנות מבקשת אישור לפני שהיא מתקינה אותו מ-npm.

## פרטיות

Obsidian Skills לא שולחות שום דבר בעצמן. כאשר סוכן משתמש בהן, ההערות שהוא קורא הופכות לחלק מהשיחה ומעובדות על ידי מודל ה-AI שאתם משתמשים בו. בדקו את מדיניות הפרטיות של הסוכן שלכם לפני שתכוונו אותו לכספת עם הערות רגישות.
