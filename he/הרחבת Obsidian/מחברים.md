מחברים מאפשרים לך לתת לסוכנים גישה ל-Obsidian בקלות, תוך שמירה על בעלות מלאה על הנתונים שלך. מחברי Obsidian זמינים עבור אפליקציות כולל Claude, ChatGPT, Antigravity, Cursor, GitHub Copilot, Grok Bot, Hermes, Kiro, Muse, OpenCode, ו[רבים נוספים](https://agentskills.io/clients).

זה אומר שהסוכנים שלך יכולים ללמוד כיצד:

- לכתוב הערות ב-[[Obsidian Flavored Markdown]], עם [[קישורים פנימיים|קישורי ויקי]], הטמעות, תיבות הערה, ו[[מאפיינים|מאפיינים]].
- ליצור ולערוך קבצי [[מבוא ל-Bases|Bases]] ו[[קנבס|Canvas]].
- לחפש, לקרוא ולנהל הערות באפליקציה הפעילה עם [[Obsidian CLI]].
- לסנכרן ולפרסם כספות ללא אפליקציית שולחן העבודה באמצעות [[Obsidian Headless]].

מחברי Obsidian וכישורי קוד פתוח זמינים ב-[obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills).

## התקנה

ניתן למצוא את מחברי Obsidian על ידי חיפוש בחנות או בספריית התוספים באפליקציית הסוכן שלכם. אפשר גם לשלוח לסוכן שלכם קישור לעמוד זה.

### Claude

הוסיפו את [Obsidian](https://claude.ai/customize/plugins/id/a38fa062-ebd3-48e0-9a0a-1875a6e94ad5%40anthropic-plugin-directory) מספריית התוספים הרשמית של Claude.

עבור Claude Code CLI השתמשו ב:

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

כדי לקבל כישורים חדשים מאוחר יותר, הריצו `claude plugin update obsidian@obsidian-skills`.

### ChatGPT

הוסיפו את [Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096) מספריית התוספים של ChatGPT. התוסף עובד ב-ChatGPT, Codex, ו-Dots.

### Antigravity

ב-CLI של Antigravity, הריצו:

```shell
agy plugin install https://github.com/obsidianmd/obsidian-skills
```

### Grok Bot

פתחו את [Obsidian עבור Grok Bot](https://x.ai/bot/plugin/88871845) ובחרו **Add to Grok Bot**.

### Muse

בקשו מ-Muse להתקין את הכישורים מ-https://github.com/obsidianmd/obsidian-skills.

Muse רץ בענן של Meta, כך שהכישור `obsidian-cli` לא עובד שם. אם אתם משתמשים ב-Obsidian Headless ב-Muse, אתם מתחברים ומסנכרנים את הכספת שלכם בענן של Meta.

### Cursor

התקינו את [Obsidian](https://cursor.com/marketplace/obsidian) מה-Cursor Marketplace.

### Hermes Agent

```shell
hermes plugins install obsidian
```

### Kiro

```shell
kiro-cli powers install obsidian
```

### GitHub Copilot, OpenCode, וסוכנים אחרים

התקינו עם [npx skills](https://github.com/vercel-labs/skills), שישאל לאילו סוכנים להתקין:

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

להתקנה ידנית, העתיקו את התיקיות ב-`plugins/obsidian/skills/` לתיקיית הכישורים של הסוכן שלכם, לדוגמה `~/.copilot/skills/` עבור GitHub Copilot.

## כישורים כלולים

| כישור               | מה הוא עושה                                                                                                                  |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `obsidian-markdown` | יצירה ועריכה של הערות [[Obsidian Flavored Markdown]].                                                                         |
| `obsidian-bases`    | יצירה ועריכה של [[תחביר Bases\|Bases]] עם תצוגות, מסננים, נוסחאות וסיכומים.                                         |
| `json-canvas`       | יצירה ועריכה של קבצי [[קנבס|Canvas]] בפורמט [JSON Canvas](https://jsoncanvas.org/).                                     |
| `obsidian-cli`      | אינטראקציה עם הכספת שלכם דרך [[Obsidian CLI]], כולל פיתוח תוספים וערכות נושא.                                    |
| `obsidian-headless` | סנכרון ופרסום כספות משורת הפקודה עם [[Obsidian Headless]].                                                     |
| `defuddle`          | חילוץ Markdown נקי מדפי אינטרנט באמצעות [Defuddle](https://github.com/kepano/defuddle).                                   |
| `knap`              | עיבוד תבניות Markdown מנתוני JSON או CSV באמצעות [Knap](https://github.com/obsidianmd/knap).                             |

## דרישות

הכישור `obsidian-cli` דורש שאפליקציית Obsidian לשולחן העבודה תהיה פעילה עם [[Obsidian CLI#התקנת Obsidian CLI|Obsidian CLI מופעל]], וסוכן שיכול להריץ פקודות על המחשב שלכם.

הכישורים של Markdown, Bases ו-Canvas רק מתארים פורמטי קבצים, כך שהם עובדים בכל סוכן שיכול לקרוא ולכתוב קבצים בכספת שלכם.

Defuddle, Knap ו-Obsidian Headless הם כלים נפרדים שאינם מצורפים עם הכישורים. כשכלי חסר, הכישור שואל לפני התקנתו מ-npm.

## פרטיות

מחברי Obsidian לא שולחים דבר בעצמם. כאשר סוכן משתמש בהם, ההערות שהוא קורא הופכות לחלק מהשיחה ומעובדות על ידי מודל ה-AI שבו אתם משתמשים. בדקו את מדיניות הפרטיות של הסוכן שלכם לפני שתכוונו אותו לכספת עם הערות רגישות.
