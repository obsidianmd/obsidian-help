Коннекторы позволяют подключить Obsidian к любому ИИ-агенту, включая Claude, ChatGPT, Antigravity, Cursor, GitHub Copilot, Grok Bot, Hermes, Kiro, Muse, OpenCode и [многие другие](https://agentskills.io/clients).

Это означает, что ваши агенты могут научиться:

- Писать заметки в [[Obsidian Flavored Markdown]], с [[Внутренние ссылки|wiki-ссылками]], встраиваниями, выносными блоками и [[Свойства|свойствами]].
- Создавать и редактировать файлы [[Введение в Базы|Баз данных]] и [[Холст|Canvas]].
- Искать, читать и управлять заметками в работающем приложении с помощью [[Obsidian CLI]].
- Синхронизировать и публиковать хранилища без настольного приложения с помощью [[Obsidian Headless]].

Навыки имеют открытый исходный код и доступны в [obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills).

## Установка

Вы можете найти Obsidian через поиск в списке плагинов в Claude, ChatGPT, Dots, Cursor, Grok Bot, Hermes и Kiro. Большинство других агентов могут установить навыки, если вы отправите им ссылку на эту страницу.

### Claude

Добавьте [Obsidian](https://claude.ai/customize/plugins/id/a38fa062-ebd3-48e0-9a0a-1875a6e94ad5%40anthropic-plugin-directory) из официального каталога плагинов Claude.

Для CLI Claude Code используйте:

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

Чтобы получить новые навыки позже, выполните `claude plugin update obsidian@obsidian-skills`.

### ChatGPT

Добавьте [Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096) из каталога плагинов ChatGPT. Плагин работает в ChatGPT, Codex и Dots.

### Antigravity

В CLI Antigravity выполните:

```shell
agy plugin install https://github.com/obsidianmd/obsidian-skills
```

### Grok Bot

Откройте [Obsidian для Grok Bot](https://x.ai/bot/plugin/88871845) и выберите **Add to Grok Bot**.

### Muse

Попросите Muse установить навыки с https://github.com/obsidianmd/obsidian-skills.

Muse работает в облаке Meta, поэтому навык `obsidian-cli` там не функционирует. Если вы используете Obsidian Headless в Muse, вы входите в систему и синхронизируете своё хранилище в облаке Meta.

### Cursor

Установите [Obsidian](https://cursor.com/marketplace/obsidian) из Cursor Marketplace.

### Hermes Agent

```shell
hermes plugins install obsidian
```

### Kiro

```shell
kiro-cli powers install obsidian
```

### GitHub Copilot, OpenCode и другие агенты

Установите с помощью [npx skills](https://github.com/vercel-labs/skills), который спросит, в какие агенты выполнить установку:

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

Для ручной установки скопируйте папки из `plugins/obsidian/skills/` в папку навыков вашего агента, например `~/.copilot/skills/` для GitHub Copilot.

## Включённые навыки

| Навык               | Что он делает                                                                                                                 |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `obsidian-markdown` | Создание и редактирование заметок в [[Obsidian Flavored Markdown]].                                                           |
| `obsidian-bases`    | Создание и редактирование [[Синтаксис Баз|Баз данных]] с видами, фильтрами, формулами и итогами.                             |
| `json-canvas`       | Создание и редактирование файлов [[Холст|Canvas]] в формате [JSON Canvas](https://jsoncanvas.org/).                           |
| `obsidian-cli`      | Взаимодействие с хранилищем через [[Obsidian CLI]], включая разработку плагинов и тем.                                        |
| `obsidian-headless` | Синхронизация и публикация хранилищ из командной строки с помощью [[Obsidian Headless]].                                       |
| `defuddle`          | Извлечение чистого Markdown из веб-страниц с помощью [Defuddle](https://github.com/kepano/defuddle).                          |
| `knap`              | Рендеринг шаблонов Markdown из данных JSON или CSV с помощью [Knap](https://github.com/obsidianmd/knap).                      |

## Требования

Навык `obsidian-cli` требует запущенного настольного приложения Obsidian с [[Obsidian CLI#Установка Obsidian CLI|включённым Obsidian CLI]] и агента, который может выполнять команды на вашем компьютере.

Навыки Markdown, Bases и Canvas только описывают форматы файлов, поэтому они работают в любом агенте, который может читать и записывать файлы в вашем хранилище.

Defuddle, Knap и Obsidian Headless — это отдельные инструменты, не входящие в комплект навыков. Если какой-либо из них отсутствует, навык запросит разрешение перед установкой из npm.

## Конфиденциальность

Коннекторы Obsidian сами по себе ничего не отправляют. Когда агент их использует, прочитанные им заметки становятся частью диалога и обрабатываются используемой вами ИИ-моделью. Ознакомьтесь с политикой конфиденциальности вашего агента, прежде чем направлять его на хранилище с конфиденциальными заметками.
