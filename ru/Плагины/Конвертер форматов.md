Конвертер форматов выполняет миграцию [[Свойства#Устаревшие свойства|устаревших форматов свойств]] в текущий формат, используемый Obsidian.

> [!warning] Сделайте резервную копию хранилища
> Конвертация применяется ко всему хранилищу. [[Резервное копирование файлов Obsidian|Сделайте резервную копию файлов Obsidian]] перед началом.

Чтобы конвертировать свойства в заметках:

1. Откройте [[Палитра команд|палитру команд]].
2. Выберите **Импорт Markdown-файлов: Миграция начальных метаданных**.
3. Нажмите **Начать конвертацию**.

## Поддерживаемые форматы свойств

Конвертер обновляет псевдонимы, теги и CSS-классы из устаревших форматов:

**Псевдонимы**

```yaml
# До

alias: My Note Title

# После

aliases:
  - My Note Title
```

**Теги**

```yaml
# До

tag: project, important

# После

tags:
  - project
  - important
```

**CSS-классы**

```yaml
# До

cssclass: custom-style

# После

cssclasses:
  - custom-style
```
