Obsidian использует файлы Markdown `.md` в качестве основного формата для заметок. Это позволяет легко импортировать файлы Markdown в Obsidian. Многие приложения могут редактировать файлы Markdown или экспортировать в этот формат.

Существует несколько способов добавить файлы Markdown в ваше хранилище Obsidian:

1. Перетащите файлы или папки в окно [[Файловый менеджер|файлового менеджера]]
2. Используйте системный файловый менеджер (например, Проводник Windows или Finder на macOS) и переместите файлы непосредственно в папку хранилища Obsidian.

## Импорт файлов Markdown с помощью Importer

Используйте официальный [[Импортёр|плагин Importer]], если вам нужно выбрать папки при импорте, импортировать архив `.zip`, стандартизировать форматирование, переместить встроенные теги в [[Свойства|свойства]] или применить шаблон.

1. Откройте **[[Настройки|Настройки]] → Сторонние плагины** и [установите Importer](obsidian://show-plugin?id=obsidian-importer).
2. Включите плагин Importer.
3. Откройте **Importer** с помощью [[Палитра команд|палитры команд]] или значка на вертикальной панели.
4. В поле **File format** выберите **Markdown (.md, .zip)**.
5. Выберите отдельные файлы Markdown, папки или zip-архивы.
6. Просмотрите обнаруженные папки, параметры вывода, сгенерированный шаблон и примеры предпросмотра.
7. Нажмите **Import** и дождитесь завершения импорта.

См. [[Шаблоны импортера]], чтобы настроить имя импортированной заметки, свойства и содержимое.
