[[Импортёр]] позволяет определять шаблоны, которые управляют процессом импорта заметок из других приложений. Это означает, что вы можете изменять заголовок, свойства и содержимое импортируемых заметок.

## Редактирование шаблона импорта

Нажмите **Редактировать** над предварительным просмотром, чтобы отредактировать шаблон по умолчанию. Вы можете редактировать:

- Название заметки, отображаемое как встроенный заголовок.
- Свойства в начале заметки.
- Содержимое заметки в формате Markdown.

Нажмите **Сохранить**, чтобы вернуться к предварительному просмотру. Импортёр запоминает отредактированный встроенный шаблон для будущих импортов, использующих тот же формат.

Также вы можете загрузить шаблон из файла Markdown в текущем хранилище.

## Предварительный просмотр результатов

Предварительный просмотр показывает до десяти образцов из выбранных вами данных. Используйте кнопки со стрелками для переключения между образцами. Изменения настроек импорта и шаблона обновляют предварительный просмотр до того, как что-либо будет добавлено в ваше хранилище.

Некоторые вложения, удалённые элементы и перекрёстные ссылки между заметками не могут быть полностью разрешены до выполнения импорта. В таких случаях предварительный просмотр может сохранять исходную ссылку или показывать заполнитель.

## Синтаксис шаблонов

Шаблоны импортёра используют синтаксис, состоящий из переменных, [[Фильтры|фильтров]] и [[Логика|логики]]. Он использует тот же синтаксис [Knap](https://github.com/obsidianmd/knap), что и [[Введение в Obsidian Web Clipper|Web Clipper]].

Вставляйте переменные с помощью двойных фигурных скобок, например `{{title}}`, `{{content}}` или `{{date}}`. Переменные можно использовать в названии заметки, свойствах и содержимом.

Вы можете модифицировать переменные с помощью [[Фильтры|фильтров]]. Например, чтобы изменить формат даты, используйте `{{date|date:"YYYY-MM-DD"}}`. Используйте [[Логика|логику]] для более сложных условий, циклов и присвоения переменных.

## Переменные

Следующие переменные доступны для использования в любом шаблоне импортёра:

| Переменная       | Описание                                                                                                            |
| ----------------- | ------------------------------------------------------------------------------------------------------------------- |
| `{{body}}`        | Тело заметки в формате Markdown без свойств (без начальных метаданных).                                             |
| `{{content}}`     | Полный Markdown до применения выбранного шаблона.                                                                   |
| `{{ctime}}`       | Время создания источника в формате ISO 8601; пусто, если недоступно.                                                |
| `{{date}}`        | Текущая дата и время на момент рендеринга шаблона в формате ISO 8601.                                               |
| `{{importer}}`    | Идентификатор импортёра, например `keep`, `html` или `notion-api`.                                                  |
| `{{folder}}`      | Итоговая родительская папка относительно хранилища. Пусто, если заметка находится в корне хранилища.                 |
| `{{mtime}}`       | Время последнего изменения источника в формате ISO 8601; пусто, если недоступно.                                    |
| `{{noteName}}`    | Итоговое разрешённое имя заметки после удаления недопустимых символов и добавления суффиксов для дубликатов.          |
| `{{path}}`        | Итоговый путь относительно хранилища, включая расширение `.md`.                                                     |
| `{{properties}}` | Объект, содержащий свойства из начальных метаданных.                                                                |
| `{{source}}`      | Объект, содержащий сгенерированные свойства и значения, специфичные для источника.                                  |
| `{{sourceId}}`    | Стабильный идентификатор источника, если импортёр его предоставляет; в противном случае пусто.                      |
| `{{time}}`        | Псевдоним для `{{date}}`.                                                                                           |
| `{{title}}`       | Оригинальное название заметки до очистки и дедупликации.                                                            |

## Исходные значения для свойств

Для форматов импорта, которые поддерживают [[Свойства]], исходные значения также доступны как переменные верхнего уровня для удобства.

Если исходное значение имеет то же имя, что и общая переменная, обращайтесь к нему через `{{source}}`. Например, если в вашем источнике импорта есть свойство с именем `content`, оно доступно как `{{source.content}}`, тогда как `{{content}}` остаётся переменной импортёра по умолчанию.

Используйте скобочную нотацию, когда имя поля содержит пробелы, знаки пунктуации или другие специальные символы:

```twig
{{source["Project: status"]}}
```

## Пример шаблона

Вот пример шаблона с использованием переменных и [[Фильтры|фильтров]]:

```twig
---
created: {{ctime | date:"YYYY-MM-DD"}}
modified: {{mtime | date:"YYYY-MM-DD"}}
source: {{importer}}
---
# {{title}}

{{body}}
```

Вы можете добавлять данные в заметку условно, используя [[Логика|логику]]:

```twig
{% if tags %}
## Теги
{% for tag in tags %}
- {{tag}}
{% endfor %}
{% endif %}
```
