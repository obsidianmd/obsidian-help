Obsidian używa plików Markdown `.md` jako głównego formatu notatek. Dzięki temu łatwo jest importować pliki Markdown do Obsidian. Wiele aplikacji może edytować pliki Markdown lub eksportować do tego formatu.

Istnieje kilka sposobów na dodanie plików Markdown do sejfu Obsidian:

1. Przeciągnij i upuść pliki lub foldery do okna [[Przeglądarka plików|Przeglądarki plików]]
2. Użyj systemowej przeglądarki plików (np. Eksploratora Windows lub Findera na macOS) i przenieś pliki bezpośrednio do folderu sejfu Obsidian.

## Importowanie plików Markdown za pomocą Importera

Użyj oficjalnej [[Importer|wtyczki Importer]], gdy chcesz wybrać foldery w ramach importu, zaimportować archiwum `.zip`, ustandaryzować formatowanie, przenieść tagi w tekście do [[Atrybuty|atrybutów]] lub zastosować szablon.

1. Otwórz **[[Ustawienia|Ustawienia]] → Wtyczki społeczności** i [zainstaluj Importer](obsidian://show-plugin?id=obsidian-importer).
2. Włącz wtyczkę Importer.
3. Otwórz **Importer** za pomocą [[Lista poleceń|palety poleceń]] lub ikony na wstążce.
4. W polu **Format pliku** wybierz **Markdown (.md, .zip)**.
5. Wybierz pojedyncze pliki Markdown, foldery lub archiwa zip.
6. Przejrzyj wykryte foldery, opcje wyjściowe, wygenerowany szablon i podgląd przykładów.
7. Wybierz **Importuj** i poczekaj na zakończenie importu.

Zobacz [[Szablony importera|Szablony Importera]], aby dostosować nazwę importowanej notatki, atrybuty i zawartość.
