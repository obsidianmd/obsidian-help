Το Obsidian σάς επιτρέπει να μεταφέρετε τα δεδομένα σας από το Airtable χρησιμοποιώντας το [[Εισαγωγέας|πρόσθετο Εισαγωγέα]]. Αυτό θα μετατρέψει τις βάσεις σας στο Airtable σε ανθεκτικά αρχεία Markdown που μπορείτε να χρησιμοποιήσετε εκτός σύνδεσης με το Obsidian και πολλές άλλες εφαρμογές.

Κάθε πίνακας γίνεται ένας φάκελος σημειώσεων με μία σημείωση ανά εγγραφή, καθώς και ένα αρχείο [[Εισαγωγή στις Βάσεις|Βάσης]] που αναδημιουργεί τον πίνακα και τις προβολές του. Επειδή χρησιμοποιεί το API του Airtable, η εισαγωγή απαιτεί ένα προσωπικό διακριτικό πρόσβασης και σύνδεση στο διαδίκτυο.

## Δημιουργία προσωπικού διακριτικού πρόσβασης Airtable

Για να αποκτήσετε πρόσβαση στα δεδομένα σας στο Airtable μέσω του API, χρειάζεστε ένα προσωπικό διακριτικό πρόσβασης. Αυτό το βήμα χρειάζεται περίπου 1 λεπτό για να ολοκληρωθεί.

Το διακριτικό είναι μια μεγάλη σειρά αριθμών και γραμμάτων που συνήθως ξεκινά με `pat...` και σας επιτρέπει να κατεβάσετε τα δεδομένα σας από το Airtable.

1. Συνδεθείτε στο Airtable και μεταβείτε στη σελίδα [Personal access tokens](https://airtable.com/create/tokens) στις ρυθμίσεις του λογαριασμού σας.
2. Επιλέξτε **Create new token**.
3. Δώστε στο διακριτικό σας ένα όνομα, π.χ. "Obsidian". Μπορεί να χρησιμοποιηθεί οποιοδήποτε όνομα.
4. Στην ενότητα **Scopes**, προσθέστε `data.records:read` και `schema.bases:read`.
5. Στην ενότητα **Access**, προσθέστε τις βάσεις που θέλετε να εισαγάγετε ή επιλέξτε όλες τις βάσεις σε έναν χώρο εργασίας.
6. Επιλέξτε **Create token** και στη συνέχεια **Copy** για να αντιγράψετε το διακριτικό.
7. Αποθηκεύστε το διακριτικό σε ασφαλές μέρος, όπως τη διαχείριση κωδικών πρόσβασης.

Το Airtable εμφανίζει το διακριτικό μόνο μία φορά. Αν το χάσετε, δημιουργήστε ένα νέο.

## Εισαγωγή των δεδομένων σας από το Airtable

Θα χρειαστείτε το επίσημο πρόσθετο [[Εισαγωγέας]] του Obsidian, το οποίο μπορείτε να [εγκαταστήσετε εδώ](obsidian://show-plugin?id=obsidian-importer).

1. Ανοίξτε τις **[[Ρυθμίσεις]]**.
2. Μεταβείτε στα **Πρόσθετα κοινότητας** και [εγκαταστήστε τον Εισαγωγέα](obsidian://show-plugin?id=obsidian-importer).
3. Ενεργοποιήστε το πρόσθετο Εισαγωγέα.
4. Ανοίξτε το πρόσθετο **Εισαγωγέα** χρησιμοποιώντας την παλέτα εντολών ή το εικονίδιο στην κορδέλα.
5. Στη **Μορφή αρχείου** επιλέξτε **Airtable**.
6. Στο **Airtable Personal Access Token**, κάντε κλικ στο **Σύνδεση...** για να προσθέσετε ένα νέο μυστικό. Για το **Αναγνωριστικό**, δώστε ένα όνομα όπως `airtable`, και για το **Μυστικό** επικολλήστε το προσωπικό σας διακριτικό πρόσβασης.
7. Κάντε κλικ στο **Φόρτωση** για να περιηγηθείτε στις βάσεις σας και στη συνέχεια επιλέξτε τους πίνακες που θέλετε να εισαγάγετε.
8. Ελέγξτε και επεξεργαστείτε τις επιλογές εισαγωγής.
9. Επιλέξτε **Εισαγωγή** για να ρυθμίσετε πώς θα μετατραπούν τα πεδία σας σε σημειώσεις με [[Ιδιότητες|ιδιότητες]].
10. Κάντε κλικ στο **Συνέχεια** και περιμένετε μέχρι να ολοκληρωθεί η εισαγωγή.
11. Τελειώσατε!

### Επιλογές εισαγωγής

- **Μετατροπή τύπων** — επιλέξτε αν τα πεδία τύπων, αναζήτησης, rollup και μέτρησης θα ξαναγραφτούν ως [[Τύποι|τύποι Βάσεων]], επιστρέφοντας στην τιμή που υπολόγισε το Airtable όταν δεν υπάρχει αντίστοιχη, ή θα εισαχθούν μόνο ως στατικές τιμές.
- **Λήψη συνημμένων** — αποθήκευση αρχείων συνημμένων στο θησαυροφυλάκιό σας, χρησιμοποιώντας τις ρυθμίσεις φακέλου συνημμένων και μορφής συνδέσμων. Όταν είναι απενεργοποιημένο, ή όταν αποτυγχάνει η λήψη, η σημείωση συνδέεται με τη διεύθυνση URL του αρχείου στο Airtable.
- **Όνομα ιδιότητας προβολής** — η ιδιότητα που καταγράφει σε ποιες προβολές του Airtable ανήκει μια εγγραφή. Κάθε προβολή στη δημιουργημένη Βάση φιλτράρει με βάση αυτή την ιδιότητα. Προεπιλογή: `base`.
- **Σταδιακή εισαγωγή** — προσθέτει μια ιδιότητα `airtable-id` σε κάθε σημείωση ώστε μια μεταγενέστερη εισαγωγή να μπορεί να παραλείψει εγγραφές που έχουν ήδη εισαχθεί. Σε πλήρη εισαγωγή, αυτή η ιδιότητα αφαιρείται ξανά.

## Ρύθμιση του τρόπου εισαγωγής πεδίων Airtable

Στο δεύτερο βήμα της εισαγωγής, μπορείτε να επιλέξετε πώς θα εισαχθεί κάθε πεδίο.

Σε κάθε πεδίο στους πίνακές σας αποδίδεται μια μεταβλητή που ονομάζεται `{{field_name}}`. Από προεπιλογή κάθε πεδίο γίνεται ιδιότητα, και μπορείτε να χρησιμοποιήσετε αυτές τις μεταβλητές για να μετονομάσετε ιδιότητες, να αλλάξετε τις τιμές τους ή να γράψετε περιεχόμενο στο σώμα κάθε σημείωσης.

Το κύριο πεδίο κάθε πίνακα χρησιμοποιείται πάντα ως τίτλος σημείωσης, και οι εγγραφές τοποθετούνται πάντα σε φάκελο που ονομάζεται σύμφωνα με τον πίνακά τους, οπότε αυτές οι επιλογές δεν μπορούν να τροποποιηθούν.

## Τι εισάγεται

Για μια βάση με όνομα `Projects` που περιέχει πίνακα `Tasks`, ο εισαγωγέας δημιουργεί:

```
Airtable/
	Projects/
		Tasks.base
		Tasks/
			Write the proposal.md
			Review the draft.md
```

- Μία σημείωση ανά εγγραφή, με το κύριο πεδίο ως τίτλο σημείωσης και τα υπόλοιπα πεδία της εγγραφής ως [[Ιδιότητες|ιδιότητες]].
- Ένα αρχείο `.base` ανά πίνακα, με κάθε προβολή Airtable να αντιστοιχίζεται σε μια [[Προβολές|προβολή Βάσεων]]:
	- Η **Grid** γίνεται [[Προβολή πίνακα]].
	- Η **Gallery** γίνεται [[Προβολή καρτών]].
	- Η **List** γίνεται [[Προβολή λίστας]].
	- Όλοι οι άλλοι τύποι προβολών μετατρέπονται σε προβολή πίνακα.
- Οι τύποι πεδίων του Airtable αντιστοιχίζονται σε τύπους ιδιοτήτων του Obsidian, χωρίς να αντικαθιστούν τύπους που έχετε ήδη ορίσει.
- Οι συνδεδεμένες εγγραφές γίνονται σύνδεσμοι προς τις αντίστοιχες σημειώσεις.
- Τα συνημμένα λαμβάνονται στο θησαυροφυλάκιό σας χρησιμοποιώντας τις ρυθμίσεις του θησαυροφυλακίου σας.

## Περιορισμοί

> [!info] Η εισαγωγή από Airtable είναι νέα
> Ο εισαγωγέας Airtable είναι νέος. Αν αντιμετωπίσετε προβλήματα με τη μετατροπή, [υποβάλετε αναφορά σφάλματος](https://github.com/obsidianmd/obsidian-importer/issues) ώστε να μπορέσουμε να τον βελτιώσουμε.

Λόγω ορίων ρυθμού του API του Airtable, η εισαγωγή μεγάλων βάσεων μπορεί να χρειαστεί αρκετό χρόνο. Παρακαλώ κάντε υπομονή.

Λόγω περιορισμών στο API του Airtable, ορισμένα δεδομένα δεν είναι διαθέσιμα ή δεν μπορούν να μετατραπούν:

- Οι τιμές rollup δεν εισάγονται. Το API δεν εκθέτει τη συνάρτηση συγκέντρωσης που χρησιμοποιήθηκε για την υπολογισμένη τιμή ενός rollup, οπότε γράφεται μόνο το όνομα της ιδιότητας, μαζί με έναν τύπο Βάσεων όταν το σχήμα του πεδίου εκθέτει μια έκφραση.
- Οι τύποι που χρησιμοποιούν συναρτήσεις για τις οποίες το Obsidian δεν έχει αντίστοιχες, όπως `SWITCH`, `FIND`, `REGEX_EXTRACT` και `SQRT`, επιστρέφουν στη στατική τιμή από το Airtable.
- Εισάγονται μόνο οι προβολές grid, gallery και list. Άλλοι τύποι προβολών, όπως calendar, kanban, timeline και Gantt, αγνοούνται.
- Οι σύνδεσμοι σε εγγραφές πινάκων που δεν επιλέξατε γίνονται ο απλός τίτλος της εγγραφής αντί για σύνδεσμο.
- Τα σχέδια διεπαφής, οι αυτοματισμοί, τα σχόλια και το ιστορικό αναθεωρήσεων δεν εισάγονται.
