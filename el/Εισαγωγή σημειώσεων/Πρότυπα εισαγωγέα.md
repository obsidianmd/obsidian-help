Ο [[Εισαγωγέας]] σας επιτρέπει να ορίσετε πρότυπα που ελέγχουν τον τρόπο εισαγωγής των σημειώσεών σας από άλλες εφαρμογές. Αυτό σημαίνει ότι μπορείτε να τροποποιήσετε τον τίτλο, τις ιδιότητες και το περιεχόμενο των σημειώσεων που εισάγετε.

## Επεξεργασία του προτύπου εισαγωγής

Επιλέξτε **Επεξεργασία** πάνω από την προεπισκόπηση για να επεξεργαστείτε το προεπιλεγμένο πρότυπο. Μπορείτε να επεξεργαστείτε:

- Το όνομα της σημείωσης που εμφανίζεται ως τίτλος στο έγγραφο.
- Ιδιότητες στην αρχή της σημείωσης.
- Το περιεχόμενο Markdown της σημείωσης.

Επιλέξτε **Αποθήκευση** για να επιστρέψετε στην προεπισκόπηση. Ο Εισαγωγέας θυμάται ένα επεξεργασμένο ενσωματωμένο πρότυπο για μελλοντικές εισαγωγές που χρησιμοποιούν την ίδια μορφή.

Εναλλακτικά, μπορείτε να φορτώσετε ένα πρότυπο από ένα αρχείο Markdown στο τρέχον θησαυροφυλάκιο.

## Προεπισκόπηση αποτελεσμάτων

Η προεπισκόπηση εμφανίζει έως δέκα δείγματα από τα δεδομένα που επιλέξατε. Χρησιμοποιήστε τα κουμπιά με βέλη για μετακίνηση μεταξύ δειγμάτων. Οι αλλαγές στις ρυθμίσεις εισαγωγής και στο πρότυπο ενημερώνουν την προεπισκόπηση πριν προστεθεί οτιδήποτε στο θησαυροφυλάκιό σας.

Ορισμένα συνημμένα, απομακρυσμένα στοιχεία και αναφορές μεταξύ σημειώσεων δεν μπορούν να επιλυθούν πλήρως μέχρι να εκτελεστεί η εισαγωγή. Σε αυτές τις περιπτώσεις, η προεπισκόπηση μπορεί να διατηρήσει τον σύνδεσμο προέλευσης ή να εμφανίσει ένα σύμβολο κράτησης θέσης.

## Σύνταξη προτύπου

Τα πρότυπα εισαγωγέα χρησιμοποιούν μια σύνταξη που αποτελείται από μεταβλητές, [[Φίλτρα]] και [[Λογική]]. Χρησιμοποιεί την ίδια σύνταξη [Knap](https://github.com/obsidianmd/knap) με το [[Εισαγωγή στο Obsidian Web Clipper|Web Clipper]].

Εισάγετε μεταβλητές με διπλές αγκύλες, όπως `{{title}}`, `{{content}}` ή `{{date}}`. Οι μεταβλητές μπορούν να χρησιμοποιηθούν στο όνομα της σημείωσης, στις ιδιότητες και στο περιεχόμενο.

Μπορείτε να τροποποιήσετε μεταβλητές χρησιμοποιώντας [[Φίλτρα]]. Για παράδειγμα, για να αλλάξετε τη μορφή ημερομηνίας χρησιμοποιώντας `{{date|date:"YYYY-MM-DD"}}`. Χρησιμοποιήστε τη [[Λογική]] για πιο σύνθετες συνθήκες, βρόχους και αντιστοίχιση μεταβλητών.

## Μεταβλητές

Οι ακόλουθες μεταβλητές είναι διαθέσιμες για χρήση σε οποιοδήποτε πρότυπο Εισαγωγέα:

| Μεταβλητή        | Περιγραφή                                                                                                     |
| ---------------- | ------------------------------------------------------------------------------------------------------------- |
| `{{body}}`       | Σώμα Markdown χωρίς ιδιότητες (χωρίς μεταδεδομένα αρχής).                                                    |
| `{{content}}`    | Πλήρες Markdown πριν εφαρμοστεί το επιλεγμένο πρότυπο.                                                       |
| `{{ctime}}`      | Χρόνος δημιουργίας πηγής ως χρονοσφραγίδα ISO 8601· κενό όταν δεν είναι διαθέσιμο.                           |
| `{{date}}`       | Τρέχουσα ημερομηνία και ώρα κατά την απόδοση του προτύπου, ως χρονοσφραγίδα ISO 8601.                         |
| `{{importer}}`   | Αναγνωριστικό Εισαγωγέα, όπως `keep`, `html` ή `notion-api`.                                                 |
| `{{folder}}`     | Τελικός γονικός φάκελος σε σχέση με το θησαυροφυλάκιο. Κενό όταν η σημείωση βρίσκεται στη ρίζα.              |
| `{{mtime}}`      | Χρόνος τροποποίησης πηγής ως χρονοσφραγίδα ISO 8601· κενό όταν δεν είναι διαθέσιμο.                          |
| `{{noteName}}`   | Τελικό επιλυμένο όνομα σημείωσης, μετά την αφαίρεση μη έγκυρων χαρακτήρων και την προσθήκη επιθημάτων για διπλότυπα. |
| `{{path}}`       | Τελική διαδρομή σε σχέση με το θησαυροφυλάκιο, συμπεριλαμβανομένης της επέκτασης `.md`.                       |
| `{{properties}}` | Αντικείμενο που περιέχει τις ιδιότητες μεταδεδομένων αρχής.                                                   |
| `{{source}}`     | Αντικείμενο που περιέχει παραγόμενες ιδιότητες και τιμές ειδικές για την πηγή.                                |
| `{{sourceId}}`   | Σταθερό αναγνωριστικό πηγής όταν ο εισαγωγέας παρέχει ένα· αλλιώς κενό.                                     |
| `{{time}}`       | Ψευδώνυμο για `{{date}}`.                                                                                     |
| `{{title}}`      | Αρχικός τίτλος σημείωσης πριν από τον καθαρισμό και την αποδιπλασιοποίηση.                                    |

## Τιμές πηγής για ιδιότητες

Για μορφές εισαγωγής που υποστηρίζουν [[Ιδιότητες]], οι τιμές πηγής είναι επίσης διαθέσιμες ως μεταβλητές ανώτατου επιπέδου για ευκολία.

Εάν μια τιμή πηγής έχει το ίδιο όνομα με μια κοινόχρηστη μεταβλητή, αποκτήστε πρόσβαση μέσω `{{source}}`. Για παράδειγμα, εάν η πηγή εισαγωγής σας έχει μια ιδιότητα με όνομα `content`, είναι διαθέσιμη ως `{{source.content}}`, ενώ `{{content}}` παραμένει η προεπιλεγμένη μεταβλητή Εισαγωγέα.

Χρησιμοποιήστε σημειογραφία αγκυλών όταν ένα όνομα πεδίου περιέχει κενά, σημεία στίξης ή άλλους ειδικούς χαρακτήρες:

```twig
{{source["Project: status"]}}
```

## Παράδειγμα προτύπου

Ακολουθεί ένα παράδειγμα προτύπου που χρησιμοποιεί μεταβλητές και [[Φίλτρα|φίλτρα]]:

```twig
---
created: {{ctime | date:"YYYY-MM-DD"}}
modified: {{mtime | date:"YYYY-MM-DD"}}
source: {{importer}}
---
# {{title}}

{{body}}
```

Μπορείτε να προσθέσετε δεδομένα σε μια σημείωση υπό συνθήκη χρησιμοποιώντας [[Λογική]]:

```twig
{% if tags %}
## Ετικέτες
{% for tag in tags %}
- {{tag}}
{% endfor %}
{% endif %}
```
