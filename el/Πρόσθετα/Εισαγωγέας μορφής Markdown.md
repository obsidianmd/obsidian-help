Ο Εισαγωγέας μορφής Markdown μεταφέρει [[Ιδιότητες#Καταργημένες ιδιότητες|καταργημένες μορφές ιδιοτήτων]] στην τρέχουσα μορφή που χρησιμοποιείται από το Obsidian.

> [!warning] Δημιουργήστε αντίγραφα ασφαλείας του θησαυροφυλακίου σας
> Η μετατροπή εφαρμόζεται σε ολόκληρο το θησαυροφυλάκιό σας. [[Δημιουργία αντιγράφων ασφαλείας των αρχείων Obsidian|Δημιουργήστε αντίγραφα ασφαλείας των αρχείων Obsidian]] πριν ξεκινήσετε.

Για να μετατρέψετε τις ιδιότητες στις σημειώσεις σας:

1. Ανοίξτε την [[Παλέτα εντολών]].
2. Επιλέξτε **Εισαγωγέας μορφής Markdown: Μεταφορά μεταδεδομένων αρχής**.
3. Επιλέξτε **Εκκίνηση Μετατροπής**.

## Υποστηριζόμενες μορφές ιδιοτήτων

Ο εισαγωγέας ενημερώνει ψευδώνυμα, ετικέτες και κλάσεις CSS από καταργημένες μορφές:

**Ψευδώνυμα**

```yaml
# Πριν

alias: My Note Title

# Μετά

aliases:
  - My Note Title
```

**Ετικέτες**

```yaml
# Πριν

tag: project, important

# Μετά

tags:
  - project
  - important
```

**Κλάσεις CSS**

```yaml
# Πριν

cssclass: custom-style

# Μετά

cssclasses:
  - custom-style
```
