Χρησιμοποιήστε την εύρεση και αντικατάσταση για αναζήτηση μέσα στην ενεργή σημείωση. Για αναζήτηση σε ολόκληρο το θησαυροφυλάκιό σας, χρησιμοποιήστε την [[Αναζήτηση]].

## Άνοιγμα εύρεσης και αντικατάστασης

- Για να βρείτε κείμενο στην ενεργή σημείωση, ανοίξτε την [[Παλέτα εντολών]] και επιλέξτε **Εύρεση στο αρχείο**.
- Για να βρείτε και να αντικαταστήσετε κείμενο στην ενεργή σημείωση, επιλέξτε **Εύρεση + Αντικατάσταση στο αρχείο** από την παλέτα εντολών.
- Μπορείτε επίσης να επιλέξετε **Περισσότερες επιλογές** ![[lucide-more-horizontal.svg#icon]] στη σημείωση και στη συνέχεια να επιλέξετε **Αναζήτηση...** ή **Αντικατάσταση...**. Δείτε [[Μενού περισσότερων επιλογών]].

> [!tip]- Συντομεύσεις πληκτρολογίου
> Αυτές είναι οι προεπιλεγμένες συντομεύσεις πληκτρολογίου.
>
> - `Ctrl+F` (Windows και Linux) ή `Command+F` (macOS) για **Εύρεση στο αρχείο**.
> - `Ctrl+H` (Windows και Linux) ή `Command+Option+F` (macOS) για **Εύρεση + Αντικατάσταση στο αρχείο**.
>
> Μπορείτε να τις αλλάξετε στις [[Συντομεύσεις]].

## Εύρεση αντιστοιχιών

1. Ξεκινήστε μια αναζήτηση χρησιμοποιώντας μία από τις παραπάνω μεθόδους.
2. Εισαγάγετε το κείμενο που θέλετε να αναζητήσετε.
3. Επιλέξτε **Προηγ** ή **Επόμενο** για να μετακινηθείτε μεταξύ των αντιστοιχιών.
4. Επιλέξτε **Εύρεση όλων** για να επιλέξετε κάθε αντιστοιχία στην ενεργή σημείωση.

## Αντικατάσταση αντιστοιχιών

1. Ξεκινήστε μια αντικατάσταση χρησιμοποιώντας μία από τις παραπάνω μεθόδους.
2. Στο πεδίο **Αναζήτηση...**, εισαγάγετε το κείμενο που θέλετε να αντικαταστήσετε.
3. Στο πεδίο **Αντικατάσταση...**, εισαγάγετε το κείμενο αντικατάστασης.
4. Επιλέξτε **Αντικατάσταση** για να αντικαταστήσετε την τρέχουσα αντιστοιχία ή **Αντικατάσταση όλων** για να αντικαταστήσετε κάθε αντιστοιχία στην ενεργή σημείωση.
