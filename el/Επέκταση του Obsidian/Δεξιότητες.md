Τα Obsidian Skills είναι οδηγίες που διδάσκουν σε πράκτορες AI πώς να εργάζονται με το Obsidian. Ακολουθούν την ανοιχτή μορφή [Agent Skills](https://agentskills.io/specification), οπότε λειτουργούν με οποιονδήποτε πράκτορα υποστηρίζει δεξιότητες, συμπεριλαμβανομένων των Claude Code, Claude, ChatGPT, Antigravity, Cursor, GitHub Copilot, Grok Bot, Hermes Agent, OpenCode, και [πολλών άλλων](https://agentskills.io/clients).

Με τα Obsidian Skills ένας πράκτορας μπορεί:

- Να γράφει σημειώσεις σε [[Obsidian Flavored Markdown]], με [[Εσωτερικοί σύνδεσμοι|συνδέσμους wiki]], ενσωματώσεις, πλαίσια επισήμανσης και [[Ιδιότητες|ιδιότητες]].
- Να δημιουργεί και να επεξεργάζεται αρχεία [[Εισαγωγή στις Βάσεις|Βάσεων]] και [[Καμβάς|Canvas]].
- Να αναζητά, να διαβάζει και να διαχειρίζεται σημειώσεις στην τρέχουσα εφαρμογή με το [[Obsidian CLI]].
- Να συγχρονίζει και να δημοσιεύει θησαυροφυλάκια χωρίς την εφαρμογή επιφάνειας εργασίας χρησιμοποιώντας το [[Obsidian Headless]].

Οι δεξιότητες είναι ανοιχτού κώδικα στο [obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills).

## Εγκατάσταση

Το Obsidian είναι επίσημο πρόσθετο για τα Claude, ChatGPT, Dots, Cursor, Grok Bot και Hermes. Οι περισσότεροι άλλοι πράκτορες μπορούν να εγκαταστήσουν τις δεξιότητες από το GitHub.

### Claude

Προσθέστε το [Obsidian](https://claude.ai/customize/plugins/id/a38fa062-ebd3-48e0-9a0a-1875a6e94ad5%40anthropic-plugin-directory) από τον επίσημο κατάλογο προσθέτων του Claude.

Για το Claude Code CLI χρησιμοποιήστε:

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

Για να λάβετε νέες δεξιότητες αργότερα, εκτελέστε `claude plugin update obsidian@obsidian-skills`.

### ChatGPT

Προσθέστε το [Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096) από τον κατάλογο προσθέτων του ChatGPT. Το πρόσθετο λειτουργεί στο ChatGPT, στο Codex και στο Dots.

### Antigravity

Στο Antigravity CLI, εκτελέστε:

```shell
agy plugin install https://github.com/obsidianmd/obsidian-skills
```

### Grok Bot

Ανοίξτε το [Obsidian for Grok Bot](https://x.ai/bot/plugin/88871845) και επιλέξτε **Add to Grok Bot**.

### Cursor

Εγκαταστήστε το [Obsidian](https://cursor.com/marketplace/obsidian) από το Cursor Marketplace.

### Hermes Agent

```shell
hermes plugins install obsidian
```

### GitHub Copilot, OpenCode, και άλλοι πράκτορες

Εγκαταστήστε με το [npx skills](https://github.com/vercel-labs/skills), το οποίο ρωτά σε ποιους πράκτορες θέλετε να γίνει εγκατάσταση:

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

Για χειροκίνητη εγκατάσταση, αντιγράψτε τους φακέλους από το `plugins/obsidian/skills/` στον φάκελο δεξιοτήτων του πράκτορά σας, π.χ. `~/.copilot/skills/` για το GitHub Copilot.

## Περιλαμβανόμενες δεξιότητες

| Δεξιότητα            | Τι κάνει                                                                                                                      |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `obsidian-markdown`  | Δημιουργία και επεξεργασία σημειώσεων σε [[Obsidian Flavored Markdown]].                                                      |
| `obsidian-bases`     | Δημιουργία και επεξεργασία [[Σύνταξη Βάσεων|Βάσεων]] με προβολές, φίλτρα, τύπους και συνοψίσεις.                              |
| `json-canvas`        | Δημιουργία και επεξεργασία αρχείων [[Καμβάς|Canvas]] χρησιμοποιώντας τη μορφή [JSON Canvas](https://jsoncanvas.org/).          |
| `obsidian-cli`       | Αλληλεπίδραση με το θησαυροφυλάκιό σας μέσω [[Obsidian CLI]], συμπεριλαμβανομένης της ανάπτυξης προσθέτων και θεμάτων.         |
| `obsidian-headless`  | Συγχρονισμός και δημοσίευση θησαυροφυλακίων από τη γραμμή εντολών με το [[Obsidian Headless]].                                 |
| `defuddle`           | Εξαγωγή καθαρού Markdown από ιστοσελίδες χρησιμοποιώντας το [Defuddle](https://github.com/kepano/defuddle).                   |
| `knap`               | Απόδοση προτύπων Markdown από δεδομένα JSON ή CSV χρησιμοποιώντας το [Knap](https://github.com/obsidianmd/knap).               |

## Απαιτήσεις

Η δεξιότητα `obsidian-cli` χρειάζεται την εφαρμογή επιφάνειας εργασίας Obsidian να εκτελείται με [[Obsidian CLI#Εγκατάσταση του Obsidian CLI|ενεργοποιημένο το Obsidian CLI]], και έναν πράκτορα που μπορεί να εκτελεί εντολές στον υπολογιστή σας.

Οι δεξιότητες Markdown, Βάσεων και Canvas περιγράφουν μόνο μορφές αρχείων, οπότε λειτουργούν σε οποιονδήποτε πράκτορα μπορεί να διαβάζει και να γράφει αρχεία στο θησαυροφυλάκιό σας.

Τα Defuddle, Knap και Obsidian Headless είναι ξεχωριστά εργαλεία που δεν περιλαμβάνονται μαζί με τις δεξιότητες. Όταν κάποιο λείπει, η δεξιότητα ρωτά πριν το εγκαταστήσει από το npm.

## Απόρρητο

Τα Obsidian Skills δεν στέλνουν τίποτα από μόνα τους. Όταν ένας πράκτορας τα χρησιμοποιεί, οι σημειώσεις που διαβάζει γίνονται μέρος της συνομιλίας και υποβάλλονται σε επεξεργασία από το μοντέλο AI που χρησιμοποιείτε. Ελέγξτε την πολιτική απορρήτου του πράκτορά σας πριν τον κατευθύνετε σε θησαυροφυλάκιο με ευαίσθητες σημειώσεις.
