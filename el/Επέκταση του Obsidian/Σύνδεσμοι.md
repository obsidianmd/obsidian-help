Οι Σύνδεσμοι σας επιτρέπουν να δίνετε εύκολα στους agents σας πρόσβαση στο Obsidian, διατηρώντας πλήρη ιδιοκτησία των δεδομένων σας. Οι Σύνδεσμοι του Obsidian είναι διαθέσιμοι για εφαρμογές όπως Claude, ChatGPT, Antigravity, Cursor, GitHub Copilot, Grok Bot, Hermes, Kiro, Muse, OpenCode, και [πολλών άλλων](https://agentskills.io/clients).

Αυτό σημαίνει ότι οι agents σας μπορούν να μάθουν πώς να:

- Γράφουν σημειώσεις σε [[Obsidian Flavored Markdown]], με [[Εσωτερικοί σύνδεσμοι|συνδέσμους wiki]], ενσωματώσεις, πλαίσια επισήμανσης και [[Ιδιότητες|ιδιότητες]].
- Δημιουργούν και επεξεργάζονται αρχεία [[Εισαγωγή στις Βάσεις|Βάσεων]] και [[Καμβάς|Canvas]].
- Αναζητούν, διαβάζουν και διαχειρίζονται σημειώσεις στην τρέχουσα εφαρμογή με το [[Obsidian CLI]].
- Συγχρονίζουν και δημοσιεύουν θησαυροφυλάκια χωρίς την εφαρμογή επιφάνειας εργασίας χρησιμοποιώντας το [[Obsidian Headless]].

Οι δεξιότητες είναι ανοιχτού κώδικα στο [obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills).

## Εγκατάσταση

Μπορείτε να βρείτε το Obsidian αναζητώντας στη λίστα πρόσθετων στο Claude, ChatGPT, Dots, Cursor, Grok Bot, Hermes και Kiro. Οι περισσότεροι άλλοι agents μπορούν να εγκαταστήσουν τις δεξιότητες αν τους στείλετε έναν σύνδεσμο σε αυτή τη σελίδα.

### Claude

Προσθέστε το [Obsidian](https://claude.ai/customize/plugins/id/a38fa062-ebd3-48e0-9a0a-1875a6e94ad5%40anthropic-plugin-directory) από τον επίσημο κατάλογο πρόσθετων του Claude.

Για το Claude Code CLI χρησιμοποιήστε:

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

Για να λάβετε νέες δεξιότητες αργότερα, εκτελέστε `claude plugin update obsidian@obsidian-skills`.

### ChatGPT

Προσθέστε το [Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096) από τον κατάλογο πρόσθετων του ChatGPT. Το πρόσθετο λειτουργεί στο ChatGPT, Codex και Dots.

### Antigravity

Στο CLI του Antigravity, εκτελέστε:

```shell
agy plugin install https://github.com/obsidianmd/obsidian-skills
```

### Grok Bot

Ανοίξτε το [Obsidian for Grok Bot](https://x.ai/bot/plugin/88871845) και επιλέξτε **Add to Grok Bot**.

### Muse

Ζητήστε από το Muse να εγκαταστήσει τις δεξιότητες από το https://github.com/obsidianmd/obsidian-skills.

Το Muse εκτελείται στο cloud της Meta, οπότε η δεξιότητα `obsidian-cli` δεν λειτουργεί εκεί. Αν χρησιμοποιείτε το Obsidian Headless στο Muse, συνδέεστε και συγχρονίζετε το θησαυροφυλάκιό σας στο cloud της Meta.

### Cursor

Εγκαταστήστε το [Obsidian](https://cursor.com/marketplace/obsidian) από το Cursor Marketplace.

### Hermes Agent

```shell
hermes plugins install obsidian
```

### Kiro

```shell
kiro-cli powers install obsidian
```

### GitHub Copilot, OpenCode και άλλοι agents

Εγκαταστήστε με [npx skills](https://github.com/vercel-labs/skills), που ρωτά σε ποιους agents θέλετε να εγκατασταθεί:

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

Για χειροκίνητη εγκατάσταση, αντιγράψτε τους φακέλους στο `plugins/obsidian/skills/` στον φάκελο δεξιοτήτων του agent σας, π.χ. `~/.copilot/skills/` για το GitHub Copilot.

## Περιλαμβανόμενες δεξιότητες

| Δεξιότητα           | Τι κάνει                                                                                                                      |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `obsidian-markdown` | Δημιουργία και επεξεργασία σημειώσεων [[Obsidian Flavored Markdown]].                                                         |
| `obsidian-bases`    | Δημιουργία και επεξεργασία [[Σύνταξη Βάσεων\|Βάσεων]] με προβολές, φίλτρα, τύπους και συνόψεις.                               |
| `json-canvas`       | Δημιουργία και επεξεργασία αρχείων [[Καμβάς|Canvas]] χρησιμοποιώντας τη μορφή [JSON Canvas](https://jsoncanvas.org/).          |
| `obsidian-cli`      | Αλληλεπίδραση με το θησαυροφυλάκιό σας μέσω του [[Obsidian CLI]], συμπεριλαμβανομένης της ανάπτυξης πρόσθετων και θεμάτων.     |
| `obsidian-headless` | Συγχρονισμός και δημοσίευση θησαυροφυλακίων από τη γραμμή εντολών με το [[Obsidian Headless]].                                 |
| `defuddle`          | Εξαγωγή καθαρού Markdown από ιστοσελίδες χρησιμοποιώντας το [Defuddle](https://github.com/kepano/defuddle).                   |
| `knap`              | Απόδοση προτύπων Markdown από δεδομένα JSON ή CSV χρησιμοποιώντας το [Knap](https://github.com/obsidianmd/knap).               |

## Απαιτήσεις

Η δεξιότητα `obsidian-cli` χρειάζεται την εφαρμογή Obsidian για επιφάνεια εργασίας να εκτελείται με ενεργοποιημένο το [[Obsidian CLI#Εγκατάσταση του Obsidian CLI|Obsidian CLI]], και έναν agent που μπορεί να εκτελεί εντολές στον υπολογιστή σας.

Οι δεξιότητες Markdown, Βάσεων και Canvas περιγράφουν μόνο μορφές αρχείων, οπότε λειτουργούν σε οποιονδήποτε agent που μπορεί να διαβάσει και να γράψει αρχεία στο θησαυροφυλάκιό σας.

Τα Defuddle, Knap και Obsidian Headless είναι ξεχωριστά εργαλεία που δεν περιλαμβάνονται μαζί με τις δεξιότητες. Όταν κάποιο λείπει, η δεξιότητα ζητά πριν το εγκαταστήσει από το npm.

## Απόρρητο

Οι σύνδεσμοι του Obsidian δεν στέλνουν τίποτα από μόνοι τους. Όταν ένας agent τους χρησιμοποιεί, οι σημειώσεις που διαβάζει γίνονται μέρος της συνομιλίας και υποβάλλονται σε επεξεργασία από το μοντέλο AI που χρησιμοποιείτε. Ελέγξτε την πολιτική απορρήτου του agent σας πριν τον κατευθύνετε σε ένα θησαυροφυλάκιο με ευαίσθητες σημειώσεις.
