## New

- Added Quick Look previews for Markdown files on macOS (requires latest installer).
- Added document icons on macOS and Windows for `.md`, `.base` and `.canvas`.
- Bases: Added a **Group** menu to the toolbar for choosing the property to group by. Use it to reorder, hide, and add groups by hand in any view type.
- Redesigned empty state and added "New base" and "New canvas" when their plugins are enabled.

## Improvements

- Added "Increase font size" and "Decrease font size" commands.
- Added an update notice in **Settings → General** when a newer installer is available.
- Bases: Improved how dates and times are rendered in group headers and in readonly layouts (e.g. Cards, Kanban).
- Bases: Embedded kanban boards no longer have a fixed height.
- Improved fuzzy search in the Quick switcher and suggestions: matches where your letters start words now rank higher, and searching is faster in large vaults.
- When opening an untrusted vault, themes and snippets will be temporarily disabled while the "Do you trust the author of this vault" dialog is on screen.
- Improved search in the Bookmarks, Outline, Tags, and Sync views. Everything inside a matching item now stays visible. Groups with nothing to show are hidden.
- In Source mode, pressing `ArrowUp` on the first line of a note now moves the cursor to the inline title, like in Live Preview.

## No longer broken

- Fixed tooltips briefly disappearing when moving between adjacent items.
- Fixed kanban column count missing thousands separators.
- Bases: Fixed a long property name in a filter rule pushing the operator and value out of view.
- Bases: Fixed "Hide all" causing the properties menu to render incorrectly.
- Fixed a potential iframe injection in the Slides plugin.
- Fixed page preview showing behind Bases toolbar menus.
- Fixed an editor issue with `Home` and `End` key in RTL languages.
- Fixed searching headings in all notes (`[[##`) freezing the app in large vaults.
- Fixed pressing `Enter` on an invalid title in an embedded note (e.g. a new note from Bases) reverting the title and moving focus out of it. The title now stays focused so you can fix the name.
- Canvas: Fixed a card narrowed to a heading or block still showing that section after using **Swap file...** to pick the same file.

## Developers

- Added CSS variables for tooltips, notices, hotkeys, and tabs, using the prefixes `--tooltip-`, `--notice-`, `--hotkey`, `--tab-inner-` and `--tab-container-`.
