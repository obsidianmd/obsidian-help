O Obsidian usa arquivos Markdown `.md` como formato principal para notas. Isso facilita a importação de arquivos Markdown para o Obsidian. Muitos aplicativos podem editar arquivos Markdown ou exportar para esse formato.

Existem várias maneiras de adicionar arquivos Markdown ao seu cofre do Obsidian:

1. Arraste e solte arquivos ou pastas na janela do [[Explorador de arquivos]]
2. Use o explorador de arquivos do seu sistema (por exemplo, Windows Explorer ou Finder no macOS) e mova seus arquivos diretamente para a pasta do cofre do Obsidian.

## Importar arquivos Markdown com o Importer

Use o [[Importador|plugin Importer]] oficial quando quiser selecionar pastas dentro de uma importação, importar um arquivo `.zip`, padronizar a formatação, mover tags inline para [[Propriedades|propriedades]] ou aplicar um modelo.

1. Abra **[[Configurações|Configurações]] → Plugins da comunidade** e [instale o Importer](obsidian://show-plugin?id=obsidian-importer).
2. Ative o plugin Importer.
3. Abra o **Importer** usando a [[Paleta de comandos|Paleta de comandos]] ou o ícone na faixa de opções.
4. Em **Formato de arquivo**, selecione **Markdown (.md, .zip)**.
5. Escolha arquivos Markdown individuais, pastas ou arquivos zip.
6. Revise as pastas detectadas, opções de saída, modelo gerado e exemplos de visualização.
7. Selecione **Importar** e aguarde a importação terminar.

Consulte [[Modelos do importador]] para personalizar o nome da nota importada, propriedades e conteúdo.
