## ទម្រង់លក្ខណៈសម្បត្តិដែលគាំទ្រ

កម្មវិធីបម្លែងធ្វើបច្ចុប្បន្នភាពឈ្មោះក្លែងក្លាយ ស្លាក និងថ្នាក់ CSS ពីទម្រង់ដែលលែងប្រើ៖

**ឈ្មោះក្លែងក្លាយ**

```yaml
# មុន

alias: My Note Title

# ក្រោយ

aliases:
  - My Note Title
```

**ស្លាក**

```yaml
# មុន

tag: project, important

# ក្រោយ

tags:
  - project
  - important
```

**ថ្នាក់ CSS**

```yaml
# មុន

cssclass: custom-style

# ក្រោយ

cssclasses:
  - custom-style
```
