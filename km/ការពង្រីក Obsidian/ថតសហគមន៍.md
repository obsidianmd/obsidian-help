# ថតសហគមន៍

រាល់កម្មវិធីជំនួយ និងរូបរាងទាំងអស់មានទំព័របញ្ជីសាធារណៈនៅលើ [ថតសហគមន៍ Obsidian](https://community.obsidian.md)។ ជ្រើសរើសកម្មវិធីជំនួយពី [[កម្មវិធីជំនួយសហគមន៍#រុករកកម្មវិធីជំនួយសហគមន៍|រុករក]] ឬរូបរាងពី [[រូបរាង#រុករករូបរាង|រុករក]] នៅក្នុង Obsidian ឬរុករក [community.obsidian.md](https://community.obsidian.md) ដោយផ្ទាល់ ដើម្បីបើកទំព័របញ្ជីរបស់វា។

ទំព័រនេះនឹងជួយអ្នកយល់ពីអ្វីដែលផ្នែកនីមួយៗធ្វើ ពីទស្សនៈរបស់អ្នកប្រើប្រាស់ Obsidian។

> [!tip]- តើអ្នកជាអ្នកអភិវឌ្ឍន៍កម្មវិធីជំនួយ ឬរូបរាង?
> សិក្សាពីរបៀបដាក់បញ្ជូន និងគ្រប់គ្រងកម្មវិធីជំនួយ និងរូបរាងរបស់អ្នកផ្ទាល់នៅក្នុង [ឯកសារថតសហគមន៍](https://docs.obsidian.md/community-directory)។

## ក្បាលទំព័រ

ក្បាលទំព័របង្ហាញរូបតំណាង និងឈ្មោះរបស់ធាតុ ជាមួយសញ្ញា **ផ្លូវការ** ប្រសិនបើវាត្រូវបានបង្កើតដោយអ្នកបង្កើតដើមរបស់កម្មវិធីជំនួយ ឬរូបរាង រួមជាមួយរូបតំណាង និងឈ្មោះរបស់អ្នកនិពន្ធ និងចំនួនទាញយកសរុបរបស់ធាតុ។

ជ្រើសរើស **បន្ថែមទៅ Obsidian** ដើម្បីបើកធាតុដោយផ្ទាល់នៅក្នុង Obsidian ហើយដំឡើងវា។

## ទិដ្ឋភាពទូទៅ

ផ្ទាំង **ទិដ្ឋភាពទូទៅ** បង្ហាញរូបថតអេក្រង់របស់ធាតុ ការពិពណ៌នាលម្អិត អត្ថបទដកស្រង់ពីឯកសារ README របស់វា និងក្រឡាចត្រង្គនៃកម្មវិធីជំនួយ ឬរូបរាងដែលពាក់ព័ន្ធក្នុងប្រភេទដូចគ្នា។

## កាតពិន្ទុ

ផ្ទាំង **កាតពិន្ទុ** បង្ហាញរង្វាស់សុខភាព និងការពិនិត្យឡើងវិញដោយស្វ័យប្រវត្តិសម្រាប់ធាតុ។

ការវាយតម្លៃសុខភាពទូទៅ ដូចជា ល្អបំផុត ត្រូវបានបែងចែកជា អនាម័យ (ថាតើមាន README, អាជ្ញាប័ណ្ណ, មគ្គុទ្ទេសក៍ការរួមចំណែក និងការពិពណ៌នាឬអត់), ការថែទាំ (សកម្មភាព commit និង release ថ្មីៗ), ការឆ្លើយតប (ចំនួន issue ដែលត្រូវបានបិទ និងចំនួនអ្នករួមចំណែកដែលសកម្មនាពេលថ្មីៗ) និងការទទួលយក (ចំនួនការដំឡើង និង star)។

ផ្នែកពិនិត្យឡើងវិញបង្ហាញលទ្ធផលនៃការស្កេនស្វ័យប្រវត្តិចុងក្រោយ ដូចជា ឆ្លង ដែលត្រូវបានដាក់ជាក្រុមទៅជាការពិនិត្យដែលឆ្លង (ឧទាហរណ៍ គ្មាន dependencies ដែលងាយរងគ្រោះដែលគេស្គាល់ គ្មានកូដដែលបិទបាំង ការបញ្ជាក់អត្តសញ្ញាណ GitHub artifact ដែលបានផ្ទៀងផ្ទាត់ និង APIs Obsidian ណាខ្លះដែលធាតុប្រើ ដូចជា Vault Read ឬ Vault Write), ការបង្ហាញ (រឿងដែលធាតុធ្វើដែលមិនមែនជាបញ្ហាចាំបាច់ ប៉ុន្តែអ្នកគួរដឹងអំពី ដូចជាការចូលប្រើ clipboard របស់អ្នក ឬការធ្វើសំណើទៅកាន់ domain ខាងក្រៅ) និងកំណត់ចំណាំផ្សេងទៀត (ដូចជាការប្រើ browser storage ជំនួសឱ្យ APIs ទិន្នន័យកម្មវិធីជំនួយរបស់ Obsidian)។

> [!info]+ ការបកស្រាយពិន្ទុទាប
> កម្មវិធីជំនួយ ឬរូបរាងដែលមានពិន្ទុសុខភាព ឬពិនិត្យឡើងវិញទាបមិនមែនចាំបាច់គ្មានសុវត្ថិភាពនោះទេ ប៉ុន្តែវាសមនឹងពិនិត្យមើលការបង្ហាញរបស់វាឱ្យកាន់តែជិតមុនពេលដំឡើង។ ចូរគិតថាវាដូចជាភ្លើងចរាចរ៖
> - 🟢 ការបង្ហាញតិចតួច ឬគ្មាន មានន័យថាហានិភ័យទាប
> - 🟡 ការបង្ហាញមួយចំនួន សមនឹងពិនិត្យមើលរឿងដូចជាការចូលប្រើ clipboard ឬបណ្ដាញ
> - 🔴 ការបង្ហាញ ឬការព្រមានជាច្រើន មានន័យថាអ្នកគួរពិនិត្យមើលអ្វីដែលធាតុធ្វើដោយប្រុងប្រយ័ត្នមុនពេលដំឡើងវា។

## បច្ចុប្បន្នភាព

ផ្ទាំង **បច្ចុប្បន្នភាព** រាយកំណែ release របស់ធាតុ ជាមួយកំណែ និងកាលបរិច្ឆេទនៃ release នីមួយៗ។ ជ្រើសរើស **មើល release ទាំងអស់នៅលើ GitHub** ដើម្បីមើលប្រវត្តិពេញលេញនៅក្នុង repository របស់ធាតុ។

## របារចំហៀង

ក្រៅពីផ្ទាំងទាំងនោះ របារចំហៀងបង្ហាញសង្ខេបសុខភាព និងការពិនិត្យឡើងវិញដែលត្រូវនឹងផ្ទាំងកាតពិន្ទុ ការពិពណ៌នាលម្អិតរបស់ធាតុ និងព័ត៌មានលម្អិតដូចជា កំណែបច្ចុប្បន្នរបស់វា ពេលណាវាត្រូវបានអាប់ដេត និងបង្កើតចុងក្រោយ ចំនួនបច្ចុប្បន្នភាព និងការទាញយក កំណែ Obsidian ដែលឆបគ្នា វេទិកាដែលគាំទ្រ និងអាជ្ញាប័ណ្ណ។ ប្រសិនបើធាតុមិនមែនជាឥតគិតថ្លៃ ផ្នែកការទូទាត់ពន្យល់ពីរបៀបដែលតម្លៃរបស់វាដំណើរការ ឧទាហរណ៍ កម្រិតបង់ប្រាក់ ឬដែនកំណត់ការប្រើប្រាស់។ ប្រសិនបើអ្នកនិពន្ធបានបន្ថែមតំណភ្ជាប់ផ្តល់ថវិកា តំណភ្ជាប់គាំទ្រនឹងបង្ហាញនៅទីនេះផងដែរ រួមជាមួយរូបតំណាង ឈ្មោះ និងតំណភ្ជាប់ទៅកាន់ profile ផ្សេងទៀតរបស់អ្នកនិពន្ធ ឬអង្គភាព។

## សំណួរដែលគេសួរញឹកញាប់

**តើអ្វីជាភាពខុសគ្នារវាង ឥតគិតថ្លៃ ការទូទាត់ស្រេចចិត្ត និង បង់ប្រាក់ នៅលើបញ្ជី?**
ឥតគិតថ្លៃ មានន័យថាគ្មានការទូទាត់ពាក់ព័ន្ធ។ ការទូទាត់ស្រេចចិត្ត មានន័យថាធាតុពឹងផ្អែកលើសេវាភាគីទីបីដែលត្រូវបង់ប្រាក់ ឬចាក់សោមុខងារជាក់លាក់ខ្លះពីក្រោយការទូទាត់ ខណៈពេលដែលនៅតែអាចប្រើប្រាស់ដោយឥតគិតថ្លៃ។ បង់ប្រាក់ មានន័យថាធាតុអាចចូលប្រើបានតែជាមួយការទូទាត់ប៉ុណ្ណោះ។

ពិនិត្យមើលផ្នែកការទូទាត់នៃបញ្ជីនៅក្នុងរបារចំហៀង សម្រាប់ព័ត៌មានលម្អិតអំពីរបៀបដែលតម្លៃរបស់ធាតុជាក់លាក់ដំណើរការ។

**ហេតុអ្វីខ្ញុំមិនអាចស្វែងរក ឬដំឡើងកម្មវិធីជំនួយ ឬរូបរាងដែលខ្ញុំបានឃើញនៅកន្លែងផ្សេង?**
អ្នកនិពន្ធអាចនឹងបានដាក់វាទៅក្នុងប័ណ្ណសារ។ ការដាក់ក្នុងប័ណ្ណសារដកធាតុចេញពីថតសហគមន៍ និងការពារការដំឡើងថ្មី។

**តើអ្វីជាភាពខុសគ្នារវាងពិន្ទុសុខភាព និងពិន្ទុពិនិត្យឡើងវិញនៅលើបញ្ជី?**
សុខភាពឆ្លុះបញ្ចាំងពីអនាម័យ និងការថែទាំបន្តរបស់ធាតុ ដូចជា commits ថ្មីៗ និងការឆ្លើយតបចំពោះ issues។ ពិនិត្យឡើងវិញឆ្លុះបញ្ចាំងពីលទ្ធផលនៃការស្កេនស្វ័យប្រវត្តិចុងក្រោយបំផុតនៃ release។
