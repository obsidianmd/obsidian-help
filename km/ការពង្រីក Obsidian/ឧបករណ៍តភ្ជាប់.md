ឧបករណ៍តភ្ជាប់អនុញ្ញាតឱ្យអ្នកផ្តល់សិទ្ធិចូលប្រើ Obsidian ដល់ agents បានយ៉ាងងាយស្រួល ខណៈពេលដែលរក្សាភាពជាម្ចាស់ទិន្នន័យរបស់អ្នកទាំងស្រុង។ ឧបករណ៍តភ្ជាប់ Obsidian មានសម្រាប់កម្មវិធីរួមទាំង Claude, ChatGPT, Antigravity, Cursor, GitHub Copilot, Grok Bot, Hermes, Kiro, Muse, OpenCode និង[ជាច្រើនទៀត](https://agentskills.io/clients)។

នេះមានន័យថា agents របស់អ្នកអាចរៀនពីរបៀប៖

- សរសេរកំណត់ចំណាំជា [[Obsidian Flavored Markdown]] ជាមួយ [[តំណភ្ជាប់ផ្ទៃក្នុង|តំណវីគី]] បង្កប់ ប្រអប់រំលេច និង[[លក្ខណៈសម្បត្តិ|លក្ខណៈសម្បត្តិ]]។
- បង្កើត និងកែសម្រួល ឯកសារ [[ការណែនាំអំពី Bases|Bases]] និង [[Canvas|Canvas]]។
- ស្វែងរក អាន និងគ្រប់គ្រងកំណត់ចំណាំនៅក្នុងកម្មវិធីដែលកំពុងដំណើរការជាមួយ [[Obsidian CLI]]។
- សមកាលកម្ម និងផ្សាយវ៉ាល់ដោយមិនចាំបាច់កម្មវិធី desktop ដោយប្រើ [[Obsidian Headless]]។

ឧបករណ៍តភ្ជាប់ Obsidian និងជំនាញបើកប្រភពកូដមាននៅ [obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills)។

## ដំឡើង

អ្នកអាចរកឧបករណ៍តភ្ជាប់ Obsidian ដោយស្វែងរកក្នុង marketplace ឬថតកម្មវិធីជំនួយនៅក្នុងកម្មវិធី agent របស់អ្នក។ អ្នកក៏អាចផ្ញើតំណទៅទំព័រនេះទៅ agent របស់អ្នកផងដែរ។

### Claude

បន្ថែម [Obsidian](https://claude.ai/customize/plugins/id/a38fa062-ebd3-48e0-9a0a-1875a6e94ad5%40anthropic-plugin-directory) ពីថត Claude plugin ផ្លូវការ។

សម្រាប់ Claude Code CLI សូមប្រើ៖

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

ដើម្បីទទួលបានជំនាញថ្មីនៅពេលក្រោយ សូមដំណើរការ `claude plugin update obsidian@obsidian-skills`។

### ChatGPT

បន្ថែម [Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096) ពីថត ChatGPT plugin។ កម្មវិធីជំនួយនេះដំណើរការនៅក្នុង ChatGPT, Codex និង Dots។

### Antigravity

នៅក្នុង Antigravity CLI សូមដំណើរការ៖

```shell
agy plugin install https://github.com/obsidianmd/obsidian-skills
```

### Grok Bot

បើក [Obsidian for Grok Bot](https://x.ai/bot/plugin/88871845) ហើយជ្រើសរើស **Add to Grok Bot**។

### Muse

សុំឱ្យ Muse ដំឡើងជំនាញពី https://github.com/obsidianmd/obsidian-skills។

Muse ដំណើរការនៅក្នុង cloud របស់ Meta ដូច្នេះជំនាញ `obsidian-cli` មិនដំណើរការនៅទីនោះទេ។ ប្រសិនបើអ្នកប្រើ Obsidian Headless នៅក្នុង Muse អ្នកចូល និងសមកាលកម្មវ៉ាល់របស់អ្នកនៅក្នុង cloud របស់ Meta។

### Cursor

ដំឡើង [Obsidian](https://cursor.com/marketplace/obsidian) ពី Cursor Marketplace។

### Hermes Agent

ដំឡើង [Obsidian](https://hermes-agent.nousresearch.com/marketplace/obsidian) ពី Hermes Marketplace ឬដំណើរការ៖

```shell
hermes plugins install obsidian
```

### Kiro

```shell
kiro-cli powers install obsidian
```

### GitHub Copilot, OpenCode និង agents ផ្សេងទៀត

ដំឡើងជាមួយ [npx skills](https://github.com/vercel-labs/skills) ដែលនឹងសួរថាត្រូវដំឡើងទៅក្នុង agents ណា៖

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

ដើម្បីដំឡើងដោយដៃ សូមចម្លងថតនៅក្នុង `plugins/obsidian/skills/` ទៅក្នុងថតជំនាញរបស់ agent របស់អ្នក ឧ. `~/.copilot/skills/` សម្រាប់ GitHub Copilot។

## តម្រូវការ

ជំនាញ `obsidian-cli` ត្រូវការកម្មវិធី Obsidian desktop កំពុងដំណើរការជាមួយ [[Obsidian CLI#Install Obsidian CLI|Obsidian CLI បានបើក]] និង agent ដែលអាចដំណើរការពាក្យបញ្ជានៅលើកុំព្យូទ័ររបស់អ្នក។

ជំនាញ Markdown, Bases និង Canvas ពណ៌នាតែអំពីទម្រង់ឯកសារប៉ុណ្ណោះ ដូច្នេះវាដំណើរការនៅក្នុង agent ណាមួយដែលអាចអាន និងសរសេរឯកសារនៅក្នុងវ៉ាល់របស់អ្នក។

Defuddle, Knap និង Obsidian Headless គឺជាឧបករណ៍ដាច់ដោយឡែកដែលមិនបានភ្ជាប់មកជាមួយជំនាញទេ។ នៅពេលខ្វះមួយ ជំនាញនឹងសួរមុនពេលដំឡើងវាពី npm។

## ឯកជនភាព

ឧបករណ៍តភ្ជាប់ Obsidian មិនផ្ញើអ្វីដោយខ្លួនឯងទេ។ នៅពេល agent ប្រើវា កំណត់ចំណាំដែលវាអានក្លាយជាផ្នែកនៃការសន្ទនា ហើយត្រូវបានដំណើរការដោយម៉ូដែល AI ដែលអ្នកប្រើ។ សូមពិនិត្យគោលការណ៍ឯកជនភាពរបស់ agent របស់អ្នកមុនពេលអ្នកចង្អុលវាទៅវ៉ាល់ដែលមានកំណត់ចំណាំរសើប។
