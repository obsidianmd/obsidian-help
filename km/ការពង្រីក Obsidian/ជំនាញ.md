Obsidian Skills គឺជាសេចក្ដីណែនាំដែលបង្រៀន AI agents អំពីរបៀបធ្វើការជាមួយ Obsidian។ ពួកវាដើរតាមទម្រង់ [Agent Skills](https://agentskills.io/specification) ដែលបើកចំហ ដូច្នេះពួកវាដំណើរការជាមួយ agent ណាមួយដែលគាំទ្រជំនាញ រួមទាំង Claude Code, Claude, ChatGPT, Antigravity, Cursor, GitHub Copilot, Grok Bot, Hermes Agent, OpenCode និង[ជាច្រើនទៀត](https://agentskills.io/clients)។

ជាមួយ Obsidian Skills agent អាច៖

- សរសេរកំណត់ចំណាំជា [[Obsidian Flavored Markdown]] ជាមួយ [[តំណភ្ជាប់ផ្ទៃក្នុង|តំណវីគី]] បង្កប់ ប្រអប់រំលេច និង[[លក្ខណៈសម្បត្តិ|លក្ខណៈសម្បត្តិ]]។
- បង្កើត និងកែសម្រួលឯកសារ [[ការណែនាំអំពី Bases|Bases]] និង [[Canvas|Canvas]]។
- ស្វែងរក អាន និងគ្រប់គ្រងកំណត់ចំណាំក្នុងកម្មវិធីដែលកំពុងដំណើរការជាមួយ [[Obsidian CLI]]។
- សមកាលកម្ម និងផ្សាយវ៉ាល់ដោយមិនចាំបាច់កម្មវិធីផ្ទៃតុដោយប្រើ [[Obsidian Headless]]។

ជំនាញទាំងនេះជាបើកប្រភពកូដនៅ [obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills)។

## ដំឡើង

Obsidian គឺជាកម្មវិធីជំនួយផ្លូវការសម្រាប់ Claude, ChatGPT, Dots, Cursor, Grok Bot និង Hermes។ Agents ភាគច្រើនផ្សេងទៀតអាចដំឡើងជំនាញពី GitHub។

### Claude

បន្ថែម [Obsidian](https://claude.ai/customize/plugins/id/a38fa062-ebd3-48e0-9a0a-1875a6e94ad5%40anthropic-plugin-directory) ពីថតកម្មវិធីជំនួយផ្លូវការ Claude។

សម្រាប់ Claude Code CLI សូមប្រើ៖

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

ដើម្បីទទួលបានជំនាញថ្មីនៅពេលក្រោយ សូមដំណើរការ `claude plugin update obsidian@obsidian-skills`។

### ChatGPT

បន្ថែម [Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096) ពីថតកម្មវិធីជំនួយ ChatGPT។ កម្មវិធីជំនួយនេះដំណើរការក្នុង ChatGPT, Codex និង Dots។

### Antigravity

នៅក្នុង Antigravity CLI សូមដំណើរការ៖

```shell
agy plugin install https://github.com/obsidianmd/obsidian-skills
```

### Grok Bot

បើក [Obsidian for Grok Bot](https://x.ai/bot/plugin/88871845) ហើយជ្រើសរើស **Add to Grok Bot**។

### Cursor

ដំឡើង [Obsidian](https://cursor.com/marketplace/obsidian) ពី Cursor Marketplace។

### Hermes Agent

```shell
hermes plugins install obsidian
```

### GitHub Copilot, OpenCode និង agents ផ្សេងទៀត

ដំឡើងជាមួយ [npx skills](https://github.com/vercel-labs/skills) ដែលសួរថាត្រូវដំឡើងទៅក្នុង agents ណាមួយ៖

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

ដើម្បីដំឡើងដោយដៃ ចម្លងថតក្នុង `plugins/obsidian/skills/` ទៅក្នុងថតជំនាញរបស់ agent របស់អ្នក ឧ. `~/.copilot/skills/` សម្រាប់ GitHub Copilot។

## តម្រូវការ

ជំនាញ `obsidian-cli` ត្រូវការកម្មវិធីផ្ទៃតុ Obsidian ដែលកំពុងដំណើរការជាមួយ [[Obsidian CLI#ដំឡើង Obsidian CLI|Obsidian CLI ត្រូវបានបើក]] និង agent ដែលអាចដំណើរការពាក្យបញ្ជានៅលើកុំព្យូទ័ររបស់អ្នក។

ជំនាញ Markdown, Bases និង Canvas ពិពណ៌នាតែទម្រង់ឯកសារប៉ុណ្ណោះ ដូច្នេះពួកវាដំណើរការក្នុង agent ណាមួយដែលអាចអាន និងសរសេរឯកសារក្នុងវ៉ាល់របស់អ្នក។

Defuddle, Knap និង Obsidian Headless គឺជាឧបករណ៍ដាច់ដោយឡែកដែលមិនត្រូវបានភ្ជាប់ជាមួយជំនាញ។ នៅពេលដែលមួយណាបាត់ ជំនាញនោះសួរមុនពេលដំឡើងវាពី npm។

## ឯកជនភាព

Obsidian Skills មិនផ្ញើអ្វីដោយខ្លួនវាទេ។ នៅពេលដែល agent ប្រើពួកវា កំណត់ចំណាំដែលវាអានក្លាយជាផ្នែកនៃការសន្ទនា ហើយត្រូវបានដំណើរការដោយម៉ូដែល AI ដែលអ្នកប្រើ។ សូមពិនិត្យគោលការណ៍ឯកជនភាពរបស់ agent របស់អ្នកមុនពេលអ្នកចង្អុលវាទៅវ៉ាល់ដែលមានកំណត់ចំណាំរសើប។
