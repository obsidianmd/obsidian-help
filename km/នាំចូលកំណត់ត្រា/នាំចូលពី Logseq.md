Obsidian អនុញ្ញាតឱ្យអ្នកផ្ទេរកំណត់ត្រាពីក្រាហ្វ Logseq ដែលមានមូលដ្ឋានលើឯកសារ (ឥឡូវនេះហៅថា "Logseq OG") ដោយប្រើ[[កម្មវិធីនាំចូល|កម្មវិធីជំនួយ Importer]] ផ្លូវការ។ Importer អានឯកសារ Markdown របស់ Logseq ដោយផ្ទាល់ និងបម្លែងទម្រង់ជាក់លាក់របស់ Logseq ទៅជាឯកសារដែលអ្នកអាចប្រើក្រៅបណ្តាញជាមួយ Obsidian និងកម្មវិធីផ្សេងៗ។

## មុនពេលអ្នកចាប់ផ្តើម

- បម្រុងទុកក្រាហ្វ Logseq និង Vault Obsidian របស់អ្នក។
- កំណត់ទីតាំងថតឫសរបស់ក្រាហ្វ Logseq។ ជាធម្មតាវាមានថតដែលមានឈ្មោះ `pages`, `journals`, `assets`, និង `logseq`។
- ត្រូវប្រាកដថាអ្នកកំពុងប្រើក្រាហ្វ Logseq ដែលមានមូលដ្ឋានលើឯកសារ។ ក្រាហ្វមូលដ្ឋានទិន្នន័យ Logseq មិនទាន់ត្រូវបានគាំទ្រនៅឡើយ។

## នាំចូលក្រាហ្វ Logseq របស់អ្នក

អ្នកត្រូវការកម្មវិធីជំនួយ [[កម្មវិធីនាំចូល|Importer]] ផ្លូវការរបស់ Obsidian ដែលអ្នកអាច[ដំឡើងនៅទីនេះ](obsidian://show-plugin?id=obsidian-importer)។

1. បើក **[[ការកំណត់]] → Community plugins** ហើយ[ដំឡើង Importer](obsidian://show-plugin?id=obsidian-importer)។
2. បើកដំណើរការកម្មវិធីជំនួយ Importer។
3. បើក **Importer** ដោយប្រើ[[ក្ដារលាយពាក្យបញ្ជា]] ឬរូបតំណាង[[រីបិន]]។
4. នៅក្រោម **File format** សូមជ្រើសរើស **Logseq**។
5. នៅក្រោម **Choose folders** សូមជ្រើសរើសថតឫសរបស់ក្រាហ្វ។ ជ្រើសរើសថតដែលមាន `pages` និង `journals` មិនមែនថតណាមួយក្នុងចំណោមថតទាំងនោះដោយឡែកទេ។
6. ពិនិត្យមើលថតដែលត្រូវបានរកឃើញ ហើយដកចេញថតណាដែលអ្នកមិនចង់នាំចូល។
7. ជ្រើសរើសថតលទ្ធផល និងកន្លែងដែលឯកសារភ្ជាប់ដែលនាំចូលគួរត្រូវបានរក្សាទុក។
8. ពិនិត្យមើលជម្រើសនាំចូល និងមើលជាមុននូវឧទាហរណ៍នៃកំណត់ត្រាដែលបានបម្លែង។
9. ជ្រើសរើស **Import** ហើយរង់ចាំដល់ការនាំចូលបញ្ចប់។

## ដែនកំណត់

- Whiteboards មិនត្រូវបាននាំចូលទេ។
- Queries ត្រូវបានរក្សាទុកជា code blocks ប្រសិនបើអ្នកជ្រើសរើសរក្សាវា។
- Dynamic Logseq template macros នៅតែជាអត្ថបទត្រង់។
- ការកំណត់កាលវិភាគ flashcard របស់ Logseq, ការអធិប្បាយ PDF និងទិន្នន័យជាក់លាក់ផ្សេងទៀតរបស់កម្មវិធីមិនត្រូវបានផ្ទេរទេ។

## ការកំណត់

Importer បម្លែងអនុសញ្ញាទូទៅរបស់ Logseq រួមទាំង:

- លក្ខណៈសម្បត្តិទំព័រទៅជា [[លក្ខណៈសម្បត្តិ]] របស់ Obsidian។
- ឈ្មោះក្លែងក្លាយទំព័រ ស្លាក namespaces និងតំណភ្ជាប់។
- ស្ថានភាពការងារទៅជាសញ្ញាសម្គាល់បញ្ជីប្រអប់ធីក ជាមួយអាទិភាព និងកាលបរិច្ឆេទដែលត្រូវបានរក្សាទុកជាអត្ថបទអានបាន។
- Block IDs, block references និង block embeds ទៅជាតំណភ្ជាប់ និងការបង្កប់របស់ Obsidian។
- ឈ្មោះឯកសារ journal និងតំណភ្ជាប់កាលបរិច្ឆេទ។
- ការរំលេច បញ្ជីលេខ Org blocks ការបង្កប់មេឌៀ និងឯកសារដែលភ្ជាប់ពីថត `assets` របស់ក្រាហ្វ។

### Journals

តាមលំនាំដើម **Use daily notes settings** ត្រូវបានបើក។ Journals ដែលនាំចូលប្រើថត និងទម្រង់កាលបរិច្ឆេទដែលកំណត់រចនាសម្ព័ន្ធដោយកម្មវិធីជំនួយចម្បង [[កំណត់ចំណាំប្រចាំថ្ងៃ]]។ នេះអាចដាក់ journals នៅក្រៅថតលទ្ធផលដែលបានជ្រើសរើសក្នុង Importer។

ប្រសិនបើអ្នកបិទជម្រើសនេះ journals ត្រូវបានសរសេរទៅថត `Journals` នៅក្នុងថតលទ្ធផលដែលបានជ្រើសរើស ហើយប្រើទម្រង់ឈ្មោះកំណត់ត្រា `YYYY-MM-DD`។

### បន្សំគ្រោងឱ្យរាប

Logseq ប្រើចំណុចគ្រាប់ដែលដាក់ក្នុងគ្នាជារចនាសម្ព័ន្ធរបស់ទំព័រ។ តាមលំនាំដើម Importer រក្សារចនាសម្ព័ន្ធគ្រោងនេះ។ បើក **Flatten outlines** ដើម្បីបម្លែងប្លុកគ្រោងទៅជាការបញ្ចូលគ្នានៃកថាខណ្ឌ ចំណងជើង និងបញ្ជីធម្មតា។ កិច្ចការ និងក្រុមធាតុបែបបញ្ជីនៅតែជាធាតុបញ្ជី ប៉ុន្តែការបម្លែងនេះជា heuristic។ ពិនិត្យមើលឧទាហរណ៍ជាច្រើនក្នុងការមើលជាមុន មុនពេលនាំចូលក្រាហ្វធំ។

### រក្សាទិន្នន័យដែលមិនឆបគ្នា

Logseq queries, flashcards និងធាតុតាមដានពេលវេលាមិនមានសមភាគីផ្ទាល់ក្នុង Obsidian ទេ។ ជម្រើសនាំចូលអនុញ្ញាតឱ្យអ្នកជ្រើសរើសថាតើត្រូវរក្សាមាតិកាប្រភេទនីមួយៗឬទេ។ នៅពេលរក្សាទុក វានៅតែជាអត្ថបទធម្មតា។

- **Keep queries** រក្សា queries ជា fenced code blocks ឬ inline code។
- **Keep flashcards** រក្សាសញ្ញាសម្គាល់ `#card` និង cloze wrappers ជាអត្ថបទធម្មតា។
- **Keep time tracking** រក្សាធាតុ `LOGBOOK` និង `CLOCK` ជាអត្ថបទធម្មតា។

## ការដោះស្រាយបញ្ហា

ប្រសិនបើ Importer រកមិនឃើញកំណត់ត្រាណាមួយ សូមប្រាកដថាអ្នកបានជ្រើសរើសថតឫសរបស់ក្រាហ្វ ហើយថតទំព័រ ឬ journal ដែលបានកំណត់រចនាសម្ព័ន្ធមានឯកសារ Markdown។

ប្រសិនបើឯកសារភ្ជាប់ត្រូវបានរាយការណ៍ថាបាត់ សូមបញ្ជាក់ថាឯកសារដែលបានយោងនៅតែមាននៅក្នុងថត `assets` របស់ក្រាហ្វ។

សម្រាប់បញ្ហាផ្សេងទៀត សូមស្វែងរកនៅ [Importer issue tracker](https://github.com/obsidianmd/obsidian-importer/issues) ឬដាក់របាយការណ៍កំហុសជាមួយក្រាហ្វឧទាហរណ៍តូចមួយ។
