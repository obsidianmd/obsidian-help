Obsidian ប្រើឯកសារ Markdown `.md` ជាទម្រង់ចម្បងសម្រាប់កំណត់ត្រា។ នេះធ្វើឱ្យវាងាយស្រួលក្នុងការនាំចូលឯកសារ Markdown ទៅក្នុង Obsidian។ កម្មវិធីជាច្រើនអាចកែសម្រួលឯកសារ Markdown ឬនាំចេញទៅជាទម្រង់នេះ។

មានវិធីជាច្រើនដើម្បីបន្ថែមឯកសារ Markdown ទៅក្នុង vault Obsidian របស់អ្នក៖

1. អូស និង ទម្លាក់ឯកសារ ឬថតទៅក្នុងបង្អួច [[កម្មវិធីរុករកឯកសារ]]
2. ប្រើកម្មវិធីរុករកឯកសារប្រព័ន្ធរបស់អ្នក (ឧ. Windows Explorer ឬ Finder នៅលើ macOS) ហើយផ្លាស់ទីឯកសាររបស់អ្នកដោយផ្ទាល់ទៅក្នុងថត vault Obsidian។

## នាំចូលឯកសារ Markdown ជាមួយ Importer

ប្រើ [[កម្មវិធីនាំចូល|កម្មវិធីជំនួយ Importer]] ផ្លូវការ នៅពេលអ្នកចង់ជ្រើសរើសថតនៅក្នុងការនាំចូល នាំចូលឯកសារ `.zip` កំណត់ទម្រង់ឱ្យស្តង់ដារ ផ្លាស់ទីស្លាកក្នុងបន្ទាត់ទៅ [[លក្ខណៈសម្បត្តិ|លក្ខណៈសម្បត្តិ]] ឬអនុវត្តគំរូ។

1. បើក **[[ការកំណត់|ការកំណត់]] → Community plugins** ហើយ [ដំឡើង Importer](obsidian://show-plugin?id=obsidian-importer)។
2. បើកកម្មវិធីជំនួយ Importer។
3. បើក **Importer** ដោយប្រើ [[ក្ដារលាយពាក្យបញ្ជា]] ឬរូបតំណាងនៅលើខ្សែបូ។
4. នៅក្រោម **File format** ជ្រើសរើស **Markdown (.md, .zip)**។
5. ជ្រើសរើសឯកសារ Markdown ទោល ថត ឬឯកសារ zip។
6. ពិនិត្យមើលថតដែលបានរកឃើញ ជម្រើសលទ្ធផល គំរូដែលបានបង្កើត និងឧទាហរណ៍មើលជាមុន។
7. ជ្រើសរើស **Import** ហើយរង់ចាំឱ្យការនាំចូលបញ្ចប់។

សូមមើល [[ពុម្ពកម្មវិធីនាំចូល]] ដើម្បីប្ដូរតាមបំណងឈ្មោះកំណត់ត្រាដែលបាននាំចូល លក្ខណៈសម្បត្តិ និងមាតិកា។
