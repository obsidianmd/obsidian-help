[[កម្មវិធីនាំចូល]] អនុញ្ញាតឱ្យអ្នកកំណត់គំរូដែលគ្រប់គ្រងរបៀបដែលកំណត់ត្រារបស់អ្នកត្រូវបាននាំចូលពីកម្មវិធីផ្សេងទៀត។ មានន័យថាអ្នកអាចកែប្រែចំណងជើង លក្ខណៈសម្បត្តិ និងមាតិកានៃកំណត់ត្រាដែលអ្នកនាំចូល។

## កែសម្រួលគំរូនាំចូល

ជ្រើសរើស **កែសម្រួល** នៅខាងលើការមើលជាមុន ដើម្បីកែសម្រួលគំរូលំនាំដើម។ អ្នកអាចកែសម្រួល៖

- ឈ្មោះកំណត់ត្រាដែលបង្ហាញជាចំណងជើងក្នុងបន្ទាត់។
- លក្ខណៈសម្បត្តិនៅដើមកំណត់ត្រា។
- មាតិកា Markdown នៃកំណត់ត្រា។

ជ្រើសរើស **រក្សាទុក** ដើម្បីត្រឡប់ទៅការមើលជាមុន។ កម្មវិធីនាំចូលចងចាំគំរូក្នុងបន្ទាត់ដែលបានកែសម្រួលសម្រាប់ការនាំចូលនាពេលអនាគតដែលប្រើទម្រង់ដូចគ្នា។

ជម្រើសផ្សេងទៀតអ្នកអាចផ្ទុកគំរូពីឯកសារ Markdown នៅក្នុង vault បច្ចុប្បន្ន។

## មើលលទ្ធផលជាមុន

ការមើលជាមុនបង្ហាញគំរូរហូតដល់ដប់ពីទិន្នន័យដែលអ្នកបានជ្រើសរើស។ ប្រើប៊ូតុងព្រួញដើម្បីផ្លាស់ទីរវាងគំរូ។ ការផ្លាស់ប្តូរការកំណត់នាំចូល និងគំរូនឹងធ្វើបច្ចុប្បន្នភាពការមើលជាមុនមុនពេលអ្វីមួយត្រូវបានបន្ថែមទៅ vault របស់អ្នក។

ឯកសារភ្ជាប់មួយចំនួន ធាតុពីចម្ងាយ និងឯកសារយោងឆ្លងកំណត់ត្រាមិនអាចដោះស្រាយបានពេញលេញរហូតដល់ការនាំចូលដំណើរការ។ ក្នុងករណីទាំងនោះ ការមើលជាមុនអាចរក្សាតំណភ្ជាប់ប្រភព ឬបង្ហាញកន្លែងកាន់កន្លែង។

## វាក្យសម្ពន្ធគំរូ

គំរូកម្មវិធីនាំចូលប្រើវាក្យសម្ពន្ធដែលមានអថេរ [[តម្រង]] និង [[តក្កវិទ្យា]]។ វាប្រើវាក្យសម្ពន្ធ [Knap](https://github.com/obsidianmd/knap) ដូចគ្នាដែល [[ការណែនាំអំពី Obsidian Web Clipper|Web Clipper]] ប្រើ។

បញ្ចូលអថេរដោយប្រើវង់ក្រចកពីរ ដូចជា `{{title}}`, `{{content}}`, ឬ `{{date}}`។ អថេរអាចប្រើនៅក្នុងឈ្មោះកំណត់ត្រា លក្ខណៈសម្បត្តិ និងមាតិកា។

អ្នកអាចកែប្រែអថេរដោយប្រើ [[តម្រង]]។ ឧទាហរណ៍ ដើម្បីផ្លាស់ប្តូរទម្រង់កាលបរិច្ឆេទដោយប្រើ `{{date|date:"YYYY-MM-DD"}}`។ ប្រើ [[តក្កវិទ្យា]] សម្រាប់លក្ខខណ្ឌកម្រិតខ្ពស់ រង្វិលជុំ និងការកំណត់អថេរ។

## អថេរ

អថេរខាងក្រោមអាចប្រើបាននៅក្នុងគំរូកម្មវិធីនាំចូលណាមួយ៖

| អថេរ         | ការពិពណ៌នា                                                                                         |
| ---------------- | --------------------------------------------------------------------------------------------------- |
| `{{body}}`       | តួអត្ថបទ Markdown ដោយគ្មានលក្ខណៈសម្បត្តិ (គ្មាន frontmatter)។                                                  |
| `{{content}}`    | Markdown ពេញលេញមុនពេលគំរូដែលបានជ្រើសរើសត្រូវបានអនុវត្ត។                                          |
| `{{ctime}}`      | ពេលវេលាបង្កើតប្រភពជា timestamp ISO 8601; ទទេនៅពេលមិនមាន។                              |
| `{{date}}`       | កាលបរិច្ឆេទ និងពេលវេលាបច្ចុប្បន្ននៅពេលគំរូត្រូវបានបង្ហាញ ជា timestamp ISO 8601។                      |
| `{{importer}}`   | លេខសម្គាល់កម្មវិធីនាំចូល ដូចជា `keep`, `html`, ឬ `notion-api`។                                               |
| `{{folder}}`     | ថតមេដែលទាក់ទងនឹង vault ចុងក្រោយ។ ទទេនៅពេលកំណត់ត្រាស្ថិតនៅក្នុងឫស vault។                       |
| `{{mtime}}`      | ពេលវេលាកែប្រែប្រភពជា timestamp ISO 8601; ទទេនៅពេលមិនមាន។                          |
| `{{noteName}}`   | ឈ្មោះកំណត់ត្រាដែលបានដោះស្រាយចុងក្រោយ បន្ទាប់ពីដកតួអក្សរមិនត្រឹមត្រូវ និងបន្ថែមបច្ចេយវិសេសណ៍សម្រាប់ការចម្លងទ្វេ។ |
| `{{path}}`       | ផ្លូវដែលទាក់ទងនឹង vault ចុងក្រោយ រួមទាំងផ្នែកបន្ថែម `.md`។                                           |
| `{{properties}}` | វត្ថុដែលមានលក្ខណៈសម្បត្តិ frontmatter។                                                       |
| `{{source}}`     | វត្ថុដែលមានលក្ខណៈសម្បត្តិដែលបានបង្កើត និងតម្លៃជាក់លាក់តាមប្រភព។                                  |
| `{{sourceId}}`   | កម្មវិធីកំណត់អត្តសញ្ញាណប្រភពដែលមានស្ថិរភាពនៅពេលកម្មវិធីនាំចូលផ្តល់; បើមិនដូច្នោះទេ ទទេ។                           |
| `{{time}}`       | ឈ្មោះក្លែងក្លាយសម្រាប់ `{{date}}`។                                                                               |
| `{{title}}`      | ចំណងជើងកំណត់ត្រាដើមមុនការសម្អាត និងការដកចម្លងទ្វេ។                                          |

## តម្លៃប្រភពសម្រាប់លក្ខណៈសម្បត្តិ

សម្រាប់ទម្រង់នាំចូលដែលគាំទ្រ [[លក្ខណៈសម្បត្តិ]] តម្លៃប្រភពក៏មានជាអថេរកម្រិតកំពូលសម្រាប់ភាពងាយស្រួលដែរ។

ប្រសិនបើតម្លៃប្រភពមានឈ្មោះដូចគ្នាជាមួយអថេររួម សូមចូលប្រើវាតាមរយៈ `{{source}}`។ ឧទាហរណ៍ ប្រសិនបើប្រភពនាំចូលរបស់អ្នកមានលក្ខណៈសម្បត្តិឈ្មោះ `content` អាចចូលប្រើបានជា `{{source.content}}` ខណៈពេលដែល `{{content}}` នៅតែជាអថេរលំនាំដើមរបស់កម្មវិធីនាំចូល។

ប្រើសញ្ញាវង់ក្រចកនៅពេលឈ្មោះវាលមានចន្លោះ សញ្ញាវណ្ណយុត្តិ ឬតួអក្សរពិសេសផ្សេងទៀត៖

```twig
{{source["Project: status"]}}
```

## ឧទាហរណ៍គំរូ

នេះជាឧទាហរណ៍នៃគំរូដែលប្រើអថេរ និង [[តម្រង]]៖

```twig
---
created: {{ctime | date:"YYYY-MM-DD"}}
modified: {{mtime | date:"YYYY-MM-DD"}}
source: {{importer}}
---
# {{title}}

{{body}}
```

អ្នកអាចបន្ថែមទិន្នន័យទៅក្នុងកំណត់ត្រាដោយមានលក្ខខណ្ឌដោយប្រើ [[តក្កវិទ្យា]]៖

```twig
{% if tags %}
## ស្លាក
{% for tag in tags %}
- {{tag}}
{% endfor %}
{% endif %}
```
