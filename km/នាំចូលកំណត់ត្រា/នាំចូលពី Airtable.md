Obsidian អនុញ្ញាតឱ្យអ្នកផ្ទេរទិន្នន័យពី Airtable ដោយប្រើ [[កម្មវិធីនាំចូល|កម្មវិធីជំនួយ Importer]]។ វានឹងបម្លែង Airtable bases របស់អ្នកទៅជាឯកសារ Markdown ដែលមានភាពប្រកាន់មាំដែលអ្នកអាចប្រើក្រៅបណ្តាញជាមួយ Obsidian និងកម្មវិធីជាច្រើនផ្សេងទៀត។

តារាងនីមួយៗក្លាយជាថតកំណត់ត្រាដែលមានកំណត់ត org នីមួយៗក្នុងមួយកំណត់ទិន្នន័យ រួមទាំងឯកសារ [[ការណែនាំអំពី Bases|Base]] ដែលបង្កើតតារាង និងទិដ្ឋភាពរបស់វាឡើងវិញ។ ដោយសារវាប្រើ Airtable API ការនាំចូលត្រូវការ personal access token និងការតភ្ជាប់អ៊ីនធឺណិត។

## បង្កើត Airtable personal access token

ដើម្បីចូលប្រើទិន្នន័យ Airtable របស់អ្នកតាមរយៈ API អ្នកត្រូវការ personal access token។ ជំហាននេះត្រូវចំណាយពេលប្រហែល ១ នាទីដើម្បីបញ្ចប់។

Token គឺជាខ្សែអក្សរវែងនៃលេខ និងអក្សរដែលជាធម្មតាចាប់ផ្តើមដោយ `pat...` ដែលនឹងអនុញ្ញាតឱ្យអ្នកទាញយកទិន្នន័យរបស់អ្នកពី Airtable។

1. ចូលគណនី Airtable ហើយទៅកាន់ទំព័រ [Personal access tokens](https://airtable.com/create/tokens) នៅក្នុងការកំណត់គណនីរបស់អ្នក។
2. ជ្រើសរើស **Create new token**។
3. ដាក់ឈ្មោះ token របស់អ្នក ឧទាហរណ៍ "Obsidian"។ អាចប្រើឈ្មោះណាមួយបាន។
4. នៅក្រោម **Scopes** បន្ថែម `data.records:read` និង `schema.bases:read`។
5. នៅក្រោម **Access** បន្ថែម bases ដែលអ្នកចង់នាំចូល ឬជ្រើសរើស bases ទាំងអស់ក្នុង workspace មួយ។
6. ជ្រើសរើស **Create token** បន្ទាប់មក **Copy** token។
7. រក្សាទុក token នៅកន្លែងមានសុវត្ថិភាពដូចជាកម្មវិធីគ្រប់គ្រងពាក្យសម្ងាត់របស់អ្នក។

Airtable បង្ហាញ token តែម្តងប៉ុណ្ណោះ។ ប្រសិនបើអ្នកបាត់វា សូមបង្កើតថ្មីមួយទៀត។

## នាំចូលទិន្នន័យ Airtable របស់អ្នក

អ្នកនឹងត្រូវការកម្មវិធីជំនួយ [[កម្មវិធីនាំចូល|Importer]] ផ្លូវការរបស់ Obsidian ដែលអ្នកអាច [ដំឡើងនៅទីនេះ](obsidian://show-plugin?id=obsidian-importer)។

1. បើក **[[ការកំណត់]]**។
2. ទៅកាន់ **កម្មវិធីជំនួយសហគមន៍** ហើយ [ដំឡើង Importer](obsidian://show-plugin?id=obsidian-importer)។
3. បើកដំណើរការកម្មវិធីជំនួយ Importer។
4. បើកកម្មវិធីជំនួយ **Importer** ដោយប្រើក្ដារលាយពាក្យបញ្ជា ឬរូបតំណាងរីបិន។
5. នៅក្រោម **File format** ជ្រើសរើស **Airtable**។
6. នៅក្រោម **Airtable Personal Access Token** ចុច **Link...** ដើម្បីបន្ថែម secret ថ្មី។ សម្រាប់ **ID** ដាក់ឈ្មោះដូចជា `airtable` ហើយសម្រាប់ **Secret** បិទភ្ជាប់ personal access token របស់អ្នក។
7. ចុច **Load** ដើម្បីរុករក bases របស់អ្នក បន្ទាប់មកជ្រើសរើសតារាងដែលអ្នកចង់នាំចូល។
8. ពិនិត្យ និងកែសម្រួលជម្រើសនាំចូល។
9. ជ្រើសរើស **Import** ដើម្បីកំណត់របៀបដែលវាលរបស់អ្នកនឹងត្រូវបម្លែងទៅជាកំណត់ត្រាជាមួយ [[លក្ខណៈសម្បត្តិ]]។
10. ចុច **Continue** ហើយរង់ចាំរហូតដល់ការនាំចូលបានបញ្ចប់។
11. រួចរាល់ហើយ!
