Obsidian používá soubory Markdown `.md` jako primární formát pro poznámky. Díky tomu je snadné importovat soubory Markdown do Obsidian. Mnoho aplikací umí upravovat soubory Markdown nebo exportovat do tohoto formátu.

Existuje několik způsobů, jak přidat soubory Markdown do vašeho trezoru Obsidian:

1. Přetáhněte soubory nebo složky do okna [[Průzkumník souborů|Průzkumníka souborů]]
2. Použijte systémový správce souborů (např. Průzkumník Windows nebo Finder na macOS) a přesuňte soubory přímo do složky trezoru Obsidian.

## Import souborů Markdown pomocí Importeru

Použijte oficiální [[Importér|plugin Importer]], když chcete vybrat složky v rámci importu, importovat archiv `.zip`, standardizovat formátování, přesunout inline štítky do [[Vlastnosti|vlastností]] nebo použít šablonu.

1. Otevřete **[[Nastavení|Nastavení]] → Pluginy třetích stran** a [nainstalujte Importer](obsidian://show-plugin?id=obsidian-importer).
2. Zapněte plugin Importer.
3. Otevřete **Importer** pomocí [[Paleta příkazů|palety příkazů]] nebo ikony v postranním panelu nástrojů.
4. V části **File format** vyberte **Markdown (.md, .zip)**.
5. Vyberte jednotlivé soubory Markdown, složky nebo zip archivy.
6. Zkontrolujte zjištěné složky, možnosti výstupu, vygenerovanou šablonu a náhledy příkladů.
7. Vyberte **Import** a počkejte na dokončení importu.

Viz [[Šablony importéru|Šablony Importeru]] pro přizpůsobení názvu importované poznámky, vlastností a obsahu.
