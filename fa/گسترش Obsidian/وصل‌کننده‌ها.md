وصل‌کننده‌ها به شما امکان می‌دهند Obsidian را به هر عامل هوش مصنوعی از جمله Claude، ChatGPT، Antigravity، Cursor، GitHub Copilot، Grok Bot، Hermes، Kiro، Muse، OpenCode و [بسیاری دیگر](https://agentskills.io/clients) متصل کنید.

این بدان معناست که عامل‌های شما می‌توانند یاد بگیرند چگونه:

- یادداشت‌ها را در [[Markdown به سبک Obsidian]] بنویسند، با [[پیوندهای داخلی|پیوندهای ویکی]]، جاسازی‌ها، کال‌اوت‌ها و [[ویژگی‌ها|ویژگی‌ها]].
- فایل‌های [[معرفی پایگاه‌ها|پایگاه‌ها]] و [[Canvas|Canvas]] را بسازند و ویرایش کنند.
- یادداشت‌ها را در اپلیکیشن در حال اجرا جستجو، بخوانند و مدیریت کنند با [[Obsidian CLI]].
- گاوصندوق‌ها را بدون اپلیکیشن دسکتاپ با [[Obsidian بدون رابط کاربری]] همگام‌سازی و نشر دهند.

مهارت‌ها به صورت متن‌باز در [obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills) در دسترس هستند.

## نصب

می‌توانید Obsidian را با جستجو در فهرست افزونه‌ها در Claude، ChatGPT، Dots، Cursor، Grok Bot، Hermes و Kiro پیدا کنید. بیشتر عامل‌های دیگر می‌توانند مهارت‌ها را با ارسال پیوند این صفحه نصب کنند.

### Claude

[Obsidian](https://claude.ai/customize/plugins/id/a38fa062-ebd3-48e0-9a0a-1875a6e94ad5%40anthropic-plugin-directory) را از فهرست رسمی افزونه‌های Claude اضافه کنید.

برای رابط خط فرمان Claude Code از این دستورات استفاده کنید:

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

برای دریافت مهارت‌های جدید بعداً، دستور `claude plugin update obsidian@obsidian-skills` را اجرا کنید.

### ChatGPT

[Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096) را از فهرست افزونه‌های ChatGPT اضافه کنید. این افزونه در ChatGPT، Codex و Dots کار می‌کند.

### Antigravity

در رابط خط فرمان Antigravity، اجرا کنید:

```shell
agy plugin install https://github.com/obsidianmd/obsidian-skills
```

### Grok Bot

[Obsidian for Grok Bot](https://x.ai/bot/plugin/88871845) را باز کنید و **Add to Grok Bot** را انتخاب کنید.

### Muse

از Muse بخواهید مهارت‌ها را از https://github.com/obsidianmd/obsidian-skills نصب کند.

Muse در ابر Meta اجرا می‌شود، بنابراین مهارت `obsidian-cli` در آنجا کار نمی‌کند. اگر از Obsidian بدون رابط کاربری در Muse استفاده می‌کنید، وارد حساب خود می‌شوید و گاوصندوقتان را در ابر Meta همگام‌سازی می‌کنید.

### Cursor

[Obsidian](https://cursor.com/marketplace/obsidian) را از بازارچه Cursor نصب کنید.

### Hermes Agent

```shell
hermes plugins install obsidian
```

### Kiro

```shell
kiro-cli powers install obsidian
```

### GitHub Copilot، OpenCode و سایر عامل‌ها

با [npx skills](https://github.com/vercel-labs/skills) نصب کنید، که از شما می‌پرسد در کدام عامل‌ها نصب شود:

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

برای نصب دستی، پوشه‌های موجود در `plugins/obsidian/skills/` را در پوشه مهارت‌های عامل خود کپی کنید، مثلاً `~/.copilot/skills/` برای GitHub Copilot.

## مهارت‌های شامل

| مهارت               | عملکرد                                                                                                                       |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `obsidian-markdown` | ساختن و ویرایش یادداشت‌های [[Markdown به سبک Obsidian]].                                                                      |
| `obsidian-bases`    | ساختن و ویرایش [[سینتکس پایگاه‌ها\|پایگاه‌ها]] با نماها، پالایه‌ها، فرمول‌ها و خلاصه‌ها.                                      |
| `json-canvas`       | ساختن و ویرایش فایل‌های [[Canvas]] با استفاده از قالب [JSON Canvas](https://jsoncanvas.org/).                                   |
| `obsidian-cli`      | تعامل با گاوصندوق از طریق [[Obsidian CLI]]، شامل توسعه افزونه و پوسته.                                                       |
| `obsidian-headless` | همگام‌سازی و نشر گاوصندوق‌ها از خط فرمان با [[Obsidian بدون رابط کاربری]].                                                     |
| `defuddle`          | استخراج Markdown تمیز از صفحات وب با استفاده از [Defuddle](https://github.com/kepano/defuddle).                                |
| `knap`              | رندر الگوهای Markdown از داده‌های JSON یا CSV با استفاده از [Knap](https://github.com/obsidianmd/knap).                        |

## پیش‌نیازها

مهارت `obsidian-cli` نیاز دارد که اپلیکیشن دسکتاپ Obsidian با [[Obsidian CLI#نصب رابط خط فرمان Obsidian|Obsidian CLI فعال‌شده]] در حال اجرا باشد و عامل‌ای داشته باشید که بتواند دستورات را روی رایانه شما اجرا کند.

مهارت‌های Markdown، پایگاه‌ها و Canvas فقط قالب‌های فایل را توصیف می‌کنند، بنابراین در هر عامل‌ای که بتواند فایل‌ها را در گاوصندوق شما بخواند و بنویسد کار می‌کنند.

Defuddle، Knap و Obsidian بدون رابط کاربری ابزارهای جداگانه‌ای هستند که همراه مهارت‌ها ارائه نمی‌شوند. وقتی یکی از آن‌ها موجود نباشد، مهارت قبل از نصب آن از npm از شما می‌پرسد.

## حریم خصوصی

وصل‌کننده‌های Obsidian به خودی خود چیزی ارسال نمی‌کنند. وقتی عامل‌ای از آن‌ها استفاده می‌کند، یادداشت‌هایی که می‌خواند بخشی از مکالمه می‌شوند و توسط مدل هوش مصنوعی مورد استفاده شما پردازش می‌شوند. قبل از اشاره عامل به گاوصندوقی با یادداشت‌های حساس، سیاست حریم خصوصی عامل خود را بررسی کنید.
