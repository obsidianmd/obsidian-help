Obsidian Skills دستورالعمل‌هایی هستند که به عامل‌های هوش مصنوعی آموزش می‌دهند چگونه با Obsidian کار کنند. آن‌ها از قالب باز [Agent Skills](https://agentskills.io/specification) پیروی می‌کنند، بنابراین با هر عاملی که از مهارت‌ها پشتیبانی کند کار می‌کنند، از جمله Claude Code، Claude، ChatGPT، Antigravity، Cursor، GitHub Copilot، Grok Bot، Hermes Agent، Kiro، Muse، OpenCode و [بسیاری دیگر](https://agentskills.io/clients).

با Obsidian Skills یک عامل می‌تواند:

- یادداشت‌هایی در [[Markdown به سبک Obsidian]] بنویسد، با [[پیوندهای داخلی|پیوندهای ویکی]]، جاسازی‌ها، کال‌اوت‌ها و [[ویژگی‌ها|ویژگی‌ها]].
- فایل‌های [[معرفی پایگاه‌ها|پایگاه‌ها]] و [[Canvas]] را بسازد و ویرایش کند.
- یادداشت‌ها را در اپلیکیشن در حال اجرا با [[Obsidian CLI]] جستجو، بخواند و مدیریت کند.
- گاوصندوق‌ها را بدون اپلیکیشن دسکتاپ با استفاده از [[Obsidian بدون رابط کاربری]] همگام‌سازی و نشر دهد.

مهارت‌ها متن‌باز هستند در [obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills).

## نصب

Obsidian یک افزونه رسمی برای Claude، ChatGPT، Dots، Cursor، Grok Bot، Hermes و Kiro است. اکثر عامل‌های دیگر می‌توانند مهارت‌ها را از GitHub نصب کنند.

### Claude

[Obsidian](https://claude.ai/customize/plugins/id/a38fa062-ebd3-48e0-9a0a-1875a6e94ad5%40anthropic-plugin-directory) را از فهرست رسمی افزونه‌های Claude اضافه کنید.

برای استفاده از Claude Code CLI:

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

برای دریافت مهارت‌های جدید در آینده، دستور `claude plugin update obsidian@obsidian-skills` را اجرا کنید.

### ChatGPT

[Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096) را از فهرست افزونه‌های ChatGPT اضافه کنید. این افزونه در ChatGPT، Codex و Dots کار می‌کند.

### Antigravity

در رابط خط فرمان Antigravity، اجرا کنید:

```shell
agy plugin install https://github.com/obsidianmd/obsidian-skills
```

### Grok Bot

[Obsidian for Grok Bot](https://x.ai/bot/plugin/88871845) را باز کنید و **Add to Grok Bot** را انتخاب کنید.

### Muse

از Muse بخواهید مهارت‌ها را از https://github.com/obsidianmd/obsidian-skills نصب کند.

Muse در فضای ابری Meta اجرا می‌شود، بنابراین مهارت `obsidian-cli` در آنجا کار نمی‌کند. اگر از Obsidian بدون رابط کاربری در Muse استفاده کنید، وارد حساب خود می‌شوید و گاوصندوق خود را در فضای ابری Meta همگام‌سازی می‌کنید.

### Cursor

[Obsidian](https://cursor.com/marketplace/obsidian) را از فروشگاه Cursor نصب کنید.

### Hermes Agent

```shell
hermes plugins install obsidian
```

### Kiro

```shell
kiro-cli powers install obsidian
```

### GitHub Copilot، OpenCode و سایر عامل‌ها

با [npx skills](https://github.com/vercel-labs/skills) نصب کنید که می‌پرسد در کدام عامل‌ها نصب شود:

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

برای نصب دستی، پوشه‌های داخل `plugins/obsidian/skills/` را در پوشه مهارت‌های عامل خود کپی کنید، مثلاً `~/.copilot/skills/` برای GitHub Copilot.

## مهارت‌های موجود

| مهارت                | عملکرد                                                                                                                      |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `obsidian-markdown`  | ساختن و ویرایش یادداشت‌ها در [[Markdown به سبک Obsidian]].                                                                   |
| `obsidian-bases`     | ساختن و ویرایش [[سینتکس پایگاه‌ها|پایگاه‌ها]] با نماها، پالایه‌ها، فرمول‌ها و خلاصه‌ها.                                       |
| `json-canvas`        | ساختن و ویرایش فایل‌های [[Canvas]] با استفاده از قالب [JSON Canvas](https://jsoncanvas.org/).                                 |
| `obsidian-cli`       | تعامل با گاوصندوق خود از طریق [[Obsidian CLI]]، شامل توسعه افزونه و پوسته.                                                   |
| `obsidian-headless`  | همگام‌سازی و نشر گاوصندوق‌ها از خط فرمان با [[Obsidian بدون رابط کاربری]].                                                   |
| `defuddle`           | استخراج Markdown تمیز از صفحات وب با استفاده از [Defuddle](https://github.com/kepano/defuddle).                               |
| `knap`               | رندر قالب‌های Markdown از داده‌های JSON یا CSV با استفاده از [Knap](https://github.com/obsidianmd/knap).                      |

## پیش‌نیازها

مهارت `obsidian-cli` نیاز دارد که اپلیکیشن دسکتاپ Obsidian با [[Obsidian CLI#نصب رابط خط فرمان Obsidian|Obsidian CLI روشن]] در حال اجرا باشد و عاملی داشته باشید که بتواند دستورات را روی رایانه شما اجرا کند.

مهارت‌های Markdown، پایگاه‌ها و Canvas فقط قالب‌های فایل را توصیف می‌کنند، بنابراین در هر عاملی که بتواند فایل‌ها را در گاوصندوق شما بخواند و بنویسد کار می‌کنند.

Defuddle، Knap و Obsidian بدون رابط کاربری ابزارهای جداگانه‌ای هستند که همراه مهارت‌ها ارائه نمی‌شوند. وقتی یکی از آن‌ها موجود نباشد، مهارت قبل از نصب آن از npm از شما می‌پرسد.

## حریم خصوصی

Obsidian Skills به خودی خود هیچ چیزی ارسال نمی‌کنند. وقتی یک عامل از آن‌ها استفاده می‌کند، یادداشت‌هایی که می‌خواند بخشی از مکالمه می‌شوند و توسط مدل هوش مصنوعی مورد استفاده شما پردازش می‌شوند. قبل از اینکه عامل را به گاوصندوقی با یادداشت‌های حساس هدایت کنید، سیاست حریم خصوصی عامل خود را بررسی کنید.
