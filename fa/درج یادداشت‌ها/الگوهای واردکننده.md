[[درج‌کننده]] به شما امکان می‌دهد الگوهایی تعریف کنید که نحوه درج یادداشت‌ها از اپلیکیشن‌های دیگر را کنترل می‌کنند. این بدان معناست که می‌توانید عنوان، ویژگی‌ها و محتوای یادداشت‌هایی که درج می‌کنید را تغییر دهید.

## ویرایش الگوی درج

برای ویرایش الگوی پیش‌فرض، **ویرایش** را بالای پیش‌نمایش انتخاب کنید. می‌توانید موارد زیر را ویرایش کنید:

- نام یادداشت که به صورت عنوان درون‌خطی نمایش داده می‌شود.
- ویژگی‌ها در ابتدای یادداشت.
- محتوای Markdown یادداشت.

**ذخیره** را انتخاب کنید تا به پیش‌نمایش بازگردید. درج‌کننده الگوی درون‌خطی ویرایش‌شده را برای درج‌های آینده با همان قالب به خاطر می‌سپارد.

همچنین می‌توانید یک الگو را از یک فایل Markdown در گاوصندوق فعلی بارگیری کنید.

## پیش‌نمایش نتایج

پیش‌نمایش تا ده نمونه از داده‌هایی که انتخاب کرده‌اید نمایش می‌دهد. از دکمه‌های پیکان برای جابه‌جایی بین نمونه‌ها استفاده کنید. تغییرات در تنظیمات درج و الگو، پیش‌نمایش را قبل از اضافه شدن هر چیزی به گاوصندوق شما به‌روزرسانی می‌کنند.

برخی پیوست‌ها، آیتم‌های راه‌دور و ارجاعات بین یادداشت‌ها تا زمان اجرای درج نمی‌توانند به طور کامل تفکیک شوند. در این موارد، پیش‌نمایش ممکن است پیوند منبع را حفظ کند یا یک جایگزین نمایش دهد.

## سینتکس الگو

الگوهای درج‌کننده از سینتکسی استفاده می‌کنند که شامل متغیرها، [[پالایه‌ها]] و [[منطق]] است. از همان سینتکس [Knap](https://github.com/obsidianmd/knap) مانند [[معرفی Obsidian Web Clipper|Web Clipper]] استفاده می‌کند.

متغیرها را با دو کروشه درج کنید، مانند `{{title}}`، `{{content}}` یا `{{date}}`. متغیرها را می‌توان در نام یادداشت، ویژگی‌ها و محتوا استفاده کرد.

می‌توانید متغیرها را با استفاده از [[پالایه‌ها]] تغییر دهید. برای مثال تغییر قالب تاریخ با استفاده از `{{date|date:"YYYY-MM-DD"}}`. از [[منطق]] برای شرطی‌های پیشرفته‌تر، حلقه‌ها و تخصیص متغیر استفاده کنید.

## متغیرها

متغیرهای زیر برای استفاده در هر الگوی درج‌کننده در دسترس هستند:

| متغیر           | توضیحات                                                                                             |
| ---------------- | --------------------------------------------------------------------------------------------------- |
| `{{body}}`       | بدنه Markdown بدون ویژگی‌ها (بدون فرادادهٔ ابتدای فایل).                                           |
| `{{content}}`    | Markdown کامل قبل از اعمال الگوی انتخاب‌شده.                                                       |
| `{{ctime}}`      | زمان ایجاد منبع به صورت مهر زمانی ISO 8601؛ در صورت عدم دسترسی خالی است.                           |
| `{{date}}`       | تاریخ و زمان فعلی هنگام رندر الگو، به صورت مهر زمانی ISO 8601.                                     |
| `{{importer}}`   | شناسه درج‌کننده، مانند `keep`، `html` یا `notion-api`.                                              |
| `{{folder}}`     | پوشه والد نهایی نسبت به گاوصندوق. زمانی که یادداشت در ریشه گاوصندوق باشد خالی است.                 |
| `{{mtime}}`      | زمان تغییر منبع به صورت مهر زمانی ISO 8601؛ در صورت عدم دسترسی خالی است.                           |
| `{{noteName}}`   | نام نهایی تفکیک‌شده یادداشت، پس از حذف کاراکترهای نامعتبر و افزودن پسوندها برای موارد تکراری.      |
| `{{path}}`       | مسیر نهایی نسبت به گاوصندوق، شامل پسوند `.md`.                                                     |
| `{{properties}}` | شیء حاوی ویژگی‌های فرادادهٔ ابتدای فایل.                                                            |
| `{{source}}`     | شیء حاوی ویژگی‌های تولیدشده و مقادیر خاص منبع.                                                     |
| `{{sourceId}}`   | شناسه پایدار منبع زمانی که درج‌کننده آن را ارائه می‌دهد؛ در غیر این صورت خالی است.                  |
| `{{time}}`       | نام مستعار برای `{{date}}`.                                                                         |
| `{{title}}`      | عنوان اصلی یادداشت قبل از پاک‌سازی و حذف تکراری‌ها.                                                |

## مقادیر منبع برای ویژگی‌ها

برای قالب‌های درج که از [[ویژگی‌ها]] پشتیبانی می‌کنند، مقادیر منبع نیز برای راحتی به عنوان متغیرهای سطح بالا در دسترس هستند.

اگر یک مقدار منبع هم‌نام با یک متغیر مشترک باشد، از طریق `{{source}}` به آن دسترسی پیدا کنید. برای مثال، اگر منبع درج شما ویژگی‌ای به نام `content` داشته باشد، از طریق `{{source.content}}` در دسترس است، در حالی که `{{content}}` همچنان متغیر پیش‌فرض درج‌کننده باقی می‌ماند.

زمانی که نام فیلد شامل فاصله، علائم نگارشی یا کاراکترهای خاص دیگر است، از نماد براکت استفاده کنید:

```twig
{{source["Project: status"]}}
```

## نمونه الگو

در اینجا نمونه‌ای از یک الگو با استفاده از متغیرها و [[پالایه‌ها|پالایه‌ها]] آمده است:

```twig
---
created: {{ctime | date:"YYYY-MM-DD"}}
modified: {{mtime | date:"YYYY-MM-DD"}}
source: {{importer}}
---
# {{title}}

{{body}}
```

می‌توانید داده‌ها را به صورت شرطی با استفاده از [[منطق]] به یادداشت اضافه کنید:

```twig
{% if tags %}
## برچسب‌ها
{% for tag in tags %}
- {{tag}}
{% endfor %}
{% endif %}
```
