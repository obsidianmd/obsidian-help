Obsidian از فایل‌های Markdown با پسوند `.md` به‌عنوان قالب اصلی یادداشت‌ها استفاده می‌کند. این کار درج فایل‌های Markdown به Obsidian را آسان می‌سازد. بسیاری از اپلیکیشن‌ها قادر به ویرایش فایل‌های Markdown یا استخراج به این قالب هستند.

چندین روش برای افزودن فایل‌های Markdown به گاوصندوق Obsidian وجود دارد:

1. فایل‌ها یا پوشه‌ها را به پنجره [[مرورگر فایل]] بکشید و رها کنید
2. از مرورگر فایل سیستم خود (مانند Windows Explorer یا Finder در macOS) استفاده کنید و فایل‌هایتان را مستقیماً به پوشه‌ی اصلی خزانه Obsidian منتقل کنید.

## وارد کردن فایل‌های Markdown با Importer

از [[درج‌کننده|افزونه Importer]] رسمی استفاده کنید، زمانی که می‌خواهید پوشه‌هایی را درون یک ورودی انتخاب کنید، یک آرشیو `.zip` وارد کنید، قالب‌بندی را استانداردسازی کنید، برچسب‌های درون‌خطی را به [[ویژگی‌ها|ویژگی‌ها]] منتقل کنید، یا یک قالب اعمال کنید.

1. **[[تنظیمات|تنظیمات]] → افزونه‌های انجمن** را باز کنید و [Importer را نصب کنید](obsidian://show-plugin?id=obsidian-importer).
2. افزونه Importer را فعال کنید.
3. **Importer** را با استفاده از [[فرمان‌دان|پالت فرمان‌ها]] یا آیکون نوار ابزار باز کنید.
4. در بخش **File format**، گزینه **Markdown (.md, .zip)** را انتخاب کنید.
5. فایل‌های Markdown، پوشه‌ها یا آرشیوهای zip را انتخاب کنید.
6. پوشه‌های شناسایی‌شده، گزینه‌های خروجی، قالب تولیدشده و نمونه‌های پیش‌نمایش را بررسی کنید.
7. **Import** را انتخاب کنید و منتظر بمانید تا وارد کردن تمام شود.

برای سفارشی‌سازی نام یادداشت وارد شده، ویژگی‌ها و محتوا، [[الگوهای واردکننده|قالب‌های Importer]] را ببینید.
