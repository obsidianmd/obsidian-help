واردکننده‌ی قالب مارک‌داون [[ویژگی‌ها#ویژگی‌های منسوخ‌شده|قالب‌های منسوخ‌شده‌ی ویژگی‌ها]] را به قالب فعلی مورد استفاده‌ی Obsidian مهاجرت می‌دهد.

> [!warning] از گاوصندوق خود پشتیبان‌گیری کنید
> تبدیل روی کل گاوصندوق شما اعمال می‌شود. قبل از شروع، از [[پشتیبان‌گیری از فایل‌های Obsidian|فایل‌های Obsidian خود پشتیبان‌گیری کنید]].

برای تبدیل ویژگی‌ها در یادداشت‌های‌تان:

1. [[فرمان‌دان|پالت فرمان‌ها]] را باز کنید.
2. گزینه‌ی **واردکننده‌ی قالب مارک‌داون: مهاجرت فرادادهٔ ابتدای فایل** را انتخاب کنید.
3. **آغاز تبدیل** را انتخاب کنید.

## قالب‌های ویژگی پشتیبانی‌شده

واردکننده، دگرنام‌ها، برچسب‌ها و کلاس‌های CSS را از قالب‌های منسوخ‌شده به‌روزرسانی می‌کند:

**دگرنام**

```yaml
# قبل

alias: My Note Title

# بعد

aliases:
  - My Note Title
```

**برچسب‌ها**

```yaml
# قبل

tag: project, important

# بعد

tags:
  - project
  - important
```

**کلاس‌های CSS**

```yaml
# قبل

cssclass: custom-style

# بعد

cssclasses:
  - custom-style
```
