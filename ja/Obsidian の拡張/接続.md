接続を使うと、ObsidianをClaude、ChatGPT、Antigravity、Cursor、GitHub Copilot、Grok Bot、Hermes、Kiro、Muse、OpenCode、その他[多くのAIエージェント](https://agentskills.io/clients)と接続できます。

これにより、エージェントは以下のことを学習できます：

- [[Obsidian Flavored Markdown]]でノートを書く。[[内部リンク|ウィキリンク]]、埋め込み、コールアウト、[[プロパティ]]を含む。
- [[Basesの紹介|ベース]]や[[Canvas]]ファイルの作成と編集。
- [[Obsidian CLI]]を使って、実行中のアプリでノートを検索、読み取り、管理。
- [[Obsidian Headless]]を使って、デスクトップアプリなしで保管庫を同期・パブリッシュ。

スキルは[obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills)でオープンソースとして公開されています。

## インストール

Claude、ChatGPT、Dots、Cursor、Grok Bot、Hermes、Kiroのプラグインリストで「Obsidian」を検索して見つけることができます。他のほとんどのエージェントでは、このページへのリンクを送ればスキルをインストールできます。

### Claude

公式のClaudeプラグインディレクトリから[Obsidian](https://claude.ai/customize/plugins/id/a38fa062-ebd3-48e0-9a0a-1875a6e94ad5%40anthropic-plugin-directory)を追加します。

Claude Code CLIの場合：

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

新しいスキルを後で取得するには、`claude plugin update obsidian@obsidian-skills`を実行します。

### ChatGPT

ChatGPTプラグインディレクトリから[Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096)を追加します。このプラグインはChatGPT、Codex、Dotsで動作します。

### Antigravity

Antigravity CLIで以下を実行します：

```shell
agy plugin install https://github.com/obsidianmd/obsidian-skills
```

### Grok Bot

[Obsidian for Grok Bot](https://x.ai/bot/plugin/88871845)を開き、**Add to Grok Bot**を選択します。

### Muse

Museに https://github.com/obsidianmd/obsidian-skills からスキルをインストールするよう依頼します。

MuseはMetaのクラウドで実行されるため、`obsidian-cli`スキルはそこでは動作しません。Muse内でObsidian Headlessを使用する場合、ログインと保管庫の同期はMetaのクラウド上で行われます。

### Cursor

Cursor Marketplaceから[Obsidian](https://cursor.com/marketplace/obsidian)をインストールします。

### Hermes Agent

```shell
hermes plugins install obsidian
```

### Kiro

```shell
kiro-cli powers install obsidian
```

### GitHub Copilot、OpenCode、その他のエージェント

[npx skills](https://github.com/vercel-labs/skills)を使ってインストールします。どのエージェントにインストールするか尋ねられます：

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

手動でインストールする場合は、`plugins/obsidian/skills/`内のフォルダをエージェントのスキルフォルダにコピーします。例えばGitHub Copilotの場合は`~/.copilot/skills/`です。

## 含まれるスキル

| スキル               | 機能                                                                                                                  |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `obsidian-markdown` | [[Obsidian Flavored Markdown]]ノートの作成と編集。                                                                         |
| `obsidian-bases`    | ビュー、フィルタ、数式、サマリーを含む[[Bases構文|ベース]]の作成と編集。                                         |
| `json-canvas`       | [JSON Canvas](https://jsoncanvas.org/)フォーマットを使った[[Canvas]]ファイルの作成と編集。                                     |
| `obsidian-cli`      | プラグインやテーマの開発を含む、[[Obsidian CLI]]を通じた保管庫との対話。                                    |
| `obsidian-headless` | [[Obsidian Headless]]を使ったコマンドラインからの保管庫の同期とパブリッシュ。                                                     |
| `defuddle`          | [Defuddle](https://github.com/kepano/defuddle)を使ったウェブページからのクリーンなMarkdown抽出。                                   |
| `knap`              | [Knap](https://github.com/obsidianmd/knap)を使ったJSONまたはCSVデータからのMarkdownテンプレートのレンダリング。                             |

## 要件

`obsidian-cli`スキルには、[[Obsidian CLI#Obsidian CLIのインストール|Obsidian CLIが有効化された]]Obsidianデスクトップアプリが実行中であることと、コンピュータ上でコマンドを実行できるエージェントが必要です。

Markdown、ベース、Canvasのスキルはファイルフォーマットを記述するだけなので、保管庫内のファイルを読み書きできるあらゆるエージェントで動作します。

Defuddle、Knap、Obsidian Headlessはスキルにバンドルされていない別ツールです。不足している場合、スキルはnpmからインストールする前に確認を求めます。

## プライバシー

Obsidianの接続は、それ自体では何も送信しません。エージェントがそれらを使用する際、読み取ったノートは会話の一部となり、使用しているAIモデルによって処理されます。機密性の高いノートがある保管庫にエージェントを向ける前に、エージェントのプライバシーポリシーを確認してください。
