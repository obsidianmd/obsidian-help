Obsidian Skillsは、AIエージェントにObsidianでの作業方法を教える指示です。オープンな[Agent Skills](https://agentskills.io/specification)フォーマットに準拠しているため、Claude Code、Claude、ChatGPT、Antigravity、Cursor、GitHub Copilot、Grok Bot、Hermes Agent、Kiro、OpenCode、[その他多数](https://agentskills.io/clients)など、スキルをサポートするあらゆるエージェントで動作します。

Obsidian Skillsを使うと、エージェントは以下のことが可能になります：

- [[Obsidian Flavored Markdown]]でノートを作成。[[内部リンク|ウィキリンク]]、埋め込み、コールアウト、[[プロパティ|プロパティ]]に対応。
- [[Basesの紹介|ベース]]および[[Canvas|Canvas]]ファイルの作成・編集。
- [[Obsidian CLI]]を使用して、実行中のアプリでノートの検索、読み取り、管理。
- [[Obsidian Headless]]を使用して、デスクトップアプリなしで保管庫の同期と公開。

スキルはオープンソースで[obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills)にて公開されています。

## インストール

ObsidianはClaude、ChatGPT、Dots、Cursor、Grok Bot、Hermes、Kiroの公式プラグインです。その他のほとんどのエージェントはGitHubからスキルをインストールできます。

### Claude

公式Claudeプラグインディレクトリから[Obsidian](https://claude.ai/customize/plugins/id/a38fa062-ebd3-48e0-9a0a-1875a6e94ad5%40anthropic-plugin-directory)を追加します。

Claude Code CLIの場合：

```shell
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills
```

後から新しいスキルを取得するには、`claude plugin update obsidian@obsidian-skills`を実行します。

### ChatGPT

ChatGPTプラグインディレクトリから[Obsidian](https://chatgpt.com/plugins/plugins_6aee4fde227881919d61b034b1c31096)を追加します。プラグインはChatGPT、Codex、Dotsで動作します。

### Antigravity

Antigravity CLIで以下を実行します：

```shell
agy plugin install https://github.com/obsidianmd/obsidian-skills
```

### Grok Bot

[Obsidian for Grok Bot](https://x.ai/bot/plugin/88871845)を開き、**Add to Grok Bot**を選択します。

### Cursor

Cursorマーケットプレイスから[Obsidian](https://cursor.com/marketplace/obsidian)をインストールします。

### Hermes Agent

```shell
hermes plugins install obsidian
```

### Kiro

```shell
kiro-cli powers install obsidian
```

### GitHub Copilot、OpenCode、その他のエージェント

[npx skills](https://github.com/vercel-labs/skills)を使ってインストールします。インストール先のエージェントを尋ねられます：

```shell
npx skills add https://github.com/obsidianmd/obsidian-skills
```

手動でインストールする場合は、`plugins/obsidian/skills/`内のフォルダをエージェントのスキルフォルダにコピーします（例：GitHub Copilotの場合は`~/.copilot/skills/`）。

## 含まれるスキル

| スキル               | 機能                                                                                                                  |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `obsidian-markdown` | [[Obsidian Flavored Markdown]]でノートを作成・編集します。                                                                         |
| `obsidian-bases`    | ビュー、フィルター、数式、サマリーを含む[[Bases構文|ベース]]を作成・編集します。                                         |
| `json-canvas`       | [JSON Canvas](https://jsoncanvas.org/)フォーマットを使用して[[Canvas]]ファイルを作成・編集します。                                     |
| `obsidian-cli`      | プラグインやテーマの開発を含め、[[Obsidian CLI]]を通じて保管庫を操作します。                                    |
| `obsidian-headless` | [[Obsidian Headless]]を使用してコマンドラインから保管庫を同期・公開します。                                                     |
| `defuddle`          | [Defuddle](https://github.com/kepano/defuddle)を使用してウェブページからクリーンな Markdown を抽出します。                                   |
| `knap`              | [Knap](https://github.com/obsidianmd/knap)を使用してJSONまたはCSVデータから Markdown テンプレートをレンダリングします。                             |

## 要件

`obsidian-cli`スキルには、[[Obsidian CLI#Obsidian CLIのインストール|Obsidian CLIが有効になった]]Obsidianデスクトップアプリが実行されていること、およびコンピュータ上でコマンドを実行できるエージェントが必要です。

Markdown、ベース、Canvasのスキルはファイルフォーマットの記述のみであるため、保管庫内のファイルを読み書きできるあらゆるエージェントで動作します。

Defuddle、Knap、Obsidian Headlessはスキルにバンドルされていない個別のツールです。いずれかが見つからない場合、スキルはnpmからインストールする前に確認を求めます。

## プライバシー

Obsidian Skillsはそれ自体では何も送信しません。エージェントがスキルを使用する際、読み取られたノートは会話の一部となり、使用しているAIモデルによって処理されます。機密性の高いノートを含む保管庫にエージェントを向ける前に、エージェントのプライバシーポリシーを確認してください。
