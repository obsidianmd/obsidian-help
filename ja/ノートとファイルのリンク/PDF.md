ObsidianはPDFファイルを内蔵ビューアで開きます。ノートにPDFを埋め込んだり、PDF内の一節にリンクしたり、ノートをPDFとしてエクスポートしたりすることもできます。Obsidianがサポートするファイル形式については、[[対応ファイル形式]]をご覧ください。

> [!info]+ 一部の機能はデスクトップ版のみです
> モバイル版のObsidianアプリでは、PDF内の検索、引用やリンクのコピー、ノートのPDFへのエクスポートはできません。

## PDFを開く

[[ファイルエクスプローラー]]でPDFを選択すると、タブで開きます。

> [!info]+ 注釈はサポートされていません
> ObsidianはPDFへの注釈やハイライトの追加をサポートしていません。PDFにマークアップするには、別のアプリを使用してから、更新されたファイルを保管庫で開いてください。

ビューアにはこれらのコントロールを備えたツールバーがあります。モバイル版のObsidianアプリにも同じツールバーがあります。

- **サイドバーを切り替え**はサイドバーの表示・非表示を切り替え、**サイドバーオプション**はサイドバーに表示する内容を変更します。
- **縮小**と**拡大**はページのサイズを変更します。
- **表示オプション**はページのレイアウトを変更します。
- ページボックスには現在のページが表示されます。ページ番号を入力すると、そのページに移動します。

リネームや移動などPDFファイル自体を操作するには、**オプション** ![[lucide-more-horizontal.svg#icon]]を選択します。PDFのメニューはノートよりも項目が少なくなっています。[[オプションメニュー]]をご覧ください。

## PDFをナビゲートする

**サイドバーオプション**を選択し、表示する内容を選びます。

- **サムネイル**は各ページの小さなプレビューを表示します。
- **目次**はPDFのアウトラインがある場合に表示します。
- **目次に表示**は目次内で現在のページをハイライトします。

ページにリンクするには、サムネイルを右クリックして**ページNへのリンクをコピー**を選択します（Nはページ番号）。リンクをノートに貼り付けてください。

セクションにリンクするには、目次のエントリを右クリックして**"タイトル"へのリンクをコピー**を選択します（タイトルはエントリの名前）。モバイルでは、エントリを長押しします。

## PDFの表示を変更する

**表示オプション**を選択してレイアウトを変更します。

- **幅を合わせる**と**高さを合わせる**はビューアに合わせてページのサイズを調整します。
- **単一ページ**は一度に1ページを表示します。
- **二ページ (奇数)**は左側に奇数ページを配置してページを並べて表示します。例えば、ページ1と2が一緒に表示され、次にページ3と4が表示されます。
- **二ページ (偶数)**は左側に偶数ページを配置してページを並べて表示します。例えば、ページ1が単独で表示され、次にページ2と3が一緒に表示されます。
- **テーマに合わせる**はObsidianのテーマがダークの場合にPDFの色を暗くします。

## PDFを検索する

PDF内の検索はデスクトップ版でのみ利用可能です。モバイル版のObsidianアプリにはPDFビューアでの検索機能がありません。

1. `Ctrl+F`（WindowsおよびLinux）または`Command+F`（macOS）を押します。
2. **入力して検索を開始…**に検索したいテキストを入力します。
3. 上下の矢印を選択して一致箇所間を移動します。

検索の動作を変更するには、以下のオプションを使用します。

- **大文字/小文字を区別**は大文字と小文字を正確に区別します。検索フィールドの**Aa**ボタンです。
- **すべてをハイライト**はすべての一致箇所をハイライトします。矢印の横にある設定ボタンを選択すると、このオプションが見つかります。
- **発音区別符号に一致**はアクセント付きの文字を異なる文字として扱います。同じ設定メニューにあります。
- **単語全体に一致**は単語全体のみを検索します。同じ設定メニューにあります。

閉じるボタンを選択して検索を終了します。

## PDFからテキストをコピーする

デスクトップ版では、PDF内のテキストを選択してから右クリックします。

- **コピー**はテキストをコピーします。
- **引用としてコピー**はテキストを引用としてコピーし、その後にその一節へのリンクを付けます。
- **選択範囲へのリンクをコピー**はその一節へのリンクをコピーし、ノートに貼り付けることができます。

引用をノートに貼り付けると、以下のようになります。

```md
> Obsidian is awesome

[[Gemmy.pdf#page=1&selection=32,0,32,14|Gemmy, page 1]]
```

選択範囲へのリンクは、同じリンクが単独で表示されます。

```md
[[Gemmy.pdf#page=1&selection=32,0,32,14|Gemmy, page 1]]
```

モバイルでは、PDFでテキストを選択するとデバイスの標準テキストメニューが表示されます。**引用としてコピー**と**選択範囲へのリンクをコピー**は利用できません。

## PDFを埋め込む

ノート内にPDFを表示するには、[[ファイルの埋め込み#ノートにPDFを埋め込む|ノートにPDFを埋め込む]]方法をご覧ください。埋め込まれたPDFにはビューアと同じツールバーがあります。**ブロックを編集**を選択すると、埋め込みリンクを変更できます。

## ノートをPDFにエクスポートする

デスクトップ版では、任意のノートをPDFとしてエクスポートできます。PDFへのエクスポートはモバイル版のObsidianアプリでは利用できません。

1. エクスポートするノートを開きます。
2. [[コマンドパレット]]を開いて**PDFとしてエクスポート…**を選択します。ノートの**オプション** ![[lucide-more-horizontal.svg#icon]]を選択し、**PDFとしてエクスポート…**を選択することもできます。
3. 設定を選びます。
    - **ファイル名をタイトルとして含める**はPDFの先頭にファイル名を追加します。
    - **ページサイズ**は用紙サイズを設定します。A3、A4、A5、Legal、Letter、Tabloidから選択できます。
    - **横向き**はページを横向きにします。
    - **余白**はページの余白を**デフォルト**、**最小**、**なし**に設定します。
    - **倍率**は各ページのコンテンツを拡大縮小します。100ではコンテンツは元のサイズのままです。値を低くするとテキストや画像が小さくなり、各ページにより多くのコンテンツが収まります。
4. **PDFにエクスポート**を選択します。
5. ファイルの保存先を選びます。

> [!tip]- ダークテーマでノートをエクスポートする
> エクスポートは、テーマがダークでも常にライトスタイルが使用されます。エクスポートの見た目を変更するには、[[CSSスニペット|CSSスニペット]]を使用できます。Obsidianフォーラムには、印刷やエクスポート用のスニペットの例があります。[^1]

[^1]: [How can I make export pdf look the same as my theme?](https://forum.obsidian.md/t/how-can-i-make-export-pdf-look-the-same-as-my-theme/75849)および[PDF and print style reset with code syntax highlighting](https://forum.obsidian.md/t/pdf-and-print-style-reset-with-code-syntax-highlighting/31761)を参照してください。
