Obsidianでは、公式の[[インポーター|インポータープラグイン]]を使用して、個々のHTMLファイルやHTMLファイルのフォルダ全体を簡単にインポートできます。これはウェブサイト全体を[[Obsidian Flavored Markdown|Markdown]]フォーマットで保存したい場合や、HTMLにエクスポートするツールからデータをインポートしたい場合に便利です。

特定のアプリからノートをインポートする場合は、まず[[インポーター|インポータープラグイン]]がサポートするアプリの一覧を確認して、移行するデータをより適切に保持できる専用のコンバーターがあるかどうかを確認することをお勧めします。

## HTMLデータをObsidianにインポートする

公式のObsidian [[インポーター]]プラグインが必要です。[こちらからインストール](obsidian://show-plugin?id=obsidian-importer)できます。

1. **[[設定]]**を開きます。
2. **コミュニティプラグイン**に移動し、[インポーターをインストール](obsidian://show-plugin?id=obsidian-importer)します。
3. インポータープラグインを有効化します。
4. コマンドパレットまたはリボンメニューのアイコンから**インポーター**プラグインを開きます。
5. **ファイルフォーマット**で**HTML (.html)**を選択します。
6. HTMLファイルまたはフォルダのロケーションを選択します。
7. **Import**を選択して、生成されたテンプレートを確認し、ファイルのプレビュー例を確認します。
8. 再度**Import**を選択し、インポートが完了するまで待ちます。

### インポート設定

- **添付ファイルのサイズ制限**：指定したサイズより大きい添付ファイルのインポートをスキップします。
- **最小画像サイズ**：いずれかの次元で指定したサイズより小さい画像のインポートをスキップします。アイコンやロゴをスキップするために使用できます。

## テンプレート

[[インポーターテンプレート|インポーターテンプレート]]を使用して、データのインポート方法を完全に設定できます。

![[インポーターテンプレート#Variables]]

さらに、HTMLインポートでは[[Obsidian Web Clipperの紹介|Web Clipper]]と同じ変数の多くが利用できます：

| 変数 | 説明 |
| --- | --- |
| `{{author}}` | ページの著者。 |
| `{{contentHtml}}` | HTML形式で抽出されたページコンテンツ。 |
| `{{description}}` | ページの説明または抜粋。 |
| `{{domain}}` | ページのドメイン。 |
| `{{favicon}}` | ファビコンURL。 |
| `{{fullHtml}}` | ページ全体の未処理HTML。 |
| `{{image}}` | ソーシャルシェア画像のURL。 |
| `{{language}}` | ページの言語。 |
| `{{published}}` | 公開日。`date`フィルターでフォーマットできます。 |
| `{{site}}` | サイト名またはパブリッシャー。 |
| `{{url}}` | インポートされたドキュメント内に見つかったソースURL（利用可能な場合）。 |
| `{{words}}` | ワード数。 |
