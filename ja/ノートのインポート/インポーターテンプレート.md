[[インポーター]]では、他のアプリからノートをインポートする方法を制御するテンプレートを定義できます。これにより、インポートするノートのタイトル、プロパティ、コンテンツを変更できます。

## インポートテンプレートの編集

プレビューの上にある**編集**を選択して、デフォルトのテンプレートを編集します。以下を編集できます：

- インラインタイトルとして表示されるノート名。
- ノートの先頭にあるプロパティ。
- ノートのMarkdownコンテンツ。

**保存**を選択してプレビューに戻ります。インポーターは、同じフォーマットを使用する将来のインポートのために、編集されたインラインテンプレートを記憶します。

または、現在の保管庫内のMarkdownファイルからテンプレートをロードすることもできます。

## 結果のプレビュー

プレビューでは、選択したデータから最大10件のサンプルが表示されます。矢印ボタンを使用してサンプル間を移動できます。インポート設定やテンプレートの変更は、保管庫に何かが追加される前にプレビューに反映されます。

一部の添付ファイル、リモートアイテム、ノート間の参照は、インポートが実行されるまで完全に解決できません。その場合、プレビューにはソースリンクやプレースホルダーが残ることがあります。

## テンプレート構文

インポーターテンプレートは、[[変数]]、[[フィルター]]、[[ロジック]]で構成される構文を使用します。[[Obsidian Web Clipperの紹介|Web Clipper]]と同じ[Knap](https://github.com/obsidianmd/knap)構文を使用します。

変数は二重波括弧で挿入します。例えば`{{title}}`、`{{content}}`、`{{date}}`などです。変数はノート名、プロパティ、コンテンツで使用できます。

[[フィルター]]を使用して変数を加工できます。例えば、`{{date|date:"YYYY-MM-DD"}}`のように日付の書式を変更できます。より高度な条件分岐、ループ、変数の代入には[[ロジック]]を使用します。

## 変数

以下の変数は、すべてのインポーターテンプレートで使用できます：

| 変数               | 説明                                                                                                |
| ---------------- | --------------------------------------------------------------------------------------------------- |
| `{{body}}`       | プロパティなしのMarkdown本文（フロントマターなし）。                                                  |
| `{{content}}`    | 選択したテンプレートが適用される前の完全なMarkdown。                                                  |
| `{{ctime}}`      | ISO 8601タイムスタンプとしてのソース作成日時。利用できない場合は空。                                  |
| `{{date}}`       | テンプレートがレンダリングされた時点の現在の日時（ISO 8601タイムスタンプ）。                          |
| `{{importer}}`   | インポーターID。`keep`、`html`、`notion-api`など。                                                   |
| `{{folder}}`     | 最終的な保管庫からの相対的な親フォルダ。ノートが保管庫のルートにある場合は空。                       |
| `{{mtime}}`      | ISO 8601タイムスタンプとしてのソース更新日時。利用できない場合は空。                                  |
| `{{noteName}}`   | 無効な文字の除去や重複に対するサフィックスの追加後の、最終的に解決されたノート名。                   |
| `{{path}}`       | `.md`拡張子を含む、保管庫からの相対的な最終パス。                                                    |
| `{{properties}}` | フロントマタープロパティを含むオブジェクト。                                                        |
| `{{source}}`     | 生成されたプロパティとソース固有の値を含むオブジェクト。                                              |
| `{{sourceId}}`   | インポーターが提供する場合の安定したソース識別子。それ以外の場合は空。                               |
| `{{time}}`       | `{{date}}`のエイリアス。                                                                            |
| `{{title}}`      | サニタイズや重複排除前の元のノートタイトル。                                                        |

## プロパティのソース値

[[プロパティ]]をサポートするインポートフォーマットでは、ソース値も便利のためにトップレベル変数として利用できます。

ソース値が共有変数と同じ名前を持つ場合は、`{{source}}`を介してアクセスしてください。例えば、インポートソースに`content`という名前のプロパティがある場合、`{{source.content}}`としてアクセスできます。一方、`{{content}}`はデフォルトのインポーター変数のままです。

フィールド名にスペース、句読点、その他の特殊文字が含まれる場合は、ブラケット記法を使用します：

```twig
{{source["Project: status"]}}
```

## テンプレートの例

変数と[[フィルター]]を使用したテンプレートの例を示します：

```twig
---
created: {{ctime | date:"YYYY-MM-DD"}}
modified: {{mtime | date:"YYYY-MM-DD"}}
source: {{importer}}
---
# {{title}}

{{body}}
```

[[ロジック]]を使用して、条件に応じてノートにデータを追加できます：

```twig
{% if tags %}
## タグ
{% for tag in tags %}
- {{tag}}
{% endfor %}
{% endif %}
```
