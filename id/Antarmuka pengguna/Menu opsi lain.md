Menu **Opsi lain** menampilkan tindakan yang dapat Anda lakukan pada catatan yang aktif. Beberapa item hanya muncul ketika [[Plugin inti|plugin inti]] atau layanan seperti [[Pengantar Obsidian Publish|Obsidian Publish]] diaktifkan.

## Membuka menu

Di sudut kanan atas catatan, pilih **Opsi lain** ![[lucide-more-horizontal.svg#icon]].

Di desktop, Anda juga dapat mengklik kanan tab catatan. Menu tersebut memiliki item yang sama ditambah beberapa lagi. Lihat [[#Menu tab]].

> [!info]+ Item berubah sesuai tampilan
> Menu bergantung pada tampilan yang aktif, seperti catatan atau Canvas. Halaman ini menjelaskan catatan Markdown. Beberapa item juga berubah sesuai sistem operasi Anda.

## Desktop

### Tampilan dan tata letak

- **Tautan balik dalam dokumen** menampilkan tautan balik catatan di dalam catatan. Memerlukan plugin Backlink. Lihat [[Backlink#Tampilkan backlink di catatan]].
- **Tampilan baca** dan **Mode sumber** mengubah tampilan catatan dan cara Anda mengeditnya. Lihat [[Tampilan dan mode penyuntingan]].
- **Pisah ke kanan** dan **Pisah ke bawah** membuka catatan di panel baru. Lihat [[Tab]].
- **Buka di jendela baru** membuka catatan di jendelanya sendiri. Lihat [[Jendela pop-out]].

### Kelola catatan

- **Ubah nama** mengubah nama catatan. Lihat [[Kelola catatan#Ganti nama catatan]].
- **Pindahkan berkas ke...** memindahkan catatan ke folder lain. Lihat [[Penjelajah berkas]].
- **Tandai...** menambahkan catatan ke bookmark Anda. Memerlukan plugin Penanda. Lihat [[Penanda#Tambah bookmark]].
- **Gabungkan kesemua berkas dengan...** menggabungkan catatan dengan catatan lain. Memerlukan plugin Komposer catatan. Lihat [[Komposer catatan#Gabungkan catatan]].
- **Publikasikan file saat ini** mempublikasikan catatan ke situs Anda. Memerlukan Obsidian Publish.
- **Tambah properti berkas** menambahkan properti ke catatan. Lihat [[Properti]].
- **Ekspor PDF** menyimpan catatan sebagai PDF.
- **Hapus berkas** menghapus catatan. Lihat [[Kelola catatan#Hapus catatan]].

### Cari

- **Cari...** dan **Ganti...** mencari teks dalam catatan dan menggantinya. Lihat [[Find and replace]].

### Path, riwayat, dan tampilan tertaut

- **Salin path** menyalin lokasi catatan sebagai URL Obsidian, dari folder brankas, atau dari root sistem.
- **Buka riwayat versi** menampilkan versi catatan sebelumnya. Memerlukan langganan Obsidian Sync yang aktif. Lihat [[Riwayat versi]].
- **Buka tampilan tertaut** membuka tampilan yang mengikuti catatan, seperti grafik lokal. Lihat [[Tab#Tampilan tertaut]].

### Komputer Anda

- **Buka di aplikasi bawaan** membuka file di aplikasi yang digunakan komputer Anda untuk jenis file tersebut.
- **Tampilkan di Filesystem** menampilkan file di pengelola file Anda. Di macOS, item ini tertulis **Tampilkan di Finder**. Di Windows dan Linux, tertulis **Tampilkan dalam folder**.
- **Tunjukkan berkas di penjelajah berkas** menyorot catatan di Penjelajah berkas.

### Menu tab

Klik kanan tab untuk melihat semua item di atas, ditambah item berikut.

- **Tutup** menutup tab.
- **Sematkan** menyematkan tab. Lihat [[Tab#Sematkan tab]].
- **Tautkan dengan tab...** menautkan tab dengan tampilan seperti grafik lokal atau kerangka, sehingga tampilan tersebut mengikuti tab ini.
- **Pindahkan ke Jendela Baru** memindahkan tab ke jendelanya sendiri.

## Seluler

Di seluler, pilih **Opsi lain** di catatan. Menu ini menggabungkan item dari menu tab desktop dan menu **Opsi lain** desktop, dan memiliki lebih sedikit item.

Item berikut berfungsi sama seperti di desktop.

- **Tampilan baca** dan **Mode sumber**
- **Ubah nama**
- **Pindahkan berkas ke...**
- **Gabungkan kesemua berkas dengan...**
- **Tambah properti berkas**
- **Cari...** dan **Ganti...**
- **Salin path**, dengan pilihan **sebagai URL Obsidian** dan **dari folder brankas**
- **Buka riwayat versi**
- **Buka tampilan tertaut**
- **Hapus berkas**

Menu seluler juga memiliki item berikut.

- **Tutup** menutup catatan.
- **Sematkan** menyematkan tab.
- **Bagikan** membagikan catatan. Di iOS, ini membuka lembar berbagi.
