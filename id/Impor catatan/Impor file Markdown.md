Obsidian menggunakan file Markdown `.md` sebagai format utama untuk catatan. Ini memudahkan Anda untuk mengimpor file Markdown ke dalam Obsidian. Banyak aplikasi yang dapat menyunting file Markdown atau mengekspor ke format ini.

Ada beberapa cara untuk menambahkan file Markdown ke brankas Obsidian Anda:

1. Seret dan lepas file atau folder ke jendela [[Penjelajah berkas]]
2. Gunakan penjelajah file sistem Anda (misalnya Windows Explorer atau Finder di macOS), dan pindahkan file Anda langsung ke folder brankas Obsidian.

## Mengimpor file Markdown dengan Importer

Gunakan [[Impor|plugin Importer]] resmi ketika Anda ingin memilih folder dalam impor, mengimpor arsip `.zip`, menstandardisasi pemformatan, memindahkan tag sebaris ke [[Properti|properti]], atau menerapkan templat.

1. Buka **[[Pengaturan|Pengaturan]] → Plugin komunitas** dan [instal Importer](obsidian://show-plugin?id=obsidian-importer).
2. Aktifkan plugin Importer.
3. Buka **Importer** menggunakan [[Palet perintah|Palet perintah]] atau ikon bilah alat.
4. Di bagian **File format**, pilih **Markdown (.md, .zip)**.
5. Pilih file Markdown individual, folder, atau arsip zip.
6. Tinjau folder yang terdeteksi, opsi output, templat yang dihasilkan, dan contoh pratinjau.
7. Pilih **Import** dan tunggu hingga impor selesai.

Lihat [[Template Importer]] untuk menyesuaikan nama catatan, properti, dan konten yang diimpor.
