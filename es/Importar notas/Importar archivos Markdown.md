Obsidian utiliza archivos Markdown `.md` como formato principal para las notas. Esto facilita la importación de archivos Markdown a Obsidian. Muchas aplicaciones pueden editar archivos Markdown o exportar a este formato.

Hay varias formas de añadir archivos Markdown a tu bóveda de Obsidian:

1. Arrastra y suelta archivos o carpetas en la ventana del [[Explorador de archivos]]
2. Usa el explorador de archivos de tu sistema (por ejemplo, el Explorador de Windows o Finder en macOS), y mueve tus archivos directamente a la carpeta de la bóveda de Obsidian.

## Importar archivos Markdown con Importer

Usa el [[Importador|complemento Importer]] oficial cuando quieras seleccionar carpetas dentro de una importación, importar un archivo `.zip`, estandarizar el formato, mover etiquetas en línea a [[Propiedades|propiedades]], o aplicar una plantilla.

1. Abre **[[Configuración|Ajustes]] → Complementos comunitarios** e [instala Importer](obsidian://show-plugin?id=obsidian-importer).
2. Habilita el complemento Importer.
3. Abre **Importer** usando la [[Paleta de comandos|paleta de comandos]] o el icono de la barra de herramientas.
4. En **Formato de archivo**, selecciona **Markdown (.md, .zip)**.
5. Elige archivos Markdown individuales, carpetas o archivos zip.
6. Revisa las carpetas detectadas, las opciones de salida, la plantilla generada y los ejemplos de vista previa.
7. Selecciona **Importar** y espera a que la importación termine.

Consulta [[Plantillas del importador|Plantillas de Importer]] para personalizar el nombre de la nota importada, las propiedades y el contenido.
